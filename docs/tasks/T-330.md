# T-330 — Preset: `apple-tv-lt` (lowerThird, Cluster A)

**Branch**: `task/T-330-apple-tv-lt`

## Goal

Promote the existing `apple-tv-lt` preset stub from `status: stub` to `status: substantive` and ship it as the **fourth Cluster A (news / lower-third) preset to land** AND the **fourth consumer of the `lowerThird` clipKind** in the parity-CLI resolver. Apple TV+ ships the most restrained register in the cluster: text-only, no flag, no card chrome, Inter Light typography on a near-black canvas, anchored bottom-left with generous whitespace (130–150 px from left, 90–100 px from bottom). Common uses: premium / enterprise pitch decks where the content should feel "ratified by Apple."

T-330 is the **fourth** preset to bind the `lowerThird` clipKind. T-323 (`cnn-classic`, merged) holds the **clipKind-default** slot in `DEFAULT_CLIP_KIND_RESOLVER` (`lowerThird → cnnClassicBinding`). T-325 (`bbc-reith-dark`, merged) wired the **first** `PRESET_ID_BINDINGS` override for `lowerThird`. T-326 (`al-jazeera-orange`, merged) wired the **second**. T-330 adds the **third** `lowerThird`-keyed `PRESET_ID_BINDINGS` override keyed on `'apple-tv-lt'` — Pattern C from `docs/handover-phase13-mid.md` §2 (third-or-later-preset-for-clipKind via override map). Mirrors T-326's bind shape exactly, swapping snapshot constants.

T-330 is **also the first production consumer of the just-shipped T-183z primitive enhancement** (`noFlag` / `subtitleColor` / `font` props on `LowerThird`). The Apple TV+ register is text-only — there is NO flag and NO card; the talent line color is independent of the (irrelevant) accent; the type family is Inter (the OFL fallback for Apple's proprietary SF Pro). All three new props are exercised by `apple-tv-lt`'s binding, validating T-183z end-to-end in production.

T-330 is **S-sized** — slightly tighter than T-323 / T-325 / T-326 (which were M) because the cluster pattern is now triply-established (Pattern C precedent set by T-325, replicated by T-326) AND the F-4 generator-flags shipped (`--psnr=42 --ssim=0.98`) eliminate the manual `thresholds.json` hand-pin step. ~25–30 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. No primitive carve-out (T-183z already shipped). No schema change.

## Architectural decisions

### D-T330-1. Compass register match — Apple TV+ minimalist text-only register (no flag, no card chrome)

The stub (lines 22–43) defines the canonical Apple TV+ minimalist register:

- **No background elements** (line 23 "Text-only; no background elements"). The primitive renders a card; the v1 trade-off is to set `background` to the canvas color (near-black `#000000`) so the card visually disappears against a dark canvas. The thin boxShadow that the primitive hard-codes will still be visible at edges — documented as a primitive-level cosmetic divergence (D-T330-12-a; `T-183z`-family follow-up).
- **No flag / accent strip** (the Apple TV+ register has zero colored chrome). T-183z added a `noFlag: boolean` prop precisely for this case. **`noFlag: true` per D-T330-3** — the 6 px-wide accent strip is suppressed entirely.
- **Optional very subtle drop shadow** `0, 1 px, 2 px blur, 20% opacity black` (line 24). The primitive's hard-coded `boxShadow` is heavier (`'0 8px 24px rgba(0,0,0,0.24)'`); cosmetic divergence — Out-of-scope.
- **Position bottom-left, generous padding** 130–150 px from left, 90–100 px from bottom @ 1080p (line 26). v1 picks the middle of each range: `insetLeftPx: 140`, `insetBottomPx: 95`.
- **Typography**: name SF Pro fallback, Light / Medium, 26–30 pt, Mixed Case (line 30); title Thin / Light, UPPERCASE, 18–20 pt (line 31). v1 picks `font: { family: 'Inter', weight: 300 }` (Inter Light is OFL via Google Fonts; weight 300 matches Apple's Light register), Mixed Case for both per D-T330-5 / D-T330-7. The primitive renders name at fontSize 34 (slightly above the stub's 26–30 pt; cosmetic — primitive default) and title at 18 (in range).
- **Rules** (lines 41–43): "Most restrained preset in the cluster. If a dark-background compose needs more, escalate; don't add one." — T-330 honors restraint; pass minimum chrome.

T-330 binds these to the existing `LowerThird` primitive's render contract (T-183 + T-183z). The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| No flag / accent strip (text-only) | `noFlag` (T-183z) | `true` |
| No background card (visually) | `background` | `'#000000'` (canvas-matching black; card disappears against dark canvas) |
| Headline Mixed Case, white | `name` (rendered in `textColor`) | `'Sofia Coppola'` (Mixed Case, real Apple TV+ collaborator — director of "On the Rocks" Apple Original) |
| Subtitle Mixed Case, white per Apple's clean register (D-T330-4) | `title` + `subtitleColor` (T-183z) | `'Director'` + `subtitleColor: '#FFFFFF'` |
| Headline color white | `textColor` | `'#FFFFFF'` |
| `accent` (irrelevant — `noFlag: true` suppresses it) | `accent` | `'#FFFFFF'` (default-safe; not rendered because of `noFlag`) |
| Position 140 px from left, 95 px from bottom | `insetLeftPx`, `insetBottomPx` | `140`, `95` |
| Inter Light Latin family at the prop axis | `font` (T-183z) | `{ family: 'Inter', weight: 300 }` |

The preset register is **white text on a dark canvas with NO chrome**. A meaningful departure from T-323's CNN white-card-with-black-text, T-325's BBC dark-card-with-white-text, T-326's al-jazeera light-bar-with-orange-strip. Apple TV+'s register is the most restrained in the cluster and benefits directly from the just-shipped T-183z props.

### D-T330-3. `noFlag: true` per T-183z — Apple TV+ has no flag (first production consumer)

The `LowerThird` primitive's default render includes a 6 px-wide accent strip on the left edge, fill = `accent`. Apple TV+'s minimalist register has **zero colored chrome** (stub line 23 "Text-only; no background elements"). T-183z added a `noFlag: boolean` prop that, when `true`, suppresses the accent strip entirely (lines 134–139 of `lower-third.tsx` render `null` for the strip when `noFlag === true`).

**Decision**: pass `noFlag: true` in `APPLE_TV_LT_PROPS`. This is the **first production consumer of T-183z's `noFlag` prop**. Without it, T-330 would inherit the inappropriate 6 px accent strip in the wrong register entirely — contradicting Apple TV+'s "most restrained preset in the cluster" rule (stub line 41).

The `accent` prop is still passed (`'#FFFFFF'`) for type-safety; its value is irrelevant because `noFlag === true` suppresses the rendering. Documented in the snapshot constant comment.

This dissolves what would have been D-T330-12-a in a pre-T-183z world (T-323 / T-325 / T-326 had no `noFlag` and accepted the inappropriate strip as a divergence).

### D-T330-4. `subtitleColor: '#FFFFFF'` per T-183z — talent-line decoupled from `accent`

Pre-T-183z, the `LowerThird` primitive hard-coded `color: accent` on the title (subtitle) line. T-323 / T-325 / T-326 each documented this as a cosmetic divergence (`D-Txxx-12-a`). T-183z added a `subtitleColor` prop that, when present, overrides the title-line color independently of `accent` (lines 91 of `lower-third.tsx`: `const titleColor = subtitleColor ?? accent`).

Apple TV+'s register paints both name and title in **white** (the stub does not specify a subtitle color; per Apple's clean register convention the talent-line shares the name color — both neutral white on a dark canvas).
