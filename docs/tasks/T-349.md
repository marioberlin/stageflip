## Goal

Promote the existing `got-trajan-clockwork` preset stub from `status: stub` to `status: substantive` and ship it as the **sixth + final Cluster D (titles / opens / bumpers / credits) consumer preset** of the T-321 atmospheric-primitive carve-out roadmap, the **fifth multi-clip composition** in the parity-CLI (after T-348 `stranger-things-benguiat` introduced `ClipKindBinding.overlays?` and T-351 / T-352 / T-353 reused that surface), AND a **secondary consumer of `mode: 'sepia'`** (T-352 was the first end-to-end consumer of the SEPIA_MATRIX; T-349 is the second — confirms the mode is stable). T-349 ships the prestige-TV Game of Thrones S1+ canon "Trajan / clockwork" register: the **3D CG concave-world-map mechanical-clockwork register** (stub line 23) deferred to T-349-live-3d, capturing the **canonical static hero-frame visual register** in v1 — metallic gold/brown palette per stub line 24 (Clinker `#331C0E` / Electric Brown `#B9540C` / Baby Yellow `#FFF190`), Trajan-Pro-fallback ALL CAPS Roman inscription typography (EB Garamond 700 OFL fallback per stub line 12; preserves the signature serif details — long ascenders, sharp serifs — per stub line 35), `mode: 'sepia'` photographic-overlay at intensity ~0.65 (the warm-yellow SEPIA_MATRIX is the closest sealed-enum match for the metallic gold/brown palette), and grain at intensity ~0.15 (canonical default — medieval-paper / engraved-page texture; the Roman inscription register reads as ancient-document-grade, NOT VHS-tape-chatter).

T-349 is the **sixth + final Cluster D consumer** of the T-321 carve-out roadmap. Three primitives ship in this composition (mirroring T-353's 3-clip stack but with `mode: 'sepia'` instead of `mode: 'cinematic-lut'` and canonical-default grain instead of T-352's elevated 0.30):

## Why v1 ships static-fallback-only (NO live 3D ThreeSceneClip integration)

The Game of Thrones title-sequence's most distinctive technical features are the **live 3D CG world map + clockwork-driven mechanical building animations + heliocentric armillary sphere with relief + radiating sun rays + 90-second camera swoop with per-episode location variation + sigil-flip mechanics** (stub lines 23–34, 38–48). Implementing any of these requires the `ThreeSceneClip` primitive (ADR-005, frontier-tier) to be productionized, AND requires extending the `titleSequencePropsSchema` with a 3D-scene-binding shot kind, AND requires a 3D scene asset library (clockwork mechanism rigs, building unfold animations, world-map geometry, heliocentric armillary sphere with historical-event relief, sun-ray particle systems).

**Per `docs/tasks/T-321-carveout-audit.md` carve-out #5** — ThreeSceneClip integration into T-321 is documented as **deferred to consumer-preset tasks** (specifically T-349 and T-353). The audit identifies three integration paths:

1. **Ship T-349 with full ThreeSceneClip integration** — modifies `title-sequence.tsx`, integrates frontier-tier `ThreeSceneClip`, builds 3D scene asset library. **L+ scope; bleeds into multiple primitive-side modifications + frontier-tier promotion + asset library construction.**
2. **Ship T-349 with static-fallback-only register** — no live 3D rendering; renders as Trajan title plate + sepia/grain metallic-tone register over a placeholder background. **Simpler L scope; defers live 3D to T-349-live-3d follow-up. Stub line 41 EXPLICITLY ALLOWS THIS POSTURE: "static fallback is a single hero frame".**
3. **Defer T-349 entirely** — wait for ThreeSceneClip productionization + T-321 ThreeSceneClip extension before consumer ships.

**T-349 picks option (2)**, documented as D-T349-1. **The stub canon line 41 explicitly designates "static fallback is a single hero frame" as the canonical fallback posture** — making T-349's static-fallback-only register a STUB-CANON-ALLOWED v1 ship rather than an architectural divergence. This mirrors T-353's option-2 deferral (Severance also chose the static hero-frame register; T-353's stub also explicitly allowed static-fallback). T-349 is the second Cluster D preset to invoke the static-fallback option, and the precedent set by T-353 carries forward — ship-static-defer-live is the established architectural pattern for Cluster D presets needing live 3D.

The visual register that ships in v1 is "Trajan title plate over a placeholder metallic-brown background with canonical-default grain + dominant sepia tonal grading" — captures the canonical Trajan / metallic mood WITHOUT the canonical 3D animation kinetics. **Reviewer should NOT demand actual ThreeSceneClip live 3D rendering in this PR per stub line 41 + D-T349-1.**
