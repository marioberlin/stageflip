# T-325 — Preset: `bbc-reith-dark` (lowerThird, Cluster A)

**Branch**: `task/T-325-bbc-reith-dark`

## Goal

Promote the existing `bbc-reith-dark` preset stub from `status: stub` to `status: substantive` and ship it as the **second Cluster A (news / lower-third) preset to land** AND the **second consumer of the `lowerThird` clipKind** in the parity-CLI resolver. The preset captures BBC's Reith-era dark lower-third register: a dark `#1A1A1A` bar + a BBC Red `#BB1919` accent strip on the left edge + a Mixed-Case headline + a Mixed-Case subtitle, anchored bottom-left on a 1280×720 canvas. Common uses: humanist / authoritative / public-broadcaster register; presenter-and-role identification, contributor identification, on-screen attribution where the BBC's serif-and-sans pairing is the brand signal.

T-325 is the **second** preset to bind the `lowerThird` clipKind. T-323 (`cnn-classic`, just merged) holds the **clipKind-default** slot in `DEFAULT_CLIP_KIND_RESOLVER` (`lowerThird → cnnClassicBinding`); T-325 must therefore wire its binding via the **`PRESET_ID_BINDINGS` override map** keyed on `'bbc-reith-dark'` — Pattern C from `docs/handover-phase13-mid.md` §2 (second-preset-for-clipKind). Mirrors T-363 / T-364 / T-365 / T-366's caption-family override pattern for the `caption` clipKind. The `LowerThird` primitive (T-183) is unchanged; T-325 consumes it read-only.

T-325 is **M-sized** — same envelope as T-323, T-364, T-365. ~25–35 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. No primitive carve-out; no schema change. Inherits T-323's resolver shape end-to-end (`(clipKind, presetId)` lookup; presetId-override path takes precedence over the clipKind-default arm).

## Architectural decisions

### D-T325-1. Compass register match — dark `#1A1A1A` bar + BBC Red `#BB1919` accent strip + Mixed-Case headline + Mixed-Case subtitle

The stub (lines 22–47) defines the canonical BBC Reith-dark register:

- **Bar**: `#1A1A1A` fill at 85 % opacity (per D-T325-4 the parity golden renders at 100 % opacity; the 85 % spec is a production tunable), width ≈ 60–70 % of frame, ≈ 900 × 80 px @ 1080p, positioned 40–60 px from bottom (lines 23, 26).
- **Accent strip**: `#BB1919` (BBC Red) on the **left edge** (line 24); the primitive renders this as a 6 px-wide left-side flex child with `borderRadius: 3`.
- **Typography**: Headline (`name`) Mixed Case Medium 26–32 pt `#FFFFFF`; subtitle (`title`) Mixed Case Regular 18–22 pt `#FFFFFF` (lines 30–31). The primitive renders `name` at fontSize 34 / weight 700 in `textColor` (close to the stub's 26–32 pt range); `title` at fontSize 18 / weight 500 in `accent` (the red trade-off, D-T325-12-a). Both are Mixed Case (the snapshot strings are passed as-is — no programmatic case transform).
- **Rules**: "Use when a humanist, authoritative, public-broadcaster register is called for. The serif/sans pairing is the signature — do not substitute a single-family compose." (lines 41–42).

T-325 binds these to the existing `LowerThird` primitive's render contract (T-183). The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| Dark `#1A1A1A` bar background | `background` | `'#1A1A1A'` |
| BBC Red left accent strip (6 px-wide left bar) | `accent` | `'#BB1919'` |
| Headline Mixed Case, 26–32 pt, #FFFFFF | `name` (rendered at 34 px / fontWeight 700 in `textColor`) | `'Sarah Smith'` (Mixed Case string) |
| Subtitle Mixed Case, 18–22 pt | `title` (rendered at 18 px / fontWeight 500 in `accent`) | `'Chief Political Correspondent'` |
| Position 40–60 px from bottom, far left | `insetLeftPx`, `insetBottomPx` | `64`, `48` |
| Headline color #FFFFFF | `textColor` | `'#FFFFFF'` |

The primitive's render of the `title` line uses `color: accent` (red) — see D-T325-12-a for the trade-off.

### D-T325-3. v1 scope — steady-state bar + strip + headline + subtitle; multi-stage entrance / ticker / fade-down exit deferred to T-325a/b/c carve-outs IF Reviewer scrutiny demands

The stub describes a fully-instrumented BBC Reith-dark register: dark bar + red strip + headline + subtitle + multi-stage entrance choreography (red strip 150 ms → bar wipe L→R 400 ms → text slide 200 ms) + ticker / flipper companion + fade-down exit. The `LowerThird` primitive (T-183) supports only the **first four**: bar (`background`), strip (`accent`), headline (`name`), subtitle (`title`). The remaining three (multi-stage entrance, ticker, fade-down exit) are decorative additions — none of them are part of the primitive's prop surface, and adding them is a primitive-level concern (not a preset-level one).

**Decision**: T-325 v1 ships the **steady-state register** — dark bar + BBC Red left strip + Mixed-Case headline + Mixed-Case subtitle. The signed parity golden captures the steady-state mid-hold frame. The multi-stage entrance, ticker companion, and fade-down exit are **deferred** to follow-up tasks ONLY IF Reviewer scrutiny demands them:

- **`T-325a`** — multi-stage entrance choreography (red strip first / bar wipe / text slide; primitive-level entrance enum + sub-element timing).
- **`T-325b`** — ticker / flipper companion (separate `newsTicker`-clipKind preset; a sister `bbc-reith-dark-ticker` Cluster A preset, not a T-325 follow-up).
- **`T-325c`** — fade-down exit (primitive-level exit enum addition).

**Rationale**: The canonical BBC Reith-dark identity in a single steady-state frame **is** the dark bar + BBC Red strip + Mixed-Case serif/sans-intent typography. The multi-stage entrance, ticker, and fade-down exit are decorative additions present in some but not all BBC broadcast frames; a parity golden of the **steady-state lower-third** captures the brand register without overshooting the M-sized envelope. Mirrors T-323 D-T323-3's posture exactly.

If a Reviewer demands multi-stage entrance / ticker / fade-down inline → escalate per CLAUDE.md §6; that is the carve-out path, not a T-325 expansion.

### D-T325-5. Casing — `'as-is'` for both headline and subtitle (Mixed Case)

The primitive does NOT have a `casing` prop. Casing is applied at the snapshot string level. Both `name` and `title` are passed as Mixed Case strings: `'Sarah Smith'` and `'Chief Political Correspondent'` per stub lines 30–31. **This differs from T-323**, where the headline is UPPERCASE (`'BREAKING: SUPREME COURT RULES'`) per CNN's UPPERCASE-headline canon.
