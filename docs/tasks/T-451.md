# T-451 — ADR-010: Live Audience Clip Family

**Branch**: `task/T-451-adr-010-live-audience`

## Goal

Ship the second Phase 15 α ADR — the clip-family contract that consumes ADR-009's backend lifecycle. Together with ADR-009 (T-450, merged 2026-05-11 via PR #512 / v1.28), this clears the Phase 15 α hard gate; T-452+ can dispatch.

ADR-010 defines:

1. The **nine v1 audience clip families** (§D1) — six standard (LivePoll multi-choice / open-text / rating; LiveQA; LiveQuiz; Leaderboard; WordCloud; Survey) plus three motion-native differentiators (Heatmap; ReactionStream; AudienceAiPrompt). Spans the eleven `AudienceClipKind` discriminants from ADR-009 §D2.
2. The **per-clip-kind `VotePayload.value` shapes** (§D2) — discriminated voter-side payloads.
3. The **per-clip-kind `AggregationSnapshot.aggregation` shapes** (§D3) — discriminated presenter-side aggregations.
4. The **per-clip-kind snapshot-size hygiene** (§D3a) — bounds on each `snapshots/{frameNo}` Firestore document.
5. The **`staticFallback` snapshot semantics** (§D4) — when/how snapshot is taken; what bytes/JSON it carries; how renderer materializes a frame; three snapshot-selection policies (`final` / `peak` / `at-frame`); inheritance from ADR-005 §D2 two-path contract.
6. The **full `AudienceProvenance` schema** (§D5) — extends ADR-009 §D9 preview with `snapshotPolicy` + `clipKind` + inlined `aggregation: AggregationValue` payload. Mirrors `MediaProvenance` posture (ADR-008 §D2): inlined bytes for export durability.
7. The **`permissions: ['audience-network']` requirement** (§D6) on every audience clip per ADR-005 §D2; T-455 CI gate enforces.
8. The **motion-native dependency footprint** (§D7) — ReactionStreamClip → T-383 (ShaderClip, P13 γ); AudienceAiPromptClip → T-430 (Seedance video) + T-432 (ACE-Step music), both P14 β.
9. The **static-fallback vs. live-mount routing posture** (§D8) — three-state model (live / static-fallback / empty live-mount).
10. The **tenant frontier-enablement gating** (§D9) — `TenantSettings.features.audience` extends T-411a with two-flag enablement (`enabled` + `motionNativeEnabled`).
11. The **Cluster I preset cluster** (§D10) — ~6 audience presets (T-486).
12. The **determinism posture** (§D11) — inherited from ADR-009 §D10; staticFallback deterministic-by-construction.
13. The **loss-flag inventory** (§D12) — inherited from ADR-009 §D11; no new flags.
14. The **plugin manifest extensions** (§D13) — inherited; third-party-plugin clip-family contribution out-of-scope for v1.

This is **the** Phase 15 α hard gate, second of two. After ADR-009 (T-450, merged) and ADR-010 (this PR), all of T-452+ can dispatch.

**Spec / ADR only — no code, no packages, no scripts, no CI.**
