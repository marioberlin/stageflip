## Architectural decisions

### D-T373-1. Compass register match — cross-platform social-handle "passport" register

The stub (lines 22–50) defines the canonical social-handle lower-third register:

- **Horizontal bar, 30–60% of screen width** (line 23). The `LowerThird` primitive renders a card sized to its content (no width prop), so v1 inherits the natural width of the handle text.
- **Position lower 15–20% of frame** (line 24). At a 1280×720 canvas, that maps to roughly y∈[576, 612] (75–85% from top). The primitive uses **bottom-anchored** insets — `insetBottomPx` measured from the bottom edge — so the equivalent is `insetBottomPx ∈ [108, 144]`. v1 picks `insetBottomPx: 96` (the primitive default; nominally 13.3% from the bottom — slightly above the stub's 15–20% range but within visual-register tolerance for the cross-platform handoff style; the steady-state parity golden at frame 60 documents the result).
- **Background black `#000000` @ 60–80% opacity** (line 25). The `LowerThird` primitive's `background` prop is a single opaque hex string — there is **no `backgroundOpacity` axis**. v1 picks `background: '#000000'` (opaque black) and accepts the divergence from the 60–80% translucent register; the lower-third sits over a flat-color test canvas in parity rendering, so the practical visual result is identical (translucent over flat-canvas == opaque over flat-canvas). Document as a primitive-level cosmetic divergence (D-T373-12-a; `T-183z`-family follow-up if a future preset demands `backgroundOpacity`).
- **Text white `#FFFFFF` or brand-colored** (line 26). v1 picks white per the canonical "cross-platform passport" style — brand-colored handles are **per-platform**, but the social-handle register is **cross-platform**, so a neutral white reads as "all platforms" rather than any one.
- **Platform icons in OFFICIAL brand colors** (lines 27–32). Out-of-scope per the table above; the primitive has no icon-row prop.
- **Typography Roboto / Montserrat / Proxima Nova fallback (Inter), Bold (700), 18–24 pt** (lines 35–37). v1 picks `font: { family: 'Inter', weight: 700 }` — Inter Bold is the OFL fallback declared in stub frontmatter; weight 700 matches the stub's "Bold (700)" register at the primitive's uniform-weight axis. Inter Bold approximates Roboto Bold / Montserrat Bold at the same x-height for a cross-platform-handle headline.
- **Animation: slide-in 300–500 ms ease-out, hold 4–8 s, exit reverse slide** (lines 39–43). Primitive's slide-in over `ceil(fps * 0.45) ≈ 14` frames at fps=30 = ~467 ms — comfortably inside the stub's 300–500 ms range. Curve is `EASE_OUT_QUART` (asymmetric); the stub specifies generic ease-out; close enough. Steady-state mid-hold golden at frame 60 sidesteps the entry curve entirely.
- **Rules** (lines 45–50): Brief exposure + repetition (4–8 s) — the parity fixture's `durationInFrames: 150` (~5 s at fps=30) sits in the middle of that range. Lower 15–20% — see above. Platform-icon official-color rule — N/A (no icons rendered v1).

T-373 binds these to the existing `LowerThird` primitive's render contract. The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| No flag (cross-platform handle has no per-platform accent) | `noFlag` (T-183z) | `true` |
| Translucent dark bar (approximated by opaque black on flat canvas — D-T373-12-a) | `background` | `'#000000'` |
| Cross-platform handle headline, Mixed Case, white | `name` (rendered in `textColor`) | `'@yourbrand'` |
| Subtitle, white, Mixed Case | `title` + `subtitleColor` (T-183z) | `'Follow us everywhere'` + `subtitleColor: '#FFFFFF'` |
| Headline color white | `textColor` | `'#FFFFFF'` |
| `accent` (irrelevant — `noFlag: true` suppresses it) | `accent` | `'#FFFFFF'` (default-safe; not rendered) |
| Position lower 15–20% (approximated; D-T373-1 narrative) | `insetLeftPx`, `insetBottomPx` | `96`, `96` (primitive defaults) |
| Inter Bold Latin family at the prop axis | `font` (T-183z) | `{ family: 'Inter', weight: 700 }` |

The preset register is **white text on a flat-black bar with NO chrome and NO icons** — a meaningful departure from T-330's Apple TV+ (which also used `noFlag: true` + white-on-black but with Inter Light weight 300) and from T-329's Netflix (DM Sans Medium with ALL-CAPS subtitle). T-373's register is the **bold** cross-platform handle: Inter Bold weight 700, both lines Mixed Case, identifier `@yourbrand` line.

### D-T373-3. `noFlag: true` per T-183z — fifth production consumer

The cross-platform social-handle register has **no per-platform accent**: an Instagram-gradient strip would imply the handle is Instagram-only; a YouTube-red strip would imply YouTube-only. The canonical register is **neutral** (the icons themselves carry per-platform brand color, but the bar / strip do not). Pass `noFlag: true` to suppress the primitive's 6 px-wide accent strip entirely.

T-373 is the **fifth production consumer of T-183z's `noFlag` prop** (after T-330 first, T-329 second, plus implicit usage by other lowerThird presets). The pattern is now mature; no surprises.

### D-T373-4. `subtitleColor: '#FFFFFF'` per T-183z — subtitle decoupled from `accent`

The cross-platform social-handle register paints the subtitle (`'Follow us everywhere'`) in the **same white** as the headline. With `noFlag: true` + `subtitleColor: '#FFFFFF'`, the subtitle renders white-on-black matching the headline color exactly.

Without `subtitleColor`, the primitive falls back to `accent` (`'#FFFFFF'` here — by coincidence matching, since accent is also white). Pinning `subtitleColor` makes the contract explicit and protects against future binding-shape changes that tweak `accent`.

### D-T373-5. `font: { family: 'Inter', weight: 700 }` per T-183z — Inter Bold = compound-preferred fallback

The stub's `preferredFont` is a **compound** declaration: `'Roboto / Montserrat / Proxima Nova'` with `'apache-2.0 / ofl / commercial-byo'` licenses. The compound shape signals "any of these three is acceptable depending on the deploying brand's existing font corpus." All three are Bold-weight sans-serifs; the OFL fallback is `Inter` weight 700.

v1 picks `font: { family: 'Inter', weight: 700 }`. Inter Bold approximates Roboto Bold (the YouTube / Google platform default) and Montserrat Bold at the same x-height and weight curve; Proxima Nova is commercial-byo and licensable separately by deploying brands.

The primitive applies weight 700 uniformly to both name (`@yourbrand`) and title (`Follow us everywhere`). This **departs from T-329 / T-330** (which used Light / Medium weights matching Apple / Netflix's restrained registers); the social-handle register is **bold** by canon — the handle line is meant to be **immediately readable** during the 4–8 s exposure window.
