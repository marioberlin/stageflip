# T-463 — `LivePollRatingClip`

**Branch**: `task/T-463-live-poll-rating-clip`

## Goal

Ship the **rating (Likert) variant** of LivePoll. Mirrors T-461 + T-462
template; per-kind shapes:

- Vote: `{ kind: 'live-poll-rating', score: number }` (1..`clip.scaleMax`).
- Aggregation: `{ scoreCounts: readonly number[] (length === scaleMax),
  totalVotes: number, mean: number (NaN if totalVotes === 0) }`.
- Rendering: histogram with one bar per score (1 to scaleMax); a
  prominent "Mean: X.X" label above; total label "N votes" below. The
  bar at the rounded mean gets a highlight ring.
- Voter UI: `scaleMax` rating buttons (typically 5; configurable).
  Tapping a button submits + disables.

The §13 verification is option-1 again — `render-e2e.test.ts` drives
the static-fallback with a known histogram + asserts on observable
DOM ordering, mean rendering, and pixel-bucket non-blankness.

## Implementation notes

- **Schema**: `props: { question: z.string().min(1), scaleMin:
  z.literal(1), scaleMax: z.number().int().min(2).max(10), labels:
  z.array(z.string()).optional(), sessionId: z.string().optional() }`.
  `permissions: z.tuple([z.literal('audience-network')])`.
  - `scaleMin` is fixed at 1 per ADR-010 §D2 (the vote `score` is
    `1..scaleMax`); reify as a literal in the schema for type-system
    clarity.
  - `labels` (optional) lets presenters annotate ends of the scale
    (e.g., `["Strongly disagree", "Strongly agree"]` for a 5-point
    Likert) — the renderer surfaces them under the leftmost + rightmost
    bars when present.
- **Static-fallback rendering**: bar chart, one bar per score 1..scaleMax;
  bar height = `scoreCounts[score - 1] / max(scoreCounts) * containerHeight`
  (normalize to the modal bin, not totalVotes — gives a more readable
  histogram). Mean label: `"Mean: ${mean.toFixed(1)}"` if totalVotes >
  0, else `"Mean: —"`. Total label: `"${totalVotes} votes"`. Pure
  function.
- **Highlighted mean bar**: round `mean` to nearest integer; the bar at
  that score gets a `highlight` class / accent color. If totalVotes ===
  0 (mean === NaN), no highlight.
- **Voter input UI**: `scaleMax` clickable rating buttons in a row,
  numbered 1..scaleMax. Optional left/right labels under the row.
  Submit disables all buttons + shows "Vote submitted".
- **Mirror T-461 / T-462 exactly**: layout, tests, dispatcher entry.
- **Determinism perimeter**: same as T-461 / T-462 — static-fallback
  pure; factory's `runAudienceClient` is the only non-deterministic
  surface (already isolated in T-454).
- **Pre-empt skills-sync drift**: run `pnpm skills-sync`.
- **Biome format** every touched file.
- **NEVER `git add -A`**.
