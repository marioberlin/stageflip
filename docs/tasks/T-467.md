# T-467 — `WordCloudClip`

**Branch**: `task/T-467-word-cloud-clip`

## Goal

Ship the **WordCloudClip** family. Voters submit one or more words;
the aggregation tracks per-word frequency; the renderer lays out the
words at sizes proportional to their weight in a cloud layout.

Per-kind shapes (already in `@stageflip/audience-contract`):

- Vote: `{ kind: 'word-cloud', words: readonly string[] }` (length ≤
  `clip.maxWordsPerVoter`, default 3; per-word length ≤ 32).
- Aggregation: `{ words: readonly { word: string, weight: number }[]
  (length ≤ topN, default 100), totalSubmissions: number }`.
- Rendering: a wrapped flex container with each word as a span. Font
  size scales with weight: `fontSize = 14 + (weight / maxWeight) * 36`
  (range 14px..50px). Words sorted by weight desc; layout is a simple
  flex-wrap (NOT a true word-cloud — true clouds are non-deterministic
  + need physics packing; the simple flex layout is deterministic).
- Voter UI: text input + submit button; supports multi-word
  comma-separated submission up to `maxWordsPerVoter`.

§13 verification is option-1 — `render-e2e.test.ts` drives the
static-fallback with a known word-frequency snapshot + asserts on
observable DOM ordering, font-size proportionality, and pixel-bucket
non-blankness.

## Implementation notes

- **Schema**: `props: { prompt: z.string().min(1), maxWords:
  z.number().int().positive().max(500).default(100), maxWordsPerVoter:
  z.number().int().positive().max(20).default(3), sessionId:
  z.string().optional() }`. `permissions` tuple as before.
- **Static-fallback rendering**: flex-wrap container; for each word
  (sorted by weight desc): `<span style={{ fontSize: \`${14 + (weight
  / maxWeight) * 36}px\` }}>{word}</span>`. NORMALIZE to the max
  weight (not totalSubmissions). Total label reads "${totalSubmissions}
  submissions". Pure. NO Date.now, NO Math.random.
- **Voter input UI**: `<textarea placeholder="Enter up to N words,
  comma-separated">` + submit button. Parse on submit: `text.split(',')
  .map(s => s.trim()).filter(Boolean).slice(0, maxWordsPerVoter)`.
  Emit `{ kind: 'word-cloud', words: [...] }`. Disable after submit.
- **Mirror T-466 exactly** for layout / tests / dispatcher registration.
- **Determinism perimeter**: same as prior — static-fallback pure.
- **Pre-empt skills-sync drift**.

- **NEVER `git add -A`**.
