# T-339a — Preset: `espn-bottomline-flipper` (newsTicker, Cluster B)

**Branch**: `task/T-339a-espn-bottomline-flipper`

## Goal

Promote the existing `espn-bottomline-flipper` preset stub from `status: stub` to `status: substantive` and ship it as the **fourth Cluster B (sports / scoreBug + newsTicker) preset to land** AND the **second consumer of the `newsTicker` clipKind** in the parity-CLI resolver AND the **first production consumer of T-356b's `mode: 'flip'` register** on the `news-ticker-bar` primitive. Where T-356's `bloomberg-ticker` (`newsTicker` clipKind-default) consumes the continuous-marquee `mode: 'scroll'` register, T-339a binds the same primitive in the post-2018 ESPN BottomLine two-row stacked flipper register: `mode: 'flip'` + `flipDurationMs: 4500` (mid-canon "4–5 s per segment" cadence) + a sports-style six-entry NBA team-vs-team score mix exercising up / down / flat chip directions across one steady-state pair window. Common uses: live NFL/NBA/MLB match overlays where the bottom-of-frame full-width persistent two-row flipper register is the brand signal — sister-but-distinct from T-356's continuous Bloomberg-canonical equities/crypto crawl.

T-339a is the **second** preset to bind the `newsTicker` clipKind. T-356 (`bloomberg-ticker`) holds the **clipKind-default** slot via `newsTickerBinding` (`scroll` mode + Bloomberg canonical snapshot). T-339a wires its binding via a **new `PRESET_ID_BINDINGS` override** keyed on `'espn-bottomline-flipper'` — Pattern C from `docs/handover-phase13-mid.md` §2 (n-th-preset-for-clipKind via `PRESET_ID_BINDINGS`). T-356's `newsTicker` clipKind-default arm is **NOT** touched: `('newsTicker')` and `('newsTicker', 'bloomberg-ticker')` STILL return `newsTickerBinding`. T-339a adds exactly one `PRESET_ID_BINDINGS` entry + one `ESPN_BOTTOMLINE_PROPS` constant + one `espnBottomlineBinding` binding.

T-339a is the **first production consumer of T-356b's `mode: 'flip'`** feature on the `news-ticker-bar` primitive. T-356b shipped the `mode: z.enum(['scroll', 'flip']).optional()` + `flipDurationMs: z.number().positive().optional()` schema extension AND the two-row stacked render path (`news-ticker-bar-flip-top` + `news-ticker-bar-flip-bottom` testids) at commit 4766460; T-356's bloomberg-ticker is `mode: 'scroll'` (default — pre-T-356b behavior preserved). T-339a's parity golden validates the two-row stacked register at steady-state mid-segment.

T-339a is **M-sized** — same envelope as T-333 / T-334 / T-335. ~30–45 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. Inherits T-356's resolver shape (the `newsTickerBinding` signature is the canonical reference; T-339a's `espnBottomlineBinding` mirrors it with sports payload + flip-mode props). No primitive carve-out; no schema change.

## Architectural decisions

### D-T339a-1. Compass register match — ESPN BottomLine bottom-of-frame full-width persistent two-row flipper / dark `#1A1A1A` base / ESPN Red `#CC0000` for down arrows / Yellow `#FFD700` for up arrows / sports score chip mix / Roboto Condensed + Inter OFL+Apache-2.0 fallback

The stub (lines 22–45) defines the canonical post-2018 ESPN BottomLine register:

- **Position**: full-width band at absolute bottom of frame (line 23). T-339a binds `bandPosition: 'bottom'` — the primitive renders `position: absolute; left: 0; width: 100%; bottom: 0` for `bandPosition: 'bottom'`. No explicit `position` prop is needed (mirrors T-356's bloomberg-ticker shape).
- **Persistent (line 47)**: T-339a inherits the steady-state-only posture; the host scene holds the clip on-screen for the duration. NOT a render concern.
- **Two-line flipper (line 30)**: `mode: 'flip'`. **First production consumer of T-356b's `mode: 'flip'`**.
- **Segment cadence (line 40 — "each segment displays for 4–5 s")**: `flipDurationMs: 4500` — mid-canon between the stub's 4–5 s range AND matches the primitive's own `DEFAULT_FLIP_DURATION_MS = 4500` default. Setting it explicitly documents the intent at the binding site even though it equals the primitive default.
- **Band height**: `bandHeight: 100` — the primitive splits this into two 50 px rows in flip-mode, approximating the stub's 40 px BottomLine + 60 px topic-bar combined height. The topic-bar companion layer is deferred (D-T339a-11-a); the 100 px band gives flip-mode ~20 px taller-than-default rows for legible team-vs-team chips.
- **Background (line 27 — gradient `#333333 → #1A1A1A`)**: `background: '#1A1A1A'` — the primitive accepts only a single hex; T-339a picks the gradient end (deeper near-black, visually closest to most BottomLine reference frames). Document as `D-T339a-11-c`.
- **Foreground**: `foreground: '#FFFFFF'` — white text per stub line 28.
- **Up-color (Yellow score highlights / record callouts)** per stub line 28: `upColor: '#FFD700'`. The primitive renders `▲ +N` in upColor for `direction: 'up'` entries — visually conveys the stub's "Yellow `#FFD700` for score highlights" register on the wins / leads.
- **Down-color (ESPN Red brand-locked accent)** per stub line 26: `downColor: '#CC0000'`. The primitive renders `▼ -N` in downColor for `direction: 'down'` entries — visually conveys the stub's "ESPN Red `#CC0000` for accents" register on the losses / deficits. (The logo-box ESPN Red usage is deferred per D-T339a-11-b.)
- **Flat-color**: `flatColor: '#FFFFFF'` — white. Used for FINAL `'F'` / halftime `'H'` status tokens with `direction: 'flat'`; the primitive renders the `▬` flat arrow + the literal token in flatColor.
- **Sports payload (NBA score chip mix)**: six entries cover NBA team-vs-team scores with mixed up / down / flat directions:
  - `{ symbol: 'NYK', price: '102', delta: '+5', direction: 'up' }` — Knicks lead by 5
  - `{ symbol: 'BOS', price: '97', delta: 'F', direction: 'flat' }` — Celtics final
  - `{ symbol: 'LAL', price: '88', delta: '-3', direction: 'down' }` — Lakers down 3
  - `{ symbol: 'PHX', price: '91', delta: 'F', direction: 'flat' }` — Suns final
  - `{ symbol: 'PHI', price: '24', delta: '+2', direction: 'up' }` — 76ers (1H) up 2
  - `{ symbol: 'DAL', price: '22', delta: 'F', direction: 'flat' }` — Mavericks (1H)
  - **At frame 60 (= 2000 ms @ 30fps; pair window 4500 ms)**: `pairIdx = 0` → top row = NYK +5, bottom row = BOS F. Both up + flat directions exercise yellow + white chip color paths in the single mid-segment golden.
- **Roboto Condensed + Inter (Apache-2.0 + OFL) fallback** for proprietary ESPN A2 Beckett + Klavika (stub frontmatter lines 7–13): The primitive applies `system-ui, -apple-system, BlinkMacSystemFont, sans-serif` regardless of preset; the FontManager attaches Roboto Condensed + Inter at render time based on the preset's `fallbackFont` field. The bound props do NOT carry a `font` axis — the `news-ticker-bar` schema has no font slot (line 31–68); typography flows through the preset's frontmatter into the FontManager preload list.
