## Decisions

### D-T347d-1 — wired via PRESET_ID_BINDINGS (Pattern C override)

Second `weatherMap` consumer. The clipKind-default arm is taken by T-347c `bbcMarkAllenCloudsBinding`. T-347d goes via `PRESET_ID_BINDINGS['doppler-dbz-standard'] = dopplerDbzStandardBinding`.

### D-T347d-2 — productMode: 'reflectivity' (default register; 'velocity' alternative deferred)

NEXRAD canonical reflectivity dBZ palette (`DOPPLER_DBZ_REFLECTIVITY` 7-step blue→green→yellow→red→magenta) per stub line 23. The `'velocity'` alternative (bright-green inbound + bright-red outbound; mesocyclone signature preservation per stub line 28) is documented in the primitive but NOT shipped as a separate v1 preset variant — adding `productMode: 'velocity'` as a separate signed golden is out-of-scope for T-347d (would be T-347d-velocity follow-up if a separate parity register is needed).

### D-T347d-3 — sweepBeamPhase pinned for single-frame static

Per primitive D-T347a-5 (single-frame static; multi-frame radar loop deferred to T-347a-loop-cycle), `sweepBeamPhase: 0.25` pins the sweep beam at clockwise quarter-turn (3 o'clock position) — visually identifiable as "sweep just past the eastern quadrant", representative of an active scan. `loopFrameIndex: 0` (start of conceptual loop).

### D-T347d-4 — synthetic dark base map + 8 dBZ-region overlays

Per D-T347a-7, primitive does NOT bundle map geometry. Binding supplies:

- **`mapPaths[]`** (single SVG path): a synthetic dark-grey rectangular region representing the radar coverage area. Default `#1A1A1A` (doppler radar base).
- **`regions[]`** (8 entries): dBZ readings positioned across the radar image at varying `dataValue` strings (e.g. `'45 dBZ'`, `'30 dBZ'`, `'60 dBZ'`) — these render as plain text overlays per the doppler-radar style branch (NOT colored discs; that's mark-allen-clouds canon only).

The synthetic geometry is adequate-fidelity for parity-fixture verification — real NEXRAD consumers wire higher-fidelity radar-tile data via T-347a-loop-cycle when shipped.

### D-T347d-5 — typography per stub

`font: { family: 'Open Sans, system-ui, ...', weight: 400, size: 14 }` — primitive default for the `'doppler-radar'` style (matches stub line 32 "Regular, 14-16pt"). Open Sans is OFL.

### D-T347d-6 — frame 60 single-frame static; parity thresholds 40 / 0.97

Per stub line 50 reference frames `0 / 12 / 24 / 60`, single-frame golden at frame 60 (loop restart; settled register). PSNR ≥ 40 / SSIM ≥ 0.97 cluster-radar tighter thresholds (per stub: "radar pixels are deterministic"); per F-4 generator flags `--psnr=40 --ssim=0.97 --mark-signed`.

Multi-frame radar loop cycling (6-12 frames over 30-90 minutes per stub line 38) deferred to T-347a-loop-cycle; v1 single-frame static.

Update `skills/stageflip/presets/weather/doppler-dbz-standard.md` frontmatter `status: stub` → `status: substantive`. Body unchanged.
