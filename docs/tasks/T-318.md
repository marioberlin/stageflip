# T-318 — `FollowPrompt` primitive

**Branch**: `task/T-318-follow-prompt-primitive`

## Goal

Ship a frame-runtime-bridge clip — `follow-prompt` (kebab-case file/kind, mirroring `subscribe-button` / `breaking-banner` / `news-ticker-bar` / `lower-third` / `score-bug`) — that renders a creator-platform follow-CTA in the *right-thumb-zone* of vertical video from a sealed `platform: 'tiktok' | 'instagram' | 'youtube' | 'generic'` enum. The primitive is the missing piece that blocks T-370 `tiktok-follow-pulse` (Cluster G's TikTok-canon preset) and is the architectural sibling of T-317 (`SubscribeButton`, just landed at `1cc4da93`) and T-319 (`QRCodeBounce`); together the three primitives unlock all five Cluster G presets.

T-318 is **deliberately distinct from T-317**. T-317 ships a *horizontal subscribe pill* — the YouTube-canonical "SUBSCRIBE" button shape, with TikTok / Instagram pill variants — anchored bottom-right of a 16:9 desktop frame. T-318 ships a fundamentally different visual register: a *circular avatar with a "+" badge* in the right-thumb-zone of vertical (9:16) video, sized to the iOS / Android 44 px touch-target, *always present* with a periodic attention-pulse instead of a one-shot entrance. The two primitives overlap at the "follow CTA" semantic axis and diverge on every visual axis (shape, anchor, animation lexicon, pulse-vs-bounce, presence model). TikTok is the canonical anchor (per `skills/stageflip/presets/ctas/tiktok-follow-pulse.md` line 21: *"Right-thumb zone placement is non-negotiable on vertical video"*); Instagram and YouTube reuse the avatar-circle register with their respective brand canon.

T-318 is **M-sized**: ~400–600 LOC component + ~250–350 LOC tests + barrel + ~6 LOC catalog/manifest entries + changeset. Comparable to T-317 `subscribe-button` (612 + 433) — same single-axis dispatch shape (`platform`), same Zod `discriminatedUnion` posture, same theme-slot wiring — slightly smaller because the visual register is leaner (circle + badge vs. pill + label + glyph + drop-shadow). It does NOT touch T-370's preset markdown, parity resolver, or parity goldens — those land in T-370 (the consumer preset PR) after this primitive merges.

## Architectural decisions

### D-T318-1. Distinct primitive vs. extending `cta-pulse` or `subscribe-button`

T-318 ships a **distinct** primitive (`follow-prompt`), NOT an extension of `cta-pulse` (T-202a) or `subscribe-button` (T-317). Rationale:

- **Visual register diverges from `cta-pulse`.** `cta-pulse` is a *generic radial pulse* rendered around an arbitrary child element. T-318 ships *a sealed avatar-circle + "+"-badge surface itself* — the circular avatar (40 × 40 base, 44 × 44 touch-target), the platform-canonical badge color (TikTok pink `#FE2C55`, Instagram magenta `#DD2A7B`, YouTube red `#FF0000`), the platform-canonical right-thumb-zone position discipline (the consumer is responsible for absolute positioning per the canon).
- **Visual register diverges from `subscribe-button`.** T-317 is a *horizontal pill button* (border-radius 8, full-width label, optional bell / cursor glyphs); T-318 is a *circular avatar with a corner badge* (border-radius 50%, no label by default, no cursor). The two primitives share the platform-enum dispatch shape but render fundamentally different geometry.
- **Animation lexicon diverges.** `cta-pulse` ships a *radial pulse* (concentric expanding rings via SVG `<circle r=...>`). `subscribe-button` ships a *bounce-overshoot entrance* (scale 0 → 1.10 → 1.00) plus a press-dip. T-318 ships a *bounded sustained-pulse* (scale 1.00 ↔ 1.05 with optional 30%-alpha expanding ring, repeated) plus a *follow-confirmation morph* (the "+" → checkmark glyph swap with 1.00 → 1.20 → 1.00 scale pop). Different animation primitives.
- **Presence model diverges.** T-317 is a *one-shot entrance* — it appears, bounces in, and stays. T-318 is *always-present* — it never "enters"; it pulses periodically as an attention mechanism (per `tiktok-follow-pulse.md` line 41: *"Always-present, no entry — the pulse animation is the only attention mechanism"*). The `'idle'` phase has different semantics in the two primitives.
- **One consumer stub explicitly pins `clipKind: followPrompt`** (`tiktok-follow-pulse.md` line 4). The clipKind is **already** reserved in `VALID_CLIP_KINDS` (line 75). The architectural intent is a dedicated primitive.
- **Cluster G's "mimicry wins" canon** (per `skills/stageflip/presets/ctas/SKILL.md` line 44) demands platform-native register, not a generic pulse. The primitive must encode the avatar-circle + "+"-badge shape natively.

Reviewer demand for merging into `cta-pulse` or `subscribe-button` → escalate per CLAUDE.md §6.

### D-T318-2. Approach — single primitive with platform-bundle dispatch (Approach A)

**Decision**: **Approach A** — a single `follow-prompt` primitive with sealed `platform: 'tiktok' | 'instagram' | 'youtube' | 'generic'` enum dispatching to four distinct render paths within one component. Mirrors T-317 D-T317-2 verbatim.

The Orchestrator evaluated three approaches:

- **Approach A (single primitive, platform-bundle dispatch)** — Single `follow-prompt` primitive with `platform` enum. Each platform branches to a distinct render path (`renderTiktok` / `renderInstagram` / `renderYoutube` / `renderGeneric`). ~400–600 LOC. Mirrors `subscribe-button.tsx` 4-platform dispatch, `score-bug.tsx` 4-style dispatch, `caption.tsx` 6-style dispatch precedents. ALL_BRIDGE_CLIPS grows 53 → 54.
- **Approach B (generic primitive + slot-based composition)** — A `follow-prompt` primitive that exposes layout primitives (avatar-circle, badge-overlay-slot, ring-overlay-slot) and presets compose them. Smaller primitive but pushes layout concerns into resolver code.
- **Approach C (split into multiple primitives)** — `follow-prompt-tiktok`, `follow-prompt-instagram`, `follow-prompt-youtube`, `follow-prompt-generic` — 4 separate primitives. Breaks 1-clipKind = 1-primitive convention; clip count grows 53 → 57.

**Rationale for A**:

1. **Established pattern.** T-317 just shipped Approach A for the sibling primitive (`subscribe-button`). T-318 follows the same shape for tooling, schema, and reader cohesion. `caption.tsx` (6 STYLE_BUNDLES), `lyrics.tsx` (3 style bundles), `title-sequence.tsx` (4 sealed style bundles), `score-bug.tsx` (4 sealed style bundles) all use single-primitive style-bundle dispatch.
2. **One clipKind = one primitive.** Pattern C of the resolver maps `clipKind: followPrompt` → primitive `kind: 'follow-prompt'`. Approach C breaks this convention; Approach B pushes layout into the resolver where it doesn't belong.
3. **ALL_BRIDGE_CLIPS stays at 54.** Approach C bloats the catalog with four entries that share most of their schema surface; the consolidation discipline is part of the bridge's identity.
4. **Future presets bind cleanly.** Future Cluster G follow-CTA presets (Instagram-canon follow prompts, YouTube-canon follow prompts on Shorts) bind to `'instagram'` / `'youtube'` platform values on this primitive without requiring new primitives.

Reviewer demand for Approach B (slot-based) or Approach C (split) → escalate; the architectural rule is sealed at A.

### D-T318-3. Platform bundle enum — `'tiktok' | 'instagram' | 'youtube' | 'generic'`

Four sealed platform bundles cover the v1 surface. **TikTok is the canonical anchor** (the v1 consumer T-370 binds to `'tiktok'`); Instagram and YouTube reuse the same shape with their respective brand canon for future presets. Generic is the brand-neutral escape hatch.

- **`'tiktok'`** — Circular avatar (40 × 40 base diameter, configurable; 44 × 44 touch-target = 22 px padding ring around the visible 40 × 40 circle). TikTok Pink `#FE2C55` "+" badge in `'idle'` / `'pulsing'` phase (badge size ~16 × 16 px positioned at the bottom-center of the avatar, half-overlapping the circle's bottom edge). White avatar surface by default (overridable via `avatarColor?`). Optional 1–2 character monogram via `avatarText?` (TikTok Sans Bold 700, white text). Right-thumb-zone position discipline is the consumer's responsibility — the primitive accepts an absolute `position: { x, y }`. Optional 30%-alpha expanding pulse-ring around the circle in `'pulsing'` phase. **Post-follow** (`phase: 'followed'`): "+" badge replaced with white checkmark glyph (`\u{2713}`) on a TikTok Pink circle background; the avatar surface remains unchanged. Serves T-370.
- **`'instagram'`** — Circular avatar (same 40 × 40 base). Magenta `#DD2A7B` "+" badge (the middle stop of the Instagram gradient — single-color fallback for the badge dot rather than the full gradient, which is reserved for the optional ring). Optional Instagram-canonical gradient ring (`linear-gradient(135deg, #F58529 0%, #DD2A7B 50%, #8134AF 100%)`) around the avatar circle when `showRing: true` (the famous Instagram-Story ring). Helvetica Neue / Arial Semi-Bold 600 for `avatarText` fallback. Post-follow: "+" → checkmark on the magenta circle.
- **`'youtube'`** — Circular avatar (same 40 × 40 base). YouTube Red `#FF0000` "+" badge. Roboto Medium 500 for `avatarText` fallback. Post-follow: "+" → checkmark on the red circle. Note: YouTube's *primary* follow CTA is the horizontal "SUBSCRIBE" button (T-317); YouTube's right-thumb-zone register on Shorts uses an avatar-circle pattern similar to TikTok's, which is what `'youtube'` here serves.
- **`'generic'`** — Brand-neutral circular avatar (same 40 × 40 base) with theme-slot palette fallback (`palette/accent` for the "+" badge background, `palette/foreground` for the badge glyph color, `palette/background` for the avatar surface). The escape hatch when none of the three platform registers fits.

The four bundles dispatch in a single `switch (platform)` block; each platform maps to a distinct render path (`renderTiktok` / `renderInstagram` / `renderYoutube` / `renderGeneric`). No "hybrid" / configurable per-feature toggle in v1 — the four bundles are sealed. Future platforms add via additive enum extension (no breakage).

### D-T318-4. Schema shape (Zod) — discriminated union on `platform`

Top-level Zod schema is a discriminated union on `platform`. Each variant carries the common base props + the platform-specific shape. Mirrors `subscribe-button.tsx`'s `discriminatedUnion('platform', [...])` pattern verbatim.

```ts
const HEX_COLOR_RE = /^#[0-9a-fA-F]{6}$/;

const positionSchema = z
  .object({
    x: z.number(),
    y: z.number(),
  })
  .strict();

const fontSchema = z
  .object({
    family: z.string().min(1),
    weight: z.number().int().min(100).max(900).optional(),
  })
  .strict();

const phaseSchema = z.enum(['idle', 'pulsing', 'followed']);

// Common props that appear in every platform branch. Spread into each
// branch's shape since `discriminatedUnion` requires plain `ZodObject`
// branches.
const baseShape = {
  position: positionSchema,
  /** Avatar-circle diameter (px). Default 40. Touch-target padding adds ~4 px on each side. */
  size: z.number().positive().optional(),
  /** Avatar surface color hex. Theme-slot fallback when absent (generic only). */
  avatarColor: z.string().regex(HEX_COLOR_RE).optional(),
  /** 1–2 character monogram inside the avatar circle. */
  avatarText: z.string().min(1).max(2).optional(),
  /** Avatar-text color hex. Default white on branded platforms; theme-slot fallback for generic. */
  avatarTextColor: z.string().regex(HEX_COLOR_RE).optional(),
  /** Badge background color hex; per-platform default applied when absent. */
  badgeColor: z.string().regex(HEX_COLOR_RE).optional(),
  /** Badge glyph color hex; default white. */
  badgeGlyphColor: z.string().regex(HEX_COLOR_RE).optional(),
  /** Font override for `avatarText`; per-platform default applied when absent. */
  font: fontSchema.optional(),
  /** Animation phase. 'idle' (default) renders the static avatar + badge;
   * 'pulsing' renders the bounded scale-pulse + optional alpha-ring;
   * 'followed' renders the "+" → checkmark morph + scale pop. */
  phase: phaseSchema.optional(),
  /** Show the expanding 30%-alpha pulse-ring in 'pulsing' phase. Default true. */
  showPulseRing: z.boolean().optional(),
  /** Bounded count of pulse cycles when phase: 'pulsing'. Default 1, max 10. */
  pulseRepeat: z.number().int().min(1).max(10).optional(),
};

const tiktokSchema = z.object({
  platform: z.literal('tiktok'),
  ...baseShape,
}).strict();

const instagramSchema = z.object({
  platform: z.literal('instagram'),
  ...baseShape,
  /** Show Instagram-canonical gradient story-ring around the avatar. Default false. */
  showRing: z.boolean().optional(),
  /** Override gradient stops on the story-ring. Default per-platform. */
  gradient: z
    .object({
      start: z.string().regex(HEX_COLOR_RE),
      mid: z.string().regex(HEX_COLOR_RE),
      end: z.string().regex(HEX_COLOR_RE),
    })
    .strict()
    .optional(),
}).strict();

const youtubeSchema = z.object({
  platform: z.literal('youtube'),
  ...baseShape,
}).strict();

const genericSchema = z.object({
  platform: z.literal('generic'),
  ...baseShape,
}).strict();

export const followPromptPropsSchema = z.discriminatedUnion('platform', [
  tiktokSchema,
  instagramSchema,
  youtubeSchema,
  genericSchema,
]);
```

All optional except `platform` and `position`. Strict mode (no extras). Mirrors `subscribe-button.tsx` Zod posture. NO `.refine()` wrappers on union branches (Zod doesn't allow them on `discriminatedUnion` arms). Note that — unlike T-317 which requires `label` — T-318 has *no required string content* beyond the discriminator + position, because the avatar-circle is icon-only by default (per `tiktok-follow-pulse.md` line 30: *"N/A — icon-only CTA"*).

### D-T318-5. Animation lexicon — bounded sustained-pulse + checkmark-morph

The primitive ships a sealed three-phase animation lexicon, divergent from T-317's three-phase lexicon (which used entrance-bounce + press-dip + static-settled):

- **`'idle'`** (default): static avatar circle + "+" badge at scale `1.00`. No animation. The avatar is *always present* on the frame (per Cluster G canon — no entrance / exit). The `'idle'` phase exists for scene segments where the consumer wants the avatar visible but not pulsing.
- **`'pulsing'`**: bounded sustained-pulse driven by `useCurrentFrame()`. Per cycle: scale `1.00` → `1.05` (over `ceil(fps * 0.5)` frames = 500 ms) → `1.00` (over the next `ceil(fps * 1.0)` frames = 1000 ms) — full cycle 1500 ms per `tiktok-follow-pulse.md` line 34. Implemented via piecewise `interpolate(frame % cycleFrames, [0, peakFrame, cycleFrames], [1, 1.05, 1], { easing: cubicBezier(...) })`. Optional 30%-alpha expanding pulse-ring rendered as a concentric circle whose `r` interpolates from the avatar radius to `1.5 ×` avatar radius over the same cycle, with `opacity` fading from 0.30 → 0. The number of cycles is bounded by `pulseRepeat?: number` (default 1, max 10). After the bounded cycles complete, scale settles at `1.00` for the remainder of the clip.
- **`'followed'`**: the "+" → checkmark glyph swap with a single 1.00 → 1.20 → 1.00 scale pop on the badge over `ceil(fps * 0.3)` frames (300 ms per `tiktok-follow-pulse.md` line 35). The avatar circle scale stays at `1.00`. After the pop, the checkmark glyph remains static. Frame-driven; no `Date.now()`.

Animation is purely frame-derived. No `Date.now()`, no `Math.random()`, no `setTimeout` / `setInterval`, no `requestAnimationFrame`. Easing approximated via `cubicBezier` from `@stageflip/frame-runtime` (no `framer-motion`).

The `phase` prop is set by the consumer (resolver / preset). v1 does NOT auto-transition between phases via internal frame thresholds — the consumer mounts the primitive with the desired `phase` per scene segment. Same determinism contract as T-317: same props + same frame → same output.

### D-T318-6. Theme slots — `background` + `foreground` + `accent`

Mirrors `subscribe-button.tsx` D-T317-6 + score-bug.tsx + caption.tsx + lyrics.tsx posture: every color prop is **optional**; theme slot fills in when absent.

```ts
themeSlots: {
  background: { kind: 'palette', role: 'background' },
  foreground: { kind: 'palette', role: 'foreground' },
  accent: { kind: 'palette', role: 'accent' },
}
```

Top-level optional color props with theme fallback: `avatarColor?` (avatar surface) → `palette/background` (only consumed in `'generic'` mode; branded platforms default to white avatar surface unless `avatarColor` is explicitly passed); `avatarTextColor?` (monogram color) → `palette/foreground` (consumed in `'generic'` mode; branded platforms default to white); `badgeColor?` (badge background) → `palette/accent` (consumed in `'generic'` mode; branded platforms override with platform-canonical pink/magenta/red); `badgeGlyphColor?` (badge "+" / checkmark color) → defaults to white regardless of platform (the badge glyph is always a high-contrast pictogram).

For `'tiktok'` / `'instagram'` / `'youtube'`: brand-canonical badge colors are baked into the per-platform render path and override the theme slot (*brand canon dominates theme*, per D-T317-6). The `badgeColor?` prop is accepted for schema uniformity but is no-op in brand-platform modes (consumer-provided overrides for these platforms → escalate; the brand canon is sealed).

For `'generic'`: theme-slot palette drives the colors when no explicit props are passed.

### D-T318-7. Per-platform default fonts (for optional `avatarText` monogram)

Each platform branch declares its canonical default font. Fonts are consumed only when `avatarText` is set (the icon-only default has no typography surface).

- **`'tiktok'`** — TikTok Sans (the platform's font), Bold (700). Falls back to system sans when the TikTok Sans family is absent.
- **`'instagram'`** — Helvetica Neue / Arial fallback chain, Semi-Bold (600).
- **`'youtube'`** — Roboto Medium (500).
- **`'generic'`** — `'Plus Jakarta Sans, sans-serif'` weight 700 (the bridge default from T-183z / T-324a).

`fontRequirements` registration mirrors `subscribe-button.tsx`'s pattern:

```ts
fontRequirements: () => [
  { family: 'TikTok Sans', weight: 700 },
  { family: 'Roboto', weight: 500 },
  { family: 'Plus Jakarta Sans', weight: 700 },
],
```

Instagram falls through to the runtime's system-font chain (Helvetica Neue / Arial are universally available; no explicit registration).

### D-T318-8. No casing transform on `avatarText`

Unlike T-317 (which forces uppercase on YouTube's "SUBSCRIBE"), T-318 does NOT apply a casing transform to `avatarText`. The monogram is rendered verbatim from the consumer's input. Rationale: a 1–2 character avatar monogram is typically a brand initial or letter pair (e.g., "JD", "X") whose casing is canonical and not subject to platform stylization. Consumer presets pre-case the string before passing it. Decision: NO `casing` prop in the schema. Reviewer demand for adding one → escalate; the icon-only default and the brand-canonical monogram convention make the prop unnecessary.

### D-T318-9. Determinism

Frame-derived only. No `Date.now()`, no `Math.random()`, no `crypto.randomUUID()`, no `setTimeout`, no `setInterval`, no `fetch`. The Instagram gradient ring (when `showRing: true`) renders via inline CSS `background-image: linear-gradient(...)` over a circular outer wrapper — no SVG `<linearGradient id="...">` instance-IDs needed in v1. The optional 30%-alpha pulse-ring renders via inline CSS `border` + `transform: scale()` (or an absolute-positioned wrapper `<div>`), NOT via SVG `<circle>` with an instance-ID.

If a future v2 introduces SVG gradient / filter IDs (e.g., for animated brand-canonical morphing), they MUST be platform-derived stable IDs (e.g., `follow-prompt-instagram-gradient`), NOT `crypto.randomUUID()`.

`scripts/check-determinism.ts` globs `packages/runtimes/*/src/clips/**/*.{ts,tsx}` — the new file is automatically in scope. No gate plumbing needed. Verifies via the determinism test (render the same props twice at the same frame; HTML byte-identical).

3. **Schema first.** D-T318-3 / D-T318-4 / D-T318-7 / D-T318-8 all affect schema shape. Conservative defaults (per-platform fonts baked in for `avatarText`; all colors optional with theme fallback in `'generic'` only; brand canon dominates theme in branded platforms; bounded `pulseRepeat` 1–10). Required: `platform`, `position`. All other fields optional.
4. **Discriminated-union discipline.** Mirror `subscribe-button.tsx`'s `discriminatedUnion('platform', [tiktokSchema, instagramSchema, youtubeSchema, genericSchema])` verbatim. Each branch's strict `.strict()` enforces no extras. NO `.refine()` wrappers on the union branches (Zod doesn't allow them on `discriminatedUnion` arms). 5. **Per-platform render functions.** Implement `renderTiktok` / `renderInstagram` / `renderYoutube` / `renderGeneric` as separate functions called from the top-level `switch (platform)` block. Each function returns the platform-canonical `ReactElement` for the current `phase`. Avoid bloating the main component with inline platform-specific JSX.
6. **Bounded sustained-pulse math.** Use piecewise `interpolate(frame % cycleFrames, [0, peakFrame, cycleFrames], [1.00, 1.05, 1.00], { easing: cubicBezier(0.4, 0, 0.2, 1) })` with `cycleFrames = ceil(fps * 1.5)` (1500 ms full cycle) and `peakFrame = ceil(fps * 0.5)` (500 ms to peak). After `pulseRepeat` cycles complete (i.e., when `frame >= cycleFrames * pulseRepeat`), clamp scale to `1.00`. Apply via `transform: scale(${value})` on the outer avatar container.
7. **Pulse-ring geometry.** Render as an absolutely-positioned `<div>` (or SVG `<circle>` without an instance-ID) concentric with the avatar; `width` / `height` interpolate from `size` to `size * 1.5`; `opacity` interpolates from `0.30` to `0` over the same cycle window. Hidden when `showPulseRing: false` or `phase !== 'pulsing'`.
8. **Checkmark-morph math.** Conditional glyph swap: in `'idle'` / `'pulsing'`, render the "+" glyph; in `'followed'`, render the `\u{2713}` checkmark. Apply a single 1.00 → 1.20 → 1.00 scale pop on the badge container via `interpolate(frame, [0, ceil(fps * 0.15), ceil(fps * 0.3)], [1.00, 1.20, 1.00], { easing: cubicBezier(...) })`. The avatar circle scale stays at `1.00` throughout `'followed'`.

The avatar surface defaults to white in branded modes (overridable via `avatarColor?` for cases where the consumer wants a brand-tinted avatar fill).
