# T-326 — Preset: `al-jazeera-orange` (lowerThird, Cluster A)

**Branch**: `task/T-326-al-jazeera-orange`

## Goal

Promote the existing `al-jazeera-orange` preset stub from `status: stub` to `status: substantive` and ship it as the **third Cluster A (news / lower-third) preset to land** AND the **third consumer of the `lowerThird` clipKind** in the parity-CLI resolver. The preset captures Al Jazeera English's distinctive orange-on-light register: a light `#F7F7F5` bar + an Al Jazeera Orange `#F7941D` accent strip on the left edge + a Mixed-Case headline + a Mixed-Case subtitle, anchored bottom-left on a 1280×720 canvas. Common uses: warm humanist register; presenter-and-role identification, contributor identification, on-screen attribution where Al Jazeera's signature warmth (orange differentiator vs. Western networks' cool blues) is the brand signal.

T-326 is the **third** preset to bind the `lowerThird` clipKind. T-323 (`cnn-classic`, merged) holds the **clipKind-default** slot in `DEFAULT_CLIP_KIND_RESOLVER` (`lowerThird → cnnClassicBinding`). T-325 (`bbc-reith-dark`, merged) wired the **first** `PRESET_ID_BINDINGS` override for `lowerThird` (`'bbc-reith-dark' → bbcReithDarkBinding`). T-326 must therefore wire its binding via the **`PRESET_ID_BINDINGS` override map** keyed on `'al-jazeera-orange'` — Pattern C from `docs/handover-phase13-mid.md` §2 (third-preset-for-clipKind via override map). Mirrors T-325's bind shape exactly, swapping snapshot constants. The `LowerThird` primitive (T-183) is unchanged; T-326 consumes it read-only.

T-326 is **M-sized** — same envelope as T-323, T-325, T-364, T-365. ~25–35 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. No primitive carve-out; no schema change. Inherits T-325's resolver shape end-to-end (presetId-override path takes precedence over the clipKind-default arm).

## Architectural decisions

### D-T326-1. Compass register match — light `#F7F7F5` bar + orange `#F7941D` accent strip + Mixed-Case headline (dark) + Mixed-Case subtitle

The stub (lines 22–47) defines the canonical Al Jazeera English orange-on-light register:

- **Bar**: `#F7F7F5` light fill (line 23), width extended for bilingual companion (deferred per D-T326-3 to v2; v1 uses primitive default minWidth 240 plus content), positioned bottom-left.
- **Accent strip**: orange/amber gradient `#F7941D` → `#E87722` on the **left edge** (line 24); the primitive renders this as a 6 px-wide left-side flex child with `borderRadius: 3` and a single hex fill — v1 picks `#F7941D` as the dominant orange (D-T326-4). The gradient is documented as a primitive-level follow-up; flat orange is the v1 render.
- **Typography**: Headline (`name`) Mixed Case, dark `#222222` per stub line 25; subtitle (`title`) Mixed Case, dark `#222222` per stub line 25 — though the primitive renders `title` at `color: accent` (orange) per its hard-binding (D-T326-12-a). Both are Mixed Case (the snapshot strings are passed as-is — no programmatic case transform).
- **Rules** (lines 41–44): "Bilingual is the signature — always include the Arabic companion unless the tenant explicitly targets an Arabic-muted surface. Orange is the differentiator vs. Western networks' cool blues. Do not substitute a warm-red or yellow for 'warmer.' Typography fallback must preserve both a rounded-geometric Latin and a matched-x-height Arabic; if the fallback fails either, escalate." — v1 Latin-only per D-T326-3; bilingual deferred to T-326a.

T-326 binds these to the existing `LowerThird` primitive's render contract (T-183). The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| Light `#F7F7F5` bar background | `background` | `'#F7F7F5'` |
| Orange left accent strip (6 px-wide left bar) | `accent` | `'#F7941D'` (dominant orange; gradient deferred per D-T326-4) |
| Headline Mixed Case, dark `#222222` | `name` (rendered at 34 px / fontWeight 700 in `textColor`) | `'Marwan Bishara'` (Mixed Case) |
| Subtitle Mixed Case, dark `#222222` (renders in `accent` orange per D-T326-12-a) | `title` (rendered at 18 px / fontWeight 500 in `accent`) | `'Senior Political Analyst'` |
| Position 40–60 px from bottom, far left | `insetLeftPx`, `insetBottomPx` | `64`, `48` |
| Headline color dark `#222222` | `textColor` | `'#222222'` |

The preset register is **dark text on a light bar** — a significant departure from T-323's CNN white bar / black text and T-325's BBC dark bar / white text. The orange accent is the brand-distinct differentiator (Al Jazeera vs. Western networks' cool blues per stub line 43).

The primitive's render of the `title` line uses `color: accent` (orange) — see D-T326-12-a for the trade-off.

### D-T326-3. v1 Latin only — Arabic companion deferred to `T-326a` IF Reviewer demands

The al-jazeera identity is canonically **bilingual** — Latin (English) + Arabic (`الجزيرة`) on the same lower-third (stub line 26 "Extended width to accommodate bilingual text," lines 33 "Arabic companion (right-to-left): Amiri fallback, Regular, matched to Latin x-height," line 37 "Arabic and Latin text reveal in parallel, not sequentially," line 42 "Bilingual is the signature — always include the Arabic companion unless the tenant explicitly targets an Arabic-muted surface").

The `LowerThird` primitive (T-183) does NOT support bilingual rendering:

- The prop schema has a single-string `name` and a single-string `title`. There is NO `secondaryName` / `secondaryTitle` / `bilingual` / `direction` / `script` axis.
- The render path is LTR-only. There is NO RTL/bidi text-rendering pass; mixed LTR/RTL paragraphs would not align correctly.
- The FontManager preload list does NOT include a matched-x-height Arabic font (Amiri or similar).

Adding bilingual support is a **meaningful primitive carve-out**, NOT a preset-level concern. It would require:

- A new prop axis for the second-language slot (`name: string | { latin: string; arabic: string }` OR a `secondary: { name, title, direction } | undefined` block — design TBD).
- An RTL/bidi text-rendering pass with proper text-direction handling.
- A matched-x-height Arabic font preload + the corresponding `THIRD_PARTY.md` license entry (Amiri OFL).
- Layout: parallel-stack vs. side-by-side bilingual rendering; bar-width handling for the longer-of-the-two languages.

**Decision**: T-326 v1 ships **Latin-only** — `name: 'Marwan Bishara'` + `title: 'Senior Political Analyst'`. The orange-on-light register, accent strip, and DIN-like Latin typography (rendered as Plus Jakarta Sans 700 / 500 per D-T326-12-b) are sufficient parity proof of the al-jazeera identity for v1. The Arabic companion is deferred to:

- **`T-326a`** — bilingual lower-third primitive carve-out (new prop axis, RTL/bidi pass, Arabic font preload). Ships if Reviewer demands inline OR if a future tenant requires bilingual rendering. The carve-out task title would be `[T-326a] LowerThird primitive — bilingual second-language slot (Latin + Arabic) with RTL/bidi rendering`.

**Rationale** (mirrors T-350's `D-T350-12` posture for Hangul in `squid-game-geometric`): the canonical brand register in a single steady-state Latin-only frame **is** sufficient to establish brand identity for parity sign-off purposes. The Arabic companion is a meaningful additional surface but it is NOT required to evidence the al-jazeera-vs-Western-networks differentiation that the preset captures — the orange-on-light, dark-text, DIN-like Latin posture is itself the brand signal.
