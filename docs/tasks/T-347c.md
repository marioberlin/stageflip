### D-T347c-2 — synthetic UK + Europe coastal outline (3 mapPaths)

`mapPaths[]` carries hand-tuned SVG polygons sized to the 1280×720 canvas:

- Europe continent outline (rough Iberian → Scandinavian sweep)

### D-T347c-3 — 4 temperature-disc regions across UK cities

`regions[]` carries 4 entries — London, Edinburgh, Cardiff, Belfast — each with:
- `dataValue: '12°C'` / `'8°C'` / `'10°C'` / `'9°C'` (mid-spring forecast register)
- `paletteIndex: 2..3` (mid-blue/green band of `MARK_ALLEN_TEMPERATURE_DISCS`)
- `screenPosition` clustered around the UK silhouette

The mark-allen-clouds branch wraps each label in a colored disc per `paletteIndex`.

### D-T347c-4 — 6 Mark-Allen symbols

`symbols[]` carries the canonical Mark-Allen icon-set instances (one of each kind plus duplicates for atmospheric coverage):
- 2× cloud (over central / northern UK)
- 1× sun (south-east, "spell of brightness")
- 2× raindrop (north-west, Scottish weather front)
- 1× snow (Scottish highlands)

Per stub line 41 "Mark Allen's symbol set is iconic British culture — do not modernize". The primitive's built-in SVG icons match the silhouette canon.

`font: { family: 'BBC Reith Sans, Source Sans 3, system-ui, ...', weight: 700, size: 22 }` — primitive default for the mark-allen-clouds style (matches stub line 30 "Bold, 22-28pt"). BBC Reith Sans is `proprietary-byo` per preset frontmatter; Source Sans 3 OFL is the rendered fallback.
