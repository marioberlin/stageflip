# T-450 — ADR-009: Audience Backend

**Branch**: `task/T-450-adr-009-audience-backend`

## Goal

Ship the first Phase 15 α ADR — the audience-backend contract that builds on ADR-007's `AdapterDescriptor` envelope. ADR-009 defines:

1. The audience backend service architecture (§D1) — WebSocket multiplexer + Firestore `audience-sessions` collection, extending `apps/api` (not a separate deployment).
2. The `AudienceBackendProvider` interface (§D2) — four-method contract (`openSession` / `submitVote` / `subscribe` / `closeSession`) + `AudienceCapabilityDescriptor` extending `AdapterDescriptor`.
3. The three-layer rate-limit model (§D3) — per-tenant + per-session voter cap + per-voter anti-spam, with drop-not-queue backpressure.
4. The real-time SLA target (§D4) — 1000 concurrent voters v1; p50 < 200 ms / p95 < 500 ms voter-tap → screen latency budget.
5. The persistence model (§D5) — Firestore `tenants/{tenantId}/projects/{projectId}/audience-sessions/{sessionId}` with `events/` + `snapshots/` sub-collections, TTL policy, voter-token hashing at rest.
6. The WebSocket transport (§D6) — connection lifecycle, exponential backoff reconnect (6 attempts × max 30 s), heartbeat cadence.
7. The dual-trust-domain auth model (§D7) — presenter admin token (tenant-scoped) + anonymous voter session token (session-scoped).
8. The vendor adapter bridge contract (§D8) — how Slido / Mentimeter / Poll Everywhere / Vevox / Wooclap implement the same interface + vendor parity matrix.
9. The `AudienceProvenance` schema preview (§D9) — slots named here; full schema lands in ADR-010 + T-460.
10. The determinism posture (§D10) — live path observably non-deterministic; `staticFallback` contractually deterministic.
11. Eight `LF-AUDIENCE-*` loss-flag codes (§D11).
12. Plugin manifest per-modality extensions (§D12).
13. Permissions manifest cross-reference (§D13) — `audience-network` per ADR-005 + T-455.

This is **the** Phase 15 α hard gate, first of two. After ADR-009 (this PR) and ADR-010 (T-451, pending) merge, all of T-452+ can dispatch.

**Spec / ADR only — no code, no packages, no scripts, no CI.**
