# T-417 — Provider Seam concept SKILL

**Branch**: `task/T-417-provider-seam-concept-skill`

## Goal

Ship the concept SKILL that summarises the provider-seam meta-pattern just
ratified in **ADR-007** (T-415, PR #478) + extended in **ADR-008** (T-416,
PR #479). The SKILL is a human-and-agent-readable reference that:

1. States what the meta-pattern is in one paragraph.
2. Names the four canonical seam instances on `main` today
   (`@stageflip/runtimes/contract`, `TranscriptionProvider`,
   `@stageflip/storage` incl. T-411a's `TenantSettingsStore`, future
   `@stageflip/adapters-core` from T-418).
3. Summarises the `AdapterDescriptor` envelope from ADR-007 §D1.
4. Summarises the asset-gen extensions from ADR-008 (`MediaProvenance`,
   voice consent, `Document.research?`, `ResearchSessionProvider` wiring).
5. Documents the checklist for adding a new seam.

This is the first post-hard-gate Phase 14 task. ADR-007 + ADR-008 just
merged; downstream T-418 / T-419 / T-420 / T-421 / T-422 / T-423 / T-424 /
T-425 dispatch alongside / after this PR.

**Pure docs SKILL — no code, no packages, no scripts, no CI.**

## SKILL body structure

The SKILL body covers, in order:

1. **What it is** — 1-paragraph summary of the meta-pattern (descriptor +
   routing + sandbox + license posture, all uniform across modalities).
2. **Where it applies** — table of the four canonical seam instances on
   `main` + the upcoming `@stageflip/adapters-core` (T-418).
3. **AdapterDescriptor envelope** — concise summary of the ADR-007 §D1
   shape (id, modality, capability, license, sandbox, costPerCall,
   latencyMs, sourceGrounded, requiresResearchProvider) with link.
4. **Asset-gen extensions (ADR-008)** — what ADR-008 adds on top:
   `MediaProvenance` slot, voice-consent policy, `Document.research?`,
   `ResearchSessionProvider` wiring, content-addressed cache key.
5. **Routing posture** — license-aware filter → modality filter →
   source-grounded preference → cost / latency rank (one-paragraph
   summary; the algorithm itself is T-425's responsibility).
6. **How to add a new seam** — checklist a downstream task follows:
   define contract → implement reference adapter → register in
   meta-registry → add concept SKILL pointer → add consumer ADR if it
   crosses package boundaries.
7. **Determinism posture** — adapters live OUTSIDE the determinism
   perimeter (CLAUDE.md §3); the cache key derivation IS deterministic.
8. **Conformance retrofit posture** — ADR-007 §D9: the four existing
   instances do NOT have to retrofit to `AdapterDescriptor`. New seams
   use the descriptor.
9. **Related** — links to the four consumer concept SKILLs + the two
   ADRs + the downstream Phase 14 tasks.
