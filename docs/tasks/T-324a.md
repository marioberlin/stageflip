# T-324a — `BreakingBanner` primitive (full-width banner + Fox-sliver, horizontal/vertical slide)

**Branch**: `task/T-324a-breaking-banner-primitive`

## Goal

Ship a frame-runtime-bridge clip — `breaking-banner` (kebab-case, mirroring `lower-third`) — that renders a **full-width "BREAKING NEWS" banner** at the bottom of the frame (horizontal slide; CNN-style register) AND a **Fox-style narrow sliver** (vertical slide; persistent-during-coverage register) from the **same primitive** dispatched by a `mode` + `slideAxis` enum pair. The primitive is the missing piece that blocks two stub presets:

- **T-324 `cnn-breaking`** — `clipKind: breakingBanner`, post-2023 rounded white banner with red end-cap + "BREAKING NEWS" red label + UPPERCASE headline; horizontal slide entrance from the left.
- **T-327 `fox-news-alert`** — `clipKind: breakingBanner`, Prussian Blue narrow sliver mode + "Fox News Alert" / "BREAKING" label + Mixed-Case headline; vertical slide entrance from below.

T-324a is **distinct from T-356a (`news-ticker-bar`)** — both are full-width band-of-frame primitives, but the ticker is a **scrolling marquee of N price chips**; the breaking banner is a **single static label + headline pair** with a **slide entrance** and (in sliver mode) a **persistent steady-state**. They cohabit naturally: a layout can pair `news-ticker-bar` (below) with `breaking-banner` (above) without primitive-level coupling.

T-324a is **M-sized**: ~400–600 LOC component + ~150–250 LOC tests + barrel + ~6 LOC catalog/manifest entries + changeset. Comparable to `news-ticker-bar` (T-356a, ~216 LOC) plus the styled-banner overhead and dual-mode (banner / sliver) dispatch. NOT L-sized — the v1 surface is intentionally narrow; LIVE pulse bug, ticker strip, searchlight morph, return-from-commercial sequence, red-block-wipe text-change, and asymmetric corners are all OUT OF SCOPE for v1 (deferable to Ta-family follow-ups). It does NOT touch T-324 or T-327's preset markdown, parity resolver, or parity goldens — those land in the consumer-retry PRs after this primitive merges.

## Architectural decisions

### D-T324a-1. Distinct primitive vs. extending `lower-third` or `news-ticker-bar`

T-324a ships a **distinct** primitive (`breaking-banner`), NOT an extension of `lower-third` (T-183) or `news-ticker-bar` (T-356a). Rationale:

- **Layout register diverges from `lower-third`.** Lower-third is **anchored** (fixed-width at `insetLeftPx`, `insetBottomPx`); breaking-banner is **full-width** (banner mode) or **partial-width persistent** (sliver mode). Bolting a `mode: 'lower-third' | 'breaking-banner'` switch onto lower-third pollutes its style-bundle dispatch and breaks its existing tests.
- **Slide axis diverges.** Lower-third slides **horizontally only** (translateX). Breaking-banner slides **horizontally** (CNN) or **vertically** (Fox). The horizontal/vertical dispatch is meaningful enough to deserve its own primitive.
- **Layout register diverges from `news-ticker-bar`.** Ticker is a **scrolling marquee of N chips**; banner is a **single label + headline pair** with a slide entrance. Different render path; different schema; different determinism shape. Bolting a `mode: 'ticker' | 'banner'` switch onto news-ticker-bar bloats its scroll math and breaks its existing tests.
- **Two consumer stubs explicitly pin `clipKind: breakingBanner`** (`cnn-breaking.md`, `fox-news-alert.md`). The clipKind is reserved in `VALID_CLIP_KINDS` (line 56). The architectural intent is a dedicated primitive.

Reviewer demand for merging into `lower-third` or `news-ticker-bar` → escalate per CLAUDE.md §6.

### D-T324a-2. Single primitive serves both CNN + Fox via `slideAxis` + `mode` (vs. two separate primitives)

T-324a ships **one** primitive with `slideAxis: 'horizontal' | 'vertical'` + `mode: 'banner' | 'sliver'` enums, NOT two separate primitives (`breaking-banner-cnn` / `breaking-banner-fox`). Rationale:

- **Shared layout** >> divergent. Both registers carry: a banner shape (full-width or partial-width); a colored label badge ("BREAKING NEWS" / "Fox News Alert"); a headline; an optional end-cap flag; an entrance slide. The shared surface is ~80% of the component; the divergent surface is the slide axis (X vs Y) and the mode (full-width banner vs partial-width sliver). A single primitive with two enum dispatches captures this cleanly.
- **`slideAxis` enum is sufficient.** Horizontal slide reuses `lower-third.tsx`'s enterX/exitX math (`-100 → 0` translate %, `0 → 120` exit). Vertical slide swaps the same math to enterY/exitY (`+100 → 0` translate %, `0 → 120` exit). Same easing curves (`EASE_OUT_QUART` / `EASE_IN_QUART`); same `ceil(fps * 0.45)` / `ceil(fps * 0.35)` windows.
- **`mode` enum dispatches the layout shape.** `'banner'` (default) → full-width strip at bottom of frame; CNN posture. `'sliver'` → partial-width strip (anchored to a corner per `sliverAnchor`); Fox posture; persistent (no entrance animation, see D-T324a-6).
- **Future networks add via additive enum extension** — a new mode (e.g., `'side-rail'`) or a new slideAxis value (e.g., `'diagonal'`) can be added without breaking either consumer.

Reviewer demand for splitting into two primitives → escalate; the v1 single-primitive shape is the architectural choice.

### D-T324a-3. Mode dispatch — `'banner' | 'sliver'`, default `'banner'`

Two orthogonal layout registers cover the canonical breaking-news posture:

- **`'banner'`** (default) — full-width strip anchored to the bottom of the frame (`insetBottomPx` default `80`). Width = full frame width; height = ~96 px (typical TV breaking-banner). Hosts the colored label badge on the left + headline center/right + optional end-cap on the right. Slides in via `slideAxis` (horizontal default; banner enters from the left). The CNN posture.
- **`'sliver'`** — partial-width strip (~25–35% of frame width) anchored to a corner (default top-left, see D-T324a-13). Persistent steady-state (no entrance animation; see D-T324a-6). Hosts the colored label badge on the left + headline (single short line) + optional small end-cap. The Fox posture per `fox-news-alert.md` line 25 ("Persistent 'Fox News Alert' sliver remains visible during nearly all breaking coverage").

The two modes dispatch in a single `switch (mode)` block in the component; each mode maps to a distinct render path. No "hybrid" / configurable per-feature toggle in v1 — the two modes are sealed. Future modes add via additive enum extension.

### D-T324a-4. Schema shape (Zod)

```ts
export const breakingBannerPropsSchema = z
  .object({
    /** Layout register. Default 'banner' (CNN full-width); 'sliver' = Fox partial-width persistent. */
    mode: z.enum(['banner', 'sliver']).optional(),
    /** Headline text (the single line of breaking news content). */
    headline: z.string(),
    /** Label badge — the colored block hosting "BREAKING NEWS" / "Fox News Alert" / "BREAKING" text. */
    label: z.object({
      text: z.string(),
      fill: z.string(),  // backdrop hex (e.g. '#CC0000' red)
      color: z.string(), // text hex (e.g. '#FFFFFF')
    }),
    /** Banner backdrop fill. Defaults to theme palette/background. */
    background: z.string().optional(),
    /** Headline text color. Defaults to theme palette/foreground. */
    headlineColor: z.string().optional(),
    /** Optional end-cap flag (small colored block at one end of the banner). When absent, no end cap renders. */
    endCap: z
      .object({
        fill: z.string(),
        position: z.enum(['left', 'right']),
      })
      .optional(),
    /** Slide-axis dispatch. Default 'horizontal' (CNN); 'vertical' = Fox up-from-bottom. */
    slideAxis: z.enum(['horizontal', 'vertical']).optional(),
    /** Distance from the viewport bottom, in px. Default 80. */
    insetBottomPx: z.number().nonnegative().optional(),
    /** Sliver-mode anchor (only consumed when mode === 'sliver'). Default 'top-left'. */
    sliverAnchor: z.enum(['top-left', 'top-right', 'bottom-left', 'bottom-right']).optional(),
    /** Sliver-mode width as a fraction of frame width (0..1). Default 0.30. */
    sliverWidthPct: z.number().min(0.1).max(0.6).optional(),
    /** Banner border radius (px). Default 0; CNN register sets 8. */
    borderRadius: z.number().nonnegative().optional(),
    /** Optional font family + weight override. Defaults: 'Plus Jakarta Sans, sans-serif' weight 800. */
    font: z
      .object({
        family: z.string(),
        weight: z.number().optional(),
      })
      .optional(),
    /** Headline casing transform. Default 'as-is'. CNN uses 'uppercase'; Fox uses 'as-is'. */
    casing: z.enum(['as-is', 'uppercase', 'lowercase', 'title-case']).optional(),
  })
  .strict();
```

All optional except `headline` and `label`. Strict mode (no extras). Mirrors caption.tsx / lyrics.tsx Zod posture.

### D-T324a-5. Slide-axis math — `'horizontal'` mirrors `lower-third`'s X-axis; `'vertical'` swaps to Y-axis

Mirrors `lower-third.tsx` verbatim, parameterized by axis:

- **`slideAxis: 'horizontal'`** (default) — `enterX = interpolate(frame, [0, enterEnd], [-100, 0], { ..., easing: EASE_OUT_QUART })`; `exitX = interpolate(frame, [exitStart, durationInFrames], [0, 120], { ..., easing: EASE_IN_QUART })`. `transform: translateX(${enterX + exitX}%)`. Banner enters from the left edge.
- **`slideAxis: 'vertical'`** — `enterY = interpolate(frame, [0, enterEnd], [+100, 0], { ..., easing: EASE_OUT_QUART })`; `exitY = interpolate(frame, [exitStart, durationInFrames], [0, +120], { ..., easing: EASE_IN_QUART })`. `transform: translateY(${enterY + exitY}%)`. Banner enters from below (slides up); exits downward.

Same `enterEnd = ceil(fps * 0.45)` and `exitStart = max(enterEnd + 1, durationInFrames - ceil(fps * 0.35))`. Same fade-in / fade-out windows aligned with the slide. No `Date.now()`, no `Math.random()`, no `setTimeout` — purely frame-derived.

### D-T324a-6. Sliver mode skips entrance animation

`mode: 'sliver'` renders steady-state immediately at `frame=0` — the persistent register Fox uses during all breaking coverage per `fox-news-alert.md` line 25 ("Persistent 'Fox News Alert' sliver remains visible during nearly all breaking coverage"). No entrance slide; no fade-in; the sliver is visible at full opacity from the first rendered frame.

Implementation: when `mode === 'sliver'`, the slide-axis math is skipped (`translateX`/`translateY` set to `0`; `opacity` set to `1`). The `slideAxis` prop is still accepted (for schema uniformity) but is functionally a no-op when `mode === 'sliver'`. Document this in the component header.

Rationale: Fox's posture is **persistent register**, not **entrance animation**. Bolting a slide on the sliver violates the canonical posture per the consumer stub. If a Reviewer demands a sliver-with-entrance variant → escalate; that's a v2 enum extension (e.g., `mode: 'sliver-animated'`).

### D-T324a-7. Casing transform — applies to `headline` only

Per the two consumer stubs (`cnn-breaking.md` line 33: *"UPPERCASE headline"*; `fox-news-alert.md` line 35: *"Mixed Case headline"*): top-level optional `casing?: 'as-is' | 'uppercase' | 'lowercase' | 'title-case'` (default `'as-is'`). Applied to the `headline` text only (NOT the `label.text`) via JS string transform at render time (no CSS `text-transform` — keeps the rendered text byte-stable for parity goldens).

Mirrors caption.tsx D-T316-13 + lyrics.tsx D-T322-12 verbatim. Title case is naive ASCII (capitalize first letter of each whitespace-separated token); locale-aware title casing is v2.

CNN register sets `casing: 'uppercase'` to render `'severe storms hit Florida coastline'` as `'SEVERE STORMS HIT FLORIDA COASTLINE'`. Fox register defaults to `'as-is'` to preserve `'Five Killed in DC Plane Crash'`. The `label.text` is rendered verbatim regardless of `casing`; presets that want UPPERCASE labels pass uppercased strings ("BREAKING NEWS").

### D-T324a-8. Theme slots — `background` + `headlineColor` only

Mirrors lower-third.tsx + caption.tsx + lyrics.tsx posture: every color prop is **optional**; theme slot fills in when absent.

```ts
themeSlots: {
  background: { kind: 'palette', role: 'background' },
  headlineColor: { kind: 'palette', role: 'foreground' },
}
```

Top-level optional color props with theme fallback: `background?` (banner backdrop) → `palette/background`; `headlineColor?` (headline text) → `palette/foreground`.

`label.fill` + `label.color` + `endCap.fill` are **required** (no theme fallback). Rationale: they are preset-specific brand-anchored colors (red badges, Prussian Blue sliver fill) and should not silently drift to theme defaults. Cluster owners pass explicit hex per the consumer stubs.

### D-T324a-9. Default font — `'Plus Jakarta Sans, sans-serif'` weight 800

Matching the T-183 / T-183z cluster precedent — Bold (800) for breaking-news labels and headlines. Override via `font` prop per T-183z pattern (consumer presets pass e.g. `{ family: 'Bebas Neue, Impact, sans-serif', weight: 700 }` for the canonical CNN look).

`fontRequirements: () => [{ family: 'Plus Jakarta Sans', weight: 800 }]` — mirrors lower-third's font requirement registration.

### D-T324a-10. Determinism

Frame-derived only. No `Date.now()`, no `Math.random()`, no `crypto.randomUUID()`, no `setTimeout`, no `setInterval`, no `fetch`. Stable IDs not needed (single instance per composition; no clipPath / filter generation in v1 — the banner is a flat `<div>` tree, not SVG `<text>`-with-clipPath like caption.tsx / lyrics.tsx).

`scripts/check-determinism.ts` globs `packages/runtimes/*/src/clips/**/*.{ts,tsx}` — the new file is automatically in scope. No gate plumbing needed. Verifies via the determinism test (render the same props twice at the same frame; HTML byte-identical).

### Primitive shape (AC #1–#13)

2. `breakingBannerPropsSchema` (Zod) accepts the 12 fields per D-T324a-4 (`mode`, `headline`, `label`, `background`, `headlineColor`, `endCap`, `slideAxis`, `insetBottomPx`, `sliverAnchor`, `sliverWidthPct`, `borderRadius`, `font`, `casing` — all optional except `headline` and `label`). 3. `breakingBannerClip` is `defineFrameClip<BreakingBannerProps>({ kind: 'breaking-banner', component: BreakingBanner, propsSchema: breakingBannerPropsSchema, themeSlots: { background: { kind: 'palette', role: 'background' }, headlineColor: { kind: 'palette', role: 'foreground' } }, fontRequirements: () => [{ family: 'Plus Jakarta Sans', weight: 800 }] })`.

6. `mode: 'sliver'` skips the entrance animation: at `frame=0`, the sliver renders at full opacity with `translate*(0)` — visible immediately. The sliver anchors per `sliverAnchor` (default `'top-left'`) at width `sliverWidthPct * frameWidth` (default `0.30`).
7. `slideAxis: 'vertical'` (banner mode) translates Y instead of X: enters from `+100%` translateY, exits to `+120%` translateY. Same easing curves; same windows.
8. `casing: 'uppercase'` renders `headline = 'severe storms hit Florida coastline'` as `'SEVERE STORMS HIT FLORIDA COASTLINE'` in the headline text. `casing: 'title-case'` capitalizes the first letter of each whitespace-separated token (naive ASCII). `casing: 'as-is'` is the no-op default. The `label.text` is rendered verbatim regardless of `casing`.
9. `endCap`, when present, renders a colored block of `endCap.fill` at the `endCap.position` end of the banner (verifiable via a `data-testid="breaking-banner-endcap"` element). When absent, no end-cap element renders.
10. `font` prop, when present, overrides the default `'Plus Jakarta Sans, sans-serif'` family + `800` weight on both the label and headline text.
11. `borderRadius` prop applies to the banner backdrop (and sliver backdrop) via inline `borderRadius: <px>`. Default `0`.
12. Theme slots `palette/background` + `palette/foreground` provide defaults when their corresponding optional props (`background`, `headlineColor`) are absent; explicit prop colors win when set (per D-T324a-8). `label.fill` + `label.color` + `endCap.fill` carry no theme fallback (required-only).
13. Frame-deterministic — same `frame` + same props → byte-identical DOM output. No `Date.now()`, no `Math.random()`, no `crypto.randomUUID()`, no `setTimeout`, no `setInterval`, no `fetch`.

## Implementer's notes

1. **Read `lower-third.tsx` first** before writing a line. It is the primary template for slide-axis math; T-324a mirrors its enterX/exitX shape verbatim, parameterized by axis. LOC yardstick: comparable to lower-third's 194 LOC plus the dual-mode (banner/sliver) dispatch and label-badge + endCap rendering. Target ~400–600 LOC.
2. **Read `news-ticker-bar.tsx` second** for full-width-band-of-frame layout reference (216 LOC). Skip its scrolling marquee math — banner mode is static (entrance + steady-state + exit), not scrolling.
3. **Schema first.** D-T324a-3 / D-T324a-4 / D-T324a-7 / D-T324a-8 / D-T324a-9 all affect schema shape. Conservative defaults (mode `'banner'`, slideAxis `'horizontal'`, casing `'as-is'`, font Plus Jakarta Sans 800, sliverAnchor `'top-left'`, sliverWidthPct `0.30`, borderRadius `0`, insetBottomPx `80`). Required: `headline`, `label`. All other fields optional.
4. **Slide-axis math.** Mirror lower-third.tsx's `enterX` / `exitX` exactly for `slideAxis: 'horizontal'`. For `slideAxis: 'vertical'`, swap the same shape to translateY: `enterY = interpolate(frame, [0, enterEnd], [+100, 0], ...)`; `exitY = interpolate(frame, [exitStart, durationInFrames], [0, +120], ...)`. Same easing curves; same windows. Apply via `transform: translateX(...)` or `translateY(...)` based on the axis.
5. **Sliver mode skips entrance.** When `mode === 'sliver'`, override the slide math: `translatePct = 0`; `opacity = 1`. The `slideAxis` prop is accepted but not consumed when mode is sliver. Document this in the component header.
6. **Banner full-width vs sliver partial-width.** Banner mode: outer container at `width: '100%'` (or `width: useVideoConfig().width`), anchored bottom via `bottom: insetBottomPx`. Sliver mode: outer container at `width: ${sliverWidthPct * 100}%` (or absolute pixel based on `useVideoConfig().width * sliverWidthPct`), anchored per `sliverAnchor` (top-left → `top: 0; left: 0`; top-right → `top: 0; right: 0`; etc.).
7. **Casing transform.** Apply via JS string transform (NOT CSS `text-transform`) for parity-golden byte-stability. Mirrors caption.tsx D-T316-13 + lyrics.tsx D-T322-12.
8. **Determinism is sacred.** No `Date.now()`, no `Math.random()`, no `crypto.randomUUID()`, no `setTimeout` / `setInterval`. Only frame-derived inputs are `useCurrentFrame()` + `useVideoConfig().fps` / `.width` / `.height` / `.durationInFrames`. No SVG `<clipPath>` / `<filter>` ID generation in v1 (the banner is a flat `<div>` tree).
9. **Theme-slot fallback discipline.** `background?` / `headlineColor?` fall back to theme palette/background and palette/foreground. `label.fill` / `label.color` / `endCap.fill` are required (no theme fallback) — they are preset-specific brand-anchored colors.
