# T-454 — `packages/runtimes/audience/`

**Branch**: `task/T-454-runtimes-audience`

## Goal

Ship `@stageflip/runtimes-audience` — the audience runtime tier extending
`interactive` per ADR-003 §D1. Implements the
`@stageflip/runtimes-contract` runtime registry interface; provides the
substrate the nine v1 audience clip families (T-461..T-471) plug into.
Concretely, ships:

1. **`AudienceMountContext` / `AudienceMountHandle` interfaces** — the
   audience-specific extension of T-306's `MountContext` / `MountHandle`:
   - Inherits `clip`, `root`, `permissions`, `tenantPolicy`,
     `emitTelemetry`, `signal`, `frameSource` from `MountContext`.
   - Adds `provider: AudienceBackendProvider` (resolved by the router at
     mount time per ADR-009 §D2; one provider per active session — the
     native provider T-478 or a vendor adapter T-479..T-483).
   - Adds `sessionId: AudienceSessionId` (the open session this mount
     attaches to; one per active audience clip on the slide).
   - Adds `voterToken?: string` (when this mount is a voter view) /
     `presenterToken?: string` (when this mount is the presenter view).
2. **`AudienceClient` — WebSocket client wrapping `provider.subscribe()`**:
   - Materializes the `AsyncIterable<AggregationSnapshot>` from
     `AudienceBackendProvider` into a JavaScript event-source.
   - Connects to `/v1/audience/ws/:sessionId` (the T-453 server) via the
     provider's transport (the native provider opens the socket; vendor
     providers translate).
   - Reconnect logic per ADR-009 §D6: 6 retries × max 30s; emits
     `LF-AUDIENCE-CONNECTION-LOST` (the eighth client-side loss flag) on
     budget exhaustion. The server enforces a parallel budget via the
     `ReconnectBudget` from T-453.
   - On successful reconnect, the client re-subscribes and the renderer
     resumes from the new snapshot.
3. **`StaticFallbackRenderer` — reads `AudienceProvenance` and emits a
   deterministic frame** per ADR-010 §D4:
   - Three snapshot-selection policies: `final` / `peak` / `at-frame`
     (the provenance carries `snapshotPolicy: 'final' | 'peak' | 'at-frame'`).
   - Pure layout passes for `LivePoll` / `LiveQA` / `LiveQuiz` /
     `Leaderboard` / `Survey` / `WordCloud` (computed by per-clip-kind
     factory T-461..T-466).
   - Raster blend for `Heatmap` (T-467 factory; this PR provides the
     hook).
   - ShaderClip pass for `ReactionStream` (T-468 factory; this PR
     provides the hook).
   - P14-cache fetch for `AudienceAiPrompt` (T-469 factory; this PR
     provides the hook).
   - Implementation deferred to per-clip-kind factories (T-461..T-471);
     T-454 ships the dispatcher + the `staticFallback(snapshot,
     context)` signature.
4. **`AudienceRuntime` — runtime contract impl + clip registry**:
   - Implements `@stageflip/runtimes-contract` (`tier: 'live'`,
     `kind: 'audience'`).
   - Empty clip registry on landing — T-461..T-471 register their clip
     kinds via `registerAudienceClip(kind, factory)`. The registry
     pattern mirrors the `interactive` runtime's `registerInteractiveClip`.
   - Composition-time `findClip(kind)` resolution per the runtime
     contract.
5. **Three-state routing** per ADR-010 §D8:
   - `live` — clip mounted with a session; renders via WebSocket
     subscription.
   - `staticFallback` — clip with `AudienceProvenance` only (no session);
     renders deterministically from the inlined snapshot.
   - `empty-live-mount` — audience clip placed in editor authoring with
     neither session nor provenance; renders a "no live data yet" hint
     (factory-specific). T-454 provides the dispatcher branch; per-clip
     hint visuals land in T-461..T-471.
6. **Loss-flag emission** for `LF-AUDIENCE-CONNECTION-LOST` per ADR-009
   §D11 (the eighth code; the other seven are server-side per T-453):
   - Emitted when the reconnect budget exhausts (`6 retries × 30s` per
     ADR-009 §D6).
   - Uses the existing loss-flag plumbing (`@stageflip/loss-flags`
     emission per the package contract); imports `LF_AUDIENCE_CODES`
     from `@stageflip/audience-contract` (T-452).

**Strict scope** — runtime substrate only. NO concrete clip
implementations (T-461..T-471 ship the nine clip families: LivePoll
multi-choice/open-text/rating, LiveQA, LiveQuiz, Leaderboard, WordCloud,
Survey, Heatmap, ReactionStream, AudienceAiPrompt). NO concrete
`AudienceBackendProvider` (T-478 native; T-479..T-483 vendor adapters).
NO host integration (the editor / renderer-core wiring is downstream).
NO CI permission rule (T-455). NO Cluster I preset cluster (T-486). NO
parity fixtures (T-476).

## §13 (structural extension) statement

**NOT a structural extension.** This task adds a new runtime package
implementing the existing `@stageflip/runtimes-contract`. It does not
add a new degree of freedom to the document model, the binding model, or
the renderer pipeline; the `AudienceClipKind` discriminants are already
on the schema-side `RIRElement` union via T-451 / ADR-010. The
`AudienceProvenance` field on `Document.research` (or wherever ADR-010
§D5 wires it) is the structural extension owned by T-460 — that PR
bears the §13 obligation.

Render verification N/A at the substrate level (no concrete clip
factories ship in this PR; the dispatcher branches are tested via mock
factories). Per-clip render verification is owned by the nine clip
implementations (T-461..T-471), each of which bears the §13 obligation
for its discriminant.

## Implementation notes

- **Determinism perimeter**: `packages/runtimes/audience/**` is INSIDE
  the perimeter. The `AudienceClient` IS the non-deterministic surface;
  isolate it in one module. The `staticFallback` path MUST be free of
  banned primitives (no `Date.now`, no `Math.random`, no `fetch`, no
  `setTimeout`). Tests run under the determinism shim. If you need a
  clock for the reconnect-budget timer in `AudienceClient`, use
  `// determinism-safe: WebSocket reconnect timer — non-deterministic
  by ADR-009 §D6 design; lives behind the AudienceClient boundary` on
  the exact line and cite ADR-009 §D6.
- **Audience client implementation**: prefer a thin wrapper over the
  provider's `subscribe()` iterator rather than direct WebSocket calls.
  The native provider (T-478) implements the WebSocket; vendor providers
  (T-479..T-483) translate vendor APIs. The client is provider-agnostic.
- **Reconnect-budget timer**: 6 attempts × `min(2^attempt × 1s, 30s)`
  exponential backoff per ADR-009 §D6. Tests use a fake-timers approach
  — inject `setTimeoutFn: typeof setTimeout` into the client constructor
  so tests can advance time. Default `setTimeoutFn: setTimeout`
  (production) with the determinism-safe comment per above.
- **Static-fallback dispatch**: a `Map<AudienceClipKind, (snapshot,
  context) => RenderOutput>` registry. Empty on instantiation; T-461..T-471
  populate via per-kind `registerStaticFallback(kind, factory)`. The
  dispatcher emits `LF-AUDIENCE-SNAPSHOT-MISSING` if the snapshot is
  absent (the provenance was attached but the `aggregation` is `null` /
  malformed); this matches ADR-009 §D11.
- **Registry pattern**: mirrors `packages/runtimes/interactive/src/registry.ts`
  verbatim, swapping `InteractiveClip` for `AudienceClip`. The audience-clip
  type lives in T-460 (`@stageflip/schema`) but T-454 doesn't depend on
  that — it uses the `AudienceClipKind` const-array from
  `@stageflip/audience-contract` (T-452) as the registry key universe.
- **File headers**: every NEW file starts with `// path/to/file.ts` +
  one-line purpose, per CLAUDE.md §3.
- **TSDoc**: on every new exported function / interface / type.
- **No `console.log`**: anywhere in the runtime package.
- **No `any`, no `@ts-ignore`** without justifying comment.
- **`noUncheckedIndexedAccess` + `exactOptionalPropertyTypes` strict**.
- **Pre-empt skills-sync drift** (lesson hit 5+ times in this loop):
  run `pnpm skills-sync` before committing. If audience-tier SKILL
  pages reference the runtime's surface, the sync updates them; commit
  those.
- **Biome format** every touched file before commit (lesson
  `feedback_biome_format_before_commit.md`).
- **NEVER `git add -A`** (lesson `feedback_git_add_specific_paths.md`).
- **Workspace `pnpm-lock.yaml`** — the new package depends on existing
  workspace packages; no new external deps. Re-run `pnpm install` if
  needed and commit the lockfile changes.
