## Architectural decisions

### D-T336-1. Compass-register match

Stub describes a **top-of-screen** complex multi-line panel (~40–50% frame width) carrying simultaneously: batting team score (runs/wickets), overs, current + required run rates, both batsmen (name + runs + balls + on-strike marker), current bowler (name + figures), partnership, plus team-color dominant accents (India `#0066B3` / Australia `#FFCD00`). T-332a's `'cricket'` branch supports all of these natively:

- Multi-row complex panel → cricket branch renders `team` (line 519) + `runrate` (line 558) + `batsmen` (line 567) + `bowler` (line 584) + `partnership` (line 593) as stacked rows inside the rooted `<div>`.
- Top-of-screen anchor → `props.anchor: 'top-center'` enum value (primitive line 151).
- Team color dominant → `battingTeam.color` renders as background of code chip (line 532); `bowlingTeam.color` mirrored on the right (line 545).
- Score `runs/wickets` → `${team.runs}/${team.wickets}` rendered verbatim (line 539).
- Overs → `(${team.overs} ov)` rendered verbatim (line 540).
- Run rate / required run rate → `RR` and `· RRR` labels with verbatim values (lines 562–563).
- Batsmen with on-strike marker → `* ` prefix when `onStrike: true` (line 576); name + runs + `(balls)` formatted (line 577–578).
- Bowler → name + figures (line 589).
- Partnership → `P/S` label + verbatim string (line 598).

Ball-by-ball dot row is NOT part of T-336 — T-358 cricket-ball-by-ball-dots ships that as a separate preset using the `outcome-row` primitive. The two presets compose externally at the host level (one above, one below).

### D-T336-4. Snapshot constants `CRICKET_SCOREBUG_PROPS`
