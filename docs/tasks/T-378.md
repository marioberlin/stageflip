### D-T378-3 — static-fallback content surface (label + sublabel + nba-red accent border)

The primitive's static-fallback render path (D-T375a-5) renders a centered card on a backdrop with optional 1px accent border + an "AR · STATIC FALLBACK" badge bottom-right. The preset binds:

```ts

  },
  font: {
    family: "'NBA Brand', 'Inter', system-ui, -apple-system, sans-serif",
```

Per stub frontmatter lines 7-13 — NBA brand custom face is `proprietary-byo`; Inter OFL is the rendered fallback (its bold weights + tabular figures match the player-numbers + stats register per stub line 32). The primitive renders the label at fixed 48px (per D-T375a-5); the preset's `font` declaration governs the family stack.

**Visual differentiation from sibling Cluster H presets:**
- Sky Sports: navy backdrop (`#0A1128`) + Premier League purple accent border (`#38003C`) + `'Sky Sports Sans', 'Inter'` font stack — register: pitch-anchored formation lineup.
- Hawk-Eye VAR: PL purple backdrop (`#34003A`) + decision-green accent border (`#00FC8A`) + `'Premier Sans', 'Champions', 'Space Grotesk'` font stack — register: VAR offside-decision moment, dramatic suspense beat.

All four presets ship the SAME primitive (`arOverlay`) but render visually distinct cards — broadcaster brand canon lives in the per-preset binding, not the primitive (per D-T375a-3).

### D-T378-5 — Live-mount permission posture: `permissions: ['camera-tracking']`

Per stub line 42 ("Court-anchored overlay requires camera tracking. Without it, fall back to a 2D court diagram with shot chart"), the binding declares `permissions: ['camera-tracking']` to reserve the schema slot for the post-T-397 live-mount path's camera-tracking surface.

The `'camera-tracking'` permission is a valid value on the primitive's `permissionEnum` (`packages/runtimes/frame-runtime-bridge/src/clips/ar-overlay.tsx` line 118: `z.enum(['camera-tracking', 'live-data', 'network', 'audio'])`); no schema change is required.

**Differentiation from sibling Cluster H presets' permission declarations:**
- sky-sports-ar-formations (T-375): `permissions: ['camera-tracking']` — Zero Density / Stype tracking source data (camera-side).
- hawkeye-var-3d-skeletal (T-376): `permissions: ['camera-tracking']` — Hawk-Eye limb-tracking source data (camera-side).
- olympic-swim-lane-track (T-377): `permissions: ['network']` — Omega Vionardo timing-feed network access (data-side).
- **nba-ar-replay (this PR): `permissions: ['camera-tracking']`** — court-anchored 3D AR overlay requires camera tracking per stub line 42 (camera-side, like sky-sports + hawkeye-var; NBA shot-arc projection requires court-coordinate tracking, not network-bound timing data).

The stub frontmatter `permissions: []` is intentionally empty (the stub author left it as a TODO for the consumer to fill from the rules section — line 42 makes camera-tracking explicit). The binding promotes this to `['camera-tracking']` per line 42's hard requirement.

This field is on the schema for forward compatibility (declared in T-375a's primitive `permissionEnum`; ignored at v1 render time per D-T375a-2). It will be consumed by the live-mount path post-T-397.

### D-T378-6 — frame 60 single-frame static; thresholds 36 / 0.93

Per stub line 49 — PSNR ≥ 36 dB / SSIM ≥ 0.93. Cluster H thresholds run looser than the cluster-norm 38/0.95 because the stub authorises that variance for "3D + slow-mo footage variance" — the v1 static-fallback render is byte-deterministic, so the looser thresholds carry no risk for the v1 register and reserve headroom for the post-T-397 live-mount path's expected variance (slow-mo replay footage at 25% speed introduces sub-frame timing variance; parabolic shot-arc draw-in animates over 800 ms; court-marker scale-in animates 250 ms each).

Reference frames per stub line 48 are 0 / 36 / 60 / 120 (slow-mo entry / arc drawing mid-trajectory / arc complete + marker / settled with stats); **single-frame golden at frame 60** for cluster-norm consistency with sibling sky-sports + hawkeye-var + olympic-swim presets (also frame 60). The "settled" register at frame 60 (arc complete + marker drawn + stats stable) is canonical across Cluster H presets. Multi-frame animated slow-mo-entry / arc-draw / marker-scale / vector-animate defers to T-378-animated.

NBA-specific threshold note: NBA has the tightest thresholds in Cluster H (36 / 0.93) compared to sky-sports (36 / 0.93), hawkeye-var (36 / 0.93), and olympic-swim (34 / 0.91). The looser olympic-swim thresholds reflected the network-bound timing-feed sub-frame variance; NBA's slow-mo + 3D variance is comparable to sky-sports + hawkeye-var. Use the stub's declared 36 / 0.93.
