# T-415 — ADR-007: Provider Seam Pattern (meta)

**Branch**: `task/T-415-adr-007-provider-seam`

## Goal

Ship the first Phase 14 α ADR — the meta-pattern that codifies the adapter contract every Phase 14 (Asset Generation), Phase 15 (Live Audience), and Phase 16 (Bundles & Marketplace) downstream task plugs into. The ADR defines the `AdapterDescriptor` shape, license-aware routing rules, sandbox model, the `ResearchSessionProvider` meta-interface, and the seven per-modality source-grounded provider classes (preserved scope for ADR-008 / T-416).

This is **the** Phase 14 hard gate — no T-417+ code lands until ADR-007 + ADR-008 (T-416) merge.

**Spec / ADR only — no code, no packages, no scripts, no CI.**
