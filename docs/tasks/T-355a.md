# T-355a — `magic-wall-panel` runtime-clip primitive (fullscreen layered hierarchical-data panel)

**Branch**: `task/T-355a-magic-wall-panel-primitive`

## Goal

Ship a generic frame-runtime-bridge clip — `magic-wall-panel` — that renders a fullscreen panel of N (1..56) labeled, color-shaded region tiles arranged on an absolute-positioned grid (`x` / `y` / `width` / `height` per region), each tile carrying a label + optional value + optional value-format-driven percentage / count, with a frame-derived per-region entrance stagger. The primitive is the missing piece that blocked T-355 (`magic-wall-drilldown`, Cluster E): T-355's D-T355-2 verified that no existing bridge primitive carries the broadcast magic-wall fullscreen layered hierarchical-data panel — `animated-map.tsx`'s file header (lines 1–11) explicitly pins it as SVG-fallback-only with a generic grid + decorative route + camera-pan progress, no region semantics, no party shading, no percentage labels; the dashboard family, `kpi-grid`, `comparison-table`, `financial-statement`, the chart family, and the cluster-E sibling carve-outs (`outcome-row`, `news-ticker-bar`, `standings-table`) are all the wrong shape.

T-355 surfaces the gap first, but the same primitive is needed across multiple clusters: Cluster E `magic-wall-drilldown` (election results: states / counties / precincts), Cluster A `msnbc-big-board` (broadcast big-board), Cluster B `uefa-starball-refraction` (sports playoff brackets / tournament drawer), Cluster C `twc-retrocast-8bit` + `twc-immersive-mixed-reality` (weather radar drilldown), plus future scientific heatmap / data-exploration presets. Building `magic-wall-panel` once as a reusable generic amortizes the cost across these clusters; per-cluster prop builders (party palettes, weather-radar bands, bracket-color schemes) live in `parity-cli` resolver shims, not in this primitive. Same pattern as T-358 → T-358a → T-358-retry, T-356 → T-356a → T-356-retry, T-357 → T-357a → T-357-retry.

T-355a is **S-sized**: ~250–350 LOC component + ~150–200 LOC tests + barrel + ~6 LOC catalog/manifest entries + changeset. Roughly the envelope of `standings-table` (T-357a, ~365 LOC) — fullscreen panel layout with absolute-positioned region tiles is comparable to a header + ranked-table dispatch. It does NOT touch T-355's preset markdown, the parity resolver entry, or the parity goldens — those land in the T-355-retry PR after this primitive merges.

## Architectural decisions

### D-T355a-1. Generic `magic-wall-panel` vs election-specific `election-map`

T-355a ships a **generic** primitive named `magic-wall-panel`, NOT an election-specific `election-map`. Rationale:

- "Fullscreen panel of N labeled, color-shaded region tiles + value labels" recurs across ≥4 cluster A/B/C/E preset families: election results (T-355), broadcast big-boards (Cluster A `msnbc-big-board`), sports playoff brackets / tournament drawers (Cluster B `uefa-starball-refraction`), weather radar drilldown (Cluster C `twc-retrocast-8bit` / `twc-immersive-mixed-reality`), plus future scientific heatmap / data-exploration presets. An election-specific clip would re-implement per cluster.
- Cluster-specific semantics (party color → tile fill, weather-radar band → tile fill, bracket-region → tile fill) belong in the `parity-cli` resolver's `buildProps` shim, not in the runtime primitive. The primitive accepts pre-resolved `{ id, label, value?, valueLabel?, color?, bounds }` regions.
- Genericity cost is moderate (~250–350 LOC vs the ~150–200 LOC an election-only clip might need). Reviewer should reject if `MagicWallPanel` grows cluster knowledge (e.g., `domain: 'election' | 'weather' | 'sports'` enums or hard-coded party palette).

Reviewer demand for election-specific naming → escalate per CLAUDE.md §6.

### D-T355a-2. Maximum region count — 56

`regions` array bounded `1..56`. Covers the canonical broadcast use cases:

- US states + DC = 51 (the canonical electoral panel).
- US states + DC + 5 territories (Puerto Rico, Guam, USVI, Northern Marianas, American Samoa) = 56 (full electoral / territorial panel).
- Sports playoff brackets cap below 32 (March Madness Round-of-64 collapses to 32 region cards by Round-of-32; UEFA bracket tops at 16 + 8 + 4 + 2 + 1 = 31).
- Weather radar regional drilldowns cap below 30.
- Scientific heatmaps cap below 50.

56 is generous headroom without forcing the renderer to compute scrollable inner-band geometry. Higher counts are corner cases (full county-level US map = ~3,000); a future preset needing >56 is a one-line bump after layout review.

### D-T355a-3. Region geometry — explicit `bounds` rectangles in v1; real SVG paths are a v2 follow-up

Each region carries a required `bounds: { x: number; y: number; width: number; height: number }` rectangle in canvas-pixel coordinates. The primitive renders each region as a `<div>` (or SVG `<rect>` — internal choice; DOM is the default per D-T355a-7) at its absolute-positioned bounds. v1 ships rectangles; real US state outlines / county shapes / projection helpers are out of envelope per T-355 D-T355-6 (requires asset pipeline + license-clean PD outlines + Albers-USA projection + topology-data dependency such as `us-atlas`).

The schema does NOT expose an optional `path?: string` SVG-path slot in v1 — adding it now invites half-implemented partial path support without a full asset pipeline. A future task (`T-XXXc` per T-355 prose) extends the schema additively when the pipeline lands.

The placeholder-rectangle posture is **visually distinct from a real map** (rectangular tiles arranged on a grid, not state-shaped polygons), but it carries every other element of the visual contract: region label, color shading, value label, percentage formatting, entrance stagger. T-355's parity golden bakes this in as the v1 contract.

### D-T355a-4. Value rendering — `valueFormat: 'percent' | 'count' | 'raw'` enum + optional `valueLabel` override

Each region carries an optional `value?: number` and an optional `valueLabel?: string`. The primitive's top-level `valueFormat?: 'percent' | 'count' | 'raw'` (default `'percent'`) drives format dispatch when `valueLabel` is absent:

- `'percent'` — `value` rendered as `${value.toFixed(1)}%` (e.g., `62.1` → `'62.1%'`). Trailing zero retained for tabular alignment.
- `'count'` — `value` rendered as `value.toLocaleString('en-US')` (e.g., `54000` → `'54,000'`). Integer thousands grouping.
- `'raw'` — `value` rendered as `String(value)` (e.g., `54` → `'54'`). No formatting.

When `region.valueLabel` is set, it wins over the format dispatch (lets a preset emit non-numeric labels like `'Too Close'` or `'CALLED'`). When `region.value` is absent AND `region.valueLabel` is absent, no value is rendered for that region.

Numeric-formatted cells (`'percent'` / `'count'` formats, OR `'raw'` when the value is a number) carry `font-variant-numeric: tabular-nums` per cluster-E convention (mirrors T-357a D-T357a-7) — column-edge alignment when multiple regions render numerics side by side.

### D-T355a-5. Per-region color override + theme-slot fallback

Each region's `color?: string` (hex, optional) tints the region tile fill. When absent, falls back to the theme `foreground` slot (the safe-but-bland default — every region rendered in the panel's foreground color is a degenerate but non-broken render). Cluster-specific palettes (party A blue, party B red, weather-band greens / yellows / reds, bracket-region team colors) live in the preset's `parity-cli` resolver `buildProps` shim per D-T355a-1.

v1 does NOT introduce tagged region kinds (`kind: 'party-a' | 'party-b' | 'tied' | 'undecided'`); that would couple the primitive to election semantics. The preset's resolver wires the hex literals into `region.color` slots. Mirrors T-357a D-T357a-5 verbatim.

### D-T355a-6. Theme slots vs explicit prop colors — explicit with theme-slot fallback

Mirrors `outcome-row` (T-358a D-T358a-4), `news-ticker-bar` (T-356a D-T356a-6), `standings-table` (T-357a D-T357a-6): every color prop is **optional**; theme slot fills in when absent. Cluster owners pass explicit hex (election Dem Blue / Rep Red, weather-band greens, team colors) or rely on the theme.

```ts
themeSlots: {
  background: { kind: 'palette', role: 'background' },
  foreground: { kind: 'palette', role: 'foreground' },
}
```

Top-level `background?: string` and `foreground?: string` props let cluster owners override the theme without touching theme tokens. Per-region `region.color` always wins over theme `foreground` when set. If `palette/foreground` or `palette/background` are not defined on the active theme, the bridge's slot resolution falls back per T-131a rules (Implementer verifies; if rules differ from spec, document + adjust).

### D-T355a-7. Entrance animation — `'stagger-rise'` default; `'fade'` simpler; `'none'` instant

Each region's entrance is computed purely from frame:

```ts
// region i, default 'stagger-rise':
const delayFrames = (i * staggerMs) / (1000 / fps);
const t = interpolate(frame - delayFrames, [0, 12], [0, 1], {
  extrapolateLeft: 'clamp',
  extrapolateRight: 'clamp',
});
const opacity = t;
const translateY = (1 - t) * 12;  // 12 → 0 px (rises)
```

Default `staggerMs: 60` means at 30 fps the 56th region settles by `frame ≈ 12 + 55 × (60 × 30 / 1000) = 111`. Well past T-355's canonical mid-hold frame 60 for the eight-region top-level snapshot (eighth region settles by `frame ≈ 12 + 7 × 1.8 ≈ 25`).

Three `entrance` modes:

- `'stagger-rise'` (default) — fade + 12 px rise per region; per-region delay per row index.
- `'fade'` — fade only (no translation); per-region delay per row index.
- `'none'` — every region renders at full opacity at frame 0; entrance baked off.

No `setTimeout` / `Date.now()` / `Math.random()`; pure frame-derived.

### D-T355a-10. NO drilldown / zoom transitions in v1 — single-state render only

Drilldown (state → county → precinct) and zoom transitions (camera-pan + scale ease-in-out) are **runtime composition concerns** per ADR-003 §D2. The runtime drives state transitions across multiple `magic-wall-panel` renders (e.g., LiveDataClip's host-driven state machine swaps the `regions` prop between snapshots, with crossfade / scale composed at the layer-stack level). The primitive renders **one level** of the hierarchy at a time.

v1 does NOT expose `hierarchyLevel: 'top' | 'mid' | 'leaf'` as a render-gating prop — even if T-355's resolver passes it as a documentation field, the primitive ignores it (no behavioral impact). A future task may add zoom-coordinate animation hooks; out of envelope.

### D-T355a-11. Title + subtitle — optional top-of-panel slots

Optional `title?: string` and `subtitle?: string` render at the top of the panel (above the region tiles). When absent, region tiles fill the panel from `panelPadding` top edge. When present:

- `title` — large heading, centered, theme `foreground` color.
- `subtitle` — smaller secondary line below title, centered, theme `foreground` color at 70% opacity.

This lets presets emit a panel header (e.g., `"2024 Presidential Election — State Results"` + `"Updated: 11:42 PM ET"`) without composing a separate text clip. Mirrors `news-ticker-bar`'s optional title posture.

5. **Render at frame 0 with `entrance: 'none'` produces title + region tiles at their bounds** — render `<MagicWallPanel title="2024 Election" regions={<3 with bounds>} entrance="none" />`; assert title text present; assert three region tiles with data-testid `magic-wall-panel-region-CA/TX/NY`; assert each tile's style includes `left: <bounds.x>px; top: <bounds.y>px`.
6. **`valueFormat: 'percent'` renders e.g. `'62.1%'`** — region with `value: 62.1`, `valueFormat: 'percent'`; assert tile body text matches `/62\.1%/`.
7. **`valueLabel` overrides format** — region with `value: 62.1`, `valueLabel: 'CALLED'`, `valueFormat: 'percent'`; assert tile body text matches `/CALLED/` (NOT `/62\.1%/`).
8. **Per-region `color` applies** — region with `color: '#0044CC'`; assert the rendered tile carries that fill (style or computed style).
9. **Theme `foreground` falls back when `region.color` absent** — region without `color`; assert the rendered tile's fill matches the panel's `foreground` (or the bridge's resolved theme slot).
10. **Stagger-rise entrance: low opacity at frame 0, full opacity at large frame** — render `<MagicWallPanel regions={<8>} entrance="stagger-rise" />` at `frame=0`; assert region 0's opacity is near zero. Re-render at `frame=120`; assert every region's opacity === 1.
11. **`entrance: 'none'` renders all regions at full opacity at frame 0** — render with `entrance: 'none'` at `frame=0`; assert every region's opacity === 1.
12. **Determinism** — render the same props twice at frame 60; rendered HTML strings byte-identical (catches accidental `Date.now()` / `Math.random()`).
