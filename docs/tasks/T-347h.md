# T-347h — `imrStaticFallback` primitive + `twc-immersive-mixed-reality` preset

Combined primitive carve-out + preset implementation. **Closes Cluster C to 6/6 ELIGIBLE** once shipped (alongside T-347c/d/e/f/g).

The TWC IMR (Immersive Mixed Reality) canon is fundamentally a Track A frontier feature: live 3D rendering via `ThreeSceneClip` (Unreal Engine + Zero Density Reality Engine + Mo-Sys StarTracker per stub line 34). Per stub line 41, the explicit static-fallback allowance ("fall back to a high-quality pre-composited video if frontier is not enabled") authorizes a v1 static-only register — same posture as T-353 severance-surreal-3d's stub-canon-explicit static-fallback allowance for `ThreeSceneClip` deferral.

T-347h introduces a dedicated `imrStaticFallback` primitive that captures the static-fallback canon (storm-gray backdrop + foreground severity HUD with danger-red callouts) without attempting to render the live 3D scene. The live IMR path defers to a Track A follow-up (`T-347h-three-scene` / `ThreeSceneClip` integration per ADR-005).

## Decisions

### D-T347h-1 — new primitive `imrStaticFallback` (single-style v1)

Static-fallback-only v1. Single-object schema (no `discriminatedUnion` — single consumer + single static register). The live `ThreeSceneClip` IMR path is a Track A frontier feature deferred to T-347h-three-scene. v1 captures the fallback visual canon (storm-gray backdrop + severity HUD overlay).

Mirrors T-353 severance-surreal-3d's stub-canon-explicit static-fallback posture: ship the v1 static register; live 3D defers to a downstream task.

### D-T347h-2 — canonical palette baked as static module constants

Three exported palette constants:

- `IMR_STORM_GRAYS`: `['#1A1F26', '#2C3441', '#4A5566']` (deep-storm + mid-storm + light-overcast greys for backdrop gradient)
- `IMR_DANGER_REDS`: `['#CC0000', '#FF3333']` (severity callout primary + glow-edge per stub line 26)
- `IMR_DATA_FOREGROUND_WHITE`: `'#FFFFFF'` (data label foreground per stub line 30)

Per stub line 26 "storm grays + danger reds for severity; calmer blues / greens for non-severe register". v1 ships the SEVERE register (`scenario: 'severe'` is the default). The non-severe `'calm'` register is documented in the spec but defers a separate parity sign-off to a follow-up T-347h-calm if needed.

### D-T347h-3 — primitive prop surface

```ts
{
  // Sealed scenario enum — v1 ships 'severe' canon; 'calm' deferred.
  scenario: 'severe' | 'calm';

  // Severity callout — large UPPERCASE banner with 2px black stroke
  // per stub line 29.
  severity: {
    label: string;          // e.g. "TORNADO WARNING"
    location: string;       // e.g. "ATLANTA METRO"
    timestamp?: string;     // e.g. "ISSUED 4:12 PM EDT"
  };

  // Data labels — array of label/value pairs (mph, °F, ft) per stub
  // line 30.
  data: Array<{ label: string; value: string }>;

  // Optional storm-particle overlay density (0..1; per stub line 24
  // "physics-modeled particle systems" — v1 ships static-noise
  // approximation, not physics-driven).
  particleDensity?: number;

  // Optional position (defaults to full canvas).
  position?: { x, y, width, height };
  font?: { family, weight?, size? };
  background?: { from: string; to: string }; // overrides IMR_STORM_GRAYS
  foreground?: string; // overrides IMR_DATA_FOREGROUND_WHITE
}
```

### D-T347h-4 — backdrop: 3-stop storm-gray vertical gradient

Per D-T347h-2, the backdrop is a vertical linear-gradient through `IMR_STORM_GRAYS` (deep-storm at top → mid-storm → light-overcast at bottom). Approximates the photo-real-3D atmospheric depth without attempting actual 3D rendering. Frame-deterministic — pure CSS gradient.

### D-T347h-5 — particle overlay: deterministic SVG noise (no physics)

When `particleDensity > 0`, primitive renders ~`Math.round(particleDensity * 200)` SVG `<line>` segments at deterministic positions seeded from a closed-form PRNG (32-bit integer hash mixer per the grain primitive precedent). Approximates rain/snow/debris streaks; v1 is NOT physics-driven (per stub line 36 the canon is "physics-modeled" but that requires `ThreeSceneClip` — explicit deferral). Fixed seed = 0; same `(particleDensity)` → byte-identical SVG output.

### D-T347h-6 — severity callout: bottom-third HUD card

Renders an absolutely-positioned card at the bottom-third of the canvas:
- `severity.label` ALL CAPS, Bold Condensed 48px font-size, white with 2px black text-stroke (`-webkit-text-stroke: 2px black`)
- `severity.location` Bold 32px below
- Optional `severity.timestamp` Regular 22px right-aligned

Wrapped in a semi-transparent black panel (`rgba(0, 0, 0, 0.45)`) for legibility over the photo-real backdrop. Severity color band on the left edge in `IMR_DANGER_REDS[0]` (8px wide vertical bar).

### D-T347h-7 — data labels: top-right HUD strip

Right-aligned vertical strip of label-value rows per stub line 30 (Regular 22-28pt tabular). Label in `IMR_DATA_FOREGROUND_WHITE`, value Bold same color. Mid-range size 24pt.

### D-T347h-8 — typography per stub

Default `font.family: 'Inter Tight', system-ui, ...sans-serif` (Inter Tight OFL fallback for the proprietary TWC custom modernized typeface per preset frontmatter). Bold Condensed weight 700 for severity callout; Regular 400 for data labels.

### D-T347h-9 — frame 60 single-frame static; thresholds 36 / 0.93

Per stub line 47 PSNR ≥ 36 / SSIM ≥ 0.93. Reference frames `0 / 60 / 120 / 180`; single-frame golden at frame 60 (mid-camera-sweep / "settled" register). Multi-frame cinematic camera sweep deferred to T-347h-camera-sweep follow-up (requires per-frame transform animation; v1 single-frame static).
