# T-470 — `ReactionStreamClip`

**Branch**: `task/T-470-reaction-stream-clip`

## Goal

Ship the **ReactionStreamClip** family — the second Phase 15 marquee
differentiator. Voters tap emoji buttons; the renderer animates a
particle storm via the T-383 ShaderClip primitive. This clip
showcases the motion-platform: a shader-driven emoji stream that
Slido / Mentimeter / Poll Everywhere structurally cannot reach (per
ADR-010 §D7).

Per-kind shapes (already in `@stageflip/audience-contract`):

- Vote: `{ kind: 'reaction-stream', emojiId: string }` (the emoji
  comes from `clip.props.palette`).
- Aggregation: `{ emojiCounts: readonly { emojiId, count, recentBurst
  }[], totalReactions }`. `recentBurst` drives particle density;
  `count` accumulates lifetime tally.
- Rendering: a `<ShaderClipHost>` wrapper rendering a fragment shader
  that emits per-emoji particles. Uniforms: `uEmojiTex[N]` (texture
  per emoji palette entry), `uEmojiDensity[N]` (recent-burst-derived
  density per emoji 0..1), `uTime` (deterministic — derived from
  frame clock, NOT `performance.now()`), `uCanvasSize`.
- Voter UI: a row of emoji buttons (`clip.props.palette`). Tap emits
  `{ kind: 'reaction-stream', emojiId }`. **No disable after submit**
  — voters can tap repeatedly; the server-side rate-limit (T-458's
  per-voter 10 Hz override per ADR-009 §D3) bounds spam.

§13 verification is option-1 — `render-e2e.test.ts` drives the
static-fallback with a known emojiCounts snapshot + asserts:
1. `<canvas>` element present (rendered by ShaderClipHost).
2. The shader compiles + links (no error from `validateFragmentShader`).
3. After microtask wait, canvas's pixel data is non-blank where
   particles should be (per the spec's known densityvalues).
4. Determinism: same snapshot + same `localFrame` → same canvas
   pixels (verify via two-call equality, or skip if WebGL context
   not available in the test environment — document).

## Implementation notes

- **Schema**: `props: { prompt: z.string().min(1), palette:
  z.array(z.object({ emojiId: z.string().min(1), glyph: z.string().min(1) })).min(1).max(12),
  sessionId: z.string().optional() }`.
  - `palette`: each entry has `emojiId` (stable id used in vote
    payloads) + `glyph` (the actual emoji character or asset reference
    used for rendering).
  - `permissions: z.tuple([z.literal('audience-network')])`.
  - `provenance: audienceProvenanceSchema.optional()`.
- **`uniforms.ts`** — PURE function:
  ```ts
  export function computeReactionStreamUniforms(
    emojiCounts: readonly { emojiId: string; count: number; recentBurst: number }[],
    palette: readonly { emojiId: string; glyph: string }[],
    localFrame: number,
    fps: number,
  ): UniformsForFrame
  ```
  - For each palette entry, compute density = clamped(recentBurst /
    10, 0, 1) — the max burst is 10/s per the per-voter cap (per
    ADR-009 §D3 line 231 override for reaction-stream).
  - `uTime: localFrame / fps` (seconds; deterministic).
  - `uDensities: Float32Array(paletteLength)` — per-emoji density.
  - `uTotalReactions: float` — for global animation modulation.
- **`fragment.glsl.ts`** — fragment shader source string. Renders N
  emoji particle streams using a deterministic pseudo-random hash of
  `(uTime, particleIndex)`. The exact shader content can be a
  minimal scaffold: a few colored circles whose density scales with
  `uDensities[i]`. The v1 visual is a stand-in; future polish task can
  enrich it.
  - MUST start with `precision highp float;` per T-065.
  - MUST be deterministic — only `uTime` + `uDensities` + hash
    functions; NO `mod` of randomness.
- **Static-fallback rendering**: `<ShaderClipHost>` from T-383
  configured with the fragment shader + the computed uniforms. The
  static-fallback path uses `localFrame: 0` (the snapshot's "peak"
  frame); the live-mount path uses the actual frame from
  `ClipRenderContext.frame`. Per ADR-010 §D4: "ShaderClip pass at
  peak for ReactionStream".
- **Voter UI**: `<ReactionStreamVoterInput palette onSubmit>` — a
  row of `<button>` per palette entry; each renders the `glyph`. Tap
  emits `{ kind: 'reaction-stream', emojiId }`. NO client-side disable
  — repeated taps allowed; server rate-limits at 10 Hz per T-458.
- **Mirror T-469 exactly** for layout / tests / dispatcher registration.
- **Determinism perimeter**: same as prior — uniform computation
  pure; shader is deterministic by T-065 invariant.
- **Skip rendering tests gracefully** when WebGL is unavailable:
  jsdom/happy-dom do NOT support WebGL contexts. Tests should check
  `canvas.getContext('webgl')` and skip pixel-buffer assertions with
  a documented note if it returns null. The uniform determinism
  test does NOT require WebGL.
- **Pre-empt skills-sync drift**.
- **Biome format** the audience-runtime + apps/audience-join +
  schema directories ONLY (NOT workspace root — avoid the T-469
  golden-fixture incident).
- **NEVER `git add -A`**.
