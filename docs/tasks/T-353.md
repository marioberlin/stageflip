# T-353 — Preset: `severance-surreal-3d` (titleSequence, Cluster D)

**Branch**: `task/T-353-severance-surreal-3d`

## Goal

Promote the existing `severance-surreal-3d` preset stub from `status: stub` to `status: substantive` and ship it as the **fifth Cluster D (titles / opens / bumpers / credits) consumer preset** of the T-321 atmospheric-primitive carve-out roadmap, the **fourth multi-clip composition** in the parity-CLI (after T-348 `stranger-things-benguiat` introduced `ClipKindBinding.overlays?`, T-351 `true-detective-double-exposure` reused that surface, and T-352 `succession-home-video` reused it again), AND a **tertiary consumer of the T-321d `photographic-overlay` primitive** — exercising the sterile / muted / desaturated register of the canonical Severance look. T-353 ships the prestige-TV Severance S1 canon "sterile corporate" register: the **hyper-realistic 3D-rendered bodies / mid-century corporate-identity color palette** (stub line 23 — sterile color palette; muted neutrals; desaturated greens; occasional bright accent), warm-but-flattened tonal grading via `mode: 'cinematic-lut'` OR `mode: 'fade'` at moderate intensity (~0.4 — neither dominates the visual nor disappears; the photographic cast is the canonical "office corridor under fluorescent lighting" mood signal), subtle film grain at intensity ~0.10 (LOWER than the canonical 0.15 default — the corporate canon is "clean" vs Stranger Things' "mandatory grain" or Succession's "VHS chatter"; subtle hyperreal-3D grain still appropriate but explicitly subdued), tight-tracking corporate-identity typography (Severance custom face based on Helvetica + mid-century Massimo Vignelli era preferred, proprietary-byo; Inter Display 500 OFL fallback for v1 rendering), ALL CAPS at very-tight letter-spacing per stub line 31 (Bold, ALL CAPS, scaled large, very tight tracking; pick `letterSpacing: 0` — neutral — to anchor the mid-century-corporate-identity-manual register).

T-353 is the **fifth Cluster D consumer** of the T-321 carve-out roadmap. Three primitives ship in this composition (mirroring T-351 / T-352's 3-clip stack but with a different register: sterile/corporate, NOT cinematic-photo or VHS):

- **T-321** (parent) — `titleSequence` primitive with the `'photographic-overlay'` style register OR `'plate-and-credits'` register (D-T353-6 picks the cleanest match for the corporate credit hold).
- **T-321a** — `grain` primitive (deterministic xxhash32 per-pixel film-grain noise; **LOW intensity 0.10** — corporate canon is "clean"; opposite posture from T-352's HIGH 0.30 VHS chatter and SLIGHTLY-BELOW T-348/T-351's canonical 0.15 default).
- **T-321d** — `photographic-overlay` primitive (`mode: 'cinematic-lut'` for the muted-desaturated office register; intensity ~0.4 — moderate; tertiary consumer of the primitive after T-351 PRIMARY + T-352 secondary).

Cluster D is **4/6 signed** as of `main` HEAD `fd8bd3f3` (T-348 + T-350 + T-351 + T-352 all merged; T-349 + T-353 remain — both were originally ThreeSceneClip-dependent). **T-353 brings Cluster D to 5/6 signed.** After T-353, Cluster D will be one ThreeSceneClip-dependent task (T-349 got-trajan-clockwork) away from full closeout — and that task can leverage T-353-live-3d follow-up's primitive-side groundwork once filed.

T-353 is **L-sized** (matching T-348 / T-351 / T-352 envelope; L is driven by the same multi-clip composition surface, lowered thresholds, photographic-overlay register exercise, AND the documented v1-vs-canon divergence around the deferred live ThreeSceneClip integration). The L-size envelope is driven by:
1. Three primitive snapshots (titleSequence + grain + photographic-overlay), each requiring per-primitive prop tuning for the sterile-corporate register.
2. Lowered parity thresholds (PSNR ≥ 36 dB / SSIM ≥ 0.92 per D-T353-5 — TIGHTER than T-351's / T-352's 34 / 0.90 because T-353's register has LESS aggressive photographic engagement than its siblings: lower grain intensity 0.10 + moderate photographic-overlay 0.4 + sterile/flat color palette = more headroom).
3. **Documented divergence**: the canonical Severance sequence is a hyper-realistic 3D-animation register with surreal vignettes (bodies melting through walls / liquify into ooze; cloth simulation; camera dolly-ins) — fundamentally a live ThreeSceneClip rendering. **The stub explicitly accepts a static hero-frame fallback (stub line 39: "Use `ThreeSceneClip` for the live 3D path; static fallback is a hero frame from the canonical season variant")**. v1 ships ONLY the static photographic-overlay-graded credit hold (which captures the sterile-corporate MOOD via typography + tonal grading); the actual live ThreeSceneClip 3D rendering, the surreal melt-vignettes, the cloth simulation, and the S2 darker-register variants are all deferred to follow-up tasks (D-T353-1 / D-T353-9). The stub-explicit allowance is itself the L-grade rationale for a clean v1 ship.

## Why v1 ships static-fallback per stub-canon explicit allowance (NO live ThreeSceneClip integration)

The Severance register's most distinctive technical feature is **live 3D animation rendered via `ThreeSceneClip`** — surreal vignettes scripted at Cinema 4D + Houdini + Octane render quality, ~60 s of camera dolly-ins, bodies melting through walls / liquifying into ooze, cloth simulation hyper-detail (stub lines 35–38). Implementing this requires extending the `titleSequencePropsSchema` shot enum with a 6th `kind: 'threeScene'` discriminator AND modifying `title-sequence.tsx`'s per-shot dispatch to delegate to the interactive ThreeSceneClip primitive OR the bridge `scene-3d` clip — substantial primitive-side work spanning runtime tier decisions (live vs bridge), permission envelope, and static-fallback paths.

**Per `docs/tasks/T-321-carveout-audit.md` carve-out #5** — ThreeSceneClip integration into T-321 is documented as a `titleSequence` modification deferred to the FIRST consumer preset task (T-349 or T-353 — whichever lands first). The audit identifies it as L-sized work in its own right, distinct from the consumer preset envelope.

**Crucially, the Severance stub line 39 explicitly accepts a static hero-frame fallback**:

> "Use `ThreeSceneClip` for the live 3D path; **static fallback is a hero frame from the canonical season variant**"

This is the canonical posture — the stub canon DOES NOT mandate live 3D in the parity render; it explicitly enumerates a static hero-frame as an acceptable rendering. This is a **stub-canon-explicit allowance**, NOT a documented divergence. T-353 v1 ships the static-fallback path; the live 3D integration is deferred to T-353-live-3d follow-up WITHOUT canon violation.

**T-353 picks option (2)**, documented as D-T353-1 (mirrors T-351's option 2 deferral of the silhouette-as-window technique AND T-352's option 2 deferral of the videoShot shot-kind extension; all three Cluster D presets share the same shape — ship the static register canonically, defer the live primitive integration to a follow-up):

1. **Ship T-353 with full live ThreeSceneClip integration** — modifies `title-sequence.tsx`, extends shot enum with `kind: 'threeScene'`, threads ThreeSceneClip OR scene-3d delegation, requires hero-frame asset library for static-fallback paths. **L+ scope; bleeds into primitive-side modification AND a separate frontier-track ADR-005 review for live-tier vs bridge-tier delegation.**

**T-353 picks option (2)**, documented as D-T353-1. The visual register that ships in v1 captures the canonical Severance MOOD (sterile / corporate / mid-century-Vignelli typography + muted color palette) without the canonical Severance MEDIUM (live 3D animation). **Stub line 39 explicitly authorizes this posture** — no canon violation. **Reviewer should NOT demand actual live ThreeSceneClip rendering in this PR.**
