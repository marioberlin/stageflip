## Decisions

### D-T347f-1 — wired via DEFAULT_CLIP_KIND_RESOLVER (Pattern C clipKind-default arm)

First (and only v1) `stormTracker` consumer. Add `if (clipKind === 'stormTracker') return nhcConeOfUncertaintyBinding;` to the resolver's clipKind-default chain.

### D-T347f-2 — synthetic Atlantic hurricane "MARGOT"

`storm: { name: 'HURRICANE MARGOT', advisoryTimestamp: 'Advisory 18 — 5 PM EDT Mon' }`. ALL CAPS storm name banner per primitive default; advisory timestamp formatted per NHC convention.

### D-T347f-3 — 6 track dots with canonical D→S→H→M→H→S intensity arc

Forecast positions covering 0/24/48/72/96/120 hours, intensity progression D (depression) → S (storm) → H (hurricane Cat 1) → M (major Cat 3+) → H (post-peak weakening) → S (extratropical decay). Shows the full canonical forecast arc.

| `pos-0h` | 5pm Mon | (700, 460) | H |
| `pos-24h` | 5pm Tue | (760, 420) | H |

### D-T347f-4 — cone polygon widening over 5 days

Synthetic SVG path describing the cone of uncertainty — narrow at current position (∼20 px wide), widening along the forecast track to ∼160 px wide at the 120h endpoint. Default semi-transparent white fill (`#FFFFFF` at opacity 0.4 per primitive default). Anchored to the forecast track.

### D-T347f-5 — 3 coastal warnings (sealed warningType enum)

`coastalWarnings[]` carries 3 entries demonstrating the canonical NHC palette dispatch:
- **Florida coast** — `warningType: 'hurricane-warning'` (Crimson `#DC143C`)
- **Georgia / South Carolina coast** — `warningType: 'storm-surge-warning'` (Dark Purple `#B524F7`)
- **North Carolina coast** — `warningType: 'hurricane-watch'` (Magenta `#FF00FF`)

The synthetic SVG region paths are coastal-strip approximations sized to 1280×720; not pixel-accurate cartography.

### D-T347f-6 — synthetic SE US + Atlantic basin map

`mapPaths[]` carries 2 entries — SE US coastal silhouette (FL/GA/SC/NC), and a small Bahamas / Caribbean coastline strip — sized to 1280×720. Default fill `#22354F` (dark navy NHC base). Real-time NHC consumers wire higher-fidelity coastal geometry via T-347b-live-data when shipped.

### D-T347f-7 — typography per stub

Storm-name banner: 32pt Bold (top range of stub line 35 "Bold, 28-32pt"). Track-dot intensity letters: 20pt Bold (mid-range of stub line 36 "Bold, 18-22pt"). Time-stamp + disclaimer: 14pt Regular (mid-range of stub line 37). Open Sans OFL.

### D-T347f-8 — mandatory disclaimer per primitive D-T347b-2

The primitive emits `data-testid="storm-tracker-disclaimer"` for every render with default text `'Impacts extend beyond the cone'` — this preset uses the default. The disclaimer cannot be suppressed (the primitive's safety contract). Verifies §13 mandatory-disclaimer invariant under real consumption.

### D-T347f-9 — frame 60 single-frame static; parity thresholds 38 / 0.95

Per stub line 53 reference frames `0 / 30 / 60 / 120`, single-frame golden at frame 60 (3-day forecast register; canonical mid-arc state). PSNR ≥ 38 / SSIM ≥ 0.95 cluster-norm thresholds.

Multi-advisory animated time-lapse (1.5s per advisory step per stub line 42) deferred to T-347b-advisory-cycle.

`status: stub` → `status: substantive`. Body unchanged.
