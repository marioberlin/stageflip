# T-347g — `weatherStar4000Panel` primitive + `twc-retrocast-8bit` preset

Combined primitive carve-out + preset implementation. The existing `magic-wall-panel` primitive (which serves the `fullScreen` clipKind via `DEFAULT_CLIP_KIND_RESOLVER`) does NOT fit the WeatherStar 4000 register — the register is structurally different (L-bar sidebar, 8-bit pixel font, no anti-aliasing, period-authentic 30fps, deep-blue gradient + orange/gold accent palette). T-347g introduces a new primitive `weatherStar4000Panel` and binds the preset to it via `PRESET_ID_BINDINGS` (Pattern C override).

## Decisions

### D-T347g-1 — new primitive `weatherStar4000Panel` (single-style v1)

The WeatherStar 4000 register is structurally distinct from `magic-wall-panel`'s hierarchical-tile-drilldown register. Architecturally:

- **L-bar sidebar** on the left — signature pre-2019 TWC element
- **8-bit pixel font** (Press Start 2P fallback for WeatherStar 4000 canon)
- **Deep-blue gradient background** + orange/gold accent palette
- **Pixel-precise sizes** (8px increments, no fractional)
- **Optional CRT scan-line overlay** at 4% opacity

These constraints don't compose into magic-wall-panel's prop surface. New primitive is the right call.

Primitive `kind: 'weatherStar4000Panel'` (camelCase). Single-style v1 (no `discriminatedUnion` — single consumer); future TWC variants would extend to a sealed-style enum then.

### D-T347g-2 — canonical palette baked as static module constants

Three exported palette constants per cluster pattern:

- `WEATHER_STAR_BLUE_GRADIENT`: `['#000066', '#000099']` (deep-blue background gradient endpoints per stub line 24)
- `WEATHER_STAR_ORANGE_GOLD`: `['#FF9900', '#DAA520']` (accent bars per stub line 25)
- `WEATHER_STAR_FOREGROUND_WHITE_GOLD`: `['#FFFFFF', '#DAA520']` (temperature/label foreground options per stub line 26)

Per cluster SKILL.md the WeatherStar palette is canonical (TWC launched RetroCast in 2025 — first-class register, NOT theme-able). Caller-supplied palette overrides REJECTED.

### D-T347g-3 — primitive prop surface

```ts
{
  // Header banner — city + condition (e.g., "ATLANTA — PARTLY CLOUDY").
  header: { city: string; condition: string };

  // Temperature display — 32-48px pixel font; gold or white per stub line 26.
  temperature: { value: number; unit: 'F' | 'C'; foreground?: 'white' | 'gold' };

  // Optional metadata rows (label + value pairs) — humidity, wind, pressure, etc.
  // Each row uses 14-20px label font; sized in 8-px-step increments.
  metadata?: Array<{ label: string; value: string }>;

  // Optional bottom ticker scrolling at integer pixel speeds.
  ticker?: {
    items: string[]; // city/state segments separated by " • ".
    scrollSpeedPxPerFrame: 1 | 2 | 4; // sealed enum per stub line 38.
    frameOffset?: number; // for parity-fixture pinning of ticker position.
  };

  // L-bar sidebar (signature pre-2019 element). Default true.
  showLBar?: boolean;

  // Optional CRT scan-line overlay (subtle, 4% opacity per stub line 41).
  showCrtScanlines?: boolean;

  // Background gradient endpoints (defaults to WEATHER_STAR_BLUE_GRADIENT).
  background?: { from: string; to: string };

  // Foreground (defaults to WEATHER_STAR_FOREGROUND_WHITE_GOLD[0]).
  foreground?: string;

  // Optional position (defaults to full canvas).
  position?: { x, y, width, height };
}
```

### D-T347g-4 — pixel-precision rendering: integer-only sizes + `imageRendering: pixelated`

Per stub line 45 "Pixel-precision is non-negotiable: anti-aliased rendering breaks the register". The primitive renders all child elements with:

- Integer-pixel sizes (no fractional `font-size`, `width`, `height`)
- 8-px-step font sizes (16 / 24 / 32 / 40 / 48)
- CSS `image-rendering: pixelated` on text / borders where supported
- No CSS `text-shadow`, `box-shadow`, or `border-radius` (period-authentic flat blocks)

The primitive's reset CSS forces these on children regardless of caller props.

### D-T347g-5 — typography: 8-bit pixel font

Default `font.family: 'Press Start 2P, ...VT323, monospace'`. Press Start 2P is OFL (registered Google Font; license-cleared). Sizes: 32px (temperature large), 24px (city/header), 16px (metadata), 14px (ticker / labels). The primitive snaps any caller-supplied size to the nearest 8-px multiple.

### D-T347g-6 — frame-determinism

No `Date.now` / `Math.random` / `crypto.*` / `setTimeout` / `setInterval` / `fetch` / `requestAnimationFrame` / `addEventListener`. Ticker scroll position derived from `(frame, scrollSpeedPxPerFrame, items, frameOffset)` — closed-form integer math (no `useEffect` accumulation). Stable per-frame output.

### D-T347g-7 — preset binding: `PRESET_ID_BINDINGS['twc-retrocast-8bit']`

Preset frontmatter `clipKind: fullScreen` STAYS UNCHANGED (the existing magic-wall-panel clipKind-default arm continues to serve other fullScreen consumers). Per `PRESET_ID_BINDINGS` precedent (T-328 msnbc-big-board / T-339 uefa-starball-refraction), the override binding maps to a different primitive via `clipName: 'weatherStar4000Panel'`. This is exactly the pattern those bindings established.
