# T-369 — Preset: `youtube-subscribe-bounce` (subscribeButton, Cluster G)

**Branch**: `task/T-369-youtube-subscribe-bounce`

## Goal

Promote the existing `youtube-subscribe-bounce` preset stub from `status: stub` to `status: substantive` and ship it as the **first Cluster G (CTAs / social) preset to land** AND the **first consumer of the `subscribeButton` clipKind** in the parity-CLI resolver AND the **first production consumer of T-317's `'youtube'` platform bundle** in the just-merged `subscribe-button` runtime-clip primitive (main HEAD `1cc4da93`). The preset captures the YouTube native subscribe-button broadcast canon: a compact YouTube-Red `#FF0000` rounded pill anchored lower-right, white "SUBSCRIBE" label in Roboto Medium 500 forced uppercase, optional bell glyph in the post-press `'subscribed'` state, optional cursor glyph in the `'pressing'` state, settled steady-state at frame 60 (post-bounce-overshoot scale 1.00). Common uses: creator-monetization end-cards, mid-roll subscribe prompts on YouTube-anchored posts, "Don't forget to subscribe" lower-third bumpers.

T-369 is the **first** preset to bind the `subscribeButton` clipKind. The `'subscribeButton'` clipKind is in `VALID_CLIP_KINDS` (verified: `scripts/check-preset-integrity.ts` line 74) but has no entry in the parity-CLI resolver as of main `1cc4da93`. T-369 must therefore wire its binding via the **`PRESET_ID_BINDINGS` override map** keyed on `'youtube-subscribe-bounce'` — Pattern C from `docs/handover-phase13-cluster-b.md` §"Pattern C", consistent with the entire Cluster B cohort (T-333 / T-334 / T-335 / T-336 / T-337 / T-338 / T-339 / T-339a / T-332). The `DEFAULT_CLIP_KIND_RESOLVER` is **NOT** modified — there is no clipKind-default arm for `'subscribeButton'`, and T-369 does NOT introduce one (the override-only pattern matches T-339a/T-326/T-327's posture; clipKind-defaults are reserved for the all-presets-of-the-clipKind-share-a-binding case, which does not apply here since later Cluster G presets bind to other primitives — `follow-prompt` for tiktok-follow-pulse, `qr-code-bounce` for coinbase-dvd-qr).

T-369 is the **first production consumer of T-317's `'youtube'` platform bundle**: T-317 (just merged at `1cc4da93`) shipped the `subscribe-button` primitive with four sealed platform branches (`'youtube'` / `'tiktok'` / `'instagram'` / `'generic'`); T-369 is the first preset to bind the `'youtube'` discriminant to a parity golden. T-371 / T-373 (sister Cluster G presets) bind a different primitive (`follow-prompt` / T-318) — they will NOT exercise the remaining `subscribe-button` platform branches. The TikTok / Instagram / Generic branches will get production consumers via separate v2 preset additions (none in v1 Cluster G).

T-369 is **M-sized** — same envelope as T-333, T-334, T-336, T-337, T-339, T-339a. ~30–40 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. No primitive carve-out; no schema change. Inherits the Cluster B `PRESET_ID_BINDINGS` shape end-to-end.

Cluster G is currently **0/5 signed** as of main `1cc4da93`. T-369 brings it to **1/5**. The remaining four (T-370 instagram-link-sticker, T-371 tiktok-follow-pulse, T-372 coinbase-dvd-qr, T-373 social-handle-lower-third — verify exact T-numbering against `docs/implementation-plan.md` before pinning) ship in their own preset PRs.

## Architectural decisions

### D-T369-1. Compass register match — YouTube-Red `#FF0000` rounded pill + white "SUBSCRIBE" + Roboto Medium 500 + drop shadow + lower-right anchor

The stub (lines 22–43) defines the canonical YouTube subscribe-button register:

- **Position**: lower-right or lower-left, ~15–20% of screen width (line 29). T-369 anchors at `position: { x: 1480, y: 920 }` — lower-right of a 1920×1080 canvas, leaving ~440 px to the right edge after a ~220 px button width AND ~160 px to the bottom edge. Mirrors the YouTube native end-card placement convention.
- **Primary fill / chrome**: YouTube Red `#FF0000` (line 24) — rendered by the `'youtube'` branch as the hard-bound background (brand canon dominates theme per D-T317-6); `background?` prop is no-op but accepted for schema uniformity.
- **Text**: white `#FFFFFF` "SUBSCRIBE" (line 25) — rendered by the primitive's hard-bound foreground; force-uppercased per D-T317-8 regardless of `casing` prop.
- **Border-radius**: 8 px native (stub line 23) — matches the primitive's `YOUTUBE_BORDER_RADIUS = 8` default; T-369 inherits the default (does NOT override `borderRadius`).
- **Drop shadow**: `0 / 4 px / 8 px blur, 20% opacity black` (stub line 30) — matches the primitive's `YOUTUBE_DROP_SHADOW = '0 4px 8px rgba(0, 0, 0, 0.20)'` default; T-369 inherits the default (`dropShadow` left absent — primitive default is `dropShadow !== false`, so the shadow renders).
- **Typography**: Roboto Medium 500 at 18 px native (stub lines 32–34) — matches the primitive's `YOUTUBE_FONT_FAMILY = 'Roboto, sans-serif'` / `YOUTUBE_FONT_WEIGHT = 500` / `YOUTUBE_FONT_SIZE = 18` defaults; T-369 inherits the defaults (does NOT override `font`).
- **Phase**: default `'idle'` (line 38: "Entry: scale 0% → 100% with bounce overshoot to 110%, 400–600 ms"). T-369's parity golden is rendered at frame 60 (well past settle frame 15 at fps 30) — the bounce is COMPLETE; scale clamps to 1.00 via `extrapolateRight: 'clamp'`. The render is byte-identical to a static-layout snapshot.
- **Solid background (no transparency)**: implicit — the primitive renders 100% opacity by default. Aligns with the YouTube-canonical opaque-pill register.

T-369 binds these to the existing `subscribe-button` primitive's `'youtube'` branch (T-317). The mapping:
