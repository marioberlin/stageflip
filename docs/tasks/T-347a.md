## Decisions

### D-T347a-1 — sealed style enum, single primitive

3 distinct visual registers ship as one `weatherMap` primitive with a sealed `style: 'mark-allen-clouds' | 'doppler-radar' | 'heat-map'` discriminator. Per-style content + canonical palette baked as static module-level constants (NOT theme-able per cluster SKILL.md "Color palettes are standard, not brand").

Mirrors T-321 `titleSequence`'s 4-style architecture: one primitive, sealed style enum, per-style render dispatch.

**Rejected**: shipping 3 separate primitives (`bbc-weather-map`, `doppler-radar`, `temperature-heat-map`). Each style shares enough surface (region labels, legend, base map, time-period transitions) that 3 primitives would triplicate code; the sealed-enum pattern is the established Cluster D / F approach.

### D-T347a-2 — discriminated union on style for content shape

Each style has distinct content shape:
- `mark-allen-clouds`: `symbols: Array<{ kind: 'cloud' | 'sun' | 'raindrop' | 'snow', position, scale? }>`
- `doppler-radar`: `productMode: 'reflectivity' | 'velocity'`, `loopFrameIndex: 0..N`, optional sweep beam phase
- `heat-map`: `units: 'F' | 'C'`, `oscillation?: boolean` (Meriam light-dark across classes)

Common across styles: `regions: Array<{ id, name, dataValue, screenPosition }>`, `legend?: { enabled, position }`, `font?`, `background?`, `position?: { x, y, width, height }`.

Schema: `z.discriminatedUnion('style', [...])` per the established T-321 + T-317/T-318 pattern.

### D-T347a-3 — canonical palettes baked as static module constants

Three palette constants exported for parity-cli + downstream consumers to reference:

- `MARK_ALLEN_TEMPERATURE_DISCS`: `['#0000FF', '#00B0FF', '#00FF00', '#FFFF00', '#FFA500', '#FF0000']` (blue→red gradient on temperature discs).
- `DOPPLER_DBZ_REFLECTIVITY`: `['#00BFFF', '#00FF00', '#009900', '#FFFF00', '#FFA500', '#FF0000', '#FF00FF']` (universal NEXRAD canon; do-not-rebrand per stub line 23).
- `MERIAM_38_CLASS_HEAT`: 38-step Esri/NWS gradient from `#4B0082` (deep purple, sub-zero F) → `#800000` (dark maroon, extreme heat). Light-dark oscillation across classes preserved per Meriam canon (stub line 30).

Caller-supplied palette overrides REJECTED — these are public-interest standards with decades of literacy. Consumer presets that want to "rebrand" the palette escalate per the cluster SKILL Type-design section.

### D-T347a-4 — v1 ships flat (2D) maps; 3D globe deferred

bbc-mark-allen-clouds canon ("3D rotating globe Weatherscape register") relies on `ThreeSceneClip` (ADR-005). Per the stub line 38 ("static fallback shows a frozen regional view"), v1 ships the flat 2D register; the 3D globe is deferred to T-347a-3d-globe (titleSequence-pattern carve-out — `ThreeSceneClip` integration with shared regions/symbols input).

D-T347a-4-a: the BBC preset's parity golden frame uses the flat fallback. Compass canon's "globe rotates and tilts; camera swoops" register is a Track-A frontier deliverable; v1 flat-register PSNR ≥ 38 / SSIM ≥ 0.95 thresholds (per stub line 47).

### D-T347a-5 — v1 ships single-frame static; per-frame loop deferred

Canon for all three styles describes time-based animation:
- bbc: globe rotation 4-6s, camera swoop, app-companion icon transitions
- doppler: radar loop 6-12 frames over 30-90 min, sweep beam clockwise rotation
- heat-map: time-lapse 1.5-2s per period, ease-in-out cycling

v1 ships a SINGLE-FRAME render with `frameIndex` / `loopFrameIndex` passed by caller — caller pins which frame of the conceptual loop to render. Multi-frame animated playback deferred to:
- T-347a-loop-cycle (doppler radar loop frame cycling)
- T-347a-time-lapse (heat-map time-period cycling with `useCurrentFrame()`)

D-T347a-5-a: parity-fixture goldens use single-frame static at the canonical reference frames documented per preset stub.

### D-T347a-6 — region labels rendered as positioned text overlays

Each region in `regions[]` has `screenPosition: { x, y }` (px) and `dataValue` (string — e.g., "72°F" / "85" / "Heavy Rain"). Rendered as absolutely-positioned `<div>` overlays inside the primitive's container, positioned per coordinate and styled per the active style's typography canon (per-stub `Typography` sections):

- bbc: BBC Reith Sans Bold 22-28pt on colored discs (canonical Mark-Allen disc-shape labels)
- doppler: Open Sans Regular 14-18pt
- heat-map: Open Sans Bold 18-22pt tabular

Style determines disc/chip rendering: `'mark-allen-clouds'` wraps each region label in a colored disc; other styles render plain labels.

### D-T347a-7 — base map: SVG path data passed as a prop

Map background geometry (country / region outlines) is consumer-supplied as `mapPaths: Array<{ id, d: SVG-path-d, fill? }>`. The primitive does NOT bundle map data — that's parity-cli resolver-shim territory (preset bindings carry their own region geometry, sized to the 1280×720 default canvas).

`fill` defaults are style-specific:
- `mark-allen-clouds`: muted darkening (`#3F4F5F` for cloud-covered regions; `#5F6F7F` for clear)
- `doppler-radar`: dark grey base `#1A1A1A` (radar product overlays atop)
- `heat-map`: per-region `dataValue` is mapped through the active palette (`MERIAM_38_CLASS_HEAT`) to determine fill

### D-T347a-8 — theme-slot fallback

Theme-slot map declared at clip-definition level for the small set of brand-theme-able properties:

- `background` → `palette.background` (canvas backdrop; useful for tenant-brand overrides on a fullScreen weather card)
- `foreground` → `palette.foreground` (region-label text color, per stub typography sections)

NOT theme-bound: any palette / disc-color / chip-color / radar-color (canonical canon per cluster SKILL.md).

### D-T347a-9 — frame-determinism

No `Date.now` / `Math.random` / `crypto.randomUUID` / `setTimeout` / `setInterval` / `fetch` / `requestAnimationFrame` / `addEventListener`. Stable region/symbol IDs derived from `region.id` / `symbol.kind + index`. Sweep-beam angle (when shipped in T-347a-loop-cycle) deterministic from `(frame, fps, sweepDurationMs)`.

### D-T347a-10 — acceptance thresholds vary per consuming preset

Each consumer preset pins its own PSNR/SSIM (stub-canonical — strict for radar / heat-map; relaxed for cloud icons):

- bbc-mark-allen-clouds: PSNR ≥ 38 / SSIM ≥ 0.95 (cluster-norm)
- doppler-dbz-standard: PSNR ≥ 40 / SSIM ≥ 0.97 (radar pixels are deterministic)
- heat-map-cool-to-warm: PSNR ≥ 40 / SSIM ≥ 0.97 (gradient is deterministic)

Per F-4 generator flags: each consumer preset's impl PR uses `--psnr=N --ssim=N --mark-signed`.
