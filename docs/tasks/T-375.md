## Decisions

### D-T375-1 — wired via DEFAULT_CLIP_KIND_RESOLVER (Pattern C)

First `arOverlay` consumer. Add `if (clipKind === 'arOverlay') return skySportsArFormationsBinding;` to the resolver's clipKind-default chain. Subsequent Cluster H consumers (T-376 hawkeye-var-3d-skeletal, T-377 olympic-swim-lane-track, T-378 nba-ar-replay) wire via `PRESET_ID_BINDINGS`.

**`PRESET_ID_BINDINGS` length stays at 34** — no override entry. The preset's `clipKind: arOverlay` matches the primitive's `kind: 'arOverlay'` directly; the resolver's clipKind-default arm handles routing.

### D-T375-2 — sealed canonical palette `SKY_SPORTS_AR_FORMATIONS_PALETTE`

Per the orchestrator's "sealed canonical palettes" instruction, bake the broadcaster brand canon as a frozen module-level constant at the top of the binding file:

```ts
export const SKY_SPORTS_AR_FORMATIONS_PALETTE = Object.freeze({
  /** Sky Sports navy — primary fill of marker badges per stub line 26. */
  skyNavy: '#0A1128',
  /** Premier League purple — sport-specific accent per stub line 27. */
  premierPurple: '#38003C',
  /** Foreground white — player numbers / labels. */
  foreground: '#FFFFFF',
} as const);
```

Mirrors the Cluster C presets' pattern (`BBC_MARK_ALLEN_CLOUDS_REGIONS`, `MARK_ALLEN_TEMPERATURE_DISCS`, `IMR_STORM_GRAYS`, etc.) — bake palette as a `const` exposed for tests + future consumers.

### D-T375-3 — static-fallback content surface (label + sublabel + accent border)

The primitive's static-fallback render path (D-T375a-5) renders a centered card on a backdrop with optional 1px accent border + an "AR · STATIC FALLBACK" badge bottom-right. The preset binds:

```ts
{
  staticFallback: {
    label: 'AR FORMATION OVERLAY',
    sublabel: '4-3-3 LINEUP',
    backgroundColor: SKY_SPORTS_AR_FORMATIONS_PALETTE.skyNavy,         // #0A1128 — Sky Sports navy backdrop
    foregroundColor: SKY_SPORTS_AR_FORMATIONS_PALETTE.foreground,      // #FFFFFF — player numbers / labels
    accentColor: SKY_SPORTS_AR_FORMATIONS_PALETTE.premierPurple,       // #38003C — Premier League brand accent border
    showLiveMountIndicator: true, // explicit (default true) — operator signal that live-mount is gated
  },
  font: {
    family: "'Sky Sports Sans', 'Inter', system-ui, -apple-system, sans-serif",
    weight: 700,
  },
  permissions: ['camera-tracking'], // declared (Sky Sports AR requires Zero Density / Stype tracking) but NOT exercised in v1 static-fallback path
}
```

Per stub line 31 ("Sky Sports Sans fallback (Inter), Bold, 16-22 pt") — Sky Sports Sans is `proprietary-byo` per preset frontmatter; Inter OFL is the rendered fallback. The primitive renders the label at fixed 48px (per D-T375a-5); the preset's `font` declaration governs the family stack.

### D-T375-4 — `setupRef` reserved (NOT exercised in v1)

Per D-T375a-2, the primitive's v1 dispatch ignores `setupRef` at render time and always renders the static-fallback path. **The preset binding does NOT supply `setupRef` in v1** — the ThreeSceneClip live-mount surface lands with T-375-live-mount post-T-397 Track A finale.

When live-mount lands, the binding extends to:
```ts
setupRef: { module: '@stageflip/scenes/sky-sports-ar-formations#setup', symbol: 'setupSkySportsArFormations' }
```

For now, the binding documents the deferral inline.

### D-T375-5 — `permissions: ['camera-tracking']` declared (forward-compat)

Per the preset stub line 42 ("Requires camera-tracking input (Zero Density / Stype). Without it, fall back to 2D pitch diagram") and the cluster SKILL line 42 ("AR requires camera-tracking input"), the binding declares `permissions: ['camera-tracking']`. This field is on the schema for forward compatibility (declared in T-375a's primitive; ignored at v1 render time per D-T375a-2). It will be consumed by the live-mount path post-T-397.

### D-T375-6 — frame 60 single-frame static; thresholds 36 / 0.93

Per stub line 48 — PSNR ≥ 36 / SSIM ≥ 0.93. Cluster H thresholds are slightly looser than the cluster-norm 38/0.95 because the stub authorizes that variance for "live AR composited frames" — the v1 static-fallback render is byte-deterministic, so the looser thresholds carry no risk for the v1 register and reserve headroom for the post-T-397 live-mount path's expected variance.

Reference frames per stub line 47 are 0 / 30 / 60 / 120; **single-frame golden at frame 60** (canonical "settled" register matching the cluster norm). Multi-frame animated camera-pan defers to T-375-camera-pan / T-375-live-mount.
