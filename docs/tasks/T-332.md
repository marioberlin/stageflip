## Architectural decisions

### D-T332-1. Compass-register match

Stub describes a **vertical 20-driver tower on the LEFT** with team-color stripes (3-4 px) on row leading edges, sector colors (purple session-best / green personal-best / yellow slower), tire compound glyphs, and gap times truncated (not rounded). T-332a's `'racing'` branch supports all of these natively:
- Vertical tower → racing branch renders rows stacked top-down at fixed `30 px` row height per primitive default.
- Team-color stripe → `row.teamColor` renders as a 4 px-wide left border on each row (primitive line 414 area).
- Sector colors → `row.sectorColors[]` of `'session-best' | 'personal-best' | 'slower' | 'neutral'` maps to canonical hexes (primitive `SECTOR_COLORS` constants: purple `#6F2E9E` / green `#00B54A` / yellow `#F0C800` / gray `#666666`).
- Tire compounds → `row.tireCompound` enum maps to glyph (S/M/H/I/W) + color via `TIRE_COMPOUND_GLYPH` and `TIRE_COMPOUND_COLOR` primitive constants.
- Gap times → `row.gap` is a verbatim string passed through to the rendered text.
