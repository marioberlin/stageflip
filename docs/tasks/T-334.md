# T-334 — Preset: `fox-nfl-no-chrome` (scoreBug, Cluster B)

**Branch**: `task/T-334-fox-nfl-no-chrome`

## Goal

Promote the existing `fox-nfl-no-chrome` preset stub from `status: stub` to `status: substantive` and ship it as the **second Cluster B (sports / score-bug) preset to land** AND the **third consumer of the `scoreBug` clipKind** in the parity-CLI resolver AND the **second production consumer of T-332a's `'football'` style bundle** in the `score-bug` runtime-clip primitive AND the **first production consumer of three new T-332a primitive features**: the `backdropGradient` prop (radial gradient backdrop), the `down` prop (down-and-distance text), and the `possession: 'home' | 'away'` prop (per-team brightness highlight). The preset captures Fox Sports' 2025 NFL redesign register (debuted Super Bowl LIX): a chromeless bottom-center scoreclock — NO traditional container box — with typography floating over a subtle radial gradient backdrop (`centerOpacity: 0.4`, `edgeOpacity: 0`), team primary colors filling team-code boxes (KC red `#E31837`, PHI green `#004C54`), white text, 3-letter team codes (`'KC'` / `'PHI'`) on kit-color team boxes, massive-scale tabular-numeric scores, match clock + period + down-and-distance (`'3rd & 7'`), home-team possession brightness highlight, and Inter Display 900 (Black) as the OFL fallback for the proprietary Fox Sports custom typeface. Common uses: live NFL match overlays where the chromeless / bottom-center / massive-score register is the brand signal — radically distinct from the upper-left rectangular-chrome PL register T-333 ships.

T-334 is the **third** preset to bind the `scoreBug` clipKind. T-358 (`cricket-ball-by-ball-dots`, merged earlier) holds the **clipKind-default** slot in `DEFAULT_CLIP_KIND_RESOLVER` (`scoreBug → scoreBugDotsBinding`), but binds via the `outcome-row` primitive (NOT score-bug) — T-358 predates the T-332a `score-bug` primitive. T-333 (`premier-league-field-of-play`, merged at 7f990ab) added the **first `PRESET_ID_BINDINGS` override** keyed on `'premier-league-field-of-play'`, binding the `score-bug` primitive's `'football'` style branch. T-334 must therefore wire its binding via a **second `PRESET_ID_BINDINGS` override** keyed on `'fox-nfl-no-chrome'` — Pattern C from `docs/handover-phase13-mid.md` §2 (n-th-preset-for-clipKind via `PRESET_ID_BINDINGS`). Mirrors T-333's resolver-binding shape verbatim, swapping `premier-league-field-of-play → fox-nfl-no-chrome` AND substituting Fox-NFL-specific snapshot constants. T-358's clipKind-default arm is **NOT** touched. T-333's `premierLeagueFopBinding` + `'premier-league-field-of-play'` `PRESET_ID_BINDINGS` entry are **NOT** touched.

T-334 is **second production consumer of T-332a's `'football'` style branch** (T-333 was the first; the four sister Cluster B presets exercising the racing / cricket / tennis branches will land in their own preset PRs). It is also the **first production consumer** of three optional fields on the `'football'` schema that T-333 did not exercise: `backdropGradient`, `down`, and `possession`. T-333 omitted all three — its register is a solid-purple-chrome rectangle with no possession highlight. T-334's register specifically requires all three: chromeless gradient backdrop replaces the rectangular-chrome look; down-and-distance text appears below the clock; KC has the ball at the snapshot frame so the home-team box brightens by `brightness(1.12)`.

T-334 is **M-sized** — same envelope as T-333 / T-323 / T-325 / T-364 / T-365. ~30–45 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. ~5 extra LOC vs T-333 to carry `backdropGradient` + `down` + `possession` in the snapshot constant. No primitive carve-out; no schema change. Inherits T-333's resolver shape end-to-end (`PRESET_ID_BINDINGS` override path; clipKind fall-through unchanged).

## Architectural decisions

### D-T334-1. Compass register match — Fox NFL 2025 chromeless / bottom-center / radial gradient backdrop / KC vs PHI Super Bowl LIX rematch / massive scores / Inter Display 900 OFL fallback

The stub (lines 22–44) defines the canonical Fox NFL 2025 register:

- **Position**: bottom-center, NO traditional container box (line 23). T-334 anchors at `position: { x: 280, y: 600 }` on a 1280×720 canvas: the primitive's default bug-width is `720 px` (T-332a primitive default per `score-bug.tsx`), so `x = (1280 − 720) / 2 = 280` centers the bug horizontally; `y = 600` puts the bug `~120 px` above the bottom edge (`720 − 600 − 80 (bug height) = 40 px` clearance below the bug, with the bug's own `80 px` height, totals ~120 px from canvas bottom to bug top).
- **No chrome**: the stub explicitly **rules out** a container box (line 23, 41). The `'football'` branch renders the element's `backgroundColor` from the `background` prop (lines 326–340 of `score-bug.tsx`); to render a chromeless / floating-typography look, T-334 sets `background: '#000000'` (black) AND supplies `backdropGradient: { centerOpacity: 0.4, edgeOpacity: 0 }`, which renders a radial darkening overlay BEHIND the three flex children. The visual effect is "typography + kit-colored team boxes float over a subtle radial dark gradient" — the `backgroundColor: '#000000'` is the chromeless base, the `backdropGradient` is the subtle darkening at the centroid, the three flex children sit atop both. The element's bg is black for a "no chrome" feel against the radial gradient; rendering the preset on a non-black canvas would composite the bug's bg into the canvas (per CSS layering — `backgroundColor` paints behind the primitive's flex children).
- **Subtle gradient backdrop** (line 24 — "radial darkening, ~40% opacity at centroid, fading to 0 at edges"): `backdropGradient: { centerOpacity: 0.4, edgeOpacity: 0 }`. Per the primitive's render path (lines 346–374 of `score-bug.tsx`), this paints `<stop offset="0%" stopColor="#000000" stopOpacity={0.4}/>` to `<stop offset="100%" stopColor="#000000" stopOpacity={0}/>` in a `radialGradient` — exactly the stub's spec. **First production consumer of `backdropGradient`**.
- **Team primary colors fill team-code boxes** (line 25 — "KC red, PHI green"): KC red `#E31837` (Kansas City Chiefs official primary — Super Bowl LIX home), PHI green `#004C54` (Philadelphia Eagles official primary — Super Bowl LIX away). The KC vs PHI fixture pairing is the canonical 2024–25 NFL Super Bowl LIX rematch.
- **White text** (line 26): `foreground: '#FFFFFF'` — clock + period + down all white. Team-box text (`code` + `score`) is hard-bound to `#ffffff` regardless of `foreground` per primitive line 314.
- **Team abbreviations**: 3-letter (`'KC'` 2-letter — note: KC is a 2-letter abbreviation, NOT 3-letter; the primitive's `code: z.string().min(1)` accepts any length-1+ string; `'KC'` and `'PHI'` are both canonical NFL conference team codes; document this register flexibility).
- **Scores**: tabular massive-scale per the stub (line 31). Snapshot uses `'24'` (KC) / `'17'` (PHI) — a plausible mid-Q3 2-score-margin scoreline. The `score` field is a **string** per the schema; passes the primitive's `applyCasing` numeric short-circuit unchanged.
- **Clock + period + down**: `'04:32'` (Q3 mid-quarter clock), `'Q3'` (third-quarter token; NFL canonical period notation), `'3rd & 7'` (down-and-distance — the canonical NFL "third down with seven yards to go" notation; sits below the period text per primitive line 409–411). The down string `'3rd & 7'` starts with a digit (`'3'`); the `applyCasing` numeric short-circuit leaves it untouched regardless of `casing`.
- **Possession**: `possession: 'home'` (KC has the ball; brightness `1.12` boost on the home team box — per primitive line 309). **First production consumer of `possession`** in production goldens.
- **Inter Display 900 (Black) OFL fallback** for proprietary Fox Sports custom (stub frontmatter lines 7–13): `font: { family: 'Inter Display', weight: 900 }`. Heavier than T-333's Space Grotesk 600 (PL stub register is SemiBold; Fox NFL stub is Black/Extra-Bold per stub line 30–31).

T-334 binds these to the existing `score-bug` primitive's `'football'` branch (T-332a). The mapping:
