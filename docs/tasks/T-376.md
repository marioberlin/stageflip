### D-T376-2 — sealed canonical palette `HAWKEYE_VAR_SKELETAL_PALETTE`

Per the orchestrator's "sealed canonical palettes" instruction + sister Cluster C / Cluster H precedent (`SKY_SPORTS_AR_FORMATIONS_PALETTE`, `DOPPLER_DBZ_REFLECTIVITY`, etc.), bake the Hawk-Eye / VAR brand canon as a frozen module-level constant:

```ts
export const HAWKEYE_VAR_SKELETAL_PALETTE = Object.freeze({
  /** PL purple background per stub line 30 — VAR-decision moment register (NOT Sky Sports navy; intentionally differentiates from sibling sky-sports-ar-formations preset). */
  premierLeaguePurple: '#34003A',
  /** Green accent per stub line 30 — "white text + green accents" decision-moment trim. Doubles as decision-confirmed flash color (D-T376-3 deferral). */
  decisionGreen: '#00FC8A',
  /** Foreground white — banner text + player labels per stub typography. */
  foreground: '#FFFFFF',
  /** Attacker offside-line red/orange per stub line 26 — reserved for live-mount path (T-376-live-mount post-T-397). */

```

Mirrors the Cluster H first-consumer pattern (`SKY_SPORTS_AR_FORMATIONS_PALETTE` D-T375-2). The two offside-line colors are exported for future live-mount consumers; v1 static-fallback doesn't surface them on the rendered card.

### D-T376-3 — static-fallback content surface (label + sublabel + green accent border)

The primitive's static-fallback render path (D-T375a-5) renders a centered card on a backdrop with optional 1px accent border + an "AR · STATIC FALLBACK" badge bottom-right. The preset binds:

```ts
{
  staticFallback: {
    label: 'VAR — CHECKING OFFSIDE',
    sublabel: 'HAWK-EYE 3D SKELETAL TRACKING',
    backgroundColor: HAWKEYE_VAR_SKELETAL_PALETTE.premierLeaguePurple, // #34003A — PL purple decision-moment backdrop
    foregroundColor: HAWKEYE_VAR_SKELETAL_PALETTE.foreground,           // #FFFFFF — banner text
    accentColor: HAWKEYE_VAR_SKELETAL_PALETTE.decisionGreen,            // #00FC8A — decision-green 1px accent border (NOT PL purple — visually differentiates from sibling sky-sports preset's purple-on-navy register)
    showLiveMountIndicator: true,
  },
  font: {
    family: "'Premier Sans', 'Champions', 'Space Grotesk', system-ui, -apple-system, sans-serif",
    weight: 700,
  },
  permissions: ['camera-tracking'], // declared (Hawk-Eye limb-tracking requires source data per stub line 46) but NOT exercised in v1 static-fallback path
}
```

Per stub line 33 ("'VAR — CHECKING ...' banner: Premier Sans / Champions fallback, Bold, 28–34 pt, ALL CAPS") — Premier Sans + Champions are `proprietary-byo` per preset frontmatter; Space Grotesk OFL is the rendered fallback. The primitive renders the label at fixed 48px (per D-T375a-5); the preset's `font` declaration governs the family stack.

**Visual differentiation from sibling sky-sports-ar-formations preset:**
- Sky Sports: navy backdrop (`#0A1128`) + Premier League purple accent border (`#38003C`) + `'Sky Sports Sans', 'Inter'` font stack — register: pitch-anchored formation lineup.
- Hawk-Eye VAR: PL purple backdrop (`#34003A`) + decision-green accent border (`#00FC8A`) + `'Premier Sans', 'Champions', 'Space Grotesk'` font stack — register: VAR offside-decision moment, dramatic suspense beat.

Both presets ship the SAME primitive (`arOverlay`) but render visually distinct cards — the broadcaster brand canon lives in the per-preset binding, not the primitive.

### D-T376-4 — `setupRef` reserved (NOT exercised in v1)

Per D-T375a-2, the primitive's v1 dispatch ignores `setupRef` at render time and always renders the static-fallback path. **The preset binding does NOT supply `setupRef` in v1** — the ThreeSceneClip live-mount surface (Hawk-Eye limb-tracking 3D wireframe overlay; Three.js scene with skeletal mesh + animated offside lines) lands with T-376-live-mount post-T-397 Track A finale.

When live-mount lands, the binding extends to:
```ts
setupRef: { module: '@stageflip/scenes/hawkeye-var-3d-skeletal#setup', symbol: 'setupHawkeyeVarSkeletal' }
```

For now, the binding documents the deferral inline.

### D-T376-5 — `permissions: ['camera-tracking']` declared (forward-compat)

Per the preset stub line 46 ("3D limb-tracking from Hawk-Eye: requires the source data") and the cluster SKILL line 42 ("AR requires camera-tracking input"), the binding declares `permissions: ['camera-tracking']`. This field is on the schema for forward compatibility (declared in T-375a's primitive; ignored at v1 render time per D-T375a-2). It will be consumed by the live-mount path post-T-397.

### D-T376-6 — frame 60 single-frame static; thresholds 36 / 0.93

Per stub line 52 — PSNR ≥ 36 / SSIM ≥ 0.93. Cluster H thresholds are slightly looser than the cluster-norm 38/0.95 because the stub authorizes that variance for "3D overlay variance" — the v1 static-fallback render is byte-deterministic, so the looser thresholds carry no risk for the v1 register and reserve headroom for the post-T-397 live-mount path's expected variance.

Reference frames per stub line 51 are 0 / 30 / 90 / 150 (banner-entering / loading-pulse / lines-drawn / decision-flash); **single-frame golden at frame 60** for cluster-norm consistency with sibling sky-sports preset (also frame 60). The "settled" register at frame 60 is canonical across Cluster H presets. Multi-frame animated banner-slide / loading-pulse / decision-flash defers to T-376-animated.
