# T-327 — Preset: `fox-news-alert` (breakingBanner, Cluster A)

**Branch**: `task/T-327-fox-news-alert`

## Goal

Promote the existing `fox-news-alert` preset stub from `status: stub` to `status: substantive` and ship it as the **seventh Cluster A preset to land**, the **second consumer of the `breakingBanner` clipKind**, and the **first production consumer of the T-324a sliver mode + vertical slide axis**. The preset captures the canonical Fox News Alert register: a persistent **Prussian Blue narrow sliver** anchored top-left + Fox-red `FOX NEWS ALERT` label badge + Mixed-Case white headline. Common uses: Fox-channel breaking-news segments where the sliver remains visible during nearly all breaking coverage (per stub line 26 — "Persistent 'Fox News Alert' sliver remains visible during nearly all breaking coverage").

T-327 is the **second `breakingBanner` clipKind binding** wired into the parity-CLI resolver (T-324 `cnn-breaking` was the first, the clipKind-default arm via `DEFAULT_CLIP_KIND_RESOLVER` returning `cnnBreakingBinding`). Per **Pattern C** from `docs/handover-phase13-mid.md` §2 ("First preset for a clipKind uses clipKind-default; second-and-later share the clipKind via `PRESET_ID_BINDINGS`"), T-327 binds via `PRESET_ID_BINDINGS['fox-news-alert']` — the existing `'breakingBanner'` arm in `DEFAULT_CLIP_KIND_RESOLVER` (returning `cnnBreakingBinding`) stays UNCHANGED.

T-327 is **M-sized** — on par with T-324 (the closest sibling first-binding) and T-325 / T-326 / T-329 / T-330 (sister `lowerThird` `PRESET_ID_BINDINGS` overrides). Comparable shape: ~30–40 LOC binding entry + a canonical-snapshot constant + single steady-state parity golden + sign-off in-PR. The primitive (T-324a) and clipKind-default (T-324 `cnnBreakingBinding`) are already on `main`; T-327 is the second consumer with no further carve-out — Pattern E rebuild is the only operational discipline. Inherits T-359a's multi-variant infra in trivial-arity mode, T-359b's prod-renderer pipeline, T-359c's tsx fix, T-360's `(clipKind, presetId)` resolver shape (used in `PRESET_ID_BINDINGS` override mode here per D-T327-2), T-325's first-`PRESET_ID_BINDINGS`-override-for-a-clipKind shape (the analog template for the override pattern), T-367's in-PR sign-off (Pattern D from `docs/handover-phase13-mid.md` §2), F-4 hand-pin via `--psnr=42 --ssim=0.98 --mark-signed` flags (T-324 / T-330 / T-329 precedent — generator-flag-driven, no manual `thresholds.json` edit).

The architectural novelty is **first production validation of T-324a's sliver mode + vertical slide axis**: the canonical Fox posture (per stub line 23 + line 26 + line 35) is a persistent narrow sliver, not an entrance-animated banner. Per T-324a D-T324a-6 sliver mode skips entrance entirely (`translatePct = 0`, `opacity = 1` at frame 0). The `slideAxis: 'vertical'` setting is documented for the **exit** (per stub line 38 — "Exit: slide down, 400 ms") and for any other consumer that opts in; at the canonical steady-state mid-hold frame 60, sliver mode renders the persistent register regardless of `slideAxis`.

## Architectural decisions

### D-T327-1. Compass register match — Prussian Blue persistent narrow sliver + Fox-red `FOX NEWS ALERT` label badge + Mixed-Case white headline + sliver mode (no entrance)

The stub (lines 22–43) defines the canonical Fox News Alert register:

- **Sliver fill**: `#003366` Prussian Blue (line 24, "Primary fill").
- **Label badge**: `FOX NEWS ALERT` red `#C20017` block with white `#FFFFFF` text (line 25, "Accent / alert: Red `#C20017`"; line 30, "Banner label (ALERT / BREAKING): FF Good OT Black fallback, ALL CAPS"). Brand-locked.
- **Persistent posture**: "Persistent 'Fox News Alert' sliver remains visible during nearly all breaking coverage" (line 26).
- **Headline**: "Heavy / Black, Mixed Case" (line 31) — white `#FFFFFF` on Prussian Blue. Mixed-Case (NOT all-caps), unlike CNN's UPPERCASE register.
- **Animation**: Vertical-slide signature (line 35 "Signature vertical slide motion — elements slide up/down, not horizontal wipes"); exit slides down 400 ms (line 38). Sliver mode skips entrance per T-324a D-T324a-6 — the Fox posture is persistent register, not entrance animation.

T-327 binds these to the just-shipped `BreakingBanner` primitive's render contract (T-324a). The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| Persistent narrow sliver | `mode` | `'sliver'` (first production consumer of T-324a sliver mode per D-T324a-3 / D-T324a-6) |
| Sliver anchored to upper-left of frame | `sliverAnchor` | `'top-left'` (T-324a default; matches Fox's canonical persistent posture in upper area of frame, leaving the lower portion clear for ticker / aux graphics) |
| Sliver width ≈ 30 % of frame | `sliverWidthPct` | `0.30` (T-324a default; matches Fox's canonical narrow-sliver proportion) |
| Prussian Blue sliver background | `background` | `'#003366'` |
| Red `FOX NEWS ALERT` label, white text | `label` | `{ text: 'FOX NEWS ALERT', fill: '#C20017', color: '#FFFFFF' }` |
| White Mixed-Case headline | `headline` + `headlineColor` + `casing` | `headline: 'Major Storm Approaches East Coast'`; `headlineColor: '#FFFFFF'`; `casing: 'as-is'` (Mixed-Case per stub line 31) |
| Heavy / Black weight, Mixed Case | `font` | `{ family: 'League Gothic', weight: 700 }` (the OFL fallback declared in the stub frontmatter; D-T327-13) |
| Vertical slide signature | `slideAxis` | `'vertical'` (set defensively for the exit / future v2 sliver-with-entrance; functional no-op at the steady-state mid-hold per D-T327-5) |
| No flag end-cap | `endCap` | **Omitted** — Fox doesn't use a flag end-cap; the sliver IS the brand identifier (D-T327-4). |

Note: `borderRadius` is left at the primitive default `0` — Fox's flat-design sliver register (stub line 23: "Bug: flat design with white border") matches a flat 0-radius rectangle; the "white border" element is not a primitive-supported axis and is documented as a deferred minor cosmetic.

### D-T327-3. v1 scope — steady-state sliver only; searchlight morph / return-from-commercial / LIVE pulse / ticker / dark overlay deferred to T-327a/T-327b/T-324b/sister carve-outs IF Reviewer scrutiny demands

The stub describes a fully-instrumented Fox News Alert broadcast register: persistent Prussian Blue sliver + red `FOX NEWS ALERT` label + Mixed-Case white headline + ticker strip + LIVE pulse bug + searchlight morph (return-from-commercial bumper) + semi-transparent dark overlay. The `BreakingBanner` primitive (T-324a) supports only the **first three** via the canonical mapping (D-T327-1): sliver (`mode: 'sliver'` + `background` + `sliverAnchor` + `sliverWidthPct`), label badge (`label`), headline (`headline` + `headlineColor` + `casing` + `font`). The remaining four are decorative additions — none of them are part of the primitive's prop surface (per T-324a D-T324a-12), and adding them is a primitive-level or sister-clip concern.

**Decision**: T-327 v1 ships the **steady-state sliver register** — Prussian Blue narrow sliver anchored top-left + red `FOX NEWS ALERT` label + Mixed-Case white headline. The signed parity golden captures the steady-state mid-hold frame. The searchlight morph, return-from-commercial sequence, LIVE pulse, ticker, and dark overlay are **deferred** to follow-up tasks ONLY IF Reviewer scrutiny demands them:

- **`T-327a`** — Fox searchlight morph (multi-stage angled-lines → searchlight-beams glyph morph; primitive-level OR sister-clip; NOT a preset-level fix).
- **`T-327b`** — return-from-commercial multi-stage sequence (multi-clip orchestration; NOT a primitive prop).
- **`T-324b`** — LIVE pulse bug (shared with T-324; primitive-level — `BreakingBanner` would gain an optional `livePulse` prop).
- **Ticker strip** — composes externally via existing `news-ticker-bar` (T-356a) in adjacent layout slot, NOT a follow-up to T-327.
- **Dark overlay** — sister composed clip (e.g., a `colorPanel` with low-alpha gradient); NOT a `breakingBanner` prop.

**Rationale**: The canonical Fox News Alert identity in a single steady-state frame **is** the persistent Prussian Blue sliver + red `FOX NEWS ALERT` label + Mixed-Case white headline. The searchlight morph, return-from-commercial sequence, LIVE pulse, ticker, and overlay are decorative additions present in some but not all Fox breaking-coverage frames; a parity golden of the **steady-state persistent sliver** captures the brand register without overshooting the M-sized envelope. Mirrors T-324's "v1 banner only; LIVE pulse / CNN bug / ticker / wipe deferred" posture.

If a Reviewer demands searchlight morph or LIVE pulse or ticker inline → escalate per CLAUDE.md §6; that is the carve-out path, not a T-327 expansion.
