# T-317 — `SubscribeButton` primitive

**Branch**: `task/T-317-subscribe-button-primitive`

## Goal

Ship a frame-runtime-bridge clip — `subscribe-button` (kebab-case file/kind, mirroring `breaking-banner` / `news-ticker-bar` / `lower-third` / `score-bug`) — that renders a creator-platform subscribe / follow CTA button from a sealed `platform: 'youtube' | 'tiktok' | 'instagram' | 'generic'` enum. The primitive is the missing piece that blocks T-369 `youtube-subscribe-bounce` (Cluster G first preset) and is the architectural sibling of T-318 (`FollowPrompt`) and T-319 (`QRCodeBounce`); together the three primitives unlock all five Cluster G presets.

T-317 is **distinct from every existing bridge clip**. `lower-third` (T-183) renders a wide caption strip anchored bottom-left — not a button-shaped pill with bounce / pulse / press-down state. `cta-pulse` (T-202a) is a generic radial pulse around an arbitrary child — it does not render a sealed-platform button surface (YouTube red rounded pill, TikTok pink pulse, Instagram gradient outline). `breaking-banner` (T-324a) renders a label + headline pair — not a clickable-looking button. The architectural intent is a dedicated primitive whose visual register is *the platform-native subscribe / follow button itself* (per the Cluster G canon's "mimicry wins" rule — `skills/stageflip/presets/ctas/SKILL.md` line 44: *"Don't 'design around' native UI — mimic it"*). T-317 ships the platform-button shape; T-318 ships the animated face / hand-cursor "follow prompt" register; T-319 ships the DVD-bouncing QR rectangle register.

T-317 is **M-sized**: ~300–450 LOC component + ~150–200 LOC tests + barrel + ~6 LOC catalog/manifest entries + changeset. Comparable to `breaking-banner` (T-324a, ~400–600 LOC, dual-mode dispatch with two style enums) but slightly leaner — single dispatch axis (`platform`) and a single sealed animation lexicon (entrance bounce → idle → optional cursor-press → post-press settle). Bigger than `outcome-row` (T-358a, ~250 LOC, single-mode chips) due to four sealed platform bundles + a bounce animation phase + an optional cursor-overlay slot. It does NOT touch T-369's preset markdown, parity resolver, or parity goldens — those land in T-369-retry (the consumer preset PR) after this primitive merges.

## Architectural decisions

### D-T317-1. Distinct primitive vs. extending `cta-pulse`

T-317 ships a **distinct** primitive (`subscribe-button`), NOT an extension of `cta-pulse` (T-202a). Rationale:

- **Visual register diverges.** `cta-pulse` is a *generic radial pulse* rendered around an arbitrary child element — it has no opinion on the child's shape, color, or text. T-317 ships *a sealed-platform button surface itself* — the rounded pill, the platform-canonical color (YouTube red `#FF0000`, TikTok pink `#FE2C55`, Instagram gradient), the platform-canonical label ("SUBSCRIBE" / "Follow" / "Follow"), the platform-canonical typography (Roboto Medium 500 / TikTok Sans / Instagram's platform sans). The two surfaces overlap at a single visual axis (both are CTA-anchored) and diverge on every other axis.
- **Style bundle dispatch is foreign to `cta-pulse`.** `cta-pulse` has no `platform` enum. Bolting a sealed `platform: 'youtube' | 'tiktok' | 'instagram' | 'generic'` switch onto `cta-pulse` pollutes its current zero-opinion posture and breaks its existing tests.
- **Animation lexicon diverges.** `cta-pulse` ships a *radial pulse* (concentric expanding rings via SVG `<circle r=...>`). T-317 ships a *bounce overshoot entrance* (scale 0% → 100% with overshoot to 110% per the YouTube canon) plus an optional *press-down* state (button color flips red → gray, scale dips briefly to 95% then returns). Different animation primitives.
- **One consumer stub explicitly pins `clipKind: subscribeButton`** (`youtube-subscribe-bounce.md` line 4). The clipKind is **already** reserved in `VALID_CLIP_KINDS` (line 74). The architectural intent is a dedicated primitive.
- **Cluster G's "mimicry wins" canon** (per `skills/stageflip/presets/ctas/SKILL.md` line 44) demands platform-native register, not a generic pulse. The primitive must encode the platform-button shape natively.

Reviewer demand for merging into `cta-pulse` → escalate per CLAUDE.md §6.

### D-T317-2. Approach — single primitive with platform-bundle dispatch (Approach A)

**Decision**: **Approach A** — a single `subscribe-button` primitive with sealed `platform: 'youtube' | 'tiktok' | 'instagram' | 'generic'` enum dispatching to four distinct render paths within one component.

The Orchestrator evaluated three approaches:

- **Approach A (single primitive, platform-bundle dispatch)** — Single `subscribe-button` primitive with `platform` enum. Each platform branches to a distinct render path (`renderYoutube` / `renderTiktok` / `renderInstagram` / `renderGeneric`). ~300–450 LOC. Mirrors `score-bug.tsx` 4-style dispatch, `caption.tsx` 6-style dispatch, `title-sequence.tsx` 4-style dispatch precedents. ALL_BRIDGE_CLIPS grows 52 → 53.
- **Approach B (generic primitive + slot-based composition)** — A `subscribe-button` primitive that exposes layout primitives (background-pill, label-slot, glyph-slot, post-press-glyph-slot) and presets compose them. ~250–300 LOC primitive + meaningful per-preset composition logic in `parity-cli` resolver. Smaller primitive but pushes layout concerns into resolver code.
- **Approach C (split into multiple primitives)** — `subscribe-button-youtube`, `subscribe-button-tiktok`, `subscribe-button-instagram`, `subscribe-button-generic` — 4 separate primitives. Breaks 1-clipKind = 1-primitive convention; clip count grows 52 → 56.

**Rationale for A**:

1. **Established pattern.** `caption.tsx` (6 STYLE_BUNDLES), `lyrics.tsx` (3 style bundles), `title-sequence.tsx` (4 sealed style bundles), `score-bug.tsx` (4 sealed style bundles) all use single-primitive style-bundle dispatch. Each platform render path is a separate function called from a top-level `switch (platform)` block — keeps dispatch clean even when intra-platform render paths diverge.
2. **One clipKind = one primitive.** Pattern C of the resolver maps `clipKind: subscribeButton` → primitive `kind: 'subscribe-button'`. Approach C breaks this convention; Approach B pushes layout into the resolver where it doesn't belong (the resolver should map to a primitive + props, not own visual layout).
3. **ALL_BRIDGE_CLIPS stays at 53.** Approach C bloats the catalog with four entries that share most of their schema surface; the consolidation discipline is part of the bridge's identity.
4. **Future presets bind cleanly.** TikTok-follow-pulse and Instagram-link-sticker eventually need a button surface; they should not require new primitives — they bind to `'tiktok'` / `'instagram'` platform values on this primitive (as auxiliary visual elements within `followPrompt` / dedicated presets).

Reviewer demand for Approach B (slot-based) or Approach C (split) → escalate; the architectural rule is sealed at A.

### D-T317-3. Platform bundle enum — `'youtube' | 'tiktok' | 'instagram' | 'generic'`

Four sealed platform bundles cover the v1 surface:

- **`'youtube'`** — Rounded pill button. YouTube Red `#FF0000` background, white text "SUBSCRIBE" (always uppercase regardless of `casing`). Border-radius `8` (per `youtube-subscribe-bounce.md` line 23). Roboto Medium (500) at base font-size 18. Optional bell glyph (Unicode `\u{1F514}` or stylized SVG path) renders to the right of the text in the post-press state. Post-press state: gray `#AAAAAA` background, "SUBSCRIBED" label. Drop shadow `0 4 8 rgba(0,0,0,0.20)`. Serves T-369.
- **`'tiktok'`** — Rounded pill (`borderRadius` default `8`) — TikTok Pink `#FE2C55` background, white text "Follow" (mixed case per TikTok canon). TikTok Sans (the platform's font) — falls back to a generic system sans when the TikTok Sans family is absent. Right-thumb zone discipline (per Cluster G canon) is the consumer's responsibility — the primitive does not auto-position. Optional plus glyph (`+`) renders left of the text. Post-press state: outline `1 px solid #FE2C55` background `transparent`, label "Following".
- **`'instagram'`** — Rounded rectangle (`borderRadius` default `4`) with Instagram-canonical gradient background (`linear-gradient(135deg, #F58529 0%, #DD2A7B 50%, #8134AF 100%)` — the orange-pink-purple Instagram gradient). White text "Follow" (mixed case). Post-press state: outline `1 px solid white` over a dimmed gradient background, label "Following".
- **`'generic'`** — Brand-neutral rounded pill (`borderRadius` default `8`) for non-platform CTAs (e.g., a campaign-anchored "Subscribe" / "Join" button). Theme-slot palette fallback drives the colors (`palette/accent` for background, `palette/foreground` for text). Required `label` prop is consumed verbatim. No platform glyph. The escape hatch when none of the three platform registers fits.

The four bundles dispatch in a single `switch (platform)` block in the component; each platform maps to a distinct render path (`renderYoutube` / `renderTiktok` / `renderInstagram` / `renderGeneric`). No "hybrid" / configurable per-feature toggle in v1 — the four bundles are sealed. Future platforms add via additive enum extension (no breakage).

### D-T317-4. Schema shape (Zod) — discriminated union on `platform`

Top-level Zod schema is a discriminated union on `platform`. Each variant carries the common base props + the platform-specific shape. Mirrors `score-bug.tsx`'s `discriminatedUnion('style', [...])` pattern verbatim.

```ts
const HEX_COLOR_RE = /^#[0-9a-fA-F]{6}$/;

const positionSchema = z
  .object({
    x: z.number(),
    y: z.number(),
    width: z.number().positive().optional(),
    height: z.number().positive().optional(),
  })
  .strict();

const fontSchema = z
  .object({
    family: z.string().min(1),
    weight: z.number().int().min(100).max(900).optional(),
  })
  .strict();

const casingSchema = z.enum(['as-is', 'uppercase', 'lowercase', 'title-case']);

// Common props that appear in every platform branch. Spread into each branch's
// shape since `discriminatedUnion` requires plain `ZodObject` branches.
const baseShape = {
  position: positionSchema,
  /** Optional explicit background hex; theme-slot fallback when absent (per platform). */
  background: z.string().regex(HEX_COLOR_RE).optional(),
  /** Optional explicit foreground (text) hex; theme-slot fallback when absent. */
  foreground: z.string().regex(HEX_COLOR_RE).optional(),
  /** Optional explicit accent (post-press background; bell-glyph color). */
  accent: z.string().regex(HEX_COLOR_RE).optional(),
  /** Font override; per-platform default applied when absent. */
  font: fontSchema.optional(),
  /** Casing transform applied to the rendered label only. Default 'as-is'. */
  casing: casingSchema.optional(),
  /** Border radius (px). Per-platform default applied when absent. */
  borderRadius: z.number().nonnegative().optional(),
  /** Animation phase. 'idle' (default) renders the entrance bounce; 'pressing'
   * renders the press-down state; 'subscribed' renders the post-press settled
   * state. Frame-derived; the consumer drives transitions by mounting two
   * consecutive instances or by passing `phase` through `interpolate`-driven
   * scene timing.
   */
  phase: z.enum(['idle', 'pressing', 'subscribed']).optional(),
  /** Optional cursor glyph slot (right-edge static cursor in 'pressing' phase). */
  showCursor: z.boolean().optional(),
  /** Optional drop shadow. Default per-platform (YouTube emits a shadow; others none). */
  dropShadow: z.boolean().optional(),
};

const youtubeSchema = z.object({
  platform: z.literal('youtube'),
  ...baseShape,
  /** Pre-press label. YouTube canon: 'SUBSCRIBE'. */
  label: z.string().min(1),
  /** Post-press label. YouTube canon: 'SUBSCRIBED'. */
  subscribedLabel: z.string().min(1).optional(),
  /** Show bell glyph in 'subscribed' phase. Default true. */
  showBell: z.boolean().optional(),
}).strict();

const tiktokSchema = z.object({
  platform: z.literal('tiktok'),
  ...baseShape,
  label: z.string().min(1),
  followingLabel: z.string().min(1).optional(),
  /** Show '+' plus glyph in 'idle' phase. Default true. */
  showPlus: z.boolean().optional(),
}).strict();

const instagramSchema = z.object({
  platform: z.literal('instagram'),
  ...baseShape,
  label: z.string().min(1),
  followingLabel: z.string().min(1).optional(),
  /** Override gradient stops. Default per-platform. */
  gradient: z
    .object({
      start: z.string().regex(HEX_COLOR_RE),
      mid: z.string().regex(HEX_COLOR_RE),
      end: z.string().regex(HEX_COLOR_RE),
    })
    .strict()
    .optional(),
}).strict();

const genericSchema = z.object({
  platform: z.literal('generic'),
  ...baseShape,
  label: z.string().min(1),
  postPressLabel: z.string().min(1).optional(),
}).strict();

export const subscribeButtonPropsSchema = z.discriminatedUnion('platform', [
  youtubeSchema,
  tiktokSchema,
  instagramSchema,
  genericSchema,
]);
```

All optional except `platform`, `position`, and `label`. Strict mode (no extras). Mirrors score-bug.tsx Zod posture. NO `.refine()` wrappers on union branches (Zod doesn't allow them on `discriminatedUnion` arms — see D-T332a-4 footnote).

### D-T317-5. Animation lexicon — entrance bounce overshoot + optional press-dip

The primitive ships a sealed three-phase animation lexicon:

- **`'idle'`** (default): entrance bounce overshoot driven by `useCurrentFrame()`. Scale interpolates from `0` (at `frame=0`) to `1.10` (at `frame=ceil(fps * 0.30)` — the overshoot peak), back to `1.00` (at `frame=ceil(fps * 0.50)` — the settle frame). Implemented via piecewise `interpolate(frame, [0, peak, settle], [0, 1.10, 1.00], { easing: cubicBezier(...) })`. After settle, scale stays at `1.00` for the remainder of the clip's duration. No infinite-pulse breathing in v1 (carve-out: T-317c if requested).
- **`'pressing'`**: scale dips briefly from `1.00` to `0.95` over `ceil(fps * 0.083)` frames (~83 ms at 30 fps; the canonical button press-feel duration), then returns to `1.00` over the next `ceil(fps * 0.083)` frames. Background color stays at the platform-canonical pre-press color (YouTube red, TikTok pink, etc.). Optional cursor glyph renders at the button's right edge if `showCursor: true`.
- **`'subscribed'`**: button renders at scale `1.00` with the platform's *post-press* background + label (gray + "SUBSCRIBED" for YouTube; outlined transparent + "Following" for TikTok / Instagram; consumer's `postPressLabel` for `'generic'`). YouTube's bell glyph renders if `showBell !== false` and `platform === 'youtube'`. No animation in this phase — the post-subscribe wiggle is deferred to T-317a.

Animation is purely frame-derived. No `Date.now()`, no `Math.random()`, no `setTimeout`/`setInterval`, no `requestAnimationFrame`. Spring-like easing approximated via `cubicBezier` from `@stageflip/frame-runtime` (no `framer-motion`).

The `phase` prop is set by the consumer (resolver / preset). v1 does NOT auto-transition between phases via internal frame thresholds — the consumer mounts the primitive with the desired `phase` per scene segment. This keeps the determinism contract simple: same props + same frame → same output.

### D-T317-6. Theme slots — `background` + `foreground` + `accent`

Mirrors score-bug.tsx + caption.tsx + lyrics.tsx posture: every color prop is **optional**; theme slot fills in when absent.

```ts
themeSlots: {
  background: { kind: 'palette', role: 'background' },
  foreground: { kind: 'palette', role: 'foreground' },
  accent: { kind: 'palette', role: 'accent' },
}
```

Top-level optional color props with theme fallback: `background?` (button backdrop) → `palette/background` (only consumed in `'generic'` mode; YouTube / TikTok / Instagram override with their canonical brand colors regardless of theme slot — *brand canon dominates theme*); `foreground?` (label text) → `palette/foreground` (consumed in `'generic'` mode; brand-platform modes override with white/canonical); `accent?` (post-press background; bell-glyph color) → `palette/accent`.

For `'youtube'`/`'tiktok'`/`'instagram'`: brand-canonical colors are baked into the per-platform render path and override the theme slot. The `background?` / `foreground?` / `accent?` props are accepted for schema uniformity but are no-op in brand-platform modes (consumer-provided overrides for these platforms → escalate; the brand canon is sealed).

For `'generic'`: theme-slot palette drives the colors when no explicit `background` / `foreground` / `accent` is passed.

### D-T317-7. Per-platform default fonts

Each platform branch declares its canonical default font:

- **`'youtube'`** — Roboto Medium (500), base size `18` (per `youtube-subscribe-bounce.md` line 33).
- **`'tiktok'`** — TikTok Sans (the platform's font), Bold (700). Falls back to system sans when the TikTok Sans family is absent.
- **`'instagram'`** — Instagram's platform sans (Helvetica Neue / Arial fallback), Semi-Bold (600).
- **`'generic'`** — `'Plus Jakarta Sans, sans-serif'` weight 700 (the bridge default from T-183z / T-324a).

### D-T317-8. Casing transforms — apply to `label` and `subscribedLabel` / `followingLabel` / `postPressLabel`

## Implementer's notes

1. **Read `score-bug.tsx` first** before writing a line. It is the primary template for `discriminatedUnion('platform', [...])` dispatch + per-bundle render-function fan-out. T-317 mirrors its file shape verbatim, swapping `style` for `platform` and 4 sport bundles for 4 platform bundles. LOC yardstick: leaner than score-bug (~700 LOC) because the per-platform render paths are simpler (single button shape + label + optional glyph; vs sport-specific multi-row layouts).
2. **Read `breaking-banner.tsx` second** for the entrance-interpolate idiom. T-317's bounce-overshoot uses a similar `interpolate(frame, [...], [...], { easing: cubicBezier(...) })` shape, but with three keyframes (0, peak, settle) instead of two (start, end). Apply via `transform: scale(${overshoot})`.
3. **Schema first.** D-T317-3 / D-T317-4 / D-T317-7 / D-T317-8 all affect schema shape. Conservative defaults (per-platform fonts + casings + border-radii baked in; all colors optional with theme fallback in `'generic'` only; brand canon dominates theme in branded platforms). Required: `platform`, `position`, `label`. All other fields optional.
4. **Discriminated-union discipline.** Mirror `score-bug.tsx`'s `discriminatedUnion('platform', [youtubeSchema, tiktokSchema, instagramSchema, genericSchema])` verbatim. Each branch's strict `.strict()` enforces no extras. NO `.refine()` wrappers on the union branches (Zod doesn't allow them on `discriminatedUnion` arms). Use `z.literal('youtube')` etc. for the discriminator.
5. **Per-platform render functions.** Implement `renderYoutube` / `renderTiktok` / `renderInstagram` / `renderGeneric` as separate functions called from the top-level `switch (platform)` block. Each function returns the platform-canonical `ReactElement` for the current `phase`. Avoid bloating the main component with inline platform-specific JSX.
