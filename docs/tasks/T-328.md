# T-328 — Preset: `msnbc-big-board` (fullScreen, Cluster A)

**Branch**: `task/T-328-msnbc-big-board`

## Goal

Promote the existing `msnbc-big-board` preset stub from `status: stub` to `status: substantive` and ship it as the **eighth and final Cluster A preset to land**, the **second consumer of the `fullScreen` clipKind** (after T-355 `magic-wall-drilldown` which holds the clipKind-default arm), and the second production binding of T-355a's `magic-wall-panel` primitive. Closes Cluster A to **8/8 substantive + signed**, unlocking T-382 cluster-batch type-design review eligibility for all eight Cluster A presets.

T-328 binds via **`PRESET_ID_BINDINGS['msnbc-big-board']`** per **Pattern C** from `docs/handover-phase13-mid.md` §2 ("First preset for a clipKind uses clipKind-default; second-and-later share the clipKind via `PRESET_ID_BINDINGS`"). T-355 (`magic-wall-drilldown`) was the first `fullScreen` consumer and lives in the `DEFAULT_CLIP_KIND_RESOLVER` `'fullScreen'` switch arm returning `fullScreenBinding` (= the magic-wall-drilldown CNN-default binding). T-328 is the **second** `fullScreen` consumer; it lands a `PRESET_ID_BINDINGS` override keyed by preset id `'msnbc-big-board'`. **The `'fullScreen'` arm of `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED.**

T-328 is **M-sized** — on par with T-327 (the just-shipped sibling Cluster A `breakingBanner` second-consumer), T-325 / T-326 / T-329 / T-330 (sister `lowerThird` `PRESET_ID_BINDINGS` overrides). Comparable shape: ~30–40 LOC binding entry + a canonical-snapshot constants block (region payload + party-color palette) + single steady-state parity golden + sign-off in-PR. The primitive (T-355a `magic-wall-panel`) and clipKind-default (T-355 `fullScreenBinding` = magic-wall-drilldown CNN-default) are already on `main`; T-328 is the second consumer with no further carve-out — Pattern E rebuild is precautionary only.

The architectural novelty is **second consumer of the `fullScreen` clipKind sharing the same primitive (`magic-wall-panel`) with different snapshot data + a tenant-distinct partisan-neutral color palette**. v1 ships ONLY the steady-state county-level overlay panel layer; the stub's 3D virtual backdrop, operator cursor, real-time vote count-ups, and zoom transitions between hierarchy levels are deferred to follow-up carve-outs OR external composition (see D-T328-3). Inherits T-359a's multi-variant infra in trivial-arity mode, T-359b's prod-renderer pipeline, T-359c's tsx fix, T-360's `(clipKind, presetId)` resolver shape (used in `PRESET_ID_BINDINGS` override mode here per D-T328-2), T-355's first-`fullScreen`-consumer-via-clipKind-default precedent (= the analog template for the override pattern), T-367's in-PR sign-off (Pattern D), F-4 hand-pin via `--psnr=42 --ssim=0.98 --mark-signed` flags (T-324 / T-325 / T-326 / T-327 / T-329 / T-330 precedent — generator-flag-driven, no manual `thresholds.json` edit).

## Architectural decisions

### D-T328-1. Compass register match — partisan-color-neutral NBC peacock palette + steady-state county-level overlay panel mirroring T-355's posture

The stub (lines 22–43) defines the canonical MSNBC Big Board register:

- **Full-screen interactive map / touchscreen register** (line 23). Persistent overlay panel at canvas scale.
- **3D virtual backdrop** (line 24 — virtual White House / 30 Rock with projected data) — out of v1 scope per D-T328-3 (composes externally).
- **High-contrast state / county / precinct overlays** (line 25) — v1 captures the **county-level settled** layer (per stub line 38 third candidate frame "60 (county-level settled)").
- **Operator cursor / touch overlay** (line 26 — Kornacki-style rapid-fire tap-and-swipe) — out of v1 scope per D-T328-3 (carve-out `T-328a` IF demanded).
- **Layered UI** (line 27 — map base + data overlay + callout panel) — v1 ships the data overlay layer ONLY; the map base is the placeholder-rectangle grid (inherited from T-355 D-T355-6); the callout panel is documented in prose, NOT in the primitive's prop surface.
- **Stub line 41**: "Do not adopt CNN's Magic Wall color palette (Dem Blue / Rep Red) as-is — defer to the tenant's partisan-color-neutral alternative when applicable." This is the **central palette divergence** between T-328 (msnbc-big-board) and T-355 (magic-wall-drilldown).

T-328 binds these to the just-shipped `magic-wall-panel` primitive (T-355a)'s render contract. The mapping mirrors T-355's verbatim, swapping the tenant identity (CNN → MSNBC) + party palette (CNN-default Dem-Blue / Rep-Red → NBC peacock-derived partisan-neutral hues) + title / subtitle strings (Election Results / State-by-state breakdown → 2024 ELECTION NIGHT / County-level — 92% Reporting). Region geometry (4×2 grid of placeholder rectangles), region count (50 → reduced to 8 for v1 per D-T328-5), entrance posture (`'stagger-rise'` at 60 ms), background `#0E0E12`, foreground `#FFFFFF`, `valueFormat: 'count'` + `valueLabel` percentage override pattern → all inherited from T-355 verbatim.
