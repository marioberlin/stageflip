# T-329 — Preset: `netflix-doc-lt` (lowerThird, Cluster A)

**Branch**: `task/T-329-netflix-doc-lt`

## Goal

Promote the existing `netflix-doc-lt` preset stub from `status: stub` to `status: substantive` and ship it as the **fifth Cluster A (news / lower-third) preset to land** AND the **fifth consumer of the `lowerThird` clipKind** in the parity-CLI resolver. Netflix's documentary register is the platform's typographic-art lower-third: white text directly on footage, NO background shape, Mixed-Case name in DM Sans Medium (Netflix Sans OFL fallback), ALL-CAPS title with wide tracking. Common uses: documentary credits, talent role-identification on dark-leaning footage, "documentary-neutral default" when no broadcast-register brand is specified.

T-329 is the **fifth** preset to bind the `lowerThird` clipKind. T-323 (`cnn-classic`, merged) holds the **clipKind-default** slot in `DEFAULT_CLIP_KIND_RESOLVER` (`lowerThird → cnnClassicBinding`). T-325 (`bbc-reith-dark`, merged) wired the **first** `PRESET_ID_BINDINGS` override for `lowerThird`. T-326 (`al-jazeera-orange`, merged) wired the **second**. T-330 (`apple-tv-lt`, merged) wired the **third**. T-329 adds the **fourth** `lowerThird`-keyed `PRESET_ID_BINDINGS` override keyed on `'netflix-doc-lt'` — Pattern C from `docs/handover-phase13-mid.md` §2 (third-or-later-preset-for-clipKind via override map). Mirrors T-330's bind shape exactly, swapping snapshot constants.

T-329 is **also the second production consumer of T-183z** (`noFlag` / `subtitleColor` / `font` props on `LowerThird`). T-330 was first (Apple TV+); T-329 reuses the same prop-axis pattern for Netflix's no-chrome register: NO flag, subtitle white-decoupled-from-accent, DM Sans Medium (Netflix Sans OFL fallback) at the prop axis. T-329 also is the **second preset PR to use F-4 generator flags** (`--psnr=42 --ssim=0.98`) — eliminating the manual `thresholds.json` hand-pin step.

T-329 is **S-sized** — same envelope as T-330 because the cluster pattern is now quadruply-established (Pattern C precedent locked across T-325 + T-326 + T-330) AND F-4 + T-183z have shipped. ~25–30 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. No primitive carve-out (T-183z already shipped). No schema change.

## Architectural decisions

### D-T329-1. Compass register match — Netflix doc minimalist register (no chrome; white-on-footage; DM Sans Medium humanist)

The stub (lines 22–43) defines the canonical Netflix documentary register:

- **No background shape** (line 23 "Clean white `#FFFFFF` text directly on footage"). The primitive renders a card; the v1 trade-off is to set `background` to a canvas-matching black `#000000` (the renderer's default canvas color) so the card visually disappears against a dark canvas. The thin boxShadow that the primitive hard-codes will still be visible at edges — documented as a primitive-level cosmetic divergence (D-T329-11-a; `T-183z`-family follow-up). This mirrors T-330's posture for Apple TV+'s text-only register.
- **No flag / accent strip** — Netflix's documentary register has zero colored chrome. T-183z added a `noFlag: boolean` prop precisely for this case. **`noFlag: true` per D-T329-3**.
- **Optional dark gradient vignette** at bottom of frame (line 24). Canvas-level treatment, NOT a primitive prop — Out-of-scope.
- **Optional thin line separator** between name and title (line 25). Primitive has no separator — Out-of-scope.
- **Position bottom-left, generous padding** 120 px from left, 80 px from bottom @ 1080p (line 26). v1 picks the stub's exact values: `insetLeftPx: 120`, `insetBottomPx: 80`.
- **Typography**: name Netflix Sans fallback, Medium / SemiBold, Mixed Case, 24–30 pt, letter spacing +50–100 (line 29); title Light / Regular, often ALL CAPS, wide tracking +150–200, 18–22 pt (line 30). v1 picks `font: { family: 'DM Sans', weight: 500 }` (DM Sans Medium = OFL fallback for Netflix Sans; weight 500 matches Netflix's "Medium / SemiBold" register at the lighter end). Mixed Case for name + **ALL CAPS for title via snapshot-string casing** per D-T329-6. The primitive renders name at fontSize 34 (slightly above the stub's 24–30 pt; cosmetic — primitive default) and title at 18 (in range).
- **Rules** (lines 41–44): "No background box. ... Generous padding is non-negotiable; this is typographic art, not information packing. ALL CAPS + wide tracking on the title is the signature; do not collapse to Mixed Case. Use this preset by default when no broadcast-register brand is specified (falls back to documentary-neutral)." — T-329 honors restraint AND the ALL-CAPS title rule via D-T329-6.

T-329 binds these to the existing `LowerThird` primitive's render contract (T-183 + T-183z). The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| No flag / accent strip (no chrome) | `noFlag` (T-183z) | `true` |
| No background card (visually) | `background` | `'#000000'` (canvas-matching black; card disappears against dark canvas) |
| Headline Mixed Case, white | `name` (rendered in `textColor`) | `'Ava DuVernay'` (Mixed Case, real Netflix doc collaborator — director of *13TH* (2016, Oscar-nominated Netflix Original)) |
| Subtitle ALL CAPS via snapshot-string casing (D-T329-6) | `title` + `subtitleColor` (T-183z) | `'DIRECTOR'` (literal upper) + `subtitleColor: '#FFFFFF'` |
| Headline color white | `textColor` | `'#FFFFFF'` |
| `accent` (irrelevant — `noFlag: true` suppresses) | `accent` | `'#FFFFFF'` (default-safe; not rendered) |
| Position 120 px from left, 80 px from bottom | `insetLeftPx`, `insetBottomPx` | `120`, `80` |
| DM Sans Medium humanist family at the prop axis | `font` (T-183z) | `{ family: 'DM Sans', weight: 500 }` |

The preset register is **white text on a dark canvas with NO chrome and ALL-CAPS title via snapshot string**. A meaningful departure from T-330's Apple TV+ all-Mixed-Case register (Netflix's "ALL CAPS title" is a defining brand signature per stub line 43; Apple TV+'s register is uniformly Mixed Case). T-329 establishes the **snapshot-string casing pattern** for "Mixed-Case name + ALL-CAPS title" presets without primitive change — this becomes the canonical posture for any future preset whose stub demands per-line casing without a `casing` prop.

### D-T329-3. `noFlag: true` per T-183z — Netflix doc register has no chrome (second production consumer)

The `LowerThird` primitive's default render includes a 6 px-wide accent strip on the left edge, fill = `accent`. Netflix's documentary register has **zero colored chrome** (stub line 23 "Clean white `#FFFFFF` text directly on footage"; line 41 "No background box."). T-183z added a `noFlag: boolean` prop; `noFlag === true` suppresses the strip entirely (line 134 of `lower-third.tsx` returns `null` instead of the `<span data-testid="lower-third-accent">`).

**Decision**: pass `noFlag: true` in `NETFLIX_DOC_LT_PROPS`. T-329 is the **second production consumer of T-183z's `noFlag` prop** (T-330 was first). Without it, T-329 would inherit the inappropriate 6 px accent strip — contradicting the "no chrome / typographic art" register.

The `accent` prop is still passed (`'#FFFFFF'`) for type-safety; its value is irrelevant because `noFlag === true` suppresses the rendering.

### D-T329-4. `subtitleColor: '#FFFFFF'` per T-183z — talent-line decoupled from `accent`

Pre-T-183z, the `LowerThird` primitive hard-coded `color: accent` on the title (subtitle) line. T-183z added a `subtitleColor` prop that, when present, overrides the title-line color independently of `accent` (`const titleColor = subtitleColor ?? accent`).

Netflix's register paints both name and title in **white** directly on footage (stub line 23). With `noFlag: true` + `subtitleColor: '#FFFFFF'`, the subtitle renders as white DM Sans Medium — matching the stub's "Title: Light / Regular ... 18–22 pt" register at the right color.

**Decision**: pass `subtitleColor: '#FFFFFF'`. **Second production consumer of T-183z's `subtitleColor` prop**. Without it, the subtitle would render in `accent` (`'#FFFFFF'` here — by coincidence the same color, since we don't render the strip — but the binding shape would be wrong if a future preset tweaks `accent`). Pinning `subtitleColor` makes the contract explicit.

### D-T329-5. `font: { family: 'DM Sans', weight: 500 }` per T-183z — DM Sans Medium = Netflix Sans fallback

Pre-T-183z, the `LowerThird` primitive hard-coded `fontFamily: 'Plus Jakarta Sans, sans-serif'` with weights 700 (name) and 500 (title). T-183z added a `font: { family: string; weight?: number }` prop that, when present, overrides both family and a uniform weight applied to name + title.

Netflix's preferred font is `Netflix Sans` (proprietary-byo; Netflix-licensed in-house typeface — saves Netflix "millions of dollars" in Gotham licensing per stub line 53). The OFL fallback is `DM Sans` weight 500 (Medium) — declared in stub frontmatter and registered as OFL via Google Fonts. DM Sans is Google's "approachable geometric grotesque" (stub line 31 "fallback must preserve this register") and closely approximates Netflix Sans's humanist warmth at the same x-height.

**Decision**: pass `font: { family: 'DM Sans', weight: 500 }`. **Second production consumer of T-183z's `font` prop**. The primitive applies weight 500 uniformly to both name and title — matching the stub's "Medium / SemiBold" name + "Light / Regular" title register at a single Medium weight. (Distinguishing Medium-vs-Regular per line is not possible with the primitive's uniform-weight axis; v1 picks weight 500 — DM Sans Medium is closest to the stub's "Medium / SemiBold" name register, and per line lighter weight differentiation is a primitive-level carve-out.)

### D-T329-6. Casing — Mixed Case name + ALL CAPS title via snapshot-string casing (canonical "headline Mixed + title ALL CAPS" pattern)

The primitive does NOT have a per-line `casing` prop. **Decision**: apply casing at the **snapshot-string level**. `name: 'Ava DuVernay'` (Mixed Case) and `title: 'DIRECTOR'` (literal upper). This establishes T-329 as the canonical example of the **"headline Mixed Case + title ALL CAPS"** pattern for any future preset whose stub demands per-line casing without a per-line `casing` prop. ### D-T329-7. Reference frame for the parity golden — frame 60 (steady-state mid-hold)

Stub line 47 lists candidate frames: "0 (pre-fade), 24 (mid-fade), 48 (settled), 144 (pre-exit)." Frame 48 is post-entry and steady-state; **frame 60** is comfortably mid-hold (`60 > enterEnd = 14 && 60 < exitStart = 79` at fps=30 / `durationInFrames=90`); aligns with `--frame=60` default in `docs/ops/parity-fixture-signoff.md` and matches T-323 / T-325 / T-326 / T-330 cluster-internal consistency.

**Canonical reference frame: 60**. Steady-state mid-hold; `translatePct == 0`; `opacity == 1`; full text on screen, no chrome, no strip. Mirrors T-330.

Verify via the manifest after generation; if the rendered frame shows partial-opacity or partial-translate, shift to frame **30** (well past entry, well before any plausible exit). Document.
