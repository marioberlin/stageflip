# T-333 — Preset: `premier-league-field-of-play` (scoreBug, Cluster B)

**Branch**: `task/T-333-premier-league-field-of-play`

## Goal

Promote the existing `premier-league-field-of-play` preset stub from `status: stub` to `status: substantive` and ship it as the **first Cluster B (sports / score-bug) preset to land** AND the **second consumer of the `scoreBug` clipKind** in the parity-CLI resolver AND the **first production consumer of T-332a's `'football'` style bundle** in the `score-bug` runtime-clip primitive. The preset captures the Premier League's 2017+ broadcast canon: a compact upper-left rectangular scoreclock with PL purple `#34003A` chrome, PL green `#00FC8A` accent, white text, 3-letter team codes (ARS / CHE) on kit-color team boxes, and tabular-numeric scores + match clock + period token. Common uses: live football match overlays; pre-match / mid-match / settled-state scoreboards on a flat broadcast canvas where the PL purple+green register is the brand signal.

T-333 is the **second** preset to bind the `scoreBug` clipKind. T-358 (`cricket-ball-by-ball-dots`, already merged) holds the **clipKind-default** slot in `DEFAULT_CLIP_KIND_RESOLVER` (`scoreBug → scoreBugDotsBinding`), but binds via the `outcome-row` primitive (NOT score-bug) — T-358 predates the T-332a `score-bug` primitive. T-333 must therefore wire its binding via the **`PRESET_ID_BINDINGS` override map** keyed on `'premier-league-field-of-play'` — Pattern C from `docs/handover-phase13-mid.md` §2 (second-preset-for-clipKind). Mirrors T-325's bbc-reith-dark second-`lowerThird`-consumer pattern verbatim, swapping `lowerThird → scoreBug` AND swapping the bound primitive (`lower-third` → `score-bug`). T-358's clipKind-default arm is **NOT** touched — T-358's `outcome-row` binding stays as the `scoreBug`-clipKind-default for unbound presets.

T-333 is **first production consumer of T-332a's `'football'` style bundle**: T-332a (just merged at d91220a) shipped the `score-bug` primitive with four sport-register style branches (`'football'` / `'racing'` / `'cricket'` / `'tennis'`); T-333 is the first preset to bind the `'football'` discriminant to a parity golden. T-336 / T-337 / T-334 / T-335 (sister Cluster B presets) will exercise the remaining three branches in their own preset PRs.

T-333 is **M-sized** — same envelope as T-323, T-325, T-364, T-365. ~30–40 LOC binding + snapshot constant + single steady-state parity golden + sign-off in-PR. No primitive carve-out; no schema change. Inherits T-325's resolver shape end-to-end (`(clipKind, presetId)` lookup; presetId-override path takes precedence over the clipKind-default arm).

## Architectural decisions

### D-T333-1. Compass register match — PL purple `#34003A` chrome + PL green `#00FC8A` accent + 3-letter team codes ARS/CHE on kit-color team boxes + tabular-numeric scores + clock + period

The stub (lines 22–46) defines the canonical Premier League scoreclock register:

- **Position**: compact rectangular scoreclock, upper-left (line 23). T-333 anchors at `position: { x: 60, y: 60 }` (60 px in from top-left; standard cluster-internal upper-left register).
- **Primary fill / chrome**: PL purple `#34003A` (line 24) — passed via `background` prop (the primitive's root `backgroundColor` per `rootStyle()`).
- **Accent**: PL green `#00FC8A` (line 25) — declared in frontmatter for theme-slot mapping but NOT bound to a primitive prop in the steady-state football branch (no green-stripe slot in T-332a). The primitive's `accent` theme-slot is a palette role, not a per-render-element binding for the football branch. Cosmetic; documented.
- **Text**: `#FFFFFF` (line 26) — passed via `foreground`. NOTE: team-box text is hard-bound to `#ffffff` regardless of `foreground` (lines 314); only the **clock** + **period** lines obey `foreground`. Aligns with stub since text is white anyway.
- **Per-team kit colors**: ARS Arsenal red `#EF0107` + CHE Chelsea blue `#034694` — the canonical PL fixture pairing; both teams have distinct, high-contrast kit signals (red vs blue) that exercise the kit-color-as-instant-ID rule of the preset (stub line 43).
- **Team abbreviations**: 3-letter (`'ARS'`, `'CHE'`) Mixed-Case-but-already-uppercase (line 32) — Bold tabular per the primitive's 28 px / weight 800 default.
- **Scores**: Tabular Bold (line 33). Snapshot uses `'2'` (Arsenal) / `'1'` (Chelsea) — a plausible mid-second-half scoreline. The `score` field is a **string** per the schema; passes the primitive's `applyCasing` numeric short-circuit unchanged.
- **Clock + period**: `'67:42'` + `'2H'` (line 34: minute / period Regular 12–14 pt) — the primitive renders clock at 20 px / weight 700, period at 12 px / opacity 0.85; both Bold-leaning rather than the stub's Regular but in the same hierarchical neighborhood.
- **Solid background, no transparency** (line 29) — primitive renders at 100 % opacity by default; aligns with stub.

T-333 binds these to the existing `score-bug` primitive's `'football'` branch (T-332a). The mapping:

| Stub element | Primitive prop | Snapshot value |
|---|---|---|
| Compact upper-left position | `position: { x, y }` | `{ x: 60, y: 60 }` |
| PL purple chrome `#34003A` | `background` | `'#34003A'` |
| White text on chrome | `foreground` | `'#FFFFFF'` |
| Arsenal home team — kit-color-stripe instant-ID | `home: { code, color, score }` | `{ code: 'ARS', color: '#EF0107', score: '2' }` |
| Chelsea away team — kit-color-stripe instant-ID | `away: { code, color, score }` | `{ code: 'CHE', color: '#034694', score: '1' }` |
| Match clock | `clock` | `'67:42'` |
| Period (second half) | `period` | `'2H'` |
| Premier Sans proprietary-byo → Space Grotesk OFL fallback | `font: { family, weight, tabularNums }` | `{ family: 'Space Grotesk', weight: 600, tabularNums: true }` |
| Casing (3-letter codes / period token) | `casing` | `'as-is'` (snapshot strings already in target casing) |
| PL green `#00FC8A` accent | (frontmatter only — not bound to football branch) | declared via theme-slot, not rendered |
