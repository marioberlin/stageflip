# T-351 — Preset: `true-detective-double-exposure` (titleSequence, Cluster D)

**Branch**: `task/T-351-true-detective-double-exposure`

## Goal

Promote the existing `true-detective-double-exposure` preset stub from `status: stub` to `status: substantive` and ship it as the **third Cluster D (titles / opens / bumpers / credits) consumer preset to consume the T-321 atmospheric-primitive carve-out roadmap end-to-end**, the **second multi-clip composition** in the parity-CLI (sister to T-348 `stranger-things-benguiat` which landed the `ClipKindBinding.overlays?` extension), AND the **PRIMARY consumer of the T-321d `photographic-overlay` primitive** (compass canon "photographic clip" register per T-321d's own header line 28). T-351 ships the prestige-TV True Detective S1 canon: muted desaturated earth-tone palette (oily yellows, sickly greens, industrial grays — Richard Misrach "Petrochemical America" Cancer-Alley register), unobtrusive clean sans-serif credit typography (Inter Regular fallback at 24–30 pt; the photography is the foreground; the type is deferential), photographic-overlay-dominant tonal grading via `mode: 'cinematic-lut'` at high intensity, and mandatory subtle film grain throughout per the stub canon line 27.

T-351 is the **third Cluster D consumer** of the just-completed T-321 carve-out roadmap (T-348 — stranger-things-benguiat — was the first multi-clip consumer; T-350 squid-game-geometric was a single-clip Cluster D preset that pre-dated the multi-clip extension). - **T-321d** — `photographic-overlay` primitive (`mode: 'cinematic-lut'` for the muted desaturated earth-tones palette; PRIMARY consumer per T-321d's own header line 28 explicitly designating T-351 as the primary consumer).

Cluster D is **2/6 signed** as of `main` HEAD `e6d1a034` (T-350 squid-game-geometric merged earlier in Phase 13 single-clip; T-348 stranger-things-benguiat just landed multi-clip). **T-351 brings Cluster D to 3/6 signed.**

T-351 is **L-sized** (matching T-348's L-size envelope; both compose multi-clip + ship lowered thresholds + introduce a new register). The L-size envelope is driven by:
1. Three primitive snapshots (titleSequence + grain + photographic-overlay), each requiring per-primitive prop tuning from the stub-canon register.

### D-T351-2. Composition order (z-stack) — titleSequence (base) → grain → photographic-overlay (top); 3 clips total (vs. T-348's 5)

The three clips compose at full canvas in this strict declaration order = z-order:

```
zIndex 0 — titleSequence ('photographic-overlay' style; titlePlate shot only) — typography base
zIndex 1 — grain — film-grain noise overlay (alpha-blended over typography)
zIndex 2 — photographic-overlay ('cinematic-lut' mode @ 0.6 intensity) — top tonal pass; muted earth-tone grading
```

**Rationale**:
1. **Typography first** — credit text must render in the underlying composition; placing it at the bottom of the stack lets grain + photographic-overlay cast their effects ON the type rather than under it. Stub line 33: "Typography is unobtrusive — the photography is the foreground." This z-stack interpretation is correct: type goes BEHIND the photographic-overlay tonal cast so the cast applies to the type as well as the (placeholder) background.
2. **Grain second** — grain coats every pixel of the canvas equally. Placing it directly above the typography lets grain texture the credit letterforms AND the underlying composition. Grain at intensity 0.15 is non-destructive; it does not obscure type.
3. **Photographic-overlay third (top)** — final tonal pass; SVG filter primitives are pure pixel-level transforms over the underlying composite. Placing it at the top guarantees the cinematic-LUT tonal grading applies to the FULL composite (type + grain), producing a uniform muted earth-tone wash across both underlying layers. The cinematic-LUT matrix's lifted R + slightly-lifted B channels muted via slightly-suppressed G mid-tones produces the "oily yellow / sickly green / industrial gray" register per stub line 23.

**No light-leak overlay (vs. T-348's zIndex-2 layer)**:
- The True Detective canon does NOT include warm-orange light leaks — these would conflict with the muted-earth-tone register. Stub line 23 specifies "muted, desaturated earth tones — oily yellows, sickly greens, industrial grays" — adding warm-orange radial blobs (T-131b.2's default register) would shift the palette toward "warm-festival-lights" rather than the desolate Cancer-Alley register. v1 ships zero light-leak overlay. Documented in this decision letter.

**No particles overlay (vs. T-348's zIndex-3 layer)**:
- The True Detective canon does NOT include atmospheric drifting particles — the visual interest IS the photographic-overlay-dominant tonal register, not snow/dust drift. Adding `'snow'` particles (T-131d.1's default closest-match for atmospheric dust) would import an unintended cool-white-tinted highlight stream. v1 ships zero particles overlay. Documented in this decision letter.

The overlay-array's declaration order in `trueDetectiveDoubleExposureBinding.overlays = [grainOverlay, photographicOverlayOverlay]` directly encodes this z-stack.

If a Reviewer demands one of (light-leak / particles) be added → escalate per CLAUDE.md §6; the stub canon explicitly does NOT enumerate either layer. The 3-clip composition is intentionally simpler than T-348's 5-clip stack.

### D-T351-3. Photographic-overlay props — `mode: 'cinematic-lut'` @ `intensity: 0.6` (DOMINANT muted-earth-tone register)

The stub line 23 declares "muted, desaturated earth tones — oily yellows, sickly greens, industrial grays". The `photographic-overlay` primitive has a sealed `mode` enum `['sepia', 'cross-process', 'cinematic-lut', 'fade']`. **`'cinematic-lut'`** is the closest sealed-enum match for True Detective's register — the `CINEMATIC_LUT_MATRIX` (T-321d primitive lines 105–110):

```
1.10  0.05 -0.05  0  0
0.00  1.05  0.05  0  0
-0.05 0.05  1.10  0  0
0     0    0     1  0
```

The matrix's diagonal terms boost R (×1.10), G (×1.05), B (×1.10) modestly while the off-diagonal cross-channel terms (-0.05 G→R, -0.05 R→B, +0.05 R→G, +0.05 B→G, -0.05 B→R, +0.05 G→B) introduce subtle teal-orange contrast. Applied at intensity 0.6, this produces the muted desaturated grading that matches True Detective's "oily yellows, sickly greens, industrial grays" palette closely — **NOTE**: the photographic-overlay primitive's teal-and-orange contrast bias actually MATCHES the True Detective palette closely (industrial grays come through in the moderately-boosted G channel; oily yellows from the boosted R + slight G-channel lift; sickly greens from the cross-channel mixing).

**Intensity 0.6 (HIGH, vs. T-348's 0.4)**: opposite posture from T-348. T-348 capped intensity at 0.4 to NOT obliterate the underlying red-glow letterform register; T-351's photographic-overlay IS the foreground per stub line 33 ("the photography is the foreground"). Pushing intensity to 0.6 makes the cinematic-LUT cast dominate the visual without overwhelming the credit typography (which sits at unobtrusive 24–30 pt per stub line 30).

```typescript
const TRUE_DETECTIVE_PHOTOGRAPHIC_OVERLAY_PROPS = {
  mode: 'cinematic-lut' as const,
  intensity: 0.6,
  // position omitted (defaults to full-canvas)
```

### D-T351-4. Reference frame — frame 360 at default fps 30 (compass-canonical "mid-arc")

**The fps story**:
- Stub line 48 lists candidate frames: "0 (entry), 360 (mid-arc), 720 (climax), 1080 (resolution at 90 s @ 12 fps effective)".
- The "12 fps effective" annotation refers to the canonical real-world sequence pace at slowed footage (~1/10 speed per stub line 26 — actually 12 fps is closer to 1/2.5 than 1/10, but the stub's 12-fps annotation is what we work from); 90 s × 12 fps = 1080 frames.
- **The parity render uses default fps 30** (not 12). `scripts/generate-preset-parity-fixture.ts` `parseArgs` does NOT accept a `--fps` flag (verified during T-348 implementation; lessons documented). The composition default is 1280×720 @ 30 fps × 5 s = 150 frames per `DEFAULT_COMPOSITION` (line 60–66).
- **Decision**: T-351 picks `--frame=360` directly under default fps 30. This is interpreted as the "mid-arc" stub annotation; under fps 30, frame 360 = 12 s in (well past the entry but before any climax / resolution effect — for a static-frame snapshot of a credit hold, this is the canonical mid-arc pose).
- **Mismatched stub annotation accepted**: the stub's "12 fps effective" frame numbering does NOT map to the parity-render's fps-30 frame numbering. The mid-arc REGISTER (a steady-state credit hold under the photographic-overlay tonal grading) is preserved at frame 360 fps 30 as well as it would be at frame 360 fps 12 — the static photographic-overlay primitive is fps-agnostic; the grain primitive's xxhash32 hash IS frame-dependent (hash includes `frame` per primitive); the titleSequence's `titlePlate` shot kind is frame-stable for the duration of the shot (no per-letter staggered fade under `'photographic-overlay'` style — the type just renders).

**Rationale for frame 360 specifically**:
- Frame 0 (entry) — at fps 30, frame 0 = 0 s; the canvas may show only the deep-background palette + grain. Misses the typographic identity if the title-sequence's `titlePlate` shot has not yet entered.
- Frame 360 (mid-arc) — at fps 30, frame 360 = 12 s; the title-sequence's `titlePlate` shot is fully visible (`startMs` set to 0 so it's visible from frame 0 onward); grain is at canonical hash; photographic-overlay applies its static grading. Cleanest mid-arc steady-state register.
- Frame 720 (climax) — at fps 30, frame 720 = 24 s. Equivalent register to 360 (no time-dependent state in the photographic-overlay primitive); the title may have transitioned out by 24 s if `endMs` is set to mid-sequence. Avoid; frame 360 is the canonical pick.
- Frame 1080 (resolution) — at fps 30, frame 1080 = 36 s. Equivalent register to 360 if `endMs` is past 36 s.

**Decision**: `--frame=360` (mid-arc; no `--fps` flag — uses default 30). Manifest pins `composition.fps: 30`.

If a Reviewer prefers a different reference frame (e.g., 0 to capture an "entry" register; 720 to capture "climax"; 1080 to capture "resolution") → escalate per CLAUDE.md §6; v1 ships single-frame golden; multi-variant infra is a T-359a-family follow-up. Mid-arc (360) is the cleanest steady-state pose.

If a Reviewer prefers `--fps=12` to match the stub's "12 fps effective" annotation → escalate; the parity-CLI does NOT accept a `--fps` flag (verified). Adding the flag is out-of-envelope for this preset PR; would require a parity-CLI surface extension.

### D-T351-5. Lowered thresholds — PSNR 34 / SSIM 0.90 (per stub line 49; lower than T-348's 36 / 0.92)
