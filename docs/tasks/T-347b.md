## Decisions

### D-T347b-1 — single-style primitive (NHC 5-day cone)

`stormTracker` ships v1 with a SINGLE style — the NHC 5-day cone of uncertainty. Schema is a single Zod `object().strict()` (NOT `discriminatedUnion`) — there is only one consumer preset, and the cone register is the dominant US national hurricane-tracking convention.

Mirrors the T-319 qr-code-bounce / T-321a grain pattern (single object schema, no style enum) rather than the T-321 titleSequence / T-347a weatherMap pattern (discriminatedUnion across multiple style branches).

**Rejected**: prematurely introducing a `style: 'nhc-cone'` enum for forward-compat with future "inland warnings" 2026 update or regional alternatives (JMA / NHK, etc.). Adding the enum NOW with a single member buys nothing; when a second register lands, that PR introduces the enum + migrates this primitive.

### D-T347b-2 — disclaimer is a HARD-CODED render output, not an optional prop

The cluster SKILL declares the "Impacts extend beyond the cone" disclaimer **non-negotiable** — it's a documented public-safety failure mode where viewers misread "outside cone = safe". Per D-T347b-2 the disclaimer text is rendered ALWAYS; the caller cannot suppress it. The caller MAY override the exact wording via an optional `disclaimerText?: string` prop with sensible default `"Impacts extend beyond the cone"`; the primitive renders the prop value (or default) and applies a minimum visibility floor (text size + contrast) regardless of caller styling.

A test asserts the rendered DOM contains a `data-testid="storm-tracker-disclaimer"` element with non-empty text content for every render. **Rejected**: an `enabled?: boolean` flag on disclaimer (would let consumers disable it; that's the public-safety failure mode the rule guards against).

### D-T347b-3 — canonical NHC coastal-warning palette baked as static module constants

Three palette constants exported (consistent with T-347a sibling pattern):

- `NHC_HURRICANE_WARNING_RED`: `'#DC143C'` (Crimson — Hurricane Warning per stub line 26)
- `NHC_HURRICANE_WATCH_MAGENTA`: `'#FF00FF'` (Hurricane Watch per stub line 27)
- `NHC_TROPICAL_STORM_FIREBRICK`: `'#B22222'` (Tropical Storm Warning per stub line 28)
- `NHC_STORM_SURGE_PURPLE`: `'#B524F7'` (Dark Purple — Storm Surge Warning per stub line 29)

Plus `NHC_INTENSITY_LETTERS = ['D', 'S', 'H', 'M']` for forecast-track-dot labels (Depression / Storm / Hurricane / Major) per stub line 30 — NWS-mandated shorthand, not customizable.

Caller-supplied palette overrides REJECTED — these are public-safety standards.

### D-T347b-4 — cone polygon: caller supplies SVG path data

The cone widening over 5 days is consumer-specific (storm-by-storm geometry). Per the T-347a `mapPaths[]` precedent, callers supply the cone as `cone: { d: string, fill?: string, opacity?: number }` — a single SVG path describing the cone polygon, with optional fill (default semi-transparent white `rgba(255, 255, 255, 0.4)`) and opacity (default 0.4).

The primitive does NOT generate the cone geometry — that's storm-data territory and depends on real-time NHC advisory positions. Parity-fixture goldens carry a synthetic 5-day cone path sized to the 1280×720 default canvas.

### D-T347b-5 — track-dots with intensity letters

`trackDots: Array<{ id: string, position: {x, y}, intensity: 'D' | 'S' | 'H' | 'M', timestamp?: string }>`. Each dot renders as a circle with a centered intensity letter (D/S/H/M). Optional `timestamp` renders as a small label below the dot (e.g., "5pm Mon"). Sealed `intensity` enum mirrors the NHC mandate.

Track dots are rendered on top of the cone (z-stack inside the SVG: cone path → track dots → labels → disclaimer overlay).

### D-T347b-6 — coastal warning regions: per-region `warningType` enum maps to palette

`coastalWarnings?: Array<{ id, regionPaths: Array<SVGPathString>, warningType: 'hurricane-warning' | 'hurricane-watch' | 'tropical-storm-warning' | 'storm-surge-warning' }>`. Each warning region renders as one or more SVG paths colored per the canonical NHC palette resolved from `warningType`.

`warningType` is sealed; the resolution helper `resolveCoastalWarningColor(warningType)` is exported for parity-cli resolver-shim use.

### D-T347b-7 — storm-name + advisory-timestamp top banner

`storm: { name: string, advisoryTimestamp?: string }` — storm name renders ALL CAPS bold 28-32pt at the top of the canvas (per stub line 35); optional timestamp renders smaller below. Theme-slot fallback `foreground` applies for the text color.

### D-T347b-8 — base map via consumer-supplied `mapPaths[]` (mirrors T-347a)

Same pattern as T-347a `weatherMap`. `mapPaths?: Array<{ id, d, fill? }>` for the coastal map underlying the storm graphic. Default fill `#1A2A3F` (dark navy — typical NHC map base). Primitive does NOT bundle map geometry.

### D-T347b-9 — theme-slot fallback (D-T347b-9)

Per cluster SKILL conventions: theme slots on `background` (canvas backdrop) + `foreground` (storm name + track-dot label text). Palettes NOT theme-bound.

### D-T347b-10 — frame-determinism

Per CLAUDE.md §3 + T-347a precedent: no `Date.now` / `Math.random` / `crypto.*` / `setTimeout` / `setInterval` / `fetch` / `requestAnimationFrame` / `addEventListener`. v1 ships single-frame static; multi-advisory animation (cone expansion frame-by-frame, advisory step-through) deferred to T-347b-advisory-cycle.

### D-T347b-11 — acceptance thresholds (deferred to consumer preset)

Per stub line 53: PSNR ≥ 38 dB / SSIM ≥ 0.95 for the consumer preset's parity golden. The primitive itself has no parity threshold (only consumer presets do).
