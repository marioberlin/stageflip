# T-412 — Documentation pass (user-manual + skill index) (Phase δ Lock-in)

**Branch**: `task/T-412-docs-pass`

## Goal

Refresh `docs/user-manual.md` and the skill-tree index files so that
public-facing documentation reflects everything that landed in Phase 13.
The user-manual on `main` was last touched before Phase 13 cluster work
shipped — it does not mention any of the eight cluster-compose surfaces
(50 presets / 7 compose bundles), the `arrange_reveal` semantic tool
(T-407), the `@stageflip/export-router` package (T-408), the
`Gate - preset × export parity` CI step (T-409), or the
`pnpm check-ga-readiness` audit (T-410). A user installing the plugin
or CLI today would have no path from the manual to those surfaces.

T-412 also adds a top-level `skills/stageflip/SKILL.md` index so that
agents and humans landing in the skill tree have one place to start
that points at the auto-generated tools / runtimes / clips / reference
sub-SKILLs and the eight cluster preset SKILLs. There is no top-level
index on `main` today.

This is **pure docs**. No code, no new package, no new CI gate. The
inaugural `pnpm check-ga-readiness` run on the merge commit should
flip Category 6 criterion 6.1 from FAIL → PASS for T-412 (T-411
remains FAIL by design until that spec ships).
