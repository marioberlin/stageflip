## Architectural decisions

### D-T339-1. Compass-register match — palette-level UEFA register only (Starball + refracted typography deferred)

The stub describes a fully-instrumented premium-broadcast register: 3D-tracked Starball composited around players (Framestore 30K source), per-character refracted color gradient typography (2024–27 "Champions Display Refracted" cycle), light-refraction patterns tracing across frame edges, "Ultimate Stage" CGI stadium background composite, Starball-shape promo wipes (28 / 36 frames), continuous light-wave texture drift (8–10 s cycle), and per-character staggered 40 ms reveal. **None of this is renderable by the existing `magic-wall-panel` primitive.**

**Decision**: T-339 v1 binds `magic-wall-panel` (T-355a) with a **placeholder tile-grid composition** that captures the UEFA Champions League register at the **palette level** (dark navy `#041E42` background + refraction blue `#2DA8D8` / cyan `#6EE0E8` / magenta `#C2185B` accents per stub lines 22–23) WITHOUT attempting to render the canonical Starball or refracted typography. The signed parity golden captures a steady-state mid-match standings register frame: six region tiles representing major UCL clubs (Real Madrid / Liverpool / Bayern / Manchester City / PSG / Inter), color-shaded with refraction-palette accents, on the UEFA dark-navy background with title `'CHAMPIONS LEAGUE'` (UPPERCASE per stub line 29 typography contract) and subtitle `'MATCHDAY 6 — STANDINGS'`.

The canonical Starball + refracted typography + light-wave + Ultimate Stage CGI stadium are documented as deferred (D-T339-3, D-T339-10) pending follow-up carve-outs T-339a (Starball 3D composition), T-339b (refracted-typography primitive extension), T-339c (light-wave continuous drift). **External composition** handles the Ultimate Stage CGI backdrop (host responsibility per ADR-005).

**Alternative considered + rejected**: spec a sister primitive `uefa-title-card`. Rejected because (a) it bloats the clip catalog for one preset, (b) the canonical Starball requires `ThreeSceneClip` integration which is itself out of v1, (c) the parity-fixture sign-off validates the **resolver path** + **snapshot register** — not pixel-perfect canonical Starball. The `magic-wall-panel`-with-placeholder-tile-grid posture is sufficient parity proof of the UEFA register at the palette layer.

### D-T339-4. Snapshot constants `UEFA_STARBALL_PROPS`

Six-region tile composition representing the major UCL knockout-stage clubs at standings register. UEFA Champions League canonical mid-matchday register; numbers chosen to exercise the `magic-wall-panel` schema's optional fields (`title` + `subtitle` + per-region `color` + `value` + `valueLabel`). Anchored at `position` derived from primitive defaults; regions arranged on a 3×2 grid sized for the 1280×720 default composition.

```ts
export const UEFA_STARBALL_REGIONS: ReadonlyArray<{
  readonly id: string;
  readonly label: string;
  readonly points: number;
  readonly accent: 'navy' | 'blue' | 'cyan' | 'magenta' | 'white';
}> = [
  { id: 'RMA', label: 'RMA', points: 16, accent: 'blue' },     // Real Madrid
  { id: 'LIV', label: 'LIV', points: 15, accent: 'cyan' },     // Liverpool
  { id: 'BAY', label: 'BAY', points: 13, accent: 'magenta' },  // Bayern
  { id: 'MCI', label: 'MCI', points: 12, accent: 'blue' },     // Manchester City
  { id: 'PSG', label: 'PSG', points: 11, accent: 'cyan' },     // PSG
  { id: 'INT', label: 'INT', points: 10, accent: 'magenta' },  // Inter
];

/**
 * UEFA Champions League refraction palette per stub lines 22–23. Distinct
 * from `MAGIC_WALL_PARTY_COLORS` (CNN Dem-Blue / Rep-Red — T-355) and
 * `MSNBC_BIG_BOARD_PARTY_COLORS` (NBC peacock — T-328); the refraction
 * palette evokes light-physics prism dispersion rather than a partisan
 * map. Five swatches drawn from the canonical UEFA broadcast register.
 */
export const UEFA_STARBALL_PALETTE: Readonly<
  Record<'navy' | 'blue' | 'cyan' | 'magenta' | 'white', string>
> = {
  navy:    '#041E42', // dark navy primary (night-match canon, stub line 22)
  blue:    '#2DA8D8', // refraction bright blue (stub line 23)
  cyan:    '#6EE0E8', // refraction cyan (stub line 23)
  magenta: '#C2185B', // refraction magenta (stub line 23)
  white:   '#FFFFFF', // foreground (stub line 23)
};

const UEFA_STARBALL_TILE_ORIGIN_X = 200;
const UEFA_STARBALL_TILE_ORIGIN_Y = 200;
const UEFA_STARBALL_TILE_WIDTH = 280;
const UEFA_STARBALL_TILE_HEIGHT = 200;
const UEFA_STARBALL_TILE_GAP = 12;

const uefaStarballRefractionBinding: ClipKindBinding = {
  runtimeId: 'frame-runtime',
  clipName: 'magic-wall-panel',
  buildProps() {
    return {
      regions: UEFA_STARBALL_REGIONS.map((r, i) => ({
        id: r.id,
        label: r.label,
        value: r.points,
        valueLabel: `${r.points} PTS`,
        color: UEFA_STARBALL_PALETTE[r.accent],
        bounds: {
          x: UEFA_STARBALL_TILE_ORIGIN_X + (i % 3) * (UEFA_STARBALL_TILE_WIDTH + UEFA_STARBALL_TILE_GAP),
          y:
            UEFA_STARBALL_TILE_ORIGIN_Y +
            Math.floor(i / 3) * (UEFA_STARBALL_TILE_HEIGHT + UEFA_STARBALL_TILE_GAP),
          width: UEFA_STARBALL_TILE_WIDTH,
          height: UEFA_STARBALL_TILE_HEIGHT,
        },
      })),
      title: 'CHAMPIONS LEAGUE',
      subtitle: 'MATCHDAY 6 — STANDINGS',
      valueFormat: 'count' as const,
      entrance: 'stagger-rise' as const,
      staggerMs: 60,
      background: '#041E42', // UEFA dark navy (stub line 22; OVERRIDES primitive default `#0E0E12`)
      foreground: '#FFFFFF',
    };
  },
};
```

Snapshot exercises: six regions in 3×2 grid, all five palette swatches reachable (`navy` background, `blue` / `cyan` / `magenta` per-region accents, `white` foreground), `title` + `subtitle` both set, `valueFormat: 'count'` + per-region `valueLabel` override (`'<n> PTS'`), `entrance: 'stagger-rise'` + `staggerMs: 60` (resolved by frame ~25 per T-355 D-T355-5 verified analysis), `background: '#041E42'` overrides primitive default `#0E0E12` (UEFA dark navy is the central palette divergence vs T-355 / T-328).
