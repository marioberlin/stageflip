### D-T377-3 — static-fallback content surface (label + sublabel + olympic-gold accent border)

The primitive's static-fallback render path (D-T375a-5) renders a centered card on a backdrop with optional 1px accent border + an "AR · STATIC FALLBACK" badge bottom-right. The preset binds:

```ts
{
  staticFallback: {
    label: 'OLYMPIC SWIM — LANE TRACK',
    sublabel: 'OMEGA VIONARDO TIMING · WR-LINE',
    backgroundColor: OLYMPIC_SWIM_LANE_TRACK_PALETTE.poolBlue,    // #0E3B6E — pool-blue backdrop evokes the rendered moment
    foregroundColor: OLYMPIC_SWIM_LANE_TRACK_PALETTE.foreground,  // #FFFFFF — banner + tabular timing
    accentColor: OLYMPIC_SWIM_LANE_TRACK_PALETTE.olympicGold,     // #D4AF37 — Olympic-gold 1px accent border (NOT pool-blue — visually differentiates from sibling presets' navy / PL-purple registers; gold is the world-record / Olympic-record canon)
    showLiveMountIndicator: true,
  },
  font: {
    family: "'Paris 2024', 'Atkinson Hyperlegible', system-ui, -apple-system, sans-serif",
    weight: 700,
  },
  permissions: ['network'], // declared (Omega Vionardo timing-feed integration via LiveDataClip per stub frontmatter line 14 + stub line 45) but NOT exercised in v1 static-fallback path
}
```

Per stub frontmatter lines 8-13 — Paris 2024 (Games-specific) is `proprietary-byo`; Atkinson Hyperlegible OFL is the rendered fallback (its tabular figures + high-contrast register match the timing-precision canon per stub line 32 "Times: Bold, 24-30 pt, tabular — to .01 second precision (Omega touch-pad standard)"). The primitive renders the label at fixed 48px (per D-T375a-5); the preset's `font` declaration governs the family stack.

**Visual differentiation from sibling Cluster H presets:**
- Sky Sports: navy backdrop (`#0A1128`) + Premier League purple accent border (`#38003C`) + `'Sky Sports Sans', 'Inter'` font stack — register: pitch-anchored formation lineup.
- Hawk-Eye VAR: PL purple backdrop (`#34003A`) + decision-green accent border (`#00FC8A`) + `'Premier Sans', 'Champions', 'Space Grotesk'` font stack — register: VAR offside-decision moment, dramatic suspense beat.
- **Olympic swim: pool-blue backdrop (`#0E3B6E`) + Olympic-gold accent border (`#D4AF37`) + `'Paris 2024', 'Atkinson Hyperlegible'` font stack — register: lane-anchored timing graphics on a pool surface, world-record-line dramatic moment.**

All three presets ship the SAME primitive (`arOverlay`) but render visually distinct cards — the broadcaster brand canon lives in the per-preset binding, not the primitive.

### D-T377-4 — `setupRef` reserved (NOT exercised in v1)

Per D-T375a-2, the primitive's v1 dispatch ignores `setupRef` at render time and always renders the static-fallback path. **The preset binding does NOT supply `setupRef` in v1** — the `ThreeSceneClip` + `LiveDataClip` live-mount surface (Olympic swim AR lane graphics tracked to camera motion + live Omega Vionardo timing-feed integration with .01s touch-pad precision + WR-line draw-in + record gold/red flash on touch) lands with T-377-live-mount post-T-397 Track A finale.

### D-T377-N — Live-mount permission posture (forward-compat) — `permissions: ['network']` declared

**This preset is the FIRST Cluster H preset to declare `permissions: ['network']`.** Per the preset stub frontmatter line 14 (`permissions: [network]`) and stub line 45 ("Requires camera-tracking + timing-data feed. Without both, fall back to a 2D scoreboard"), the binding declares `permissions: ['network']` to reserve the schema slot for the post-T-397 live-mount path's `LiveDataClip` integration with the Omega Vionardo timing feed.

The `'network'` permission is a valid value on the primitive's `permissionEnum` (`packages/runtimes/frame-runtime-bridge/src/clips/ar-overlay.tsx` line 118: `z.enum(['camera-tracking', 'live-data', 'network', 'audio'])`); no schema change is required.

**Differentiation from sibling Cluster H presets' permission declarations:**
- sky-sports-ar-formations (T-375): `permissions: ['camera-tracking']` — Zero Density / Stype tracking source data (camera-side).
- hawkeye-var-3d-skeletal (T-376): `permissions: ['camera-tracking']` — Hawk-Eye limb-tracking source data (camera-side).
- **olympic-swim-lane-track (this PR): `permissions: ['network']` — Omega Vionardo timing-feed network access (data-side, NOT camera-side).** The Olympic swim register is fundamentally network-bound (touch-pad timing data arrives over the Omega network; without the timing feed, the canonical .01s precision register collapses to a 2D scoreboard fallback per stub line 45).

This field is on the schema for forward compatibility (declared in T-375a's primitive `permissionEnum`; ignored at v1 render time per D-T375a-2). It will be consumed by the live-mount path post-T-397 — specifically by the `LiveDataClip` integration that subscribes to the Omega Vionardo timing feed.

**v1 render verification:** the v1 static-fallback render path is byte-deterministic — `permissions` is declared on the binding's `buildProps()` payload but the primitive's render dispatch ignores it (per D-T375a-2). The new test in `generate-fixture.test.ts` asserts `expect(props.permissions).toEqual(['network'])` to confirm the declaration flows through, and the round-trip e2e test confirms the schema-validated RIRDocument carries the same `permissions: ['network']` array.

Live-mount of the Omega timing feed is gated on Track A finale T-397+ (no LiveDataClip implementation merged on `main` yet); this PR ships static-fallback rendering only.

### D-T377-6 — frame 60 single-frame static; thresholds 34 / 0.91

Per stub line 51 — PSNR ≥ 34 dB / SSIM ≥ 0.91. Cluster H thresholds are looser than the cluster-norm 38/0.95 because the stub authorises that variance for "live AR + camera motion has high variance" — the v1 static-fallback render is byte-deterministic, so the looser thresholds carry no risk for the v1 register and reserve headroom for the post-T-397 live-mount path's expected variance (Omega timing-feed data is asynchronous; touch-pad flash + WR-line draw-in introduce sub-frame timing variance in the live render path).

Reference frames per stub line 50 are 0 / 60 / 120 / 150 (start / mid-race / finish + touch flash / record flash); **single-frame golden at frame 60** for cluster-norm consistency with sibling sky-sports + hawkeye-var presets (also frame 60). The "settled" register at frame 60 (mid-race; lane graphics + WR-line drawn + position numbers stable) is canonical across Cluster H presets. Multi-frame animated start-tick / mid-race-update / touch-flash / record-flash defers to T-377-animated.
