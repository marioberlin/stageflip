T-431 — New package `@stageflip/video-runway` shipping the **sixth reference adapter** in the Phase 14 β sequence (T-426..T-434), the **second `video-gen` modality adapter** after T-430 Seedance, and the **fourth `proprietary-byo` license posture** to clear the `pnpm check-asset-licenses` gate (Tripo3D was the first via T-428, Meshy was the second via T-429, Seedance was the third via T-430). Wraps the Runway Gen-4 commercial production-tier text-to-video model accessed via the Runway HTTPS API (up to 10s output at 1080p / 4K; NO native audio — silent video only; broad aspect-ratio support; batch latency ~1–3 min per video; tenant-supplied API credentials) behind the `VideoGenerationProvider` interface from T-419 and declares an `AdapterDescriptor` per T-418. Public surface: `runwayDescriptor` (and its `descriptor` alias for the T-422 `check-asset-licenses` discovery walker), `runwayVideoGenCapability`, `RunwayVideoProvider`, `RunwayProviderMode` (`'stub' | 'production'`), `RunwayVideoProviderOptions`, `NotYetImplementedError`, `generateStubMp4DataUri`, plus the `RUNWAY_MAX_DURATION_S` / `RUNWAY_FRAME_RATE` / `RUNWAY_BASE_URL_ENV_VAR` constants. The descriptor declares `aspectRatios: ['16:9', '9:16', '1:1', '4:3', '3:4']` (broader set than Seedance's three; Runway Gen-4 supports portrait + square + classic 4:3 framings in addition to widescreen + vertical), `frameRates: [24]` (film-style / cinematic — distinguishing the production-tier posture from Seedance's 30fps), `maxDurationS: 10` (Runway Gen-4 conservative cap; longer durations gated on tier), `outputFormats: ['mp4']`, `emitsAudio: false` (THE primary differentiator vs Seedance — Runway is silent video; pairing audio is an orchestrator concern handled by T-436 with a TTS / music-gen adapter), `safetyFilters: []` (the strict T-419 capability subset) plus the catalog-summary field `maxDurationSec: 10` the T-424 generator reads, plus the differentiator-surface fields `supportsLipSync: false`, `supportsNativeAudio: false`, `supportedResolutions: ['1080p', '4k']` (Runway Gen-4 supports 4K), `qualityHint: 'highest'` (production-tier) the agent UI surfaces. License `proprietary-byo` clears the per-modality whitelist (ADR-008 §D13 line 654: `video-gen` admits `apache-2.0`, `mit`, `proprietary-byo`, `proprietary-vendored`). Sandbox `{ kind: 'remote-service', baseUrlEnvVar: 'RUNWAY_API_BASE_URL' }` — that env var is the production wire-up's credentials anchor (T-431a; the stub mode never reads it). `costPerCall.usd: 2.0` (paid; tenant pays Runway; bucketed as `enterprise` cost-tier per skills-sync's >$0.10 threshold; production-grade pricing per Runway commercial rates — higher than Seedance's $1.50 reflecting the production-tier positioning); `latencyMs: { p50: 90_000, p95: 180_000 }` (batch tier per skills-sync's `latencyTier` bucketing; ~1–3 min typical; same band as Seedance). Ships in **stub mode**: `generate()` validates the prompt (empty / whitespace-only → throw), then emits a deterministic minimal valid MP4 `data:video/mp4;base64,...` URI built by a pure `generateStubMp4DataUri()` (~489-byte hard-coded base64 fixture: ftyp box with major_brand `isom` + moov box with one 3840×2160 video track at 24fps / 10s declarative duration + empty mdat; **Option A** trade-off carried verbatim from T-430's spec — base64 fixture instead of procedural MP4 box writer — chosen for ~50 LOC vs ~500 LOC and zero box-writer maintenance surface; the production wire-up replaces the entire body). The stub MP4 is **byte-distinct from the Seedance stub**: the moov declares different width (3840 vs 1920), height (2160 vs 1080), mdhd timescale (24 vs 30), and sample duration (240 vs 450) — a `data:` URI consumer comparing the two stubs at the byte level can tell them apart. Derives the canonical cache key per ADR-008 §D1 via `deriveCacheKey()` from `@stageflip/asset-cache` (model `'runway:gen-4'`; params include `outputFormat`, `aspectRatio`, `frameRate`, `durationS` — different prompts / aspect-ratios / durations / seeds produce different cache keys; the MP4 bytes are byte-identical for ANY input so cache-key roundtrip tests are trivially satisfied), and returns `{ cacheKey, url, durationS, aspectRatio, frameRate }`. Production mode throws `NotYetImplementedError` — wire-up to the real Runway HTTPS API (job submit, polling, MP4 download, AssetStorage upload) is deferred to T-431a (Runway public Gen-4 API surface still iterating). Side-effect-free import — adapters-core uses an instance-based per-tenant registry, so the host shell owns registration timing; `scripts/sync-skills.ts` registers `runwayDescriptor` alongside `kokoroDescriptor`, `fishSpeechDescriptor`, `tripoDescriptor`, `meshyDescriptor`, and `seedanceDescriptor` into `buildAssetProvidersPkg()` and the T-424 catalog auto-gen picks up the row (Runway now appears as the sixth row in `skills/stageflip/reference/asset-providers/SKILL.md`). NOT a structural extension (CLAUDE.md §13) — implements existing T-418 / T-419 contracts (consumer of the existing `VideoGenerationProvider` interface); render verification N/A.
