T-428 — New package `@stageflip/3d-tripo` shipping the **third reference adapter** in the Phase 14 β sequence (T-426..T-434), the **first 3D adapter**, and the **first `proprietary-byo` license posture** to clear the `pnpm check-asset-licenses` gate. Wraps the Tripo3D character-model generator (commercial AI; clean quad topology; auto-rigging; GLB output; ~1–2 min per asset; tenant-supplied API credentials) behind the `ThreeDAssetProvider` interface from T-419 and declares an `AdapterDescriptor` per T-418. Public surface: `tripoDescriptor` (and its `descriptor` alias for the T-422 `check-asset-licenses` discovery walker), `tripoThreeDCapability`, `TripoThreeDProvider`, `TripoProviderMode` (`'stub' | 'production'`), `TripoThreeDProviderOptions`, `NotYetImplementedError`, `generateStubGlbDataUri`, plus the `TRIPO_MAX_VERTICES` / `TRIPO_BASE_URL_ENV_VAR` constants. The descriptor declares `outputFormats: ['glb']`, `topology: 'quad-clean'`, `supportsAutoRigging: true`, `maxVertices: 50_000` (the strict T-419 capability subset) plus the catalog-summary fields `formats: ['glb']` / `maxPolyCount: 50_000` the T-424 generator reads. License `proprietary-byo` clears the per-modality whitelist (ADR-008 §D13 line 657: `three-d` admits `apache-2.0`, `mit`, `proprietary-byo`, `proprietary-vendored`). Sandbox `{ kind: 'remote-service', baseUrlEnvVar: 'TRIPO_API_BASE_URL' }` — that env var is the production wire-up's credentials anchor (T-428a; the stub mode never reads it). `costPerCall.usd: 0.5` (paid; tenant pays Tripo); `latencyMs: { p50: 60_000, p95: 120_000 }` (batch tier per skills-sync's `latencyTier` bucketing). Ships in **stub mode**: `generate()` validates the prompt (empty / whitespace-only → throw), then emits a deterministic minimal valid GLB `data:model/gltf-binary;base64,...` URI built by a pure `generateStubGlbDataUri()` (12-byte glTF 2.0 header + JSON chunk + BIN chunk; unit cube with 8 vertices and 12 triangles via 36 indices; the `rig: true` variant adds a single named `'root'` bone with identity inverse-bind matrix and uniform skinning weights), derives the canonical cache key per ADR-008 §D1 via `deriveCacheKey()` from `@stageflip/asset-cache` (params include `outputFormat`, `topology`, `rig` — different rig flags / prompts / seeds produce different cache keys; the GLB bytes are byte-identical for a given `(rig)` flag so cache-key roundtrip tests are trivially satisfied), and returns `{ cacheKey, url, vertices: 8, rigged }` where `rigged === call.rig === true && capability.supportsAutoRigging`. Production mode throws `NotYetImplementedError` — wire-up to the real Tripo HTTPS API (multipart job submit, polling, GLB download, AssetStorage upload) is deferred to T-428a (Tripo public API surface still iterating). Side-effect-free import — adapters-core uses an instance-based per-tenant registry, so the host shell owns registration timing; `scripts/sync-skills.ts` registers `tripoDescriptor` alongside `kokoroDescriptor` and `fishSpeechDescriptor` into `buildAssetProvidersPkg()` and the T-424 catalog auto-gen picks up the row (Tripo now appears alongside Kokoro and Fish Speech in `skills/stageflip/reference/asset-providers/SKILL.md`). NOT a structural extension (CLAUDE.md §13) — implements existing T-418 / T-419 contracts (consumer of the existing `ThreeDAssetProvider` interface); render verification N/A.
