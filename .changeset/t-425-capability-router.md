T-425 — New package `@stageflip/capability-router` shipping the agent-side capability-routing engine: a pure `routeCapability(input) => RoutingDecision` function that filters + ranks `AdapterDescriptor[]` from `@stageflip/adapters-core`. Three filter stages applied in order (modality match → capability predicate → license + sandbox) with first-failure attribution into a dense per-reason rejection tally (`'modality-mismatch'`, `'capability-mismatch'`, `'license-denied'`, `'credential-missing'`, `'sandbox-unavailable'`). Four ranking preferences: `'cheapest'` (ascending `costPerCall.usd`, missing sorts last), `'fastest'` (ascending `latencyMs.p95 ?? p50`, missing sorts last), `'highest-quality'` (descending caller-supplied `qualityScorer`), `'balanced'` (default; composite `-log10(cost+ε) + -log10(latency+ε) + qualityScorer`). All ties break on ascending `id` to keep output deterministic. Side-channel exports: `buildFilterPipeline(opts)` (filter-only composition for debug UIs), `comparatorFor(preference, scorer)` + the four `rankXxx()` factories. License-gate defaults to `defaultLicenseGate` from adapters-core (ADR-007 §D3 matrix); callers may supply a custom `LicenseGate`. Sandbox-availability filter is opt-in via `hostSandboxKinds: ReadonlySet<SandboxKind>`. The function is pure — no `Date.now()`, `Math.random()`, `fetch`, timers, or workers — and does NOT mutate the input adapters array. Final Phase 14 α task; unblocks T-426..T-434 (nine reference adapters) which can now dispatch in parallel. NOT a structural extension (CLAUDE.md §13) — pure decision function over existing contracts; render verification N/A.
