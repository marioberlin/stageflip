T-423 — Add the `asset-generation` engine handler bundle: 3 agent-callable tools (`generate_asset` / `list_adapters` / `get_adapter_capabilities`) that wrap the Phase 14 α Provider Seam infrastructure (T-418 `@stageflip/adapters-core` + T-419 `@stageflip/asset-gen-contract` + T-420 `@stageflip/asset-cache` + T-421 `MediaProvenance` schema). Canonical bundle #25.

`generate_asset` dispatches a `(modality, prompt, model?, voice?, params?, seed?, researchSessionId?, target)` request through `AdapterRegistry.list(modality)` → `LicenseGate.evaluate` → `FallbackChainExecutor.execute`; on success it derives a content-addressed cache key per ADR-008 §D1 (delegated to `@stageflip/asset-cache`'s `deriveCacheKey` + `cacheKeyString`), builds a strict `MediaProvenance` (matched to modality via the kind map), and emits a JSON-Patch `add` op that mounts an `audio` / `image` / `video` element on the target slide with `provenance` populated. Sealed `modality` enum (12 asset-producing modalities; the 3 session / marketplace modalities are rejected at the input boundary). Required `target: { slideId, elementType: audio | image | video, transform, src: 'asset:<id>' }`. The bundle does not own asset upload — the caller-supplied `target.src` becomes the asset reference; the seam owns produced-bytes upload. `list_adapters` enumerates registered descriptors (optional modality filter; empty registry returns `{ ok: true, adapters: [] }`, not an error). `get_adapter_capabilities` looks up a single descriptor by `(modality, adapterId)`.

Handlers declare `MutationContext` with optional soft seams on `AssetGenerationContext` (mirrors T-386's `VariantPersistenceContext` pattern): `adapterRegistry` + `licenseGate` + `tenantContext` + `executeAdapterCall` (required for `generate_asset`) + optional `assetCacheStore`. Seam-absent / no-adapter-for-modality / no-licensed-adapter / all-adapters-failed / wrong-mode / slide-not-found paths return typed `{ ok: false, reason }` responses — never throw. T-423 ships the dispatch shell only; concrete adapters land via T-426..T-434, and the routing-engine ranking layer is T-425. With zero adapters registered on `main` today, every `generate_asset` call returns the typed `no_adapter_for_modality` response.
