T-426 — New package `@stageflip/tts-kokoro` shipping the **first reference adapter** in the Phase 14 β sequence (T-426..T-434). Wraps the Kokoro TTS model (community Apache 2.0; ~82M params; sub-0.3s latency; edge-deployable) behind the `TTSProvider` interface from T-419 and declares an `AdapterDescriptor` per T-418. Public surface: `kokoroDescriptor` (and its `descriptor` alias for the T-422 `check-asset-licenses` discovery walker), `KokoroTtsProvider`, `KokoroProviderMode` (`'stub' | 'production'`), `NotYetImplementedError`, `generateSilentWavDataUri`, plus the `KOKORO_VOICES` / `KOKORO_SAMPLE_RATE_HZ` / `KOKORO_MAX_DURATION_S` constants. The adapter declares 10 library voices (no cloning — `supportsVoiceClone: false`, so the §D4 `TenantVoiceConsentStore` consent path is not exercised), `outputFormats: ['wav']`, `sampleRates: [24000]`, `maxDurationS: 60`, `emitsWordTimestamps: false`. License `apache-2.0` clears the per-modality whitelist (ADR-008 §D13: `tts` admits `apache-2.0`). Sandbox `in-process`. `costPerCall.usd: 0`; `latencyMs: { p50: 200, p95: 300 }`. Ships in **stub mode**: `synthesize()` validates the call (unknown voiceId / wrong format / wrong sample rate → throw), then emits a deterministic silent-WAV `data:audio/wav;base64,...` URI built by a pure `generateSilentWavDataUri()` (RIFF/WAVE/fmt /data 44-byte header + zero PCM samples), derives the canonical cache key per ADR-008 §D1 via `deriveCacheKey()` from `@stageflip/asset-cache`, and returns `{ cacheKey, url, durationS }` where `durationS = clamp(text.length / 15, 0.5, 60)`. Production mode throws `NotYetImplementedError` — wire-up to `kokoro-js` / ONNX runtime is deferred to T-426a (license + edge-runtime audit pending). Side-effect-free import — adapters-core uses an instance-based per-tenant registry, so the host shell owns registration timing; `scripts/sync-skills.ts` registers `kokoroDescriptor` into `buildAssetProvidersPkg()` and the T-424 catalog auto-gen picks up the row. NOT a structural extension (CLAUDE.md §13) — implements existing T-418 / T-419 contracts; render verification N/A.
