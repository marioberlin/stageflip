T-432 — New package `@stageflip/music-acestep` shipping the **seventh reference adapter** in the Phase 14 β sequence (T-426..T-434) and the **first `music-gen` modality adapter** to clear the `pnpm check-asset-licenses` gate (opens the music modality; mit ∈ music-gen whitelist per ADR-008 §D13 line 655 — no whitelist extension required). Wraps the ACE-Step open-source music generation model (community MIT; state-of-the-art per benchmarks beating Suno v4.5; 5-minute track in <10s on RTX 3090; edge-deployable on GPU; sub-100MB checkpoint) behind the `MusicGenerationProvider` interface from T-419 and declares an `AdapterDescriptor` per T-418. Mirrors T-426 Kokoro's posture (in-process + permissive-license + edge-deployable + stub-mode-v1) — both adapters declare `sandbox.kind: 'in-process'` because both models are small enough to run inline in the host process on supported hardware. Public surface: `aceStepDescriptor` (and its `descriptor` alias for the T-422 `check-asset-licenses` discovery walker), `aceStepMusicGenCapability`, `AceStepMusicProvider`, `AceStepProviderMode` (`'stub' | 'production'`), `AceStepMusicProviderOptions`, `NotYetImplementedError`, `generateSilentWavDataUri`, plus the `ACE_STEP_GENRES` / `ACE_STEP_MAX_DURATION_S` / `ACE_STEP_SAMPLE_RATE_HZ` constants. The descriptor declares the strict `MusicGenCapabilityDescriptor` subset `genres: ['electronic', 'pop', 'rock', 'classical', 'hip-hop', 'jazz', 'ambient', 'folk']` (eight broad ACE-Step canonical buckets), `maxDurationS: 300` (5-minute track), `outputFormats: ['wav', 'mp3']`, `outputLicense: 'permissive'` (MIT-licensed model emits commercially-usable output with no attribution — the `MusicGenResult.attribution` field stays absent; the `'attribution-required'` branch is future YuE territory), plus the catalog-summary fields `maxDurationSec: 300` + `sampleRateHz: 44100` the T-424 generator reads (`music-gen` row), plus the differentiator-surface fields `supportsStructure: true` (intro / verse / chorus / bridge / outro) + `qualityHint: 'high'` (state-of-the-art) the agent UI surfaces. License `mit` clears the per-modality whitelist (ADR-008 §D13 line 655: `music-gen` admits `apache-2.0`, `mit`, `cc-by`, `proprietary-byo`, `proprietary-vendored`). Sandbox `{ kind: 'in-process' }` — ACE-Step ONNX is in-process-runnable on supported hardware; sidecar isolation lands in T-432a if the production wire-up needs it. `costPerCall.usd: 0` (free; tenant pays compute; bucketed as `free` cost-tier per skills-sync's threshold); `latencyMs: { p50: 8_000, p95: 9_500 }` (strictly < 10s p95 places the adapter in the `fast < 10s` latency tier per skills-sync's `latencyTier` bucketing; honors the upstream "5-minute track in <10s on RTX 3090" claim). Ships in **stub mode**: `generate()` validates the input (empty / whitespace-only prompt → throw; non-`'wav'` `outputFormat` → throw because the stub body emits WAV only in v1 despite the descriptor declaring mp3 as a future-supported format; `durationS` out of `(0, 300]` → throw; unknown `genre` → throw), then emits a deterministic silent-WAV `data:audio/wav;base64,...` URI built by a pure `generateSilentWavDataUri(durationS, 44100)` (44100Hz mono 16-bit PCM; standard 44-byte RIFF/WAVE/fmt /data header; all PCM samples zero; mirrors `packages/tts-kokoro/src/stub-audio.ts` verbatim — duplication is intentional to keep each adapter package self-contained for the T-422 discovery walker). Derives the canonical cache key per ADR-008 §D1 via `deriveCacheKey()` from `@stageflip/asset-cache` (modality `'music-gen'`; model `'ace-step'`; params include `outputFormat`, `durationS`, optional `genre` — different prompts / durations / genres / seeds produce different cache keys), and returns `{ cacheKey, url, durationS }` (`attribution` absent for permissive output license). Production mode throws `NotYetImplementedError` — wire-up to a real ACE-Step library call (ACE-Step npm package — pending license + edge-runtime audit — or ONNX runtime over a pinned model checkpoint) is deferred to T-432a (checkpoint redistribution clearance + ONNX export quality + edge-runtime compatibility audit still in flight). Side-effect-free import — adapters-core uses an instance-based per-tenant registry, so the host shell owns registration timing; `scripts/sync-skills.ts` registers `aceStepDescriptor` alongside `kokoroDescriptor`, `fishSpeechDescriptor`, `tripoDescriptor`, `meshyDescriptor`, `seedanceDescriptor`, and `runwayDescriptor` into `buildAssetProvidersPkg()` and the T-424 catalog auto-gen picks up the row (ACE-Step now appears as the seventh row + the first `music-gen` row in `skills/stageflip/reference/asset-providers/SKILL.md`). NOT a structural extension (CLAUDE.md §13) — implements existing T-418 / T-419 contracts (consumer of the existing `MusicGenerationProvider` interface); render verification N/A.
