T-427 — New package `@stageflip/tts-fish-speech` shipping the **second reference adapter** in the Phase 14 β sequence (T-426..T-434) and the **first voice-clone adapter** to exercise the ADR-008 §D4 `TenantVoiceConsentStore` consent path. Wraps the Fish Speech TTS model (community Apache 2.0; voice cloning; 8 languages — en/zh/ja/ko/fr/de/es/ru; MOS 4.1; 22050Hz) behind the `TTSProvider` interface from T-419 and declares an `AdapterDescriptor` per T-418. Public surface: `fishSpeechDescriptor` (and its `descriptor` alias for the T-422 `check-asset-licenses` discovery walker), `FishSpeechTtsProvider`, `FishSpeechProviderMode` (`'stub' | 'production'`), `NotYetImplementedError`, `VoiceConsentRequiredError`, `assertVoiceConsentIfNeeded`, `generateSilentWavDataUri`, plus the `FISH_SPEECH_LIBRARY_VOICES` / `FISH_SPEECH_SAMPLE_RATE_HZ` / `FISH_SPEECH_MAX_DURATION_S` / `FISH_SPEECH_SUPPORTED_LANGUAGES` constants. The adapter declares 8 library voices (one per supported language) AND accepts cloned voices (any `voiceId` not in the library list); `outputFormats: ['wav']`, `sampleRates: [22050]`, `maxDurationS: 60`, `emitsWordTimestamps: false`, `supportsVoiceClone: true`. License `apache-2.0` clears the per-modality whitelist (ADR-008 §D13). Sandbox `{ kind: 'sidecar', runtime: 'python' }`. `costPerCall.usd: 0`; `latencyMs: { p50: 1200, p95: 3000 }` (fast tier per skills-sync's `latencyTier` bucketing). Ships in **stub mode**: `synthesize()` enforces voice-consent on cloned voices via `assertVoiceConsentIfNeeded` (cloned-voice + missing/denied store → `VoiceConsentRequiredError`; library-voice bypasses), validates the call (wrong format / wrong sample rate → throw), then emits a deterministic silent-WAV `data:audio/wav;base64,...` URI built by a pure `generateSilentWavDataUri()` (RIFF/WAVE/fmt /data 44-byte header + zero PCM samples), derives the canonical cache key per ADR-008 §D1 via `deriveCacheKey()` from `@stageflip/asset-cache` (cloned voices include a `voiceCloneFingerprint` param so library-voice cache keys remain backwards-compatible), and returns `{ cacheKey, url, durationS }` where `durationS = clamp(text.length / 15, 0.5, 60)`. Production mode throws `NotYetImplementedError` — wire-up to a Fish Speech Python sidecar / pinned model checkpoint is deferred to T-427a (sidecar-runtime + checkpoint-pinning audit pending). Side-effect-free import — adapters-core uses an instance-based per-tenant registry, so the host shell owns registration timing; `scripts/sync-skills.ts` registers `fishSpeechDescriptor` alongside `kokoroDescriptor` into `buildAssetProvidersPkg()` and the T-424 catalog auto-gen picks up the row (Fish Speech now appears alongside Kokoro in `skills/stageflip/reference/asset-providers/SKILL.md`). NOT a structural extension (CLAUDE.md §13) — implements existing T-418 / T-419 contracts (incl. consumer of the existing `TenantVoiceConsentStore` interface); render verification N/A.
