T-430 — New package `@stageflip/video-seedance` shipping the **fifth reference adapter** in the Phase 14 β sequence (T-426..T-434), the **first `video-gen` modality adapter**, and the **third `proprietary-byo` license posture** to clear the `pnpm check-asset-licenses` gate (Tripo3D was the first via T-428, Meshy was the second via T-429). Wraps the Seedance 2.0 commercial text-to-video model accessed via the fal.ai HTTPS API (15s output at 1080p; native audio; lip-sync — rare among text-to-video models; batch latency ~1–3 min per video; tenant-supplied API credentials) behind the `VideoGenerationProvider` interface from T-419 and declares an `AdapterDescriptor` per T-418. Public surface: `seedanceDescriptor` (and its `descriptor` alias for the T-422 `check-asset-licenses` discovery walker), `seedanceVideoGenCapability`, `SeedanceVideoProvider`, `SeedanceProviderMode` (`'stub' | 'production'`), `SeedanceVideoProviderOptions`, `NotYetImplementedError`, `generateStubMp4DataUri`, plus the `SEEDANCE_MAX_DURATION_S` / `SEEDANCE_FRAME_RATE` / `SEEDANCE_BASE_URL_ENV_VAR` constants. The descriptor declares `aspectRatios: ['16:9', '9:16', '1:1']`, `frameRates: [30]`, `maxDurationS: 15`, `outputFormats: ['mp4']`, `emitsAudio: true`, `safetyFilters: []` (the strict T-419 capability subset) plus the catalog-summary field `maxDurationSec: 15` the T-424 generator reads, plus the differentiator-surface fields `supportsLipSync: true`, `supportsNativeAudio: true`, `supportedResolutions: ['1080p']` the agent UI surfaces. License `proprietary-byo` clears the per-modality whitelist (ADR-008 §D13 line 654: `video-gen` admits `apache-2.0`, `mit`, `proprietary-byo`, `proprietary-vendored`). Sandbox `{ kind: 'remote-service', baseUrlEnvVar: 'FAL_API_BASE_URL' }` — that env var is the production wire-up's credentials anchor (T-430a; the stub mode never reads it). `costPerCall.usd: 1.5` (paid; tenant pays fal.ai; bucketed as `enterprise` cost-tier per skills-sync's >$0.10 threshold); `latencyMs: { p50: 90_000, p95: 180_000 }` (batch tier per skills-sync's `latencyTier` bucketing; ~1–3 min typical). Ships in **stub mode**: `generate()` validates the prompt (empty / whitespace-only → throw), then emits a deterministic minimal valid MP4 `data:video/mp4;base64,...` URI built by a pure `generateStubMp4DataUri()` (~489-byte hard-coded base64 fixture: ftyp box with major_brand `isom` + moov box with one 1920×1080 video track at 30fps / 15s declarative duration + empty mdat; **Option A** trade-off from the spec — base64 fixture instead of procedural MP4 box writer — chosen for ~50 LOC vs ~500 LOC and zero box-writer maintenance surface; the production wire-up replaces the entire body), derives the canonical cache key per ADR-008 §D1 via `deriveCacheKey()` from `@stageflip/asset-cache` (model `'seedance:2.0'`; params include `outputFormat`, `aspectRatio`, `frameRate`, `durationS` — different prompts / aspect-ratios / durations / seeds produce different cache keys; the MP4 bytes are byte-identical for ANY input so cache-key roundtrip tests are trivially satisfied), and returns `{ cacheKey, url, durationS, aspectRatio, frameRate }`. Production mode throws `NotYetImplementedError` — wire-up to the real fal.ai HTTPS API (job submit, polling, MP4 download, AssetStorage upload) is deferred to T-430a (fal.ai public Seedance API surface still iterating). Side-effect-free import — adapters-core uses an instance-based per-tenant registry, so the host shell owns registration timing; `scripts/sync-skills.ts` registers `seedanceDescriptor` alongside `kokoroDescriptor`, `fishSpeechDescriptor`, `tripoDescriptor`, and `meshyDescriptor` into `buildAssetProvidersPkg()` and the T-424 catalog auto-gen picks up the row (Seedance now appears as the fifth row in `skills/stageflip/reference/asset-providers/SKILL.md`). NOT a structural extension (CLAUDE.md §13) — implements existing T-418 / T-419 contracts (consumer of the existing `VideoGenerationProvider` interface); render verification N/A.
