T-424 — New auto-gen generator `generateAssetProvidersSkill` that emits `skills/stageflip/reference/asset-providers/SKILL.md` from an `AdapterRegistry` snapshot (or equivalent `AssetProvidersPkg`). Renders a markdown catalog with columns: Adapter ID / Modality / Capability summary / License / Cost tier / Latency tier / `requiresResearchProvider`. Sort is stable `(modality.kind ASC, id ASC)`. Cost-tier bucketing: `free` (usd === 0 or zero-token), `paid` (usd ≤ 0.10), `enterprise` (usd > 0.10), `unspecified` otherwise. Latency-tier bucketing on `p95 ?? p50`: `interactive < 1s`, `fast < 10s`, `batch < 5min`, `async`, `unspecified`. Capability-summary dispatch reads documented fields per ADR-008 §D6 for each of the 15 modality kinds (`tts`, `video-gen`, `music-gen`, `sfx`, `three-d`, `slide-deck-gen`, `mind-map-gen`, `table-gen`, `quiz-gen`, `flashcard-gen`, `report-gen`, `infographic-gen`, `research-session`, `audience-backend`, `bundle`); unknown / malformed shapes render `—`. Inaugural state on `main` today is the empty-state catalog (0 adapters registered); reference adapters T-426..T-434 will register themselves at the `scripts/sync-skills.ts` dispatch site and the catalog will populate automatically. Vendor-neutral — per-tenant license-posture filtering (ADR-007 §D3 / ADR-008 §D13) is the routing engine's job (T-425), not the generator's. Wired into `scripts/sync-skills.ts` as the seventh dispatch job; `pnpm skills-sync:check` catches drift via the standard CI gate. NOT a structural extension (CLAUDE.md §13).
