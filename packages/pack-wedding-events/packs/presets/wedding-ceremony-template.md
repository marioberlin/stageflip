# Wedding-ceremony template — ceremony-recap video composition

First substantive composition template in the Wedding & Events pack (skeleton landed T-526; closes the first half of the T-526 composition-templates placeholder slot). UNLIKE the cluster-A / cluster-B / cluster-F register presets (Sky News Pro / NBA Pro / MKBHD-pro etc.) which key a single brand to a single clipKind for a strip-style lower-third register, AND unlike T-527's three theme variants (rustic / modern / classic — each keying a SINGLE clipKind), this preset is a **composition template** for a specific wedding-vertical USE CASE — the "ceremony-recap" video photographers / videographers produce within 24–72 hours of the ceremony. Multi-shot composition binding multiple existing clipKinds via PRESET_ID_BINDINGS Pattern C (the same model T-520 prestige-creator and T-522 earnings-call-template established): cluster-D `titleSequence` for the title slide + thank-you card, cluster-A `lowerThird` for the five interstitial section titles. Sister composition template to T-528's wedding-reception-template — same Pattern C cross-cluster binding model, same cluster-wedding-events vertical cluster, same theme-agnostic visual register, but tuned to a DIFFERENT lifecycle moment (ceremony arc — procession through recessional — vs the reception's toasts through send-off).

## Visual tokens

The wedding-ceremony register is theme-agnostic by design — the composition runs the SAME visual register across both ceremony and reception templates regardless of which T-527 theme variant (rustic / modern / classic) the deploy-time wiring overlays. The default register sits TONALLY-NEUTRAL inside the classic-theme aesthetic family (champagne-ivory + soft-rose accent + black text) so the composition reads correctly when production overlays the rustic-theme warm-taupe palette or the modern-theme off-white palette WITHOUT a structural rewrite at deploy time. Composition is the structural shape (seven-shot lifecycle arc); theme is the color overlay applied at the binding-wire step.

- **Background**: champagne ivory `#FFFAF0` (matching the T-527 classic-theme bar fill) — full-bleed soft-warm canvas across every shot in the composition. The tone is intentionally tonal-neutral: warm enough to blend with rustic-theme's warm-taupe overlay (T-527 rustic — `#8B7355` accent), cool enough to blend with modern-theme's off-white overlay (T-527 modern — `#FAFAFA` accent), and on-canon with classic-theme's ivory register (T-527 classic — exact match). NOT the deep slate `#0F172A` financial-broadcast canvas (T-522 earnings-call territory), NOT the confident indigo `#1E3A8A` investor-deck canvas (T-523 territory), NOT the pure black `#000000` editorial-magazine canvas (T-520 prestige-creator territory). Same backdrop across all seven shots in the composition (title / procession / vows / rings / pronouncement / recessional / thank-you) — no per-shot palette divergence.
- **Foreground / primary text color**: `#000000` — pure black. Maximum-contrast black text on the ivory canvas; cross-register wedding-broadcast canon for headline + body slots both. The black-on-ivory contrast pattern carries the engraved-invitation gravitas the ceremony-recap use case demands and reads correctly across all three T-527 theme overlays at the binding-wire step.
- **Accent color**: soft rose `#E5C0C7` — wedding-canonical pastel-pink-and-cream accent. Reserved for the section-title strip-register (lower-thirds for the five ceremony-arc interstitial shots) — the rose strip is the wedding-canon emphasis color, the dried-petal-bouquet / blush-floral-arrangement tonal-neutral accent that reads correctly against every T-527 theme. NOT committed to a specific theme palette (NOT the rustic-theme burgundy `#7F1D1D`, NOT the modern-theme sage `#84A98C`, NOT the classic-theme champagne gold `#D4AF37`) — soft rose is the composition-template's theme-neutral default. The binding-wire step at deploy time MAY flip the rose accent to a theme-specific accent (burgundy / sage / gold) by overriding the snapshot's `accent` value; v1 ships the soft-rose theme-neutral default.
- **No fourth accent color.** The three-color slot palette (ivory canvas + black text + soft-rose accent) IS the composition-template's signature; adding a fourth hue dilutes the theme-agnostic neutrality and migrates the visual onto a specific theme overlay (which is the theme-variant task's territory, not the composition-template task's).
- **Layout** — seven-shot composition per the §Composition structure section below; each shot consumes a single primitive (cluster-D `titleSequence` for shot 1 + shot 7, cluster-A `lowerThird` for shots 2–6). The strip-register positions for the lowerThird shots are pinned at `position: { x: 80, y: 580, width: 1120, alignment: 'left' }` at 1280×720 (the parity-CLI's fixed `DEFAULT_COMPOSITION`) — left-anchored cinematic-third strip, NOT centered, NOT right-anchored. The titleSequence shots (title slide + thank-you card) use the centered full-frame register (the primitive's default).
- **No atmospheric overlays, no grain, no light-leaks, no particle drift.** The composition-template canvas is clean type on a clean canvas — adding atmospheric overlays migrates the visual onto cluster-D prestige-TV title territory (T-348 stranger-things-benguiat / T-351 true-detective-double-exposure). Atmospheric overlays for the wedding-events register are candidate T-529 wedding-transitions territory (curtain reveals, bokeh particles, light-leak transitions) — NOT composition-template territory.

The seven-shot sequence IS the ceremony arc — at the parity-fixture reference frame the eye locks onto the active shot's mid-hold steady-state, framed entirely by the champagne-ivory canvas. The leisurely pacing (800 ms fade-in → 4-second mid-hold → 600 ms fade-out per shot) is the wedding-broadcast lifecycle-pacing UX gesture — slower than T-527 individual theme variants (rustic 800/600, modern 600/400, classic 1000/800) because composition-pacing leans into lifecycle-segmentation rather than per-shot dramatic timing (the audience is following the ceremony arc, not parsing a single dramatic moment).

## Typography

- **`preferredFont: GT Sectra`** (`proprietary-byo` — Grilli Type's editorial-magazine display serif). Same preferred family as T-520 prestige-creator AND T-522 earnings-call AND T-523 investor-deck AND T-527 classic-theme; the transitional / didone hybrid construction with its sharp wedge-serif terminals and high-contrast modulation IS the cross-cluster prestige register. The shared-preferred-family discipline across cluster-F (T-520) + cluster-finance (T-522 / T-523) + cluster-wedding-events (T-527 classic, T-528 compositions) establishes the cross-cluster prestige-typography signature — every prestige-register preset shares the same bespoke serif headline + sans-serif body register split. Cluster-F's type-design batch covers the cluster-wedding-events type sign-off by precedent (T-527 classic-theme is the closest sibling register); cluster-wedding-events type-design batch review is the cluster-composer task downstream. `signOff.typeDesign` MUST be `'pending-cluster-batch'` or `'signed:YYYY-MM-DD'`, NOT `'na'`.
- **`fallbackFont: Cormorant Garamond 600`** (`ofl` — SIL Open Font License 1.1 via Google Fonts). Same OFL fallback as T-520 / T-522 / T-523 / T-527 classic-theme — the canonical OFL transitional-serif-revival fallback for prestige-typography registers. Cormorant Garamond is the OFL transitional-serif-revival closest to GT Sectra in construction — sharp wedge serifs, high contrast modulation, narrow proportions. Type-design consultant approval on the GT Sectra → Cormorant Garamond fallback path is pending the cluster-wedding-events type-design batch review per ADR-004 §D4.
- **Headline (`titlePlate.content.text` for the title slide + thank-you card; `lowerThird.content.title` for the five ceremony-arc sub-shots)**: Mixed Case at the snapshot string level (`'Eleanor & Thomas'`, `'The Procession'`, `'The Vows'` etc.). Rendered via `font: { family, weight: 700, size: 56, letterSpacing: -0.005 }` at the schema-prop level on the title slide and thank-you card (56 px sits between T-527 classic-theme's per-shot 34 px and T-522 earnings-call's 48 px conservative-corporate; the ceremony-template's title slides are larger because the ceremony-arc opens and closes with full-frame display register, NOT strip register); 34 px / fontWeight 600 for the five sub-shot section-titles. Mixed Case (NOT UPPERCASE) IS the wedding-broadcast register — engraved-invitation typography uses sentence-case Mixed Case consistently across heavyweight-cardstock invitation, ballroom-table place card, and ceremony-monogram backdrop. UPPERCASE section titles would read as broadcast-news (T-507 / T-508 / T-509 register) and migrate the visual off the cluster-wedding-events register entirely.
- **Body / venue-attribution slot (`titlePlate.content.tagline` for the title slide; `lowerThird.content.subtitle` slot is unused on the ceremony-arc interstitial shots — section titles stand alone without subtitle copy)**: Plus Jakarta Sans 500 / 22 px / letterSpacing 0 — sans-serif body register for the venue / date attribution. The serif-headline + sans-body split is the canonical typographic signature shared with T-520 / T-522 / T-523 — same cross-cluster prestige-typography canon.
- **Thank-you card body slot (`titlePlate.content.tagline` for shot 7)**: Plus Jakarta Sans 500 / 24 px — slightly larger than the title-slide tagline for the closing-gratitude emphasis. Mixed Case (`'With love, Eleanor & Thomas'`).
- **Casing transform**: `'as-is'` (default). Casing is applied at the snapshot-string level (Mixed Case headlines, Mixed Case body) so the primitive's casing-transform layer is a no-op.
- **No italic, no underline, no strikethrough.** Wedding-broadcast typography never uses them — even the most formal engraved-invitation typography stays in Mixed Case sentence-case at varying sizes, not italic.

## Composition structure

Seven-shot ceremony arc in declaration order, each shot consuming a single primitive (cluster-D `titleSequence` for shot 1 + shot 7, cluster-A `lowerThird` for shots 2–6):

1. **Title slide (titleSequence shot, startMs 0, endMs 5400)** — Mixed Case headline `'Eleanor & Thomas'` centered full-frame on the champagne-ivory canvas. Style bundle `'plate-and-credits'` (same as T-520 prestige-creator and T-522 earnings-call) — the headline plate paired with a credits-block tagline carrying the venue + date combination (`'The Plaza Hotel, New York · September 12, 2026'`). Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.
2. **The Procession (lowerThird shot, startMs 5900, endMs 11300)** — left-anchored cinematic-third strip. Title `'The Procession'` in black serif at 34 px on the champagne-ivory bar with soft-rose `#E5C0C7` accent strip on the left. Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.
3. **The Vows (lowerThird shot, startMs 11800, endMs 17200)** — left-anchored cinematic-third strip. Title `'The Vows'` in black serif at 34 px on the champagne-ivory bar with soft-rose `#E5C0C7` accent strip on the left. Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.
4. **The Rings (lowerThird shot, startMs 17700, endMs 23100)** — left-anchored cinematic-third strip. Title `'The Rings'` in black serif at 34 px on the champagne-ivory bar with soft-rose `#E5C0C7` accent strip on the left. Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.
5. **The Pronouncement (lowerThird shot, startMs 23600, endMs 29000)** — left-anchored cinematic-third strip. Title `'Husband & Wife'` in black serif at 34 px on the champagne-ivory bar with soft-rose `#E5C0C7` accent strip on the left. (Spec uses `'Husband & Wife'` as the canonical default; production may flip to `'Partners for Life'` / `'Married'` / `'Spouses'` at the binding-wire step for inclusive-language variants.) Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.
6. **The Recessional (lowerThird shot, startMs 29500, endMs 34900)** — left-anchored cinematic-third strip. Title `'The Recessional'` in black serif at 34 px on the champagne-ivory bar with soft-rose `#E5C0C7` accent strip on the left. Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.
7. **Thank-you card (titleSequence shot, startMs 35400, endMs 40800)** — Mixed Case headline `'Thank You'` centered full-frame on the champagne-ivory canvas. Style bundle `'plate-and-credits'` — the headline plate paired with a credits-block tagline carrying the couple-signature line (`'With love, Eleanor & Thomas'`). Pacing: 800 ms fade-in EASE_OUT_QUART → 4000 ms mid-hold → 600 ms fade-out EASE_IN_QUART.

Total composition duration: 40.8 s (7 shots × ~5.4 s/shot + 500 ms inter-shot gap). The leisurely pacing IS the wedding-broadcast lifecycle-pacing register — the comprehension load is lifecycle-segmentation (procession → vows → rings → pronouncement → recessional) rather than per-shot dramatic comprehension (each section-title shot needs enough reading time to register the lifecycle moment without lingering on the strip).

## Animation

- **Steady-state register only at the reference frame** per the inherited posture from cluster-A `lowerThird` consumers (T-323 / T-324 / T-325 / T-326 / T-327 / T-328 / T-329 / T-330 / T-507 / T-508 / T-509 / T-510 / T-527 rustic-theme / T-527 modern-theme / T-527 classic-theme) and cluster-D `titleSequence` consumers (T-348 / T-349 / T-350 / T-351 / T-352 / T-353 / T-520 / T-522 / T-523). The composition's active shot at the reference frame renders at full opacity at its final position with no entrance / exit animation active.
- **Choreography target (spec)** — leisurely wedding-broadcast lifecycle pacing across every shot:
  - Fade-in 800 ms EASE_OUT_QUART (primitive default `entrance: 'fade'`)
  - Mid-hold 4000 ms per shot (composition-driven; each shot's `endMs - startMs - entranceMs - exitMs` resolves to 4000 ms)
  - Fade-out 600 ms EASE_IN_QUART (transitionOut `'fade'`, synchronized 600 ms before each shot's `endMs`)
  - Per-shot inter-shot gap 500 ms (the canvas holds the ivory backdrop alone between shots) — the consecutive shot fades in over the holding backdrop with no abrupt cut
  - Total per shot: ~5.4 s — slower than T-522 earnings-call (~5.5 s) is similar but visually-disciplined for the ceremony-arc; the pacing IS the wedding-broadcast lifecycle-pacing canonical UX gesture
- **Mid-segment steady-state at frame 120** (cluster-norm; the parity-CLI's fixed 150-frame composition window means frame 120 = 4000 ms @ 30 fps falls cleanly in the title-slide mid-hold window — shot 1 `startMs 0 endMs 5400`). At frame 120 the render captures the title slide at full opacity with both the headline plate and the credits-block tagline settled at their final positions.
- **No state-transition animation in v1.** State transitions (per-letter staggered entry, per-shot color-jumps, photographic-overlay tinting) belong to other style bundles and other clusters; the wedding-ceremony register is the clean steady-state register.

## Rules

- **Bound primitives**: `titleSequence` for the title slide + thank-you card (shots 1 + 7) + `lowerThird` for the five ceremony-arc sub-shots (procession / vows / rings / pronouncement / recessional). T-528 wires the binding via `PRESET_ID_BINDINGS['wedding-ceremony-template']` per Pattern C. The `'titleSequence'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at the cluster-D squid-game-geometric clipKind-default (T-350); the `'lowerThird'` arm stays at its CNN-classic default (T-323). **First cluster-wedding-events consumer of `titleSequence` primitive** — establishes the cross-cluster register reuse for the wedding-events vertical cluster, binding the cluster-D `titleSequence` primitive alongside the cluster-A `lowerThird` primitive (already bound by T-527 theme variants).
- **Cross-cluster register reuse: cluster-wedding-events preset binding cluster-D + cluster-A primitives.** Same Pattern C model T-520 prestige-creator (cluster-F), T-522 earnings-call (cluster-finance), and T-523 investor-deck (cluster-finance) established. The wedding-ceremony register's wedding-broadcast canon is materially closer to cluster-D prestige-TV title-card register + cluster-A broadcaster-strip register than to any single existing cluster. Reusing the existing `titleSequence` + `lowerThird` primitives — rather than introducing a new `weddingTitle` cluster-wedding-events primitive or a new `ceremonyTitle` cluster-wedding-events primitive — keeps the implementation surface small AND respects the structural-extension rule (§13 of CLAUDE.md): no new clipKind, no new degree-of-freedom on the document or binding model, just a new cluster-wedding-events preset binding existing primitives. The visual register difference (wedding-broadcast vs prestige-TV vs broadcaster-strip) is captured in the snapshot constants (`WEDDING_CEREMONY_TEMPLATE_PROPS`) — same primitives, different props.
- **Theme-agnostic by design.** The composition runs the same visual register (champagne-ivory backdrop + black text + soft-rose accent) regardless of which T-527 theme variant (rustic / modern / classic) the deploy-time wiring overlays. The tonal-neutral default reads correctly across all three theme overlays at the binding-wire step. Production deployments MAY flip the rose accent to a theme-specific accent (rustic burgundy / modern sage / classic gold) by overriding the snapshot's `accent` value at the binding-wire step; v1 ships the theme-neutral defaults.
- **Use for the ceremony-recap video specifically** — the 1–3 minute lifecycle-segmented clip photographers / videographers produce within 24–72 hours of the ceremony covering procession → vows → rings → pronouncement → recessional. Do not use for reception-recap videos (use T-528 wedding-reception-template). Do not use for engagement-shoot videos (different lifecycle moment; candidate cluster-wedding-events composition under a future `T-528a`-family follow-up).
- **Mixed Case headline + Mixed Case section titles — NOT UPPERCASE for either slot.** UPPERCASE titles migrate the register onto broadcast-news (Sky News / ITV / RAI / CNN-breaking) territory entirely. Engraved-invitation typography is sentence-case Mixed Case across the wedding-broadcast register; the Mixed-Case-across-the-board register IS the wedding-broadcast typographic signature.
- **Soft-rose accent stays inside the strip-accent slot.** The soft-rose `#E5C0C7` is reserved for the section-title strip-register left-edge accent. NEVER paint the full bar rose. NEVER use the soft-rose for narrative text content. The accent-only discipline matches the T-527 sister theme variants (rustic burgundy stays in strip-accent, modern sage stays in strip-accent, classic gold stays in strip-accent).
- **No atmospheric overlays.** No optical grain, no light-leak, no dust-particle drift, no compositional gradient. The composition-template canvas IS the register; atmospheric overlays migrate the visual onto cluster-D prestige-TV title territory and belong to T-529 wedding-transitions territory.
- **Designed for ceremony-recap wedding-video deliverables** — same legibility requirements as the cluster-A news-broadcaster register (headline ≥ 34 pt; primitive's 34–56 px exceeds; tagline ≥ 18 pt; primitive's 22–24 px exceeds).
- **Reference frame for parity is mid-segment (frame 120)** per cluster-norm — single canonical variant capturing the title slide at the mid-hold steady-state. The full seven-shot composition's parity coverage falls out from the per-shot steady-state register at frame 120 (title slide is the active shot at frame 120 = 4000 ms @ 30 fps).

## Trade-offs (v1 cosmetic divergences from the compass register)

- **Rendered family is `Cormorant Garamond 600` (OFL fallback), not the bespoke `GT Sectra` (proprietary BYO).** The `titleSequence` primitive's `font.family` prop IS wired into the rendered output, so the rendered family follows the binding's snapshot `font.family` value verbatim. The binding-wire step (cluster-wedding-events composer task) sets `font.family: 'Cormorant Garamond'` for the parity render; flipping to `'GT Sectra'` requires the bespoke font to be BYO-wired at deploy time. v1 ships the OFL fallback verbatim.
- **The seven-shot composition only exercises the title-slide shot at the parity reference frame.** At frame 120 = 4000 ms @ 30 fps, only the title slide (shot 1, startMs 0 endMs 5400) is active; the five `lowerThird` sub-shots (procession / vows / rings / pronouncement / recessional) and the thank-you card (shot 7) are NOT visible in the v1 parity fixture. The parity coverage for the sub-shots falls out of the per-shot steady-state register (each `lowerThird` shot renders identically to a single-shot `lowerThird` preset at its own mid-hold; the thank-you card renders identically to the title slide modulo the headline-string difference) and is verified via per-shot regression fixtures captured in the cluster-wedding-events composer task downstream. v1 ships the title-slide steady-state as the canonical reference frame.
- **Soft-rose accent `#E5C0C7` is the theme-neutral default, NOT a theme-specific accent.** The composition-template's theme-agnostic register pins the accent to soft rose for the parity render; production deployments MAY flip the accent to a theme-specific value (rustic burgundy `#7F1D1D`, modern sage `#84A98C`, classic gold `#D4AF37`) at the binding-wire step. The parity-fixture captures the soft-rose default; theme-specific overlay parity is composer-task territory under a future `T-528a`-family follow-up.
- **Title-slide headline size 56 px, not the T-522 earnings-call 48 px conservative-corporate range or the T-523 investor-deck 52 px confident-corporate range.** The wedding-broadcast register reads at a slightly larger headline scale than the financial-broadcast register — 56 px reads as ceremonial-display at 1280×720; 48 px reads as conservative-corporate. Production deployments with a 1920×1080 or 4K canvas can scale up via the binding override.
- **No `weddingMonogram` companion clip carved out.** The wedding-broadcast canon sometimes features a gold-leaf or floral-frame monogram backdrop card behind the title strip on engraved-wedding intro cards (T-527 classic-theme references this as an out-of-scope candidate). A dedicated `weddingMonogram` primitive (specialized for the engraved-foil monogram-card register with built-in floral-frame border) is a candidate primitive-level carve-out under the cluster-wedding-events compose-tools label; v1 reuses the cluster-D `titleSequence` primitive without the monogram-card.
- **`'plate-and-credits'` style overlap window pins both title-slide shots active at the reference frame.** The headline plate (startMs 0, endMs 5200) and the credits-block tagline (startMs 800, endMs 5400) overlap by 4400 ms. At the reference frame 120 (= 4000 ms @ 30 fps), both shots are active simultaneously. The primitive's `'plate-and-credits'` dispatch renders BOTH active shots layered (the title plate above, the credits block beneath); the v1 parity render captures this two-shot overlap as the steady-state register.
- **No `ceremonyTransition` cross-shot transition primitives.** Cluster-D titleSequence consumers (stranger-things-benguiat T-348, got-trajan-clockwork T-349 etc.) compose the titleSequence primitive with grain / light-leak / particles / photographic-overlay companion clips for the cluster-D prestige-TV register's analog-film aesthetic. The wedding-ceremony register intentionally OMITS these in v1 — atmospheric overlays for the wedding-events register belong to T-529 wedding-transitions territory. The binding-wire step composes each shot solo (no `overlays?` array), distinguishing the composition-template's clean register from the cluster-D prestige-TV registers structurally as well as visually.
