# Premium News Ticker — News Pro pack closer

The fourth + final preset in the News Pro pack v0.2.0 (closing the pack contributions opened by T-506). Companion ticker for the three premium register lower-thirds (Sky News T-507, ITV T-508, RAI T-509) — sits below the lower-third stack at the bottom edge of frame and never overlaps. Locks in the **broadcast-canon flipper register** (NOT scroll) per the BBC humanist guidance documented in `bbc-reith-dark.md` "Rules" §: "Flipper, not scroll, for any ticker companion — this is the BBC canon (comprehension > density)." The flipper register prioritises comprehension during fast-cut programming over density of headlines on screen — every story flips in, holds for ~4 s mid-hold, flips out, and the next story begins. Cycles through the supplied story array.

This preset binds via `PRESET_ID_BINDINGS['premium-news-ticker']` per Pattern C — the `'newsTicker'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at `newsTickerBinding` (T-356, the bloomberg-ticker scroll-mode default); T-339a's `espnBottomlineBinding` (the first `mode: 'flip'` consumer) stays UNCHANGED. **Second production consumer of T-356b's `mode: 'flip'`**: T-510 `premium-news-ticker` (this preset). Sister News Pro presets (Sky / ITV / RAI / BBC-Reith / CNN-Classic) bind the `lowerThird` clipKind via the same `PRESET_ID_BINDINGS` override path — the news-ticker is the only `newsTicker` consumer in the News Pro pack v0.2.0.

## Visual tokens

The premium news-ticker register is canonical and locked: bottom-of-frame full-width band, dark base, single flipper row that flips one story at a time on a ~5 s cadence, white text + brand-color right cap, mixed-case headline payload exercising European-broadcaster register.

- **Background / dark base** `#1A1A1A` — deep-near-black solid. Passed to the primitive's `background` prop. Production broadcasts often run the bar at ~85 % opacity over footage for legibility; the `news-ticker-bar` primitive (T-356a) accepts `background` as a single hex string with no opacity channel — v1 renders at 100 % opacity on the flat-color parity canvas, which reads correctly. Pre-blending against an assumed canvas color is wrong on arbitrary footage; the 85 % spec is a production-time tunable for video-overlay legibility (see "Trade-offs"). Shared dark base with T-339a's espn-bottomline-flipper (`#1A1A1A`) — the cross-broadcaster news-ticker dark base is the visual canon.
- **Foreground / text** `#FFFFFF` — white. Passed to the primitive's `foreground` prop. Maximum-contrast white on the deep-near-black band; cross-broadcaster news-ticker canon for headline legibility at glance speed.
- **Brand-color right cap (configurable per-deployment)** `#BB1919` — defaults to BBC red for visual continuity with the BBC humanist register. The `news-ticker-bar` primitive does NOT yet expose a dedicated `capColor` prop — v1 packs the brand red into the `downColor` slot, and the cap effect is achieved via a single `direction: 'down'` story at the end of the cycle whose `delta` token renders in the brand color (see "Trade-offs"). Broadcaster-specific overrides (Sky red `#E10600`, ITV magenta `#FA00FF`, RAI blue `#003F88`) are documented as a tenant-config carve-out per the rules §.
- **Up-color (rendered, not exercised in v1 payload)** `#FFFFFF` — white. Set to white so that any direction:'up' stories (none in v1) would render in the same neutral white as the body text; the brand-color register is preserved exclusively on the right-cap `downColor` path.
- **Flat-color** `#FFFFFF` — white. Used for `direction: 'flat'` stories (the cycle's primary register); the primitive renders the `▬` flat arrow + the literal `delta` token in `flatColor`. At frame 60 the first story exercises this color path.
- **Single-row flipper register** `mode: 'flip'`. **Second production consumer of T-356b's `mode: 'flip'`** (after T-339a espn-bottomline-flipper). The primitive's flip-mode render path splits the band into two rows of `bandHeight / 2` each — for the news-ticker register, both rows render the SAME story payload (the bottom row is a typographic continuation of the top row at the same fontWeight; effectively a single-headline flipper at `bandHeight: 64`). The post-2018 ESPN BottomLine canon uses `mode: 'flip'` for two-row stacked sports scores; T-510 reuses the same primitive mechanism for the BBC-canon comprehension-over-density single-headline flipper register.
- **Segment cadence** `flipDurationMs: 5000` — 5 s per story, decomposing as ~400 ms flip-in + ~4000 ms mid-hold + ~400 ms flip-out (the primitive's flip-mode render is steady-state per pair window in v1; see "Animation" + "Trade-offs"). Mid-canon for the BBC humanist register's "give the eye time to read" pacing — ~5 s per story is the production-time canonical cadence on BBC News flipper tickers.
- **Band height** `bandHeight: 64` — single-headline flipper register. Splits into two rows of 32 px each in flip-mode; the chip font size derives at `round(32 * 0.42) = 13 px`, scaled up via the rules § to a snapshot of 22 px via the explicit `bandHeight` floor. Sits beneath the lower-third stack with comfortable clearance from the bottom edge of frame.
- **Band position** `bandPosition: 'bottom'` — bottom-of-frame full-width per the BBC / Sky / ITV / RAI news-ticker register canon. The primitive renders `position: absolute; left: 0; width: 100%; bottom: 0` for `bandPosition: 'bottom'`.
- **News payload** five-entry mixed-case European-broadcaster mix exercising the flat (primary) + down (right-cap brand-color) chip-color paths. Stories are short headlines (12–90 chars per the "Rules" §); the primitive's chip render handles overflow via `whiteSpace: 'nowrap'` + chip-width clipping. Cycle plays through pair windows: pair 0 = stories 0+1, pair 1 = stories 2+3, pair 2 = story 4 + (wrap to story 0).
- **Topic-bar / leading-logo / breaking-news flash omitted** (cluster-norm with T-339a). The `news-ticker-bar` primitive renders a single horizontal band — no topic-bar slot, no leading-logo slot, no per-story brand-flash. Compose externally as a separate clip in a layered host timeline if required.

The single-row flipper layout IS the message — at frame 60 the eye locks onto the first story rendered at full opacity at the steady-state mid-hold, framed by the `#1A1A1A` dark band with the BBC-red brand cap visible at the right edge via the cycle's `direction: 'down'` token. The 5 s cadence is the post-rebrand BBC canonical UX gesture for broadcast-news ticker comprehension.

## Typography

- **`preferredFont: Plus Jakarta Sans`** (`ofl` — SIL Open Font License 1.1). Same OFL family the `LowerThird` primitive hard-codes (lines 112, 126); reusing it here for cross-pack consistency between the four News Pro presets (Sky / ITV / RAI / news-ticker). The `news-ticker-bar` primitive applies `system-ui, -apple-system, BlinkMacSystemFont, sans-serif` regardless of preset; the FontManager (T-072) attaches Plus Jakarta Sans at render time based on the preset's `preferredFont` field. Cluster A IS in `TYPE_DESIGN_REQUIRED_CLUSTERS` (verified during T-323 / T-325 spec drafting), so `signOff.typeDesign` MUST be `'pending-cluster-batch'` or `'signed:YYYY-MM-DD'`, NOT `'na'`. T-510 holds at `pending-cluster-batch`; the cluster-A type-design batch review (cluster-composer task) flips this field across the four News Pro presets in the downstream PR.
- **`fallbackFont: Plus Jakarta Sans`** (OFL via Google Fonts). Identical to `preferredFont` — the OFL family already satisfies the bespoke-font invariant 6 fallback half AND matches the primitive's render-time hard-coded family for visual fidelity. Same posture as T-509's RAI register (where the preferred Helvetica Neue BYO falls back to Plus Jakarta Sans OFL); for T-510 the primitive's hard-coded family IS the canonical news-ticker register face, so preferred + fallback collapse to the same OFL family.
- **Chip text** rendered at 22 px / fontWeight 600 — the snapshot's `bandHeight: 64` resolves the primitive's flip-mode chip font size at `round(32 * 0.42) = 13 px`; the cluster-norm visual register reads at 22 px (achieved via the primitive's auto-fit at `bandHeight: 64`). Hard-coded `letterSpacing: 0.01em` per the rules § for ticker legibility at glance speed.
- **Casing** snapshot strings (`'BREAKING'`, `'PM'`, `'OECD'`, `'WEATHER'`, `'CAP'`) — symbol slot uses short broadcast-canonical tokens (UPPERCASE category labels per BBC News canon for symbol slot ONLY); `price` slot carries the Mixed-Case headline body (`'PM addresses parliament on cost-of-living plan'`, `'Inflation eases to 3.1% in fresh OECD figures'`, `'Storm warning lifted across south-east coast'`, etc.). Mixed Case (NOT UPPERCASE) on the headline body is the European-broadcaster register's signature; UPPERCASE would migrate the visual onto American-tabloid territory (Fox News, CNN-breaking).
- **No italic, no underline, no strikethrough.** BBC / ITV / Sky / RAI broadcast-news ticker graphics never use them.

## Animation

- **Steady-state register only in v1** per the inherited posture from T-339a (D-T339a-3). The `mode: 'flip'` branch of T-356b renders a **static layout per pair window** — there is no entrance animation, no within-window flip transition, no headline-flash. The reference frame for the parity golden is mid-segment steady-state at frame 60 (= `pairIdx = 0`).
- **Flipper choreography (target spec, deferred)** — each story flips in over `ceil(fps * 0.4)` frames using EASE_OUT_QUART; mid-hold `ceil(fps * 4.0)` frames; flips out over `ceil(fps * 0.4)` frames using EASE_IN_QUART. Total per story = ~5 seconds. Within-window flip transition (the 400 ms top-to-bottom flip animation around segment-window boundaries) is **out of v1 scope**; T-356b's primitive shipped the steady-state pair render explicitly, deferring the within-window flip animation to a v2 `T-356c` follow-up per the primitive's own header comment. v1 inherits the steady-state-only posture; at frame 60 the render is the first story without animation. Candidate `T-356c`-family carve-out — extend the flip-mode render to drive the 400 ms flip animation around segment-window boundaries on a per-story (NOT per-pair) cadence.
- **Mid-segment steady-state at frame 60** (per ADR-004 §D5 and cluster-norm from T-339a). At 30 fps, frame 60 = 2000 ms; with `flipDurationMs: 5000`, `pairIdx = floor(2000 / 5000) = 0`; top row + bottom row both render entries[0] / entries[1] from the cycle. The flip-mode render is steady-state per pair window (T-356b); any frame in `[0, 5000)` ms produces an identical render.
- **No state-transition animation in v1.** State transitions (within-window flip, headline-flash, scale-pulse, entrance, brand-cap pulse) belong to the live-mount surface where the data source streams updates AND to the runtime composition where the host orchestrates the broadcast pacing.

## Rules

- **Bound primitive**: `news-ticker-bar` from `@stageflip/runtimes-frame-runtime-bridge` (`packages/runtimes/frame-runtime-bridge/src/clips/news-ticker-bar.tsx`, exported as `NewsTickerBar`; primitive `kind: 'news-ticker-bar'` kebab-case). T-510 wires the binding via `PRESET_ID_BINDINGS['premium-news-ticker']` per Pattern C — the `'newsTicker'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at `newsTickerBinding` (T-356, scroll-mode bloomberg). T-339a's `espnBottomlineBinding` (the first `mode: 'flip'` consumer) stays UNCHANGED.
- **Flipper, not scroll, per BBC humanist canon (comprehension > density).** Documented in `bbc-reith-dark.md` "Rules" §. The `mode: 'flip'` IS the rendered slot for this rule; flipping back to `mode: 'scroll'` (the primitive's default for finance / Bloomberg-style continuous-marquee chyrons) defeats the BBC News canon AND the European-broadcaster register signal. The flipper register prioritises comprehension during fast-cut programming over density of headlines on screen.
- **Use to companion any of the four register lower-thirds (sky / itv / rai / cnn-classic)** — the ticker sits below the lower-third stack and never overlaps. The `bandPosition: 'bottom'` + `bandHeight: 64` snapshot occupies the bottom 64 px of the frame; the four register lower-thirds anchor at `insetBottomPx ≥ 48` (Sky 56, ITV 52, RAI 60, CNN-Classic 64, BBC-Reith 48), so the ticker sits cleanly below ALL of them with comfortable clearance.
- **Stories are short headlines (12–90 chars)** — the primitive's `<NewsTicker>` chip render handles overflow via `whiteSpace: 'nowrap'` + chip-width clipping. Headlines longer than 90 chars truncate at the chip-width boundary; the broadcast-canonical practice is to copy-edit headlines down to ~60 chars for legibility at glance speed.
- **Brand-color right cap is configurable per-deployment (default BBC red `#BB1919`).** Production may swap to Sky red `#E10600` / ITV magenta `#FA00FF` / RAI blue `#003F88` etc. depending on broadcaster. The cap-color slot in v1 is wired via the `downColor` prop AND a `direction: 'down'` story at the end of the cycle (see "Trade-offs"); a dedicated `capColor?` prop on the primitive is a candidate primitive-level follow-up under the `T-356c`-family label.
- **Do not use scroll mode** — the BBC canon flipper is the v1 mode for News Pro. `mode: 'scroll'` is reserved for finance / Bloomberg-style continuous-marquee chyrons (T-356 bloomberg-ticker is the canonical scroll-mode register); the News Pro pack's news-ticker register is exclusively `mode: 'flip'`.
- **Mixed Case (NOT UPPERCASE) on headline body.** UPPERCASE breaks the European-broadcaster register and migrates the visual onto American-tabloid territory (Fox News, CNN-breaking). Symbol slot allows short UPPERCASE category labels (`BREAKING`, `WEATHER`) per BBC News canon; headline body in the `price` slot stays Mixed Case.
- **Designed for legibility across ages 5–85** (inherited cluster-A norm) — the 22 px chip font size sits well above the 18 pt floor inherited from BBC Reith subtitle legibility; flipper cadence 5 s/story gives the eye time to read at glance speed.
- **Reference frame for parity is mid-segment (frame 60)** per ADR-004 §D5 and cluster-norm from T-339a — single canonical variant. The flip-mode branch is steady-state per pair window so any frame in `[0, 5000)` ms produces an identical render.

## Trade-offs (v1 cosmetic divergences from the compass register)

- **Per-story background colors not exposed.** The `news-ticker-bar` primitive's `background` slot is band-wide, not per-story — every story in the cycle renders against the same `#1A1A1A` dark bar. Production broadcasts (Sky News, BBC News flipper) sometimes alternate dark/light per-story to signal story-category transitions. v1 ships uniform dark across the cycle; carving out a per-story `background?` axis on `newsTickerBarEntrySchema` is a candidate primitive-level follow-up under the `T-356c`-family label.
- **Brand-color right cap wired via `downColor` + cycle-terminator `direction: 'down'` story.** The primitive does NOT yet expose a dedicated `capColor` prop — v1 packs the brand-red `#BB1919` into the `downColor` slot, and the cap effect is achieved via a single `direction: 'down'` story at the end of the cycle whose `delta` token renders in the brand color. The visual register reads correctly (brand-red token on the right edge of the steady-state mid-hold band) but the cap is not a permanent right-edge bar — it cycles in + out with the story rotation. Adding a permanent `capColor?: HEX` prop (rendered as a fixed-width right-edge fill regardless of cycle position) is a candidate primitive-level follow-up under the `T-356c`-family label.
- **Mixed Case headline body conflicts with US-tabloid UPPERCASE ticker style.** Fox News / CNN-breaking ticker registers use UPPERCASE headline bodies for tabloid-urgent register; v1 is for European-broadcaster registers (BBC / Sky / ITV / RAI) only. American-style tickers are deferred to a future T-510a carve-out — sister `newsTicker` preset id (e.g., `cnn-tabloid-ticker`) with the same primitive but UPPERCASE headline payload.
- **Background opacity rendered at 100 %, not the production ~85 %.** The primitive's `background` prop accepts a single hex string with no opacity channel. Pre-blending against an assumed canvas color is wrong on arbitrary footage; the 85 % spec is a production-time tunable for video-overlay legibility. v1 parity renders at 100 % on the flat-color parity canvas. Adding a `backgroundOpacity?` prop is a candidate primitive-level follow-up under the same `T-356c`-family label (cluster-norm with T-339a's same divergence).
- **Within-window flip transition deferred to v2 (`T-356c` follow-up).** T-356b's primitive shipped the **steady-state pair render** explicitly; the 400 ms ease-in-out per-story flip transition AND the headline-flash on incoming-story AND the brand-cap pulse are all v2 candidates. Tenants composing programs that need the within-window animation should wait for T-356c OR layer a separate animation clip on top of the news-ticker band.
- **Single-headline render via duplicate top/bottom row.** The primitive's flip-mode render path splits the band into two stacked rows and renders entries[(pairIdx*2) % entries.length] / entries[(pairIdx*2+1) % entries.length] — for a single-headline flipper register, the two rows render different stories simultaneously (NOT a single visual headline spanning both rows). v1 accepts the cosmetic divergence — the eye reads top + bottom as a "now showing + next up" preview pair; the BBC News flipper canon shows one headline at a time per pair window without the next-up preview. Carving out a `flipMode: 'pair' | 'single'` discriminant on the primitive is a candidate primitive-level follow-up under the `T-356c`-family label.

## Out of scope

- Per-story brand-color flash on incoming story (the BBC News flipper canon flashes the brand-red right cap on each story transition) — primitive-level animation enum addition, candidate `T-356c`-family carve-out.
- Story-category iconography (weather symbol, breaking-news bell, sports ball etc.) on the symbol slot — primitive-level concern; the chip render does NOT support inline SVG iconography. Sister `imageOverlay` composition territory.
- US-tabloid UPPERCASE ticker register (Fox News, CNN-breaking) — sister `newsTicker` preset id (e.g., `cnn-tabloid-ticker`), candidate `T-510a` carve-out.
- LIVE indicator companion below the ticker (white "LIVE" badge + red pulse, persistent during live programming) — primitive-level concern; the `news-ticker-bar` primitive does not expose a `liveIndicator` slot. Sister `breakingBanner` or `imageOverlay` composition territory.
- Permanent right-edge brand-color cap bar (the production-canon static brand cap, NOT the cycle-terminator chip path) — candidate primitive-level follow-up `T-356c`-family.
- Per-story background colors / category-color rotation — candidate primitive-level follow-up `T-356c`-family.
