# NFL Pro — score bug

## Visual tokens
- Base bar: dark `#1A1A1A` — the sports-broadcast standard for the across-the-bottom scoring strip seen on CBS NFL / Fox NFL / ESPN MNF / NBC SNF. Dark enough to read against the green-grass + crowd backdrop that dominates an NFL broadcast frame, without going pure black. Pure black `#000000` is the news-broadcaster register (Sky News / BBC Reith / CNN-Classic); the NFL broadcast canon picks a near-black `#1A1A1A` that lets the home/away team-color boxes carry more visual weight against the bar. The `score-bug` primitive (T-332a) accepts `background` as a single hex string with no opacity channel; v1 renders at 100 % opacity. Production NFL broadcasts commonly run the strip at ~92 % over field footage for legibility; the flat-color parity canvas reads correctly at 100 % (see "Trade-offs").
- Home team box: NFL brand deep blue `#013369` filled section (the canonical NFL logo blue) — distinct from the broadcast register colors that wrap individual NFL teams (Cowboys navy, Giants royal-blue, Chiefs red). The snapshot uses Cowboys (`DAL`) home with the NFL logo blue as the fallback when a team color is not pinned by `PRESET_ID_BINDINGS`; the cluster-B composer task supplies the team-specific kit color (Cowboys navy `#003594`) at the binding wire step. v1 ships the NFL-brand-blue home box. Note the inversion from T-512 NBA Pro: NBA leads with red (home) / blue (away); NFL leads with blue (home) / red (away) — matching the NFL logo's blue-dominant identity.
- Away team box: NFL brand red `#D50A0A` filled section (the canonical NFL logo red) — the away box mirrors the brand-secondary on the right. Snapshot uses Giants (`NYG`) away. Same composer-task override path applies for the team-specific Giants royal-blue (`#0B2265`) if pinned — though the all-NFC-East matchup is a less obvious choice; an alternative AFC-vs-NFC pairing (`KC` / `BUF`) is documented under "Trade-offs" as the canonical NFL broadcast register example.
- Center clock + down-distance: `#FFFFFF` white text on the dark base for clock + down-distance token (`04:32` mid-Q3, `3rd & 4` down-and-distance). Tabular numerics for column-edge alignment of scores (`21` / `17`). The `score-bug` primitive's `'football'` branch exposes an optional `down` prop (primitive line 78 + render line 409–411) rendered below the clock at `fontSize: 12` — NFL-specific data the NBA register left empty. T-334 Fox NFL also wires `down`; this preset reuses the same slot.
- Bar anchored bottom-center at `position: { x: 280, y: 600 }` on a 1280×720 canvas — matching the T-334 / T-335 NBC SNF + Fox NFL anchor norm for the across-the-bottom scoring-strip register and the T-512 NBA Pro anchor. NFL broadcast canon places the bar tight against the bottom edge during regular game flow, with the LIVE indicator + ad ticker stacked above it.
- Card auto-fits: home box | clock + down-distance column | away box (left-to-right) per the `score-bug` `'football'` style branch (primitive line 335–423; home flex 1, clock minWidth 96, away flex 1). v1 uses the existing `score-bug` primitive's `'football'` style branch unchanged — the layout matches the NFL scoring-strip pattern verbatim. Snapshot constants live in `NFL_PRO_REGISTER_PROPS` (exported from `@stageflip/parity-cli` at the cluster-B composer task's binding-wire step).

## Typography
- Team codes (`home.code` / `away.code`): UPPERCASE 3-letter broadcast tokens (`DAL` / `NYG`) — strict NFL convention. The NFL exclusively uses 3-letter UPPERCASE team codes across all broadcast registers; this is the signature visual difference from T-512 NBA Pro's Mixed-Case-friendly identity (where Mixed-Case full names like `Lakers` / `Celtics` appear elsewhere on the broadcast). The primitive renders `home.code` / `away.code` verbatim per `applyCasing` short-circuit on numeric leading character (D-T332a-12). v1 snapshot uses already-uppercase strings; `casing: 'as-is'` (matches T-333 / T-334 / T-335 / T-512 norm).
- Mixed-Case full team names (`Cowboys` / `Giants`) appear on the production broadcast above or beside the score bug — out of scope for the `score-bug` `'football'` branch (no full-name slot). Adding a `home.name` / `away.name` slot is a candidate `T-332b`-family primitive-level follow-up under the same `score-bug` enhancement label (shared with T-512 NBA Pro's identical trade-off).
- Scores (`home.score` / `away.score`): numeric `21` / `17` — typical mid-game NFL scoring. The primitive's `applyCasing` short-circuit on leading-digit text leaves numeric strings untouched (primitive lines 233–235). Tabular numerics at the root style guarantee column-edge alignment regardless of digit count (`21` / `17` align cleanly; 3-digit scores `100`+ rare in NFL but the alignment holds).
- Clock token: `04:32` — mid-third-quarter (matches the T-334 Fox NFL precedent for Q3 mid-quarter sampling; the canonical NFL parity-frame choice for the scoring-strip register). Period token: `Q3` (NFL broadcast canon — quarters, like NBA). The primitive renders period below the clock in `fontSize: 12` per the `'football'` branch.
- Down-and-distance token (`down` prop): `3rd & 4` — third down + 4 yards to gain. NFL broadcast canon for the down-and-distance display is `<ordinal> & <yards>` (`1st & 10`, `2nd & 7`, `3rd & 4`, `4th & goal`). The primitive renders `down` below the clock at `fontSize: 12` (primitive line 409–411). v1 uses `3rd & 4` for the parity frame — typical mid-drive NFL state. The down-and-distance row is the NFL-specific data the NBA register left empty.
- Rendered family v1: `Inter Display` weight 700 — the OFL fallback declared in frontmatter. The primitive's `font` prop is honored at render time (primitive lines 286–303: `fontFamily: props.font?.family ?? DEFAULT_FONT_FAMILY`), so the rendered family in this case IS the OFL fallback — unlike the `lowerThird` primitive which hard-codes its own family. Bespoke `NFL Sans` (proprietary BYO) declared in frontmatter exists for the type-design batch review (sister cluster-B composer task) and is the BYO substitution when a tenant supplies the licensed file.

## Animation
- Slide-in from the bottom over `ceil(fps * 0.35)` frames easing `EASE_OUT_QUART`; mid-game indefinite hold; slide-out to the bottom over the last `ceil(fps * 0.25)` frames easing `EASE_IN_QUART`. At 30 fps: ~350 ms entrance, ~250 ms exit — sharper than the news-broadcaster lower-third's 450 ms entrance, in keeping with the more dynamic sports-broadcast register. Identical timing to T-512 NBA Pro (same sports-broadcast family).
- Steady-state mid-hold: `translatePct == 0`, `opacity == 1`. The parity golden captures this state at frame 60 (= 2000 ms @ 30 fps composition) — matches T-333 / T-334 / T-335 / T-512 score-bug parity-fixture frame-pinning norm.
- The `score-bug` primitive (T-332a) is static in v1 — entrance/exit choreography is provided by the composing `frame-clip` envelope at the binding wire step, NOT by the primitive itself. Score-change pulse (120 ms brightness flash on the team box whose score updated), possession-glow pulse (sister T-335 NBC SNF carve-out), touchdown comic-book celebration (T-334 Fox NFL carve-out), quarter-end clock-stop flash, two-minute-warning flash, and live-update mid-hold ticker (drive-by-drive updates) are deferred (see "Out of scope").

## Rules
- Use when an NFL football-broadcast scoring register is called for — across-the-bottom game-state strip on live game footage, replay sequences, halftime/intermission lower-frame attribution. NFL-Pro register sits within Cluster B's sports-broadcast family next to T-333 Premier League (football horizontal), T-334 Fox NFL (American-football chrome-less; a network-specific NFL variant), T-335 NBC SNF (American-football center-circle + network-mark; another network-specific NFL variant), and T-512 NBA Pro (basketball quarter-period). Choose NFL-Pro for the generic NFL register (no network-specific chrome / center-circle / down-and-distance animation) — the network-neutral premium register a tenant uses when they want NFL game-state without committing to a specific network's broadcast brand.
- Do not use for non-football sports (use `nba-pro-register` for basketball / a future MLB preset T-514 for baseball / a future F1 preset T-515 for Formula 1 / `premier-league-field-of-play` for association football).
- Do not paint the full bar NFL blue. The home-team box's blue fill is the brand identifier on that section; the rest of the bar (`#1A1A1A`) carries the dark-on-grass legibility. Pulling the base bar to NFL blue would saturate the strip and destroy the home-vs-away color contrast.
- UPPERCASE 3-letter team codes are mandatory (NOT Mixed-Case). This is strictly enforced for NFL — the league uses 3-letter UPPERCASE codes (`DAL`, `NYG`, `KC`, `BUF`, `SF`, `LV`, `LAR`, `LAC` — 2-letter codes `SF` / `KC` / `LV` are exceptions for the short city names but still UPPERCASE) across all broadcast registers and on-field signage. The scoring-strip register is space-constrained; full team names go elsewhere on the production broadcast (above the strip or to its side) and are out of scope for the `score-bug` `'football'` branch.
- Score digits left at the primitive's default `fontSize: 28`, `fontWeight: 800` (primitive lines 320–322). NFL broadcast canon uses a slightly larger score digit than the team code; the primitive's defaults are close enough to the broadcast register for v1.
- Down-and-distance row is REQUIRED (not optional like other `'football'` style consumers). NFL broadcasts always show down-and-distance during the play clock; omitting it would read as a non-NFL scoring strip. Snapshot pins `down: '3rd & 4'`; the binding wire step parameterizes per-frame.
- Designed for live NFL game footage across the regular season + playoffs broadcast — same legibility requirements as the T-333 / T-334 / T-335 / T-512 scoring-strip presets (team codes ≥ 24 pt; primitive's 28 px default satisfies).

## Trade-offs (v1 cosmetic divergences from the compass register)
- **No full team names rendered.** The `score-bug` `'football'` branch (primitive line 335–423) exposes only `home.code` / `away.code` 3-letter slots — no `home.name` / `away.name` full-name slot. NFL broadcast canon commonly renders `Cowboys` / `Giants` Mixed-Case adjacent to or above the scoring strip (less prominently than NBA broadcasts since the 3-letter NFL codes are universally recognized); v1 accepts the 3-letter-only register. Adding `home.name` + `away.name` optional slots is a candidate `T-332b`-family primitive-level follow-up shared with T-512.
- **Team box colors are NFL-brand blue + red, not Cowboys-navy + Giants-royal-blue.** The snapshot uses the canonical NFL-logo blue `#013369` (home) + NFL-logo red `#D50A0A` (away) as the fallback when the cluster-B composer task has not pinned a team-specific kit color via `PRESET_ID_BINDINGS`. Cowboys navy `#003594` + Giants royal-blue `#0B2265` are the canonical kit colors for this NFC-East matchup; an alternative AFC-vs-NFC pairing (Chiefs red `#E31837` vs Bills royal `#00338D`) is the canonical Super-Bowl-era broadcast example. The composer-task wire step is the place to override them. v1 ships the NFL-brand fallback so the preset reads as a generic NFL register that any team-matchup can wire into.
- **No `centerCircle` / `direction` / `networkLogo` decorations.** The `'football'` branch's optional props are NBC-SNF-specific (center circle, network logo, direction chevrons) or Fox-NFL-specific (backdrop gradient). NFL broadcasts use those decorations selectively per network identity; this network-neutral register omits them. v1 ships a clean home | clock + down-distance | away layout. The `backdrop: 'gradient'` Fox-NFL touch is a candidate per-binding override.
- **Helmet-logo / team-color-stripe decorations not rendered.** NFL broadcast canon prominently features helmet-logo glyphs and team-color stripes flanking the team codes — primitive-level slot additions under the `T-332b`-family label (would require an image-asset slot per team). v1 ships flat-color team boxes; the helmet-logo carve-out is the most visible deviation from the broadcast canon. Documented as a known gap for the type-design batch review.
- **Period token is `Q3` (3 chars), not `3RD QTR` or `THIRD QUARTER` long-form.** The primitive's period slot renders below the clock at `fontSize: 12` alongside the down-and-distance token — a long-form string would clip or overflow at the primitive's default width. NFL broadcast canon uses both the short and long forms depending on bar width; v1 picks the short form for safe layout. A long-form variant is a candidate per-binding override. NOTE the period token and down-distance token co-occupy the below-clock area; the primitive renders them as separate `<span>` children — visual stacking is per the primitive's default flex flow.
- **Background opacity rendered at 100 %, not the production ~92 %.** The primitive's `background` prop accepts a single hex string with no opacity channel. Pre-blending against an assumed grass color is wrong on arbitrary footage; the 92 % spec is a production-time tunable for video-overlay legibility. v1 parity renders at 100 % on the flat-color parity canvas. Adding a `backgroundOpacity?` prop is a candidate primitive-level follow-up under the `T-332b`-family label (shared with T-512).
- **Two-minute-warning flash not rendered.** NFL broadcasts pulse the clock + down-distance row red during the final 2:00 of each half. Primitive-level animation enum addition under the `T-332b`-family label.

## Out of scope
- Score-change pulse (120 ms brightness flash on the home or away box whose score just updated) — primitive-level animation enum addition under the `T-332b`-family label; sister carve-out to the T-334 Fox NFL touchdown comic-book celebration + T-335 NBC SNF possession-change animation + T-512 NBA Pro score-change.
- Touchdown comic-book celebration (Fox NFL's signature animated burst on TD) — already documented as a T-334-specific carve-out; NOT pulled into the network-neutral NFL Pro register.
- Quarter-end clock-stop flash (the clock pulsing red when reaching 0:00) — primitive-level animation under the same `T-332b`-family label.
- Two-minute-warning flash (final 2:00 of each half) — primitive-level animation enum addition.
- Possession indicator / down-arrow chevron — NFL possession is encoded in the down-and-distance text (offense's down), but the visual possession arrow on the team-box edge is a separate carve-out. Candidate `T-332c` sibling.
- Field-position indicator (yard line + side of field) — a column to the right of the down-and-distance; primitive-level slot addition under the `T-332b`-family label.
- Live drive-by-drive ticker companion — semantically a sister `newsTicker` preset (mirrors T-510 News Pro premium news-ticker); future Cluster B follow-up if Reviewer scrutiny demands.
- Network-logo glyph on the scoring strip (CBS / Fox / ESPN / NBC) — the `'football'` branch's `networkLogo` slot lives inside the optional center-circle treatment; the network-neutral NFL Pro register omits the network mark by design. T-334 Fox NFL + T-335 NBC SNF cover the network-specific variants.
