# MLB — score bug

## Visual tokens
- Base bar: dark `#1A1A1A` — the sports-broadcast standard for the across-the-bottom scoring strip seen on Fox Saturday Baseball / ESPN Sunday Night Baseball / MLB Network / Apple TV+ Friday Night Baseball. Dark enough to read against the green-grass + dirt-infield backdrop that dominates an MLB broadcast frame, without going pure black. Pure black `#000000` is the news-broadcaster register (Sky News / BBC Reith / CNN-Classic); the MLB broadcast canon picks a near-black `#1A1A1A` that lets the home/away team-color boxes carry more visual weight against the bar. The `score-bug` primitive (T-332a) accepts `background` as a single hex string with no opacity channel; v1 renders at 100 % opacity. Production MLB broadcasts commonly run the strip at ~92 % over field footage for legibility; the flat-color parity canvas reads correctly at 100 % (see "Trade-offs").
- Home team box: MLB brand deep blue `#002D72` filled section (the canonical MLB logo blue) — distinct from the broadcast register colors that wrap individual MLB teams (Yankees navy, Dodgers blue, Red Sox red). The snapshot uses Yankees (`NYY`) home with the MLB logo blue as the fallback when a team color is not pinned by `PRESET_ID_BINDINGS`; the cluster-B composer task supplies the team-specific kit color (Yankees navy `#0C2340`) at the binding wire step. v1 ships the MLB-brand-blue home box. Same blue-dominant logo identity inversion the T-513 NFL Pro register adopted relative to T-512 NBA Pro: MLB leads with blue (home) / red (away) — matching the MLB silhouette-batter logo's blue-dominant identity.
- Away team box: MLB brand red `#D50032` filled section (the canonical MLB logo red) — the away box mirrors the brand-secondary on the right. Snapshot uses Red Sox (`BOS`) away. Same composer-task override path applies for the team-specific Red Sox red (`#BD3039`) if pinned — the AL-East Yankees-vs-Red-Sox pairing is the canonical MLB broadcast register example (most prominent rivalry, played in front of cameras most frequently).
- Center clock + inning indicator: `#FFFFFF` white text on the dark base for clock token (the `clock` slot is repurposed for the count `0-2` — balls-and-strikes, MLB's mid-at-bat live state) + inning indicator (`TOP 7` — top of the seventh inning). Tabular numerics for column-edge alignment of scores (`4` / `2`). The `score-bug` primitive's `'football'` branch exposes an optional `down` prop (primitive line 78 + render line 409–411) rendered below the clock at `fontSize: 12`. v1 repurposes the `down` slot for the inning indicator (`TOP 7`) — `down` is `z.string().optional()` per the primitive schema and accepts arbitrary strings. The primitive's `'football'` style branch is reused unchanged; no `'baseball'` style branch exists (would be a candidate T-332b primitive-level addition).
- Bar anchored bottom-center at `position: { x: 280, y: 600 }` on a 1280×720 canvas — matching the T-334 / T-335 / T-512 / T-513 anchor norm for the across-the-bottom scoring-strip register. MLB broadcast canon places the bar tight against the bottom edge during regular game flow, with the count + base-runner diamond stacked above it on production.
- Card auto-fits: home box | clock + inning column | away box (left-to-right) per the `score-bug` `'football'` style branch (primitive line 335–423; home flex 1, clock minWidth 96, away flex 1). v1 uses the existing `score-bug` primitive's `'football'` style branch unchanged — the layout matches the MLB scoring-strip pattern with the `down` slot repurposed to carry inning information. Snapshot constants live in `MLB_REGISTER_PROPS` (exported from `@stageflip/parity-cli` at the cluster-B composer task's binding-wire step).

## Typography
- Team codes (`home.code` / `away.code`): UPPERCASE 2-3-letter broadcast tokens (`NYY` / `BOS`) — MLB convention. MLB uses a mix of 2-letter (`SF` for San Francisco) and 3-letter (`NYY`, `BOS`, `CHC`, `STL`, `LAD`, `LAA`, `OAK`, `KCR`) UPPERCASE codes across broadcast registers — never `LA` alone (Dodgers use `LAD` / Angels use `LAA`). This sits between T-513 NFL Pro's strict 3-letter UPPERCASE (`DAL` / `NYG`) and T-512 NBA Pro's Mixed-Case-friendly identity. The primitive renders `home.code` / `away.code` verbatim per `applyCasing` short-circuit on numeric leading character (D-T332a-12). v1 snapshot uses already-uppercase strings; `casing: 'as-is'` (matches T-333 / T-334 / T-335 / T-512 / T-513 norm).
- Mixed-Case full team names (`Yankees` / `Red Sox`) appear on the production broadcast above or beside the score bug — out of scope for the `score-bug` `'football'` branch (no full-name slot). Adding a `home.name` / `away.name` slot is a candidate `T-332b`-family primitive-level follow-up under the same `score-bug` enhancement label (shared with T-512 / T-513).
- Scores (`home.score` / `away.score`): numeric `4` / `2` — typical mid-game MLB scoring. The primitive's `applyCasing` short-circuit on leading-digit text leaves numeric strings untouched (primitive lines 233–235). Tabular numerics at the root style guarantee column-edge alignment regardless of digit count (`4` / `2` align cleanly; double-digit blowout scores `10`+ align the same way).
- Count token (rendered through the `clock` slot): `0-2` — 0 balls, 2 strikes — typical mid-at-bat MLB state. The `clock` slot in the primitive is a free-form string; MLB broadcasts use the same below-team-codes position for the balls-and-strikes count that football uses for the game clock. v1 repurposes the slot semantically; no schema change needed.
- Period token: `9TH` — the `period` slot wraps the inning ordinal. MLB broadcast canon uses inning ordinals (`1ST` through `9TH`+ for extras) in the same below-clock area where football uses the quarter (`Q3`). v1 picks `9TH` for the parity frame — top-of-the-ninth is a high-stakes broadcast-canon sampling moment (closer's inning).
- Inning-half token (`down` prop repurposed): `TOP 7` — top of the seventh inning. MLB broadcast canon for the inning-half display is `TOP <n>` / `BOT <n>` (or `▲ <n>` / `▼ <n>` with directional arrows in some networks). The primitive renders `down` below the clock at `fontSize: 12` (primitive line 409–411). v1 uses `TOP 7` for the parity frame — note this overrides the period token in the snapshot semantically; the primitive renders both period and `down` in the below-clock column. The snapshot pins both `period: '7TH'` and `down: 'TOP 7'` to demonstrate the inning-half is the dominant MLB token — the period ordinal is redundant when the half-inning token is present, but the snapshot keeps both to show the layout. Per-binding overrides at the wire step can drop the period in favor of `TOP 7` only.
- Rendered family v1: `Inter Display` weight 700 — the OFL fallback declared in frontmatter. The primitive's `font` prop is honored at render time (primitive lines 286–303: `fontFamily: props.font?.family ?? DEFAULT_FONT_FAMILY`), so the rendered family in this case IS the OFL fallback — unlike the `lowerThird` primitive which hard-codes its own family. Bespoke `MLB Tuscan` (proprietary BYO; the MLB-broadcast tuscan-serif numeral signature) declared in frontmatter exists for the type-design batch review (sister cluster-B composer task) and is the BYO substitution when a tenant supplies the licensed file.

## Animation
- Slide-in from the bottom over `ceil(fps * 0.35)` frames easing `EASE_OUT_QUART`; mid-game indefinite hold; slide-out to the bottom over the last `ceil(fps * 0.25)` frames easing `EASE_IN_QUART`. At 30 fps: ~350 ms entrance, ~250 ms exit — sharper than the news-broadcaster lower-third's 450 ms entrance, in keeping with the more dynamic sports-broadcast register. Identical timing to T-512 NBA Pro and T-513 NFL Pro (same sports-broadcast family).
- Steady-state mid-hold: `translatePct == 0`, `opacity == 1`. The parity golden captures this state at frame 60 (= 2000 ms @ 30 fps composition) — matches T-333 / T-334 / T-335 / T-512 / T-513 score-bug parity-fixture frame-pinning norm.
- The `score-bug` primitive (T-332a) is static in v1 — entrance/exit choreography is provided by the composing `frame-clip` envelope at the binding wire step, NOT by the primitive itself. Score-change pulse (120 ms brightness flash on the team box whose score updated), home-run trot animation, strikeout-K flash (the K-pitch celebration), inning-change wipe, and live-update mid-hold ticker (pitch-by-pitch updates) are deferred (see "Out of scope").

## Rules
- Use when an MLB baseball-broadcast scoring register is called for — across-the-bottom game-state strip on live game footage, replay sequences, between-innings lower-frame attribution. MLB register sits within Cluster B's sports-broadcast family next to T-333 Premier League (football horizontal), T-334 Fox NFL (American-football chrome-less), T-335 NBC SNF (American-football center-circle + network-mark), T-512 NBA Pro (basketball quarter-period), and T-513 NFL Pro (American-football network-neutral). Choose MLB for the generic MLB register (no diamond/bases indicator, no batter-walk-up signature) — the network-neutral premium register a tenant uses when they want MLB game-state without committing to a specific network's broadcast brand.
- Do not use for non-baseball sports (use `nba-pro-register` for basketball / `nfl-pro-register` for American football / a future F1 preset T-515 for Formula 1 / `premier-league-field-of-play` for association football).
- Do not paint the full bar MLB blue. The home-team box's blue fill is the brand identifier on that section; the rest of the bar (`#1A1A1A`) carries the dark-on-grass legibility. Pulling the base bar to MLB blue would saturate the strip and destroy the home-vs-away color contrast.
- UPPERCASE 2-3-letter team codes are mandatory (NOT Mixed-Case). The MLB convention permits either 2-letter (`SF`) or 3-letter (`NYY`, `BOS`, `LAD`) UPPERCASE codes — pick whichever is the unambiguous broadcast standard for the team (no `LA` alone — always `LAD` for Dodgers / `LAA` for Angels). The scoring-strip register is space-constrained; full team names (`Yankees` / `Red Sox`) go elsewhere on the production broadcast (above the strip or to its side) and are out of scope for the `score-bug` `'football'` branch.
- Score digits left at the primitive's default `fontSize: 28`, `fontWeight: 800` (primitive lines 320–322). MLB broadcast canon uses a slightly larger score digit than the team code; the primitive's defaults are close enough to the broadcast register for v1.
- Inning-half row (`down` slot repurposed) is REQUIRED. MLB broadcasts always show the inning-half during live play; omitting it would read as a non-MLB scoring strip (the count + inning-half pair is the MLB-specific data the football register left for down-and-distance, and that the NBA register left empty). Snapshot pins `down: 'TOP 7'`; the binding wire step parameterizes per-frame.
- Designed for live MLB game footage across the regular season + postseason broadcast — same legibility requirements as the T-333 / T-334 / T-335 / T-512 / T-513 scoring-strip presets (team codes ≥ 24 pt; primitive's 28 px default satisfies).

## Trade-offs (v1 cosmetic divergences from the compass register)
- **No diamond / bases indicator.** The most distinctive MLB visual signature — a small base diamond showing runners on first / second / third (and sometimes batting / on-deck colors) — is not supported by the flat-color `score-bug` primitive. MLB broadcasts render the base diamond prominently adjacent to the count + inning-half text. Adding a `bases?: { first: boolean; second: boolean; third: boolean }` slot is a candidate `T-332b`-family primitive-level follow-up (would require an SVG-path renderer addition to the primitive); v1 ships without the diamond. This is the single most visible deviation from the MLB broadcast canon.
- **Reuses `style: 'football'` (no `'baseball'` style branch).** The primitive's `discriminatedUnion('style', ...)` exposes `football` / `racing` / `cricket` / `tennis` branches (primitive line 175). No `baseball` branch exists; v1 reuses `'football'` which provides home-box | clock + below-clock | away-box layout — the closest structural match. The `down` slot is repurposed to carry the MLB-specific inning-half token (`TOP 7`). Adding a dedicated `style: 'baseball'` branch with a `bases` slot is a candidate `T-332b`-family follow-up.
- **No silhouette-batter MLB logo glyph.** MLB's logo signature is the silhouette-batter — the `'football'` branch's `networkLogo` slot lives inside the optional center-circle treatment (NBC-SNF-specific); the network-neutral MLB register omits it by design. Image-asset slots for league/team logos are a primitive-level follow-up.
- **No full team names rendered.** The `score-bug` `'football'` branch (primitive line 335–423) exposes only `home.code` / `away.code` short-code slots — no `home.name` / `away.name` full-name slot. MLB broadcast canon commonly renders `Yankees` / `Red Sox` Mixed-Case adjacent to or above the scoring strip; v1 accepts the code-only register. Adding `home.name` + `away.name` optional slots is a candidate `T-332b`-family primitive-level follow-up shared with T-512 / T-513.
- **Team box colors are MLB-brand blue + red, not Yankees-navy + Red-Sox-red.** The snapshot uses the canonical MLB-logo blue `#002D72` (home) + MLB-logo red `#D50032` (away) as the fallback when the cluster-B composer task has not pinned a team-specific kit color via `PRESET_ID_BINDINGS`. Yankees navy `#0C2340` + Red Sox red `#BD3039` are the canonical kit colors for this AL-East matchup; the composer-task wire step is the place to override them. v1 ships the MLB-brand fallback so the preset reads as a generic MLB register that any team-matchup can wire into.
- **No `centerCircle` / `direction` / `networkLogo` decorations.** The `'football'` branch's optional props are NBC-SNF-specific (center circle, network logo, direction chevrons) or Fox-NFL-specific (backdrop gradient). MLB broadcasts use diamond-and-count layout instead; this network-neutral register omits the football-specific decorations. v1 ships a clean home | clock + inning-half | away layout.
- **Period token co-occupies the below-clock area with the inning-half token.** The primitive renders `period` (`9TH`) and `down` (`TOP 7`) as separate `<span>` children below the clock — visual stacking is per the primitive's default flex flow. The snapshot keeps both pinned to demonstrate the layout; a per-binding override at the wire step can drop the period in favor of `TOP 7` only (cleaner read; recommended for production).
- **Background opacity rendered at 100 %, not the production ~92 %.** The primitive's `background` prop accepts a single hex string with no opacity channel. Pre-blending against an assumed grass-and-dirt color is wrong on arbitrary footage; the 92 % spec is a production-time tunable for video-overlay legibility. v1 parity renders at 100 % on the flat-color parity canvas. Adding a `backgroundOpacity?` prop is a candidate primitive-level follow-up under the `T-332b`-family label (shared with T-512 / T-513).
- **Pitcher / batter name slots not rendered.** MLB broadcasts often stack pitcher and batter names below the scoring strip during at-bat play. Slot additions under the `T-332b`-family label (would require optional row-add to the primitive layout).
