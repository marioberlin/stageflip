# Investor-deck template — analyst-day / fundraising-roadshow composition

Second substantive preset in the Earnings & Investor pack (skeleton landed T-521; closes the second of four placeholder slots opened by T-521). Sister composition template to T-522's earnings-call-template — same Pattern C cross-cluster binding model, same cluster-finance vertical-use-case cluster, same conservative-corporate financial-communication register family — but tuned to a DIFFERENT financial-communication use case: the **investor-deck** a CEO or IR team uses for analyst-day presentations, board updates, fundraising roadshows, and capital-markets-day talking-points narratives. UNLIKE T-522's post-earnings results-announcement video (single-event recap, backward-looking quarterly figures, SEC Reg FD compliance discipline at the foreground), the investor-deck composition is a multi-section narrative arc (problem → solution → market → traction → team / ask → footer), forward-looking (TAM / SAM / SOM, growth metrics, milestones, capital allocation), and higher-density (more shots, more visual variety, more confident pacing). The visual register stays inside the cluster-finance financial-communication family for consistency with T-522 (same serif headline + sans-serif body split, same conservative-corporate canon) but flips the canvas hue from earnings-call's deep slate `#0F172A` to confident corporate indigo `#1E3A8A` (Tailwind indigo-900) and swaps the steady-state forward-guidance green `#10B981` for the saturated growth-curve green `#22C55E` (Tailwind green-500) — same color-family, more forward-looking energy. Multi-shot composition binding multiple existing clipKinds via PRESET_ID_BINDINGS Pattern C: cluster-D `titleSequence` for the title slide (shot 1), cluster-A `lowerThird` for the six narrative-arc sub-shots (problem / solution / market / traction / team-ask / Q&A footer).

## Visual tokens

The investor-deck register is confident-corporate (more energetic than T-522 earnings-call's steady-state-corporate but still conservative-corporate at the family-level): a deep indigo full-bleed canvas across every shot, white serif headline on dark, sans-serif body metrics, saturated growth-curve green for growth metrics / TAM-SAM-SOM numerals, attention orange for milestones and opportunity highlights. The register is the YC / Sequoia / a16z investor-presentation canon — pitch-deck conventions shared across late-stage roadshow decks, analyst-day decks, and board-update narrative decks.

- **Background**: confident corporate indigo `#1E3A8A` (Tailwind indigo-900) — full-bleed cinematic canvas across every shot in the composition. Less-conservative-than-T-522's deep slate `#0F172A` (Tailwind slate-900) — the indigo-900 reads as forward-looking-confident vs the slate-900's backward-looking-steady-state; both sit inside the cluster-finance financial-communication register family but key different sub-registers (results-announcement vs investor-deck). NOT the near-black `#1A1A1A` broadcast-strip register (Cluster B sports / Cluster A news-ticker territory), NOT the pure-black `#000000` editorial-magazine register (T-520 prestige-creator territory). Same backdrop across all seven shots in the composition (title / problem / solution / market / traction / team-ask / footer) — no per-shot palette divergence.
- **Foreground / primary text color**: `#FFFFFF` — white. Maximum-contrast white text on the indigo canvas; cross-register financial-broadcast canon for headline + body slots both. Same primary text discipline as T-522 earnings-call — the white-on-deep-blue contrast pattern carries the gravitas the financial-broadcast use case demands.
- **Growth-metric numerical highlight**: `#22C55E` (Tailwind green-500) — saturated growth-curve green. More saturated than T-522's forward-guidance green `#10B981` (Tailwind emerald-500) — the saturation difference IS the sub-register difference: emerald-500 reads as steady-state-positive (last-quarter result), green-500 reads as forward-looking-growth (next-decade trajectory). Reserved for growth metrics (revenue CAGR, MRR growth, user-base expansion, TAM expansion). The discipline matches investor-presentation convention — color-coding within the numerical-metric slot reads as fair-disclosure-compliant; color-coding within the narrative-commentary slot reads as editorial editorialization.
- **Milestone / opportunity highlight**: `#F97316` (Tailwind orange-500) — attention orange. Reserved for milestone callouts (Series-B close, product-launch date, geographic expansion, regulatory approval) and opportunity-size callouts (`$10B TAM`, `$2B SAM`). The orange-500 is the same hue cluster-B Premier League sports register uses (T-333), but the investor-deck context (financial-communication, single-shot lowerThird strip, no broadcast-news / broadcast-sports atmospheric overlay) keeps the visual register inside cluster-finance — NOT a register migration. The three-color-slot palette (white headline + green growth-metric + orange milestone) is the YC / Sequoia / a16z pitch-deck canonical palette.
- **No fourth accent color.** Adding a fourth hue (e.g. brick red `#DC2626` for risk callouts) migrates the visual onto T-522 earnings-call territory (the brick-red slot belongs to negative-delta numerical signaling in the results-announcement use case) and dilutes the investor-deck's confident-forward-looking-corporate register. Risk-factor disclaimers in the investor-deck footer (shot 7) stay in white at reduced opacity, NOT brick red.
- **Layout** — seven-shot composition per the §Composition structure section below; each shot uses the `lowerThird` primitive's bottom-anchored strip-register (title slide uses `titleSequence`'s centered full-frame register). The strip-register positions are pinned at `position: { x: 80, y: 580, width: 1120, alignment: 'left' }` at 1280×720 (the parity-CLI's fixed `DEFAULT_COMPOSITION`) — left-anchored cinematic-third strip, NOT centered, NOT right-anchored.
- **No atmospheric overlays, no grain, no light-leaks, no particle drift.** The financial-communication canon is clean type on a clean canvas — adding atmospheric overlays migrates the visual onto cluster-D prestige-TV title territory (T-348 stranger-things-benguiat / T-351 true-detective-double-exposure).

The seven-shot sequence IS the narrative arc — at the parity-fixture reference frame the eye locks onto the active shot's mid-hold steady-state, framed entirely by the confident-indigo institutional canvas. The energetic-but-still-corporate pacing (500 ms fade-in → 3.5-second mid-hold → 400 ms fade-out per shot) is the forward-looking investor-presentation UX gesture — faster than T-522 earnings-call's leisurely 600/4400/500 ms steady-state pacing (the investor-deck audience comprehension load is narrative-density rather than numerical-density; the pacing leans confident-forward-looking rather than careful-comprehension-reading).

Same body family as T-522 earnings-call — the serif-headline + sans-body split is the cluster-finance canonical typographic signature shared across all cluster-finance presets. ## Composition structure

Seven-shot narrative arc in declaration order, each shot consuming a single primitive (cluster-D `titleSequence` for shot 1, cluster-A `lowerThird` for shots 2–7):

1. **Title slide (titleSequence shot, startMs 0, endMs 4400)** — Mixed Case headline `'Acme Corp · Series C'` centered full-frame on the confident-indigo canvas. Style bundle `'plate-and-credits'` (same as T-520 prestige-creator and T-522 earnings-call) — the headline plate paired with a credits-block tagline carrying the presenter-name + presentation-date combination (`'Jane Doe · Founder & CEO · Analyst Day · January 30, 2026'`). Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.
2. **Problem statement (lowerThird shot, startMs 4900, endMs 9300)** — left-anchored cinematic-third strip. Title (the problem framing) `'Enterprises spend $4B/year on legacy infra they hate.'` in white serif at 38 px. Subtitle `'Source: Gartner 2025 Enterprise Infra Report'` in Plus Jakarta Sans 22 px white at 0.6 opacity. Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.
3. **Solution / product (lowerThird shot, startMs 9800, endMs 14200)** — left-anchored cinematic-third strip. Title (the product framing) `'Acme replaces it in 30 days, at 1/10th the cost.'` in white serif at 38 px. Subtitle `'Live with 200+ enterprise customers · GA since Q2 2024'` in Plus Jakarta Sans 22 px white at 0.6 opacity. Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.
4. **Market opportunity / TAM (lowerThird shot, startMs 14700, endMs 19100)** — left-anchored cinematic-third strip. Title `'$10B TAM, $2B SAM, 35% CAGR'` with the `$10B`, `$2B`, and `35% CAGR` numerals rendered in growth-curve green `#22C55E` and the `TAM` / `SAM` labels in attention orange `#F97316` (opportunity-size callout). Subtitle `'Total addressable market · Serviceable addressable market · Compound annual growth rate'` in Plus Jakarta Sans 22 px white at 0.6 opacity. Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.
5. **Traction / growth metrics (lowerThird shot, startMs 19600, endMs 24000)** — left-anchored cinematic-third strip. Title `'$50M ARR, +180% YoY, 130% NRR'` with the `$50M ARR`, `+180% YoY`, and `130% NRR` numerals all rendered in growth-curve green `#22C55E` (forward-looking-growth signaling). Subtitle `'Annual recurring revenue · Year-over-year growth · Net revenue retention'` in Plus Jakarta Sans 28 px white. Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.
6. **Team / ask / use of funds (lowerThird shot, startMs 24500, endMs 28900)** — left-anchored cinematic-third strip. Title (the closing ask) `'Raising $80M Series C · Use of funds: GTM + R&D + EMEA'` with the `$80M` numeral in attention orange `#F97316` (milestone-callout — the round-size is the ask, not a steady-state metric). Subtitle `'Jane Doe · Founder & CEO · jane@acme.com'` in Plus Jakarta Sans 22 px white at 0.6 opacity. Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.
7. **Q&A / contact footer (lowerThird shot, startMs 29400, endMs 33800)** — left-anchored cinematic-third strip. Title `'Q&A · Thank you'` in white serif at 38 px. Subtitle `'Forward-looking statement · See S-1 Risk Factors · Reg D compliant'` in Plus Jakarta Sans 22 px white at 0.5 opacity (subtler — disclaimer register). Pacing: 500 ms fade-in EASE_OUT_QUART → 3500 ms mid-hold → 400 ms fade-out EASE_IN_QUART.

Total composition duration: 33.8 s (7 shots × ~4.4 s/shot + 500 ms inter-shot gap). The energetic-but-still-corporate pacing IS the investor-deck register — narrative-density per shot demands enough reading time for confidence-projection but moves faster than T-522 earnings-call's careful-comprehension-reading pace (the audience is leaning forward at an analyst-day, not parsing a 10-Q line-by-line).

## Animation

- **Steady-state register only at the reference frame** per the inherited posture from cluster-A `lowerThird` consumers (T-323 / T-324 / T-325 / T-326 / T-327 / T-328 / T-329 / T-330 / T-507 / T-508 / T-509 / T-510 / T-522) and cluster-D `titleSequence` consumers (T-348 / T-349 / T-350 / T-351 / T-352 / T-353 / T-520 / T-522). The composition's active shot at the reference frame renders at full opacity at its final position with no entrance / exit animation active.
- **Choreography target (spec)** — energetic-but-still-corporate pacing across every shot:
  - Fade-in 500 ms EASE_OUT_QUART (primitive default `entrance: 'fade'`)
  - Mid-hold 3500 ms per shot (composition-driven; each shot's `endMs - startMs - entranceMs - exitMs` resolves to 3500 ms)
  - Fade-out 400 ms EASE_IN_QUART (transitionOut `'fade'`, synchronized 400 ms before each shot's `endMs`)
  - Per-shot inter-shot gap 500 ms (the canvas holds the indigo backdrop alone between shots) — the consecutive shot fades in over the holding backdrop with no abrupt cut
  - Total per shot: ~4.4 s — faster than T-522 earnings-call (~5.5 s) and T-520 prestige-creator (~6.4 s) but slower than T-517 MKBHD-pro (~3.8 s) and T-519 LTT-pro (~3.05 s); the pacing IS the forward-looking investor-presentation UX gesture (confident-forward-looking vs T-522's careful-comprehension-reading)
- **Mid-segment steady-state at frame 120** (cluster-norm; the parity-CLI's fixed 150-frame composition window means frame 120 = 4000 ms @ 30 fps falls cleanly in the title-slide mid-hold window — shot 1 `startMs 0 endMs 4400`). At frame 120 the render captures the title slide at full opacity with both the headline plate and the credits-block tagline settled at their final positions.
- **No state-transition animation in v1.** State transitions (per-letter staggered entry, per-shot color-jumps, photographic-overlay tinting) belong to other style bundles and other clusters; the investor-deck register is the clean steady-state-per-shot register.

- **Cross-cluster register reuse: cluster-finance preset binding cluster-D + cluster-A primitives.** The investor-deck register's financial-presentation canon is materially closer to cluster-D prestige-TV title-card register + cluster-A broadcaster-strip register than to any single existing cluster. Reusing the existing `titleSequence` + `lowerThird` primitives — rather than introducing a new `pitchDeckTitle` cluster-finance primitive or a new `growthMetricSuper` cluster-finance primitive — keeps the implementation surface small AND respects the structural-extension rule (§13 of CLAUDE.md): no new clipKind, no new degree-of-freedom on the document or binding model, just a new cluster-finance preset binding existing primitives. - **Investor-presentation canon: YC / Sequoia / a16z pitch-deck conventions.** The register is the forward-looking financial-presentation canon — Y Combinator's seed-fundraising library, Sequoia Capital's pitch-deck template, and a16z's analyst-day / board-update conventions converged on this register because it threads the investor-attention needle (confident-corporate gravitas + forward-looking energy + numerical-density without 10-Q overload + narrative-arc legibility). Choose investor-deck-template for analyst-day presentations, board updates, fundraising roadshows, capital-markets-day talking-points narratives, and corporate-strategy-presentation video assets.
- **Color signaling — three slots, three meanings.** Growth-curve green `#22C55E` reserved EXCLUSIVELY for growth-metric numerals (revenue CAGR, MRR growth, user-base expansion, TAM expansion); attention orange `#F97316` reserved EXCLUSIVELY for milestone / opportunity-size callouts (round-size, TAM-SAM labels, product-launch dates, geographic-expansion milestones); white at varying opacity for narrative-headline + body / source-attribution. NEVER use green / orange for non-numerical / non-milestone content. The discipline matches investor-presentation convention — color-coding outside the numerical / milestone slots reads as editorial editorialization and migrates the register onto opinion-broadcast territory.
- **NO brick red `#DC2626`.** Brick red belongs to T-522 earnings-call's negative-delta numerical-signaling slot (the steady-state-corporate sub-register's color-coded delta-tracker). The investor-deck's confident-forward-looking-corporate sub-register intentionally OMITS brick red — risk-factor disclaimers stay in white at reduced opacity (shot 7 footer), NOT brick red. Adding brick red migrates the visual onto T-522 earnings-call territory and dilutes the investor-deck's forward-looking energy.
- **Mixed Case headline + Mixed Case body — NOT UPPERCASE for either slot.** Same discipline as T-522 earnings-call and the broader cluster-finance financial-communication register family. UPPERCASE headlines migrate the register onto broadcast-news (Sky News / ITV / RAI / CNN-breaking) territory entirely. - **Energetic-but-still-corporate pacing — 500 ms in, 3500 ms mid-hold, 400 ms out per shot.** Total per shot ~4.4 s. Slowing the pacing to 600 / 4400 / 500 ms migrates the register onto T-522 earnings-call's steady-state-corporate sub-register; speeding to 350 / 2500 / 300 ms migrates onto cluster-F LTT-pro broadcast-pace territory. The investor-deck pacing IS the forward-looking investor-presentation signature — confident-forward-looking rather than careful-comprehension-reading.
- **No atmospheric overlays.** Same discipline as T-522 earnings-call and the broader cluster-finance financial-communication register family. The confident-corporate canvas IS the register; atmospheric overlays migrate the visual onto cluster-D prestige-TV title territory.
- **Designed for forward-looking financial-communication assets** — analyst-day presentations, board-update narrative videos, fundraising-roadshow video assets, capital-markets-day announcement videos, corporate-strategy-presentation videos. Same legibility requirements as the cluster-finance / cluster-A news-broadcaster register family (headline ≥ 36 pt; primitive's 38–52 px exceeds; subtitle ≥ 18 pt; primitive's 22–28 px exceeds).

## Trade-offs (v1 cosmetic divergences from the compass register)

- **Rendered family is `Cormorant Garamond 700` (OFL fallback), not the bespoke `GT Sectra` (proprietary BYO).** Same trade-off as T-522 earnings-call — the `titleSequence` primitive's `font.family` prop IS wired into the rendered output, so the rendered family follows the binding's snapshot `font.family` value verbatim. The binding-wire step (cluster-finance composer task) sets `font.family: 'Cormorant Garamond'` for the parity render; flipping to `'GT Sectra'` requires the bespoke font to be BYO-wired at deploy time. v1 ships the OFL fallback verbatim.
- **Headline size 52 px on the title slide, not the T-520 prestige-creator 60 px range or T-522 earnings-call's 48 px range.** The investor-deck's confident-corporate register sits between the two — 52 px reads as forward-looking-confident at 1280×720, larger than T-522's steady-state 48 px but smaller than T-520's cinematic 60 px. Production deployments with a 1920×1080 or 4K canvas can scale up via the binding override.
- **The seven-shot composition only exercises the title-slide shot at the parity reference frame.** At frame 120 = 4000 ms @ 30 fps, only the title slide (shot 1, startMs 0 endMs 4400) is active; the six `lowerThird` sub-shots (problem / solution / market / traction / team-ask / footer) are NOT visible in the v1 parity fixture. The parity coverage for the sub-shots falls out of the per-shot steady-state register (each `lowerThird` shot renders identically to a single-shot `lowerThird` preset at its own mid-hold) and is verified via per-shot regression fixtures captured in the cluster-finance composer task downstream. v1 ships the title-slide steady-state as the canonical reference frame — same single-shot parity discipline as T-522 earnings-call.
- **`stockTicker` clipKind NOT used.** Same trade-off note as T-522 earnings-call — the `stockTicker` clipKind exists (`packages/runtimes/frame-runtime-bridge/src/clips/stock-ticker.tsx`, `kind: 'stock-ticker'`) but the investor-deck canonical composition does NOT include a candlestick-chart shot. Analyst-day / fundraising-roadshow decks run growth-metric numerical-supers (ARR / NRR / CAGR / TAM-SAM-SOM) via lower-third strips; the candlestick-chart is a different financial-broadcast use case (intraday-trading-summary clip) and lands in a sister cluster-finance preset under a future follow-up.
- **No `growth-curve-chart` companion clip carved out.** The traction shot (shot 5) uses the `lowerThird` primitive's title slot for the growth-metric numerals (ARR / NRR / YoY), with the numerals colored growth-curve green. A dedicated `growth-curve-chart` primitive (specialized for the line-chart / bar-chart growth-trajectory register with built-in CAGR-projection rendering) is a candidate primitive-level carve-out under the cluster-finance compose-tools label; v1 reuses the cluster-A `lowerThird` primitive with the snapshot-level color-coding discipline.
- **`'plate-and-credits'` style overlap window pins both title-slide shots active at the reference frame.** Same as T-522 earnings-call — the headline plate (startMs 0, endMs 4200) and the credits-block tagline (startMs 500, endMs 4400) overlap. At the reference frame 120 (= 4000 ms @ 30 fps), both shots are active simultaneously. The primitive's `'plate-and-credits'` dispatch renders BOTH active shots layered (the title plate above, the credits block beneath); the v1 parity render captures this two-shot overlap as the steady-state register.
- **No atmospheric companion clips.** Same trade-off as T-522 earnings-call — the financial-communication canon is clean type on a clean canvas. The binding-wire step composes the titleSequence solo (no `overlays?` array), distinguishing the cluster-finance financial-broadcast register from the cluster-D prestige-TV registers structurally as well as visually.
