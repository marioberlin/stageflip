# MSNBC Big Board — interactive election-night fullscreen panel

The MSNBC "Big Board" register: the full-screen interactive map / touchscreen Steve-Kornacki broadcast convention popularised across modern election-night coverage. A presenter walks through layered hierarchical data — zoom into a state → zoom into a county → show vote shares per precinct — with party-color shading, percentage labels, and smooth pan/scale transitions, all framed by NBC's peacock-derived partisan-neutral palette (distinct from CNN's canonical Dem-Blue / Rep-Red). The preset's stylistic point is the **fullscreen layered hierarchical-data panel + NBC peacock-derived partisan-neutral shading + tabular numerics + theatrical pop-in stagger** at county-level reporting status.

This preset is the **eighth and final Cluster A preset to land** (after `cnn-classic`, `cnn-breaking`, `bbc-reith-dark`, `al-jazeera-orange`, `apple-tv-lt`, `netflix-doc-lt`, `fox-news-alert`), the **second `fullScreen` clipKind consumer** (after `magic-wall-drilldown` from Cluster E which holds the clipKind-default arm), and the **second production consumer of T-355a's `magic-wall-panel` primitive**. Wired via `PRESET_ID_BINDINGS['msnbc-big-board']` per Pattern C — the `'fullScreen'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at `fullScreenBinding` (T-355's CNN-default magic-wall-drilldown binding); T-328 lands a per-preset override keyed on the preset id.

Per ADR-003 §D2 the `live-data` family ships two render paths — `liveMount` (host fetches an election-results endpoint, renders live with periodic refresh) and `staticFallback` (deterministic snapshot for parity goldens, exports, screenshots). T-328 covers the **staticFallback path** end-to-end via the bound `magic-wall-panel` primitive (T-355a) with MSNBC-themed snapshot constants; the liveMount path AND the runtime drilldown zoom-transition state machine AND the 3D virtual backdrop AND the operator cursor AND the real-time vote count-ups are documented in prose only — all are host responsibility per ADR-003 / ADR-005 OR carve-out follow-ups (`T-328a` cursor / `T-328b` zoom transitions). T-328's merge **closes Cluster A to 8/8 substantive + signed**, unlocking T-382 (or sister) cluster-batch type-design review eligibility for all eight Cluster A presets.

## Visual tokens

The four-color party palette is NBC peacock-derived per stub line 41 ("Do not adopt CNN's Magic Wall color palette ... as-is — defer to the tenant's partisan-color-neutral alternative when applicable"). The peacock's six-color identity (yellow / orange / red / purple / blue / green) seeds the four selected swatches; each is the visually distinct subset that still parses as a partisan map without conflicting with CNN's canonical Dem-Blue / Rep-Red. Per-tenant brand-recolour is locked at the cluster-A 8/8 close — the canonical NBC peacock hexes stay fixed for the v1 parity contract.

- **Background** `#0E0E12` solid (near-black; matches the broadcast graphics base used across cluster A AND cluster E). The panel is a self-contained register, not a window onto a 30 Rock venue feed.
- **Foreground** white `#FFFFFF` for the panel title, subtitle, region labels, and value text.
- **Party A — NBC peacock blue** `#0084CB` for the tile fill of states leading for Party A (typically Democratic). Distinct from CNN's `#0044CC`; NBC peacock-faithful.
- **Party B — NBC peacock red** `#CC2229` for the tile fill of states leading for Party B (typically Republican). Distinct from CNN's `#CC0000`; matches the NBC peacock's red feather.
- **Tied — NBC peacock purple** `#9B26B6` for the tile fill of states where the leading-party margin is below the broadcast's "called" threshold. Visual midpoint between blue and red; matches the NBC peacock's purple feather.
- **Undecided — NBC peacock gold** `#FCB712` for the tile fill of states where the count has not crossed a "report" threshold. Distinct from any party-leaning colour so the eye reads it as "no signal yet"; matches the NBC peacock's yellow feather. **Materially brighter than CNN's neutral gray `#666666`** — a deliberate divergence that signals the MSNBC tenant register at a glance.
- **Tile geometry**: each region renders as a rectangular tile in v1 per the inherited cluster-wide placeholder posture (D-T328-13 / T-355 D-T355-6); the `bounds` field on each region carries `{ x, y, width, height }` in canvas-pixel space. The canonical 8-region snapshot lays out in a 4×2 grid sized for the 1280×720 default composition (tiles 280×220 px each at 12 px gap, originating at `(60, 140)` to leave space for the title + subtitle band above) — coordinates inherited from T-355 verbatim per D-T328-4.
- **Title + subtitle band** sits at the top of the panel: `'2024 ELECTION NIGHT'` heading (ALL-CAPS broadcast-canonical title register; ASCII-only) + `'County-level — 92% Reporting'` subtitle (matches stub line 38 third candidate reference frame "60 (county-level settled)"). Both diverge intentionally from T-355's `'Election Results'` / `'State-by-state breakdown'` to make the tenant divergence eyeball-obvious. The primitive renders both centred at the panel's foreground colour, subtitle at 70% opacity.
- **Theatrical pop-in stagger**: each region tile fades + rises into place (12 px → 0 px) over a 12-frame entrance window with 60 ms per-region delay. At 30 fps the eighth (last) region settles by `frame ≈ 12 + 7 × (60 × 30 / 1000) = 25`; the parity-mid-hold frame 60 captures every tile fully opaque + settled.

The party-colour shading IS the message — applied uniformly to the tile fill. Region labels and value text stay white across all four party states; the eye locks onto the NBC peacock-coloured tile body as the salient signal.

## Typography

- **`preferredFont: Roboto + NBC Tinker`** (`ofl + proprietary-byo` per ADR-004 §D3). NBC's broadcast graphics package pairs `NBC Tinker` (proprietary BYO; tenants with an NBC licensing agreement slot it in via the FontManager — T-072) for headline / callout work with `Roboto` (Apache-2.0; already license-cleared in `THIRD_PARTY.md`) for data labels + legend. Cluster A IS in `TYPE_DESIGN_REQUIRED_CLUSTERS` (per `scripts/check-preset-integrity.ts` — verified during T-327 D-T327-7), so `signOff.typeDesign` MUST be `'pending-cluster-batch'` or `'signed:YYYY-MM-DD'`, NOT `'na'`. T-328 holds at `pending-cluster-batch`; the cluster-A type-design batch review (T-382 or sister composer) flips this field across all eight Cluster A presets in one downstream PR.
- **`fallbackFont: Roboto + Inter Tight`** (OFL), weight `700`. Substituted automatically by the FontManager on every rendering medium where the BYO `NBC Tinker` face is not cleared. `Inter Tight 700` provides the heavy headline mass; `Roboto 700` provides the data-row + legend register. Both OFL faces are license-cleared in `THIRD_PARTY.md`.
- **Headline / callout** at `NBC Tinker Bold` (preferred) or `Inter Tight 700` (fallback) for the panel title `'2024 ELECTION NIGHT'`. Sized at the primitive's auto-derived title height (~64 px in the 1280×720 default composition).
- **Region labels** (CA, TX, etc.) at `Roboto Medium / 700` per the stub's `## Typography` "Data labels: 20–24 pt, tabular". The 2-letter US-state codes are ASCII — any registered Latin-script font renders them correctly.
- **Value text + percentages** at `Roboto Medium / 700` with tabular numerals (`font-variant-numeric: tabular-nums`). The `magic-wall-panel` primitive applies tabular-nums to numeric-formatted cells (`'percent'` / `'count'` / `'raw'` formats) automatically — column-edge alignment when multiple regions emit numerics side-by-side. Cluster-A convention; documented in the cluster A SKILL.
- **Legend** at `Roboto Regular`, 16–18 pt — out of v1 parity envelope (the `magic-wall-panel` primitive does not render a legend slot; tenant compositions add one beside the panel via separate clip).
- **No italic, no underline, no strikethrough.** Election broadcast graphics never use them.

The frontmatter schema accepts a single `preferredFont` and a single `fallbackFont` entry today (extending it to a font-pair is a preset-system change — out of envelope), so the dual-font posture (`Roboto` for data labels + `NBC Tinker` for headline) is documented in prose: composing tools that mount `magic-wall-panel` for `msnbc-big-board` SHOULD route headline glyphs through `NBC Tinker` (or `Inter Tight 700` as the OFL fallback) and data-row glyphs through `Roboto 700` when the FontManager preload list includes both faces. The v1 parity fixture renders all glyph runs through the bridge primitive's `system-ui, sans-serif` fallback per the cluster-A "good-enough not broadcast-exact" posture (mirrors T-355 magic-wall-drilldown's typography posture verbatim).

## Animation

- **Per-region entrance stagger** at `staggerMs: 60` (default) — region `i` fades from opacity 0 → 1 and rises from `translateY: 12 px → 0 px` over a 12-frame window starting at `delay = i * staggerMs / (1000 / fps)`. At 30 fps the eighth (last) region settles by `frame ≈ 12 + 7 × (60 × 30 / 1000) = 25`. Frame 60 (the parity reference frame, mid-hold) is well past entrance — every tile is fully opaque + settled.
- **3D virtual backdrop** (virtual White House / 30 Rock projection per stub line 24) is **out of v1 scope per D-T328-3**. Composes externally per ADR-005 — a separate `ThreeSceneClip` (or equivalent backdrop primitive) layered behind the `magic-wall-panel` at compose-time. NOT a T-328 follow-up; orchestration concern handled by host composition.
- **Operator cursor / Kornacki touch overlay** (per stub line 26) is **out of v1 scope per D-T328-3**. The `magic-wall-panel` primitive (T-355a) does NOT support a cursor / touch-overlay slot. Candidate `T-328a` carve-out IF Reviewer scrutiny demands; primitive-level addition (the `magic-wall-panel` would gain an optional `cursor: { x, y, mode? }` prop OR a sister `magic-wall-cursor-overlay` primitive ships separately).
- **Real-time vote count-up animation** (per stub line 36, drawing on `big-number-stat-impact`'s underdamped-spring count-up curve) is **out of v1 scope per D-T328-3**. Compose `animated-value` clip externally; the count-up register is `bigNumber` clipKind territory (T-360 ships the underdamped-spring count-up curve). NOT a T-328 follow-up.
- **Drilldown zoom transitions** between hierarchy levels (state → county → municipality, per stub lines 35 + 37; 800 ms ease-out) are **out of v1 scope per D-T328-3**. Multi-clip orchestration. The primitive renders one level of the hierarchy at a time. Candidate `T-328b` carve-out IF demanded; OR compose multiple `magic-wall-panel` instances (state-level + county-level snapshots) at compose-time and crossfade/scale at the layer-stack level.
- **Color-transition interpolation** (smooth colour crossfade between party-colour states as a state flips, 400 ms per update) is the **liveMount surface**. The parity golden renders the steady-state party-colour shading without an active transition.
- **Theatrical pop-in anticipation + overshoot** (the stub's "designed for camera, not just dashboard" register) is referenced for runtime composition; the v1 primitive uses a flat fade + rise without overshoot per the inherited T-355a posture. The parity golden snapshots the steady-state at frame 60; the broadcast theatrics are a follow-up `T-XXX` if a Reviewer demands them.
- **Mid-hold steady-state at frame 60** (per ADR-004 §D5). Parity fixture snapshots at this frame.
- **No state-transition animation in v1.** State transitions (colour flip, count-up tick, drilldown pan/scale, 3D backdrop reveal, cursor sweep) belong to the live-mount surface where the data source streams updates AND to the runtime composition where the operator drives the hierarchy descent.

## Rules

- **Bound primitive**: `magic-wall-panel` from `@stageflip/runtimes-frame-runtime-bridge` (`packages/runtimes/frame-runtime-bridge/src/clips/magic-wall-panel.tsx`, exported as `MagicWallPanel` + `magicWallPanelClip`). T-328 wires the binding via `PRESET_ID_BINDINGS['msnbc-big-board']` (Pattern C — second-preset-for-clipKind via the override path, NOT clipKind-default). The `'fullScreen'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at `fullScreenBinding` (T-355's CNN-default magic-wall-drilldown binding); T-355 holds the clipKind-default. Composing tools should mount `MagicWallPanel` with the `regions` payload + `title` / `subtitle` + entrance parameters per `MSNBC_BIG_BOARD_REGIONS` and the resolver's `buildProps` defaults.
- **`MSNBC_BIG_BOARD_PARTY_COLORS` is distinct from `MAGIC_WALL_PARTY_COLORS`** per stub line 41. The four hex values (peacock blue `#0084CB`, peacock red `#CC2229`, peacock purple `#9B26B6`, peacock gold `#FCB712`) are NBC-faithful AND meaningfully different from CNN's canonical (`#0044CC`, `#CC0000`, `#7A3FB2`, `#666666`); a Reviewer eyeballing both goldens (T-355 magic-wall-drilldown's CNN palette next to T-328 msnbc-big-board's NBC palette) sees the tenant divergence at a glance. Tenant brand-color overrides for the party hues (e.g., adopting CNN's Dem-Blue / Rep-Red for the MSNBC tenant) are forbidden by the stub line 41 mandate; escalation per CLAUDE.md §6.
- **`LiveDataClip` wrapper bypass for parity (D-T328-15 inherits T-355 D-T355-12)**: T-328's parity flow does NOT route through `packages/runtimes/interactive/src/clips/live-data/static-fallback.ts`'s `defaultLiveDataStaticFallback` (which emits a generic `TextElement[]` summary, not a styled magic-wall panel). The resolver returns a binding that mounts `magic-wall-panel` directly with `MSNBC_BIG_BOARD_REGIONS` inlined as props. Rationale (identical to T-355 D-T355-12 / T-356 D-T356-11 / T-357 D-T357-12): the parity golden's purpose is to verify the **rendered visual** matches the prose contract; routing through the wrapper would couple the parity golden to wrapper telemetry / endpoint-validation behavior that legitimately changes between releases. The wrapper's job (host the live mount, emit telemetry, route to staticFallback on failure, run the drilldown zoom state machine) is exercised by T-391 / T-392's own tests; T-328 is not the right harness for that surface.
- **Two render paths per ADR-003 §D2**:
  - **liveMount** (host responsibility): host wires an election-results endpoint (AP election feed, Decision Desk HQ, in-house tabulator), declares a refresh policy of 10–60 s ticks, renders the per-tile colour-transition flash on state-flip AND the tally count-up on per-state update. The drilldown zoom (state → county → precinct) is operator-driven (presenter taps a region; the hierarchy descends with a 600 ms ease-in-out pan/scale per stub line 37). The preset documents the endpoint shape contract (`{ id, label, value?, valueLabel?, color?, bounds }[]` + `title?` + `subtitle?`) but does NOT implement fetching, authentication, polling, rate-limiting, or the runtime drilldown state machine. `permissions: [network]` declares the live path's network requirement; v1 parity does NOT exercise this (D-T328-15).
  - **staticFallback** (parity-golden + non-interactive export path): the `MSNBC_BIG_BOARD_REGIONS` constant in `packages/parity-cli/src/generate-fixture.ts` substitutes for the endpoint payload. The deterministic frame-runtime path renders the constant via the bound `magic-wall-panel` primitive at the county-level layer of the hierarchy. Parity golden snapshots this path at frame 60.
- **Placeholder-rectangle geometry in v1 (D-T328-13 inherits T-355 D-T355-6)**: each region renders as a rectangular tile at its `bounds.{x, y, width, height}` rather than a real US state SVG path. Real outlines exist as license-clean SVG / TopoJSON data on Wikimedia Commons (US states are public-domain; county / precinct boundaries are census-derived and PD), but adopting them requires an SVG asset pipeline + a projection helper (Albers-USA for the canonical US map) + a topology-data dependency (`us-atlas` or equivalent — license check required; not currently in the workspace). v1 ships rectangles cluster-wide; a future task `T-XXXc` (TBD) adds the asset pipeline and real geometry across every `fullScreen` consumer. The placeholder is **visually distinct from a real map** (rectangular tiles arranged on a grid, not state-shaped polygons), but it carries every other element of the visual contract: party shading, label, value, entrance stagger, totals.
- **Eight regions in the canonical snapshot** (D-T328-5): CA / TX / FL / NY / PA / OH / GA / AZ. Three Dem (CA, NY, AZ), three Rep (TX, FL, OH), one tied (PA), one undecided (GA) — exercises all four colour paths in a single golden. Mirrors T-355 verbatim: both presets are US election-night registers, so reusing the same canonical region grid keeps the cluster-wide v1 baseline coherent. Tenant divergence lives in the **palette** (NBC peacock vs CNN Dem-Blue / Rep-Red) + **title / subtitle strings** (MSNBC-themed), NOT in the region payload. The values are illustrative — cluster owners rebrand at compose time. The shape (region with id + label + value + party-colour → styled tile) IS the contract; literal entries are not.
- **No 3D virtual backdrop in v1 (D-T328-3)** — composes externally (`ThreeSceneClip` or equivalent at compose-time). The MSNBC stub's "virtual White House / 30 Rock with projected data" register (line 24) is a backdrop concern, not a panel concern.
- **No operator cursor / Kornacki touch overlay in v1 (D-T328-3)** — candidate `T-328a` carve-out IF demanded.
- **No real-time vote count-up animation in v1 (D-T328-3)** — compose `animated-value` clip externally; count-up register is `bigNumber` clipKind territory (T-360).
- **No zoom transitions between hierarchy levels in v1 (D-T328-3)** — candidate `T-328b` carve-out IF demanded; OR compose multiple `magic-wall-panel` instances at compose-time.
- **No ticker strip beneath the panel in v1** — composes externally via existing `news-ticker-bar` (T-356a) in adjacent layout slot, NOT a follow-up to T-328.
- **No multi-touch interactive UX** — the stub's pinch-and-zoom drilldowns are illustrative; the runtime drilldown state machine is liveMount-side per ADR-003 §D2. Parity render does NOT exercise touch.
- **WebGL / WebSocket runtime architecture** (Code and Theory canon mentioned in the stub) is **runtime-only**, NOT in v1 parity envelope. The bridge primitive ships SVG/DOM-based rendering for frame-determinism; WebGL-accelerated drilldowns are a future runtime concern.
- **Reference frame for parity is mid-hold (frame 60)** per ADR-004 §D5 — single canonical variant per D-T328-7 (the stub's previous four-frame hierarchy list `0 / 30 / 60 / 120` was revised to a single steady-state mid-hold at frame 60; the wide-establishing / zoom-mid-transition / count-up-completed frames are documented in this prose contract for runtime use, not parity). The PSNR / SSIM thresholds are stricter than the stub's previous `38 / 0.95` target — see Acceptance below.
