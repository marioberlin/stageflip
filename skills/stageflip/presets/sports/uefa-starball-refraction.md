# UEFA Champions League — Starball Refraction fullScreen

The UEFA Champions League broadcast register: a fullscreen title-card / standings panel anchored on a deep dark-navy `#041E42` base with refraction-palette accents (bright blue `#2DA8D8`, cyan `#6EE0E8`, magenta `#C2185B`, white `#FFFFFF`) — the canonical premium-broadcast register that signals "European football's flagship competition" at a glance. The preset's stylistic point is the **fullscreen layered standings panel + UEFA refraction-palette tile shading + tabular numerics + theatrical pop-in stagger** at canonical mid-matchday register.

This preset is the **ninth and final Cluster B preset to land** (after `premier-league-field-of-play`, `fox-nfl-no-chrome`, `nbc-snf-possession-illuminated`, `espn-bottomline-flipper`, `wimbledon-green-purple`, `masters-red-under-par`, `f1-timing-tower`, `cricket-scorebug`), the **second `fullScreen` `PRESET_ID_BINDINGS` consumer** (after T-328 `msnbc-big-board`; the clipKind-default arm stays at T-355 `magic-wall-drilldown`'s `fullScreenBinding`), and the **third production consumer of T-355a's `magic-wall-panel` primitive** (after T-355 `magic-wall-drilldown` Cluster E + T-328 `msnbc-big-board` Cluster A). Wired via `PRESET_ID_BINDINGS['uefa-starball-refraction']` per Pattern C — the `'fullScreen'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at `fullScreenBinding`; T-339 lands a per-preset override keyed on the preset id. T-339's merge **closes Cluster B to 9/9 substantive + signed**, the **fourth batch-eligible cluster** after E (T-355) + F (T-367) + A (T-328); unlocks T-340 (Cluster B composer task) + T-382 (Cluster B type-design batch review) eligibility for all nine Cluster B presets.

V1 ships the **placeholder tile-grid composition** at the UEFA Champions League palette layer ONLY (D-T339-3). Eight canonical-register elements are documented as out-of-v1 (D-T339-10): the canonical Starball 3D composition, per-character refracted-typography gradient, light-wave continuous drift, "Ultimate Stage" CGI stadium backdrop, Starball-shape promo wipes, Italic / Ritalic font variants, camera-tracked Starball composition, and per-character staggered 40 ms reveal. Each is bound to a specific carve-out (T-339a / T-339b / T-339c) or external-composition path. The signed parity golden captures a steady-state mid-matchday standings register frame: six region tiles representing major UCL clubs (Real Madrid / Liverpool / Bayern / Manchester City / PSG / Inter), color-shaded with refraction-palette accents, on the UEFA dark-navy background.

## Visual tokens

The five-color palette is UEFA refraction-palette per stub lines 22–23. Distinct from `MAGIC_WALL_PARTY_COLORS` (CNN Dem-Blue / Rep-Red — T-355) and `MSNBC_BIG_BOARD_PARTY_COLORS` (NBC peacock — T-328); the refraction palette evokes light-physics prism dispersion rather than a partisan map. Per-tenant brand-recolour is locked at the cluster-B 9/9 close — the canonical UEFA hexes stay fixed for the v1 parity contract.

- **Background** `#041E42` solid (UEFA dark navy primary; night-match canon per stub line 22). The central palette divergence vs T-355 / T-328 (both used the primitive default `#0E0E12`); UEFA's deep navy is the brand-DNA backdrop. Passed to the primitive's `background` prop as an explicit override.
- **Foreground** white `#FFFFFF` for the panel title, subtitle, region labels, and value text (stub line 23).
- **Refraction blue** `#2DA8D8` for the tile fill of regions accented with the bright-blue refraction band (stub line 23). Tiles RMA + MCI in the v1 snapshot.
- **Refraction cyan** `#6EE0E8` for the tile fill of regions accented with the cyan refraction band (stub line 23). Tiles LIV + PSG in the v1 snapshot.
- **Refraction magenta** `#C2185B` for the tile fill of regions accented with the magenta refraction band (stub line 23). Tiles BAY + INT in the v1 snapshot.
- **Tile geometry**: each region renders as a rectangular tile per the inherited cluster-wide placeholder posture (D-T339-3; same pattern as T-355 D-T355-6 + T-328 D-T328-13); the `bounds` field on each region carries `{ x, y, width, height }` in canvas-pixel space. The canonical 6-region snapshot lays out in a 3×2 grid sized for the 1280×720 default composition (tiles 280×200 px each at 12 px gap, originating at `(200, 200)` to leave space for the title + subtitle band above).
- **Title + subtitle band** sits at the top of the panel: `'CHAMPIONS LEAGUE'` heading (UPPERCASE per stub line 29 typography contract; ASCII-only) + `'MATCHDAY 6 — STANDINGS'` subtitle. Both diverge intentionally from T-355 / T-328 to make the tenant divergence eyeball-obvious. The primitive renders both centred at the panel's foreground colour, subtitle at 70% opacity.
- **Per-region value labels** `<n> PTS` (e.g., `'16 PTS'` for RMA, `'10 PTS'` for INT) — pre-formatted via `valueLabel` override; the underlying `value` field carries the raw points integer rendered via `valueFormat: 'count'` for the schema round-trip.

## Typography

- **`preferredFont: Champions (Fontsmith)`** (`proprietary-byo` per ADR-004 §D3). The bespoke broadcast display family commissioned by Fontsmith for UEFA Champions League's 2024–27 cycle ("Champions Display Refracted"); the bespoke per-character refracted-color geometry is the brand-DNA letterform. Tenants licensing the Fontsmith Champions face locally slot it in via the FontManager (T-072). Cluster B IS in `TYPE_DESIGN_REQUIRED_CLUSTERS`, so `signOff.typeDesign` MUST be `'pending-cluster-batch'` or `'signed:YYYY-MM-DD'`, NOT `'na'`. T-339 holds at `pending-cluster-batch`; the cluster-B type-design batch review (cluster-composer / T-382 task) flips this field across all nine Cluster B presets in one downstream PR.
- **`fallbackFont: Fraunces`** weight `700` (SIL Open Font License 1.1; Undercase Type's classical-revival serif). Fraunces 700 (Bold) provides clean broadcast-suitable proportions for the standings panel — required for tabular numeral rendering across the points / standings figures simultaneously visible. Substituted automatically by the FontManager on every rendering medium where the BYO Fontsmith Champions face is not cleared.
- **Per-row text** the primitive applies its system-font stack (`system-ui, -apple-system, BlinkMacSystemFont, sans-serif`) on the panel root + per-region containers. Region labels + value labels render at the primitive's defaults (bold, tabular).
- **Casing** region labels are already uppercase in the snapshot (`'RMA'` / `'LIV'` / `'BAY'` / `'MCI'` / `'PSG'` / `'INT'`); title `'CHAMPIONS LEAGUE'` + subtitle `'MATCHDAY 6 — STANDINGS'` both UPPERCASE per the UEFA broadcast-canonical title register; no transform applied at the primitive layer.
- **Distinct numeral design** the primitive's system font numerals are the v1 render typeface for points + valueLabel; Fraunces 700 OFL fallback shape + Champions Display Refracted bespoke shape are NOT preserved at the system-font layer. Cosmetic divergence — same posture as T-333 / T-334 / T-335 / T-337 / T-332 / T-336 BYO/OFL fallback divergences.
- **No italic, no underline, no strikethrough** in v1. The Italic / Ritalic (reverse-italic) Champions variants are explicitly out of v1 envelope — font-registry concern handled when bespoke Champions face is licensed.

## Animation

- **`stagger-rise` entrance + steady-state at frame 60.** The `magic-wall-panel` primitive's `'stagger-rise'` entrance mode opens a 12-frame window per region with `delay = i * staggerMs / (1000 / fps)`; opacity ramps `0 → 1` and `translateY` slides `12 → 0` px. With six regions + `staggerMs: 60` + 30 fps, full entrance resolves by frame ~21 (T-355 D-T355-5 verified analysis). Frame 60 is well past entrance — every tile fully opaque + settled.
- **Canonical Starball 3D composition deferred (T-339a carve-out)** — stub line 24 calls for the canonical Framestore 30K-source prism rendered at broadcast scale, 3D-tracked to match footage. Requires `ThreeSceneClip` integration per ADR-005 §D1 (frontier track) OR a sister `starball-3d-overlay` primitive. Out of v1 envelope. Candidate `T-339a` carve-out IF Reviewer scrutiny demands.
- **Per-character refracted-typography gradient deferred (T-339b carve-out)** — stub lines 30, 37 call for the 2024–27 cycle "Champions Display Refracted" per-character partially distinct accent fills + 40 ms staggered per-character reveal. No primitive supports per-character per-character gradient fills today; would require typography-layer primitive extension. Candidate `T-339b` carve-out.
- **Light wave texture continuous drift deferred (T-339c carve-out)** — stub line 36 calls for "Light wave texture: slow continuous drift across the composition, 8–10 s cycle." Frame-derived continuous animation; not in `magic-wall-panel` v1. Candidate `T-339c` carve-out.
- **"Ultimate Stage" CGI stadium backdrop external-composed** — stub line 26 calls for the optional "Ultimate Stage" CGI stadium background composite per broadcast cycle. Composes externally per ADR-005 (a separate `ThreeSceneClip` or equivalent backdrop layered behind the panel at compose-time); host responsibility, NOT a T-339 follow-up.
- **Starball-shape promo wipes deferred** — stub line 35 calls for "Promo wipes using Starball shape: 28 frames (HD) / 36 frames (UHD)." Multi-clip orchestration / transition register; not a primitive-level concern. Out of v1; orchestration concern handled by host composition.
- **Italic / Ritalic font variants out-of-envelope** — stub line 31 calls for "Italic + 'Ritalic' (reverse italic) variants." Font-registry concern; OFL fallback `Fraunces 700` does not include reverse-italic; bespoke `Champions (Fontsmith)` is `proprietary-byo`. Out of v1; covered by font-registry layer when bespoke font is licensed.
- **Camera-tracked Starball composition deferred** — stub line 34 calls for "Starball intro: 3D-tracked shot from the match, Starball composited around players." Frontier track per ADR-005; requires camera-track data + `ThreeSceneClip`. Frontier-deferred.
- **Reference frame for parity is steady-state at frame 60** per ADR-004 §D5 — single canonical variant. Entrance fully resolved, no within-window transition active. Replaces stub's four candidate frames (0 Starball entry, 30 mid-motion, 120 refraction at full cycle) — those candidates were all bound to the deferred Starball / light-wave register elements; v1 captures the steady-state palette frame ONLY.
