# Fox NFL No-Chrome — scoreBug (2025 redesign)

The Fox Sports 2025 NFL register (debuted Super Bowl LIX): a chromeless bottom-center scoreclock — NO traditional container box — with typography floating over a subtle radial gradient backdrop. Team primary colors fill team-code boxes (KC red `#E31837` home, PHI green `#004C54` away — the Super Bowl LIX rematch fixture); white text; massive-scale tabular-numeric scores; match clock + period + down-and-distance (`'04:32'` / `'Q3'` / `'3rd & 7'`); home-team possession brightness highlight; Inter Display 900 (Black) as the OFL fallback for the proprietary Fox Sports custom typeface. Common uses: live NFL match overlays where the chromeless / bottom-center / massive-score register is the brand signal — radically distinct from the upper-left rectangular-chrome PL register T-333 ships.

This preset is the **second Cluster B preset to land**, the **third `scoreBug` clipKind consumer** (after T-358's clipKind-default `cricket-ball-by-ball-dots` via the `outcome-row` primitive — a different primitive entirely — and T-333's `premier-league-field-of-play` first `PRESET_ID_BINDINGS` override), the **second production consumer of T-332a's `'football'` style branch** (T-333 was the first), and the **first production consumer of three optional fields** on the `'football'` schema: `backdropGradient` (radial gradient backdrop), `down` (down-and-distance text), and `possession` (per-team brightness highlight). Wired via `PRESET_ID_BINDINGS['fox-nfl-no-chrome']` per Pattern C — the `'scoreBug'` arm in `DEFAULT_CLIP_KIND_RESOLVER` stays UNCHANGED at `scoreBugDotsBinding` (T-358); T-333's `premierLeagueFopBinding` stays UNCHANGED.

## Visual tokens

The Fox NFL 2025 chromeless register is canonical and locked: the absence of a rectangular chrome container IS the design (stub line 41 — "do NOT add a border box to clean up"). The visual signal is "typography + kit-colored team boxes float over a subtle radial dark gradient" rendered against a chromeless black base.

- **Background / chromeless base** `#000000` solid. Passed to the primitive's `background` prop, which renders as the root element's `backgroundColor` per `rootStyle()` (lines 285–303 of `score-bug.tsx`). The black base supports the chromeless feel against the radial gradient overlay; rendering the preset on a non-black canvas would composite the bug's bg into the canvas (per CSS layering — `backgroundColor` paints behind the primitive's flex children).
- **Subtle gradient backdrop** `backdropGradient: { centerOpacity: 0.4, edgeOpacity: 0 }` — radial darkening at ~40% opacity at centroid, fading to 0 at edges (stub line 24). Per the primitive's render path (lines 346–374 of `score-bug.tsx`), this paints `<stop offset="0%" stopColor="#000000" stopOpacity={0.4}/>` to `<stop offset="100%" stopColor="#000000" stopOpacity={0}/>` in a `radialGradient` — a full-bleed absolutely-positioned `<svg>` sitting BEHIND the three flex children. **First production consumer of `backdropGradient`**.
- **Foreground / text** `#FFFFFF` for the clock, period, and down-and-distance text. NOTE: team-box code + score text is **hard-bound** to `#ffffff` regardless of the `foreground` prop (line 314 of `score-bug.tsx`); only the central clock + period + down obey `foreground`.
- **Per-team kit colors** KC red `#E31837` (Kansas City Chiefs official primary — Pantone 186 C / Web hex equivalent) + PHI green `#004C54` (Philadelphia Eagles official primary — Pantone 5535 C / Web hex equivalent — "midnight green"). The KC vs PHI fixture pairing is the canonical 2024–25 NFL Super Bowl LIX rematch. Each team box renders the kit color as the **whole team-box background fill** rather than a 6 px outer-edge stripe (D-T334-12 — primitive-level cosmetic divergence inherited from T-333 D-T333-11-a; the brand signal is preserved at the area level).
- **Position** anchored at `(280, 600)` — bottom-center on a 1280×720 canvas. The primitive's default bug-width is `720 px`, so `x = (1280 − 720) / 2 = 280` centers horizontally; `y = 600` puts the bug `~120 px` above the bottom edge. The primitive renders at `position: { x, y }` via `rootStyle()` absolute-positioning. Default size `720 × 80` (primitive lines 339, 285) since `position.width` / `position.height` are not provided.
- **Layout shape** horizontal flex row with three children — `score-bug-football-home` (KC-red team box; left), `score-bug-football-clock` (clock + period + down stack; center), `score-bug-football-away` (PHI-green team box; right). Home box reads `code` then `score` left-to-right (`'KC' '24'`); away box reads `score` then `code` (`'17' 'PHI'`).
- **Possession highlight** `possession: 'home'` — KC has the ball; the home team box receives `filter: 'brightness(1.12)'` (primitive line 309). The away box stays at `'none'`. **First production consumer of `possession`** in production goldens.
- **FOX-DNA letter-C-resembles-FOX-O numeral curiosity** (stub line 27): the proprietary Fox Sports custom typeface preserves the bespoke letter-shape detail; the OFL fallback Inter Display does NOT preserve this (D-T334-11-c). The proprietary-byo path is the user's escape hatch when they license Fox Sports custom locally. Cosmetic divergence; documented.

The kit-color tile fill IS the message — applied uniformly to the team-box background. Code text and score text stay white across both kit-color states; the eye locks onto the kit-colored tile body as the salient signal. The home-box brightness boost (`brightness(1.12)`) layers possession-state on top of the kit-color signal without disturbing it.

## Typography

- **`preferredFont: Fox Sports custom`** (`proprietary-byo` per ADR-004 §D3). Fox Sports' brand-licensed display face for the 2025 NFL redesign — the bespoke face that preserves the letter-C-resembles-FOX-O curiosity and the FOX wordmark DNA. Tenants with a Fox Sports licensing agreement slot it in via the FontManager (T-072). Cluster B IS in `TYPE_DESIGN_REQUIRED_CLUSTERS` (verified during T-333 / T-334 spec drafting), so `signOff.typeDesign` MUST be `'pending-cluster-batch'` or `'signed:YYYY-MM-DD'`, NOT `'na'`. T-334 holds at `pending-cluster-batch`; the cluster-B type-design batch review (cluster-composer task) flips this field across all nine Cluster B presets in one downstream PR.
- **`fallbackFont: Inter Display`** weight `900` (OFL, SIL Open Font License 1.1 via Google Fonts). The Black weight matches the stub's "Extra Bold / Black" register (lines 30–31). Heavier than T-333's Space Grotesk 600 (PL stub register is SemiBold; Fox NFL stub is Black). Substituted automatically by the FontManager on every rendering medium where the BYO Fox Sports custom face is not cleared.
- **Team abbreviations** (`'KC'` 2-letter / `'PHI'` 3-letter — both canonical NFL conference team codes; the primitive's `code: z.string().min(1)` accepts any length-1+ string) at the primitive's default 28 px / weight 800 (line 320 of `score-bug.tsx`); rendered in the active font family. Stub line 30 calls for "Extra Bold / Black, 36–44 pt" — the primitive's 28 px default is smaller than the stub's print-canon size; the relative hierarchy (heavy-weight bold tabular team codes) is preserved.
- **Scores** (`'24'` / `'17'`) at the primitive's default 28 px / weight 800 alongside the team codes (same `teamSectionStyle`). Stub line 31 calls for "Extra Bold / Black, 40–48 pt (massive scale intended)" — the primitive renders score numerics at the hard-baked 28 px (D-T334-11-d). The supplied `font.weight: 900` exercises the Black weight on the typeface but the score `fontSize: 28` cannot lift. Cosmetic divergence; primitive-level limitation applies to ALL `'football'`-style consumers; documented as a `T-332b`-family follow-up (new `scoreFontSize` axis OR `scale: 'compact' | 'massive'` enum on the football branch).
- **Match clock + period + down** (`'04:32'` / `'Q3'` / `'3rd & 7'`) — clock at 20 px / weight 700 (line 332 of `score-bug.tsx`); period at 12 px / opacity 0.85 (line 406); down at 12 px (no opacity, line 410). The down text sits BELOW the period text in the center clock column.
- **`font.tabularNums` omitted** (D-T334-13). T-333 included it explicitly; T-334 omits per the stub-implied register. Inter Display ships tabular numerals by default in its 900 weight via Google Fonts; the primitive applies `fontVariantNumeric: 'tabular-nums'` only when `font.tabularNums === true`. The 2-digit scores `'24'` / `'17'` and fixed-position clock `'04:32'` align by gravity even without explicit tabularNums; the down text `'3rd & 7'` is left-aligned and tabular-alignment is irrelevant. Cosmetic divergence; either choice (with or without tabularNums) is acceptable.
- **Casing** `'as-is'` — snapshot strings (`'KC'`, `'PHI'`, `'24'`, `'17'`, `'04:32'`, `'Q3'`, `'3rd & 7'`) are already in target casing. The primitive's `applyCasing` helper (lines 231–249) applies `'as-is'` as a no-op transform. NOTE: `applyCasing` short-circuits leading-numeric strings (`/^\d/`) regardless of the casing prop (lines 233–235), so `'04:32'`, `'24'`, `'17'`, AND `'3rd & 7'` would render verbatim under any casing.
- **Distinct numeral design preserved** is satisfied by the active typeface only. Inter Display Black numerals are the OFL fallback render; Fox Sports custom numerals (proprietary-byo) cannot render in the parity golden. Cosmetic divergence (D-T334-11-c / D-T334-12); same posture as T-333 D-T333-11-b.
- **No italic, no underline, no strikethrough.** NFL broadcast graphics never use them.

The frontmatter schema accepts a single `preferredFont` and a single `fallbackFont` entry, so a single typographic family covers team codes, scores, clock, period, AND down. The bespoke-font invariant 6 is satisfied: `Fox Sports custom` is `proprietary-byo` and the OFL `Inter Display` 900 fallback is declared in frontmatter.

## Animation

- **Steady-state register only in v1 per D-T334-3.** The `'football'` style branch of T-332a renders a **static layout** — there is no entrance animation, no score-pulse on score change, no touchdown-celebration flourish, no possession-slide animation on the down-and-distance text. The reference frame for the parity golden is mid-hold steady-state at frame 60.
- **800 ms ease-out zoom-in entrance from "FOX SPORTS" branded black field** (per stub line 35) is **out of v1 scope per D-T334-3**. Adding a primitive-level entrance enum (zoom-in / fade-in / slide-in) with cubic-bezier params is a primitive-level concern. Candidate `T-332b`-family carve-out IF Reviewer scrutiny demands. v1 captures the steady-state mid-hold frame.
- **Down-and-distance possession-slide animation** (per stub lines 32, 36 — "physically moves between teams on possession change", "350 ms" slide duration) is **out of v1 scope per D-T334-3 / D-T334-11-a**. The `'football'` branch's `down` prop renders as **static** text in the center clock column (lines 409–411 of `score-bug.tsx`). v1 ships the `down` text in its center-column position; the slide is a primitive-level concern (new frame-trigger on `down` keyed to `possession` change). Candidate `T-332b`-family carve-out IF Reviewer demands.
- **Touchdown comic-book celebration** (per stub line 37 — "comic-book-inspired 3D-rendered text, deliberately stylistically inconsistent with the minimalist bug — optional, gated by `celebration: touchdown | null`") is **out of v1 scope per D-T334-3 / D-T334-11-b**. The `'football'` branch has no `celebration` slot. Adding a `celebration: 'touchdown' | null` enum + asset bundles for the comic-book vector + frame-driven choreography is a primitive-level concern. Candidate **`T-334a`** carve-out IF Reviewer scrutiny demands.
- **120 ms score-change quick flash** (per stub line 38) is **out of v1 scope per D-T334-3**. No `scoreChange: { animation, frame }` slot in T-332a's `'football'` branch. Candidate `T-332b`-family carve-out IF Reviewer scrutiny demands; primitive-level addition.
- **Mid-hold steady-state at frame 60** (per ADR-004 §D5 and D-T334-5). Parity fixture snapshots at this frame. The football branch is a static layout so any post-mount frame produces an identical render; frame 60 is the cluster-norm reference (T-323 / T-325 / T-326 / T-327 / T-328 / T-329 / T-330 / T-333 all use 60).
- **No state-transition animation in v1.** State transitions (entrance ramp, touchdown celebration, possession-slide on down change, score-pulse) belong to the live-mount surface where the data source streams updates AND to the runtime composition where the host orchestrates the broadcast pacing.

- **Touchdown celebration intentionally clashes with the bug's minimalism** (stub line 43 — "Don't harmonize them; that breaks the Fox tonal contrast"). v1 ships none (D-T334-11-b primitive-level limitation); future PR's that add `celebration: 'touchdown' | null` MUST preserve the deliberate stylistic clash — the comic-book 3D text is the tonal-contrast brand signal.
- **FOX-DNA letter-C-resembles-FOX-O detail is preserved by the proprietary face only** (D-T334-11-c). The OFL fallback Inter Display does NOT preserve the bespoke C-shape. Cosmetic divergence; the proprietary-byo path is the tenant's escape hatch when they license Fox Sports custom locally.

The supplied `font.weight: 900` exercises the Black weight on the typeface but cannot lift the size. Primitive-level limitation; cosmetic divergence; `T-332b`-family follow-up. NOT a T-334 fix.
- **`font.tabularNums` omitted** (D-T334-13). Either choice (with or without tabularNums) resolves to a successful golden; T-334 ships without per the stub-implied register. The 2-digit scores `'24'` / `'17'` and fixed-position clock `'04:32'` align by gravity; the down text `'3rd & 7'` is left-aligned.
- **Generated significant public reaction at Super Bowl LIX debut** (stub line 44 — "the most intense public reaction of any score bug in history") — treat the register as bold, not safe. Tenants composing Fox NFL coverage MUST preserve the chromeless / gradient / massive-score combo; toning it down (re-adding a chrome box, lifting the gradient opacity, shrinking the scores) defeats the brand signal.
- **Reference frame for parity is mid-hold (frame 60)** per ADR-004 §D5 and D-T334-5 — single canonical variant. The football branch is a static layout so any post-mount frame produces an identical render.
