# Pack licensing tiers

Every `.stageflip-pack` archive declares a `LicenseClaim` in its
`manifest.json` (ADR-012 §D4) and falls into one of three pricing
tiers (ADR-013 §D3): **free**, **paid**, **enterprise**. The pack
publisher chooses how to communicate the licensing terms to tenants
by checking in a `LICENSE.md` + `NOTICE.md` file alongside the
manifest. T-501's `stageflip-pack-publish license <tier-id>`
subcommand emits boilerplate for four canonical author-facing tiers
that map onto the three pricing tiers.

## The four canonical tier IDs

| Tier ID                    | When to choose it                                                                                       | `manifest.license.kind` | SPDX (or LicenseRef)                        |
|---|---|---|---|
| `commercial-subscription`  | Paid pack billed per-tenant on subscription or one-time terms.                                          | `paid-per-tenant`       | `LicenseRef-StageFlip-Commercial-1.0`       |
| `attribution-required`     | Open-source pack that requires credit (e.g. Apache 2.0, CC-BY).                                         | `open`                  | `Apache-2.0`                                |
| `non-commercial-only`      | Open pack the author would PREFER not be used commercially (see limitation below).                      | `open`                  | `CC-BY-4.0`                                 |
| `public-domain`            | Permissively-dedicated pack with no attribution requirement.                                            | `open`                  | `CC0-1.0`                                   |

The `enterprise` pricing tier from ADR-013 §D3 is deliberately NOT
generated by the `license` subcommand: enterprise terms are
negotiated bilaterally and a boilerplate template would mislead. An
enterprise publisher should author their LICENSE.md from scratch
and use `manifest.license = { kind: 'enterprise', sku: '...',
contractRef: '...' }` directly.

## How `manifest.license` discriminates

`packages/pack-format/src/manifest.ts` defines a Zod discriminated
union keyed by `kind`:

```typescript
export const licenseClaimSchema = z.discriminatedUnion('kind', [
  openLicenseClaimSchema,        // { kind: 'open', spdx: <OPEN_LICENSE_SPDX> }
  paidLicenseClaimSchema,        // { kind: 'paid-per-tenant', sku, entitlementType }
  enterpriseLicenseClaimSchema,  // { kind: 'enterprise', sku, contractRef? }
]);
```

The whitelist `OPEN_LICENSE_SPDX` is `['MIT', 'Apache-2.0', 'CC-BY-4.0',
'CC0-1.0']`. Adding new SPDX identifiers requires updating the schema
+ rebroadcasting the change to all loaders (binary-compat concern, so
treat it as an ADR).

## CLI invocation

```bash
# Attribution-required (Apache-2.0) pack with custom name + publisher
$ stageflip-pack-publish license attribution-required \
    --out-dir ./license-templates/ \
    --var packName="Newsroom Pack" \
    --var publisherDisplayName="Example Newsroom Inc."

# Commercial subscription pack
$ stageflip-pack-publish license commercial-subscription \
    --var sku=newsroom-pro-2026 \
    --var packName="Newsroom Pro" \
    --var publisherDisplayName="Example Newsroom Inc." \
    --var contactEmail=licensing@example.com

# Public-domain dedication (CC0)
$ stageflip-pack-publish license public-domain

# Re-emit, overwriting any existing files
$ stageflip-pack-publish license attribution-required --force
```

The default output directory is `./license-templates/`. Three files
are written per invocation:

- `LICENSE.md` — the licence text + SPDX header
- `NOTICE.md` — attribution + open-source-dep + trademark sections
- `MANIFEST_LICENSE_SNIPPET.json` — the JSON object to paste under
  `manifest.json#license`

The CLI refuses to overwrite an existing file unless `--force` is
supplied; this is intentional so a publisher running `license` a
second time after manual edits doesn't lose their work.

## Variable substitution

Templates contain `{{key}}` placeholders. The substituter
(`license-templates.ts#substitute`) is Mustache-light: pure
substitution, no logic. Missing keys throw a helpful error. Defaults
are applied before user `--var k=v` overrides:

| Key                     | Default value             | Required for                 |
|---|---|---|
| `packName`              | `Your Pack`               | all tiers                    |
| `publisherDisplayName`  | `Your Org`                | all tiers                    |
| `year`                  | current year              | all tiers                    |
| `sku`                   | `your-pack-sku`           | `commercial-subscription`    |
| `contactEmail`          | `licensing@example.com`   | `commercial-subscription`    |

Setting a required variable to the empty string via `--var key=`
fails the run — the defaults are placeholders the publisher SHOULD
override, not values the publisher MUST tolerate.

## Non-commercial limitation

`non-commercial-only` maps to `CC-BY-4.0` because that's the closest
SPDX identifier in the StageFlip `OPEN_LICENSE_SPDX` whitelist that
nominally requires attribution. A true non-commercial licence
(`CC-BY-NC-4.0`) is **not** currently representable in the pack
`LicenseClaim` union and the runtime cannot enforce it. The template's
LICENSE.md and NOTICE.md content makes the author's non-commercial
intent explicit, but the pack still installs and runs as a normal
`open` pack from the runtime's point of view.

Adding true non-commercial support requires growing the `LicenseClaim`
union (e.g. a `{ kind: 'open-non-commercial', ... }` variant) plus
runtime entitlement plumbing; deferred to a future ADR.
